# 账号与管理

本章讲谁能登录 Muse Bridge、怎么登录和注册、账号分几档、注册账号的额度怎么算、管理员在服务端控制台能做什么，以及 Claude 账号怎么配。

## 身份种类

| 身份 | 怎么来 | 能做什么 |
|---|---|---|
| 管理员 | 装好时结果块里给的管理员访问令牌（或用已登录的管理员手机扫码） | 全部功能，不限额；整台服务器；服务端控制台、自定义、设置里的 Agent 与模型服务 |
| Pro 账号（完全信任） | Pro 邀请码注册，或管理员升档 | 有命令行和终端；只在自己的文件夹里建项目；隔离是「软」的 |
| 普通账号 | 普通邀请码注册，或管理员直接建 | Claude 只能在自己的文件夹里读写、联网，没有命令行 |
| 服务账号 | 管理员建，给程序用 | 「只自己用」模式下仍能登录 |
| 分享访客 | 打开只读分享链接 | 只能看、下载那条链接里的文件 |

- 「只自己用」（`set-users solo`）时只有管理员令牌和服务账号能登录，账号密码登录会提示「这台主机只接受访问令牌登录」；「多人用」（`set-users multi`）才有注册和邀请码。切换让 Muse 跑对应命令。
- 每个注册账号有自己的文件夹、会话和设置；能用哪些 agent 由管理员按人勾选（新账号默认只有 Claude）。

接口：`whoami`

## 登录方式

- 管理员令牌：登录框「用访问令牌登录」→ 粘贴 →「登录」。服务器只存令牌的哈希，丢了只能让 Muse 跑 `reset-token` 重新生成（旧令牌、所有管理员设备和管理员名下的 agent 密钥一起作废）。
- 账号和密码：同一个账号错 6 次锁 5 分钟，同一个网络错 20 次锁 15 分钟。
- 扫码登录（已登录的手机帮电脑登录）：电脑登录框「扫码登录」出二维码（3 分钟有效），手机上从账户卡菜单「扫一扫登录网页版」或 设置 ›「账户」›「登录网页版」扫码并「确认登录」。
- 登录最长保留 90 天。登录状态跟着网址存：临时地址一变，要在新地址重新登录一次。
- 「退出登录」只退出这一台设备。改密码后别的设备要重新登录。

## 邀请码注册

- 前提：多人用模式、管理员开着「凭邀请码注册」。
- 登录框「注册新账号」：账号（2–32 位小写字母、数字、`_`、`-`，不能以 `_` / `-` 开头）、密码（至少 8 位）、确认密码、「邀请码」。注册完直接登录。
- 邀请码由管理员在控制台「用户」页生成，只能用一次；Pro 邀请码注册的是 Pro 账号，普通邀请码注册的是普通账号。关掉注册开关后没用过的邀请码失效。
- 管理员也可以跳过邀请码直接「＋ 新建账号」。

## Pro 与普通

- 普通（没有命令行）：Claude 只能在自己的文件夹里读写、联网和调用工具，看不到别人的对话和文件。可以放心发。
- Pro（有命令行）：有终端、能让 Claude 跑命令。路径和命令检查防的是手滑、挡不住故意绕过，有命令行的人有可能读到服务器上共享的订阅凭据。只给完全信任的人，邀请默认发普通档。
- 升档 / 降档：控制台「用户」› 某人「管理」。

## 额度

- 只约束注册账号，管理员不受限。额度只算 Claude（大家共用一份 Claude 订阅），dimensio 不计。
- 维度：每天最多几轮、最近 7 天最多几轮、每天 / 7 天最多花多少（美元，按 API 价估算），以及全服同时最多跑几轮。留空或 0 = 不限（默认都不限）。「每天」按哪个时区换日可设。
- 默认额度在控制台「额度与注册」页；单个账号在「用户」›「管理」›「调整额度」（空着跟默认，0 = 对他不限）。
- 超额时对话里会提示什么时候恢复。定时任务的每次运行也算一轮。
- 每个账号（包括管理员）最多同时跑 3 个 Claude 对话。

接口：`usage`

## Claude 订阅额度（5 小时 / 每周）

- 服务器上配的 Claude 订阅（Pro / Max）是所有人共用的：设置 ›「账户」›「用量」和输入框旁的用量环都显示同一份 5 小时窗口和本周用量。
- 撞上限额时，回答区出限额卡，可勾「限额重置后自动继续」（见 claude 章）。

## 管理员能看到什么

- 管理员默认只看得到注册账号的元数据（会话标题、时间、用量、在不在线）。查看对话内容、代他发消息与答审批，要账号本人在 设置 ›「账户」›「管理员可见性」里允许；允许后管理员在控制台「会话 / 续聊」里选一个用户、一个对话看消息或以他的身份继续发（算他的额度）。
- 每次查看、代发都记在「管理员的访问记录」里，账号本人能看到。
- 这是应用层的约束，不是系统级隔离：Pro 账号和管理员都有命令行，技术上能读到服务器上的文件。
- 「用户」页的「管理员登录」：每台用令牌登录过的设备都能「吊销」或「吊销其它设备」。

## 服务端控制台

入口：设置 ›「连接」›「服务端控制台」→「打开」，只有管理员看得到。

- 「总览」：在跑的 agent、账号数、订阅用量。
- 「活跃进程」：所有正在跑的 Claude 对话，每个都能「中止」。
- 「用户」（只自己用时叫「服务账号」）：邀请码、新建账号、「管理」（升 / 降档、改密码、停用 / 启用、删除、「能用的 agent」、调整额度）、管理员登录。
- 「额度与注册」（多人用才有）：「凭邀请码注册」开关、默认额度、换日时区。
- 「会话 / 续聊」、「定时任务」（所有人的任务只读一览）。
- 「Claude 账号」：「＋ 添加账号」（令牌是用户在**自己电脑上**跑 `claude setup-token` 得到的，不要在 VM 上生成）、「切到此号」、「编辑」换令牌。可以加几个号手动切换；没有按额度自动换号。
- 「服务控制」：运行状态、「重启服务」（空闲时重启 / 立即重启）、「最近日志」。没有「更新」按钮：更新跟 Muse 说「更新」。
- 接口里没有控制台的操作（账号、邀请码、额度、Claude 账号、服务控制都只能人在界面上或让 Muse 用 `bootstrap.sh` 做）。

## 自定义：技能、连接器、插件

- 只有管理员能装、能管，而且只对管理员自己的对话生效（Claude、管理员的定时任务、管理员的 dimensio）；注册账号的 Claude 和 dimensio 不加载这些扩展。
- 入口：Claude 页侧栏「自定义」，或设置左栏「自定义」分组。「你的」是装好的，「发现」是 Anthropic 官方插件目录（第一次要「下载官方目录」，先让 Muse 跑 `allow-sites github.com`）。
- 也能上传自己的技能（`.md` / `.zip` / `.skill`）、插件（`.zip`）、添加自定义连接器（本地命令或远程 HTTP / SSE）。
- 生效：Claude 从下一条消息起；dimensio 在新对话里。插件只支持 Claude Code。
- 要浏览器的插件 / 连接器在 Muse 上装了也用不了（VM 起不了浏览器）。
