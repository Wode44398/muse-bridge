# 工作空间

工作空间是 bridge 的服务端文件管理器：在手机、网页、桌面客户端上浏览、预览、编辑、上传、整理服务端电脑上的文件，并能发给 AI、生成公开分享链接；安卓 app 还能浏览手机本地文件夹。

## 工作空间是什么、谁能看到什么

工作空间里的文件都在服务端那台电脑上，各客户端只是界面。每个身份看到的根目录不同：

| 身份 | 工作空间根 | 额外能去的地方 |
|---|---|---|
| 主机管理员 | 工作区（管理员配置的库目录） | 「位置」里还有「主目录」和各盘符（如「D 盘」），整台电脑都能浏览 |
| 完全信任成员 / 普通成员 | 自己的成员目录 | 无；看不到别人的目录，也看不到管理员的工作区 |
| 分享访客（`/w/` 链接） | 分享桶（一份拷贝） | 无，只读 |
| 快照访客（`/c/` 链接） | 快照桶 | 无；可读写桶内文件 |

- 管理员的「位置」切换：手机/网页顶栏返回键右边有一枚位置胶囊（图标 + 当前位置名 + 上下箭头），点开是「位置」菜单：「工作空间」「主目录」「X 盘」。从 Claude 工作台打开时菜单里还有「对话文件夹」，一键回到本会话的工作目录。成员只有一个根，不出这枚胶囊。
- 列表顺序：文件夹在前，再按名称排序。根目录（非电脑位置）顶部有「最近」区，列出最近修改的 6 个文件。
- 以「.」开头的隐藏项默认收起，分组标题右侧「显示隐藏项」/「收起隐藏项」切换（记在本机）。
- 一个目录超过 1500 项时只列前 1500 项（文件夹优先），底部提示可「按名字搜索」找其余的。

接口：`files.list`、`ui.view`

## 工作空间的入口

工作空间有一个整页入口和若干内嵌入口，打开的是同一套文件。

- 手机 / 网页主页：右上角账户胶囊 → 账户卡里的「工作空间 ›」。
- 设置 › 账户分区里有「工作空间」一行；Claude 分页的账户菜单里也有「工作空间」。
- 桌面客户端主页：Dock 上的「工作空间」图标；Ctrl+K 命令面板搜「打开工作空间」。
- Claude 工作台：标题栏工具组的 ⋮ 里点「文件」（快捷键 Ctrl+Shift+E），在侧栏打开，起点是本会话的工作目录（只是起点，管理员仍可切到别的位置）。Codex、dimensio 的工作台也内嵌同一个文件视图。
- 界面形态自动选择：手机、触屏、底部抽屉用「手机形态」（iOS 文件 app 风格）；桌面客户端且服务端就在这台电脑上时整页用「桌面形态」（资源管理器风格）；工作台侧栏够宽且用鼠标时也用桌面形态。电脑浏览器打开整页工作空间用的是手机形态。

接口：`ui.open`、`ui.view`

## 手机形态的工作空间界面

手机形态（手机 app、网页、电脑浏览器整页）的布局与手势如下。

- 顶栏：左「返回」（上一级）、管理员的位置胶囊；右「＋」（添加菜单：「上传文件」「新建文件夹」「新建 Markdown 文件」）和「传输」圆钮（环形进度，角标是进行中的任务数）。
- 路径条：当前路径一行显示，超过两级时中间折成「…」，点开逐级向上选。
- 底栏：「工作空间」/「本地」两个标签（「本地」只在安卓 app 里可用，网页点了会提示「本地工作空间需在手机 App 内使用」），右侧放大镜是搜索。
- 点文件夹进入、点文件预览。长按（鼠标是右键或长按）出菜单，条目按情况显示：「发送给 AI」「分享」「分享链接」「下载到本地」「打开方式」「解压」「压缩…」「移动到」「复制」「重命名」「显示简介」「多选」「删除」（电脑位置里是「移到回收站」）。
- 触屏上按住会把这一项「拿起来」：原地松手出长按菜单；拖到某个文件夹或路径条上的某一级松手＝移动到那里（悬停片刻会自动进入该文件夹）；拖回主页丢在 Claude / Gemini 入口上＝作为附件挂进输入栏。
- 「多选」后底部工具栏：「分享」（目前只提示「分享开发中」）、「移动到」「删除」「完成」。多选没有复制和压缩。
- 「显示简介」：种类、大小、位置、修改时间；电脑位置里还显示完整路径。
- 「传输」面板：上传与下载任务的进度、速度，可「取消上传」「取消下载」「重试」「清除已完成」，下完的文件可「打开」。
- 网页在电脑浏览器里可以直接把文件或整个文件夹拖进页面上传（见「上传」）。

## 桌面形态的工作空间界面

桌面形态是资源管理器式的高密度界面，用于桌面客户端整页（服务端在本机时）和宽侧栏。

- 左侧栏：「通用」（本会话工作目录、「最近」）和「位置」（桌面客户端是本机授权的位置，可「添加位置…」、右键「移除位置」「复制地址」「在文件资源管理器中显示」；网页/侧栏是服务端给的工作空间、主目录、各盘）。窄时侧栏收起，入口挪到地址栏左侧的「位置」下拉。
- 工具栏：后退（Alt+←）、前进（Alt+→）、上一级（Backspace）、地址栏（显示完整路径，Ctrl+L 或点空白处可直接输入路径跳转）、搜索框（Ctrl+F）、「视图」（列表视图 / 图标视图）、「排序」（名称、修改时间、类型、大小，升序/降序）、「新建 / 导入」。
- 文件右键菜单：「预览」/「打开」「用默认应用打开」「打开方式…」「在文件资源管理器中显示」「发送给 AI…」「分享链接…」「解压到当前文件夹」「另存为…」或「下载到本地」「压缩…」（多选时「压缩 N 项…」）「剪切」「复制」「重命名」「简介」「移到回收站」或「删除」。
- 空白处右键：「新建文件夹」「新建 Markdown 文件」「导入文件…」/「上传文件…」「导入文件夹…」/「上传文件夹…」「粘贴」「全选」「刷新」。
- 键盘：Ctrl+A/C/X/V、F2 重命名、Delete 删除、F5 刷新、Enter 打开、方向键移动选择。
- 拖拽：在本页把文件拖到文件夹上＝移动，按住 Ctrl＝复制；桌面客户端里可以把文件拖出到资源管理器、微信、聊天输入栏；从系统拖文件进窗口即导入。
- 「发送给 AI」「分享链接」「解压」需要服务端能访问该位置：桌面客户端里额外添加的本机位置对非管理员不出这几项。

## 工作空间的搜索

工作空间只有按文件名的搜索，不搜文件内容。

- 手机形态：底栏放大镜 → 「搜索文件」框，按名字（不分大小写的子串）过滤当前文件夹，不递归子目录；当前目录被截断（超过 1500 项）时改由服务端在该目录里筛。
- 桌面客户端的本机位置：在整个当前位置里搜（本机索引），最多 200 条，超出提示「结果超过 200 条，已截断」。桌面形态里的服务端位置同手机形态，只筛当前文件夹。
- agent 可以用接口在工作空间里递归按文件名找。

接口：`files.search`、`files.list`

## 工作空间的文件预览

工作空间点开文件进入全屏查看器（工作台侧栏里则在侧栏内打开），按类型选查看器；顶栏有返回/关闭、下载或「另存为…」，同一文件夹的图片可左右翻。

| 类型 | 扩展名（手机形态） | 查看方式 |
|---|---|---|
| 图片 | png jpg jpeg gif webp bmp svg heic | 双指缩放、双击放大、左右滑翻页、下滑关闭；先出模糊缩略再换清晰图 |
| 视频 | mp4 mov webm mkv avi m4v | 自带播放器：「画质」可选「原画」（完整分辨率与码率）或「流畅」（转码 ≤1080p，更抗弱网省流量），网络吃紧会自动切流畅；双击左右快退/快进 10 秒、长按 2 倍速、可横屏全屏 |
| 音频 | mp3 wav m4a aac flac ogg | 波形播放器，点或拖波形跳转 |
| PDF | pdf | 连续滚动、按钮或双指缩放、页码 |
| Office | doc docx xls xlsx ppt pptx odt ods odp rtf | 表格渲染成可交互表格（多工作表切换）；文档和演示优先在服务端转成 PDF 显示（需服务端装 LibreOffice，首次稍候），没装时退回近似渲染 |
| 网页 | html htm | 在隔离沙箱里直接渲染，页面引用的相对资源（js/css/图片）能加载；工具栏「刷新」「全屏」「在浏览器中打开」 |
| Markdown / 文本 | md markdown；txt js ts json css py sh yml log 等 | 文档查看器，可编辑（见下节） |

- 其他类型（压缩包、安装包等）显示「该类型暂不支持内嵌预览」，给「下载文件」，压缩包另有「解压到当前文件夹」。
- 桌面客户端里还可「用默认应用打开」；安卓 app 里可「打开方式」交给手机上的其他应用。

接口：`files.read`、`ui.open`

## Markdown 与文本编辑器

工作空间里的 Markdown 用 Obsidian 式三态查看器编辑，纯文本/代码用源码编辑框。

- 三态切换在顶栏：「阅读」（渲染后的只读视图）｜「编辑」（实时预览：光标进到哪一块就显示那块的源码，表格可以像表格一样直接改）｜「源码」（纯 Markdown 源码）。打开时默认「阅读」，本次使用中会记住上次选的态；「新建 Markdown 文件」建好后直接进「编辑」。
- 保存：Markdown 在编辑态停笔约 1.2 秒自动保存，离开时也会自动落盘；纯文本文件不自动保存，有改动时顶栏出「保存」按钮。顶栏副标题显示「未保存」「正在保存…」「已保存」。
- 防覆盖：如果保存前文件已被别处（Claude、另一台设备）改过，先自动三方合并（提示「已合并别处对这篇的修改」）；改到同一处合不上时出横幅，选「保留我的」或「用最新版」，期间暂停自动保存。没存的草稿关掉后会临时保留，再打开时提示「恢复草稿」/「丢弃」。
- Obsidian 兼容：顶部「笔记属性」（frontmatter）、`[[双链]]` 与相对 md 链接可在查看器内跳转（返回逐级回退）、#标签、==高亮==、callout、脚注；底部「反向链接」「出链」面板和词数、字符数。
- 插图：在编辑态粘贴或拖入图片/文件，会存进笔记所在目录下的 `attachments/` 子文件夹并插入链接；在阅读态粘贴会自动切到编辑态再插入。
- 限制：单次保存上限约 5MB；只读身份（分享访客）没有编辑入口。

接口：`files.read`、`files.write`、`ui.view`

## 上传文件到工作空间

工作空间的上传走分块断点续传，进度都在「传输」面板。

- 手机形态：顶栏「＋」→「上传文件」，传进当前文件夹。安卓 app 用原生选择器和原生上传，退到后台、锁屏也照传，通知栏有进度。
- 电脑浏览器：把文件或整个文件夹拖进页面，落在空白处传进当前文件夹（提示「上传到当前文件夹」），落在某个文件夹上传进那个文件夹（「上传到「名字」」）。整个文件夹作为一条任务显示，保留目录结构。
- 桌面形态：「新建 / 导入」或空白处右键 →「上传文件…」「上传文件夹…」（服务端位置），本机位置是「导入文件…」「导入文件夹…」；也可从系统直接拖进窗口。
- 规则：单个文件上限 2GB；一次拖入的文件夹最多 5000 个文件、合计 8GB。同名文件不覆盖，自动改名为「名字 (1).扩展名」。断线会自动等网络恢复后续传，重试用尽才标失败，点「重试」从已传完的部分接着传；「取消上传」会清掉服务端的半截文件。
- 「本地」标签（手机文件夹）里没有上传。

接口：`files.write`

## 新建、重命名、移动与复制

工作空间的基本整理操作如下（手机形态在长按菜单里，桌面形态在右键菜单和快捷键里）。

- 新建文件夹：「＋」→「新建文件夹」，输入名称。重名会失败。
- 新建 Markdown：「＋」→「新建 Markdown 文件」，默认名「未命名.md」，不写扩展名自动补 .md；同名已存在会提示「已有同名文件「名字」」。
- 重命名：长按 →「重命名」（桌面 F2）。目标名已存在会失败，不覆盖。
- 移动 / 复制：长按 →「移动到」或「复制」，弹出文件夹选择器逐级进入目标，底部按钮写着「移动到「目标」」/「复制到「目标」」。管理员在选择器根部还能切换到别的位置（例如把 D 盘下载里的东西挪进工作空间），跨盘时服务端自动先拷贝再删源。目标里已有同名项时自动编号，不覆盖；不能移动/复制到自身或其子文件夹。
- 桌面形态另有剪切/复制/粘贴（Ctrl+X/C/V），本机位置与系统剪贴板互通。
- 快速移动：手机上按住拖到文件夹上，桌面上直接拖拽（见各形态界面一节）。

接口：`files.mkdir`、`files.move`、`files.write`

## 删除与回收站

工作空间的删除是否可恢复取决于你在哪里删，bridge 自己没有文件回收站。

| 在哪里删 | 菜单名 | 结果 |
|---|---|---|
| 手机/网页形态的「工作空间」根（管理员的工作区、成员的自己目录） | 「删除」 | 永久删除，不可恢复；文件夹连同全部内容 |
| 管理员在电脑位置（主目录、各盘）里 | 「移到回收站」 | 送进服务端电脑的回收站，可在那台电脑上还原；确认框显示完整路径 |
| 桌面客户端的本机位置 | 「移到回收站」 | 送进本机系统回收站 |
| 桌面形态里的服务端位置 | 「删除」 | 永久删除，确认框写明「云端工作空间的删除不可撤销。」 |
| 「本地」标签里的手机文件 | 「删除」 | 直接删除手机上的文件 |

- 多选删除一次确认（「删除选中的 N 项？」/「把选中的 N 项移到回收站？」）。
- 只有管理员能用「移到回收站」；成员的删除一律是永久删除。
- 回收站只在服务端跑在 Windows 上时可用；Linux / Docker 服务端上，电脑位置里的「移到回收站」会提示失败（不会悄悄永久删除），要删就回工作空间根里用「删除」。
- 接口 `files.delete` 同理：Windows 服务端上主机身份进回收站，其余一律永久删除，返回的 recoverable 说明能不能恢复。
- 位置的根目录本身不能删。

接口：`files.delete`

## 压缩与解压

工作空间可以把文件或文件夹打成压缩包，也能就地解压，都由服务端执行。

- 压缩（手机/网页）：长按 →「压缩…」，选项单里填「存档名称」、选「格式」（ZIP、7Z、TAR.GZ；服务端电脑装了 WinRAR 时还有 RAR）和「压缩级别」（仅存储、快速、标准、最小体积）。存档放在同一个文件夹里，重名自动编号。压缩中关掉选项单不会中断，完成后存档出现在原文件夹。手机形态一次压一项。
- 压缩（桌面）：桌面客户端直接弹出 Windows 自带的「创建存档」窗口；其他情况同上面的选项单。桌面形态可多选后一起压，但只能压同一个文件夹里的项。
- 解压：压缩包长按 →「解压」（桌面「解压到当前文件夹」），支持 rar、zip、7z、tar、gz、tgz、bz2、xz，解到同目录下与压缩包同名的文件夹（重名自动编号）。
- 限制：有密码的压缩包不支持；服务端电脑上没有可用的解压/压缩工具时会报错（rar 需要 WinRAR 或 7-Zip）。「本地」手机文件不能压缩或解压。

## 下载到手机或电脑

工作空间里的文件可以下载到当前设备（只能下载文件，不能直接下载文件夹，可先压缩再下）。

- 安卓 app：长按 →「下载到本地」，由 app 原生下载器存到手机的「下载」文件夹，带断点续传、后台照样下完，进度在「传输」面板和通知栏。
- 网页：「下载到本地」交给浏览器下载。
- 桌面客户端本机位置：「另存为…」弹系统保存对话框。
- 预览查看器顶栏也有下载 / 「另存为…」。
- 只想把文件交给手机上别的应用：安卓 app 里长按 →「分享」（系统分享面板，仅文件，文件夹会提示「暂不支持分享文件夹」）或「打开方式」。

## 把工作空间文件发给 AI

工作空间的「发送给 AI」把文件作为素材交给某个 agent，可投的目标取决于文件类型和你开通了哪些 agent。

- 入口：长按 →「发送给 AI」（桌面右键「发送给 AI…」）。
- Claude：「当附件向 Claude 提问」，再选「新对话」或某个已有对话，文件挂进那个对话的输入栏，由你补一句再发。文件夹也可以发。
- Gemini（装了 Gemini · Vertex 扩展）：「Gemini 对话」同样先选对话；图片和文本文件还能投给 Vertex 生成面板：「视频生成」（图片用作「首帧素材」「尾帧素材」或「偏好图」）、「图片生成」（「作为改图素材」或「作为提示词」）、「语音合成」（「作为朗读文本」）、「音乐生成」（「作为描述」）。
- 手机「本地」文件也能发（会先上传到服务端），但本地文件夹不能发。
- 快照访客、分享访客没有这一项。

## 工作空间的分享链接

工作空间的「分享链接」把文件或文件夹做成一个公开只读网址（`/w/…`），拿到链接的人不用登录就能浏览、预览、下载。

- 入口：手机形态长按 →「分享链接」；桌面右键「分享链接…」。「本地」手机文件、快照访客没有这一项。
- 设置：「启用分享密码」开关（开了要填密码，最长 64 字符）；「过期时间」四选一：1小时、1天（默认）、7天、30天。点「创建链接」后出「链接已创建」，显示链接和「{时间} 过期」，「复制链接」会把密码一并复制。
- 分享的是拷贝：创建那一刻把内容复制进一个独立的分享桶，之后原文件再改、再删都不影响已发出的链接；过期后桶内容自动删除。
- 单个文件也按「只有一个文件的分享空间」出 `/w/` 链接，访客点开就是预览（如 md 显示渲染后的效果）。
- 限制：一次分享总大小 2GB；单个文件夹里超过 5000 项会被拒绝；依赖与缓存目录（node_modules、.git、__pycache__、.venv 等）自动跳过不拷；不能分享整个根目录；包含 bridge 自身数据目录的文件夹不能分享；访客看不到以「.」开头的隐藏文件。
- 密码错误次数有限：同一链接 10 分钟内最多试 30 次。
- 已发出的链接没有手动撤销的入口，只能等过期（删除账号时会作废该账号铸过的所有分享空间）。
- 另有单文件直链 `/s/…`（直接下载或在浏览器内联打开，默认 7 天、最长 30 天、可带密码、单文件 2GB），只给接口调用方（如群机器人）用，界面里不生成。

## 分享链接的访客页面

打开工作空间分享链接（`/w/…`）的访客看到的是专门的只读分享页。

- 头部写明分享了什么（如「名字 等 N 项」）、共多大、「链接有效期至 {时间}，到期后内容自动删除」。
- 面包屑导航子文件夹（浏览器返回＝回上一级），「列表视图」/「网格视图」切换。
- 点文件用同一套查看器预览；逐项「下载」带进度，可「取消下载」。
- 设了密码的链接先出「输入访问密码」页，验对后进入。
- 过期或不存在时显示「链接已失效」「这个分享不存在或已经过期。」，提示联系分享者重新分享。
- 访客不能上传、改名、删除或聊天。

## 手机本地文件（安卓「本地」标签）

工作空间底栏的「本地」标签让安卓 app 浏览手机自己的文件夹（经系统授权），这些文件不在服务端。

- 只在安卓 app 里可用；网页、桌面没有。
- 首次进入：「选择手机文件夹」（系统选择器挑一个文件夹授权），或「授权整个手机存储」（需在系统设置里打开「所有文件访问」开关；除各 App 私有数据区外都能访问）。
- 可授权多个位置，进「本地」先看到「本地位置」列表（每行标「手机文件夹」或「整机存储」）；右上「＋」是「添加本地位置」，行尾「管理」可「重新选择文件夹」或「移除此位置」（只撤销授权，不删除手机上的文件）。
- 能做：浏览、预览（与工作空间同一套查看器）、编辑 Markdown/文本并写回、「发送给 AI」（仅文件）、「分享」、「打开方式」；新版 app 还支持「重命名」「移动到」「复制」「删除」和多选（旧版 app 缺哪个就不显示哪个）。
- 不能做：上传、新建、「分享链接」、「下载到本地」、压缩、解压。
- 授权的这些位置也是 Claude 的手机文件工具的活动范围。

## 成员的工作空间边界

工作空间按身份严格限定可达范围，成员（非管理员）只能在自己的目录里活动。

- 成员的工作空间根就是自己的成员目录：看不到别的成员和管理员的文件，没有「主目录」「各盘」这些位置，也不能把文件移到回收站（删除即永久）。
- 成员目录根下 bridge 的系统目录（存会话、上传、设置等）在列表里隐藏，也不能写入、移动或删除。
- 普通成员（无命令行）不能往任何名为 .git 的路径里上传、新建、改名或解压；解压出来的 .git 目录会被删掉。
- 在工作台里按项目目录访问文件（项目在自己目录的子文件夹）需要完全信任档；普通成员始终以自己的目录为根。
- 分享访客、快照访客的根锁死在各自的桶里；分享访客只读。
- 管理员没有路径边界：工作区之外，整台服务端电脑的目录都能浏览和操作。

接口：`files.list`

## 工作空间的限制与常见问答

关于工作空间的几条容易问到的事实：

- 没有按内容的全文搜索，只有按文件名的搜索。
- bridge 没有自己的文件回收站；工作空间里的「删除」是永久删除（例外见「删除与回收站」）。
- 多选工具栏里的「分享」还在开发中；要分享多个文件，可以先放进一个文件夹再对文件夹点「分享链接」，或先压缩。
- 分享链接不能手动撤销、不能改有效期，过期后自动失效。
- 文件夹不能直接下载，先「压缩…」再下载压缩包。
- 上传单文件上限 2GB；分享一次上限 2GB。
- 有密码的压缩包解不开。
- agent 改动了工作空间里的文件时，打开着的文件列表会自动刷新；桌面客户端本机位置的文件变化也会实时反映。正在编辑的 Markdown 被 Claude 改过时会提示「已同步 Claude 的修改」，与你没存的改动冲突时按「Markdown 与文本编辑器」一节处理。

接口：`files.list`、`files.read`、`files.search`、`ui.view`、`ui.open`
