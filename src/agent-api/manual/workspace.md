# 工作空间

工作空间是 Muse Bridge 的服务器文件管理器：在浏览器或安卓 app 里浏览、预览、编辑、上传、整理 Muse VM 上的文件，并能把文件发给 AI、生成只读分享链接。

## 谁能看到什么

| 身份 | 工作空间根 | 在 VM 上的位置 | 额外能去的地方 |
|---|---|---|---|
| 管理员 | 主工作空间 | `/home/hatch/bridge-srv/workspace` | 顶部位置切换：「工作空间」「主目录」、dimensio 的项目目录、`/`（整台机器） |
| 注册账号（Pro / 普通） | 自己的文件夹 | `/home/hatch/bridge-srv/users/<账号名>` | 无；看不到别人的和管理员的文件 |
| 分享访客（`/w/` 链接） | 分享时拷贝出来的一份 | — | 无，只读 |

- 列表顺序：文件夹在前，再按名称；根目录顶部有「最近」区（最近修改的 6 个文件）。图片和视频有缩略图。
- 一个文件夹超过 1500 项时只列前 1500 项。
- Claude / dimensio 在项目里写的文件就在那个项目的文件夹里，工作空间里能看到；没有存储配额，受 VM 磁盘大小限制。

接口：`files.list`、`ui.view`

## 入口

- 侧栏账户卡菜单 →「工作空间」；主页右上账户胶囊里的「工作空间」；设置 ›「账户」›「文件与分享」›「打开」。
- Claude 页工作台的「文件」（电脑上 `Ctrl+Shift+E`）是同一个文件管理器，起点是当前会话的工作目录；dimensio 工作区的「文件」也是。
- 在工作台里用鼠标时是资源管理器式界面（右键菜单、`Ctrl+C / X / V`、F2 改名、Delete 删除、框选、拖到文件夹上移动、按住 Ctrl 复制）；手机和整页工作空间是列表式界面。

接口：`ui.open`

## 文件菜单

手机上长按一个文件再松手（不移动）弹出菜单；电脑上右键或点行尾 ⋯。按情况显示：

- 「发送给 AI」：选一个对话（或新对话），把它挂进输入框；文件不复制、不受附件大小限制。文件夹也能发。
- 「分享链接」：见下面「分享链接」。
- 「下载到本地」：只有文件能下载；文件夹先「压缩…」再下载。
- 「解压」：zip / 7z / tar / gz 等解到旁边的同名文件夹；带密码的不支持。
- 「压缩…」：选存档名、格式（ZIP、7Z、TAR.GZ）和压缩级别，存档放在同一个文件夹里。
- 「移动到」「复制」「重命名」：重名自动加 (1)，不覆盖；名字里不能有 `: * ? " < > |`。
- 「显示简介」：类型、大小、修改时间、位置。
- 「多选」：几个一起移动 / 删除。
- 「删除」：永久删除，没有回收站。

接口：`files.move`、`files.copy`、`files.rename`、`files.delete`

## 新建与上传

- 右上角「添加」（＋）：「上传文件」「新建文件夹」「新建 Markdown 文件」（默认名「未命名.md」，建好直接进编辑）。
- 电脑浏览器里可以把文件或整个文件夹拖进页面上传，拖到某个文件夹图标上就传进那个文件夹。
- 单个文件最大约 2GB；拖整个文件夹最多 5000 个文件、总共 8GB，跳过 `node_modules`、`.git` 这类目录。
- 大文件分块传，断网自动续传；进度在右上角「传输」里看，可以取消、失败了重试。临时地址网慢时上传会更耐心地等。
- 同名文件不覆盖，新的自动改名为「名字 (1).扩展名」。
- 对话里直接加附件是另一套限制（Claude 单个 20MB，dimensio 单个 30MB）。

接口：`files.write`、`files.mkdir`

## 预览

点一下文件预览（电脑上双击或回车）：

| 类型 | 怎么看 |
|---|---|
| 图片 | 同一文件夹里左右翻，双指 / 双击放大，下滑关闭；默认先加载轻量图（设置 ›「通用」›「原图加载」可改） |
| 视频 | 播放器：双击快进 / 快退 10 秒，长按 2 倍速，网不好时切「流畅」画质 |
| 音频 | 带波形的播放器 |
| PDF | 适应宽度，缩放、翻页 |
| Word / Excel / PowerPoint | Excel 按工作表显示表格；Word、PowerPoint 是近似预览，排版以原文件为准 |
| 网页（html） | 在沙箱里直接渲染，页面引用的相对资源（js / css / 图片）能加载，脚本和动画都会跑；有「刷新」「全屏」「在浏览器中打开」 |
| Markdown | 阅读 / 编辑 / 源码三态，见下节 |
| 代码和文本 | 可以直接改，点保存 |
| 其他（zip 等） | 显示暂不支持预览，可下载或解压 |

- 做网页时 agent 写好 html，用户在工作空间里点开就能看效果（这台 VM 上 agent 自己没有浏览器）。

接口：`files.read`、`ui.open`

## Markdown 笔记

- 顶部切换「阅读」「编辑」「源码」。编辑时停手约 1 秒自动保存，也可 `Ctrl+S`；单个文件最大 5MB。
- Claude 或别的设备改了同一篇：你没在改就自动同步；你也有没保存的改动时自动合并，合不上时选「保留我的」或「用最新版」。
- 支持 Obsidian 写法：`[[笔记名]]` 双链（输入 `[[` 有提示）、`![[图片]]` 与 `![[另一篇笔记]]` 嵌入、文件开头的笔记属性、`#标签`、列表与任务列表；文末有反向链接。
- 插图片 / 附件：粘贴截图或把文件拖进正文，存到笔记旁的 `attachments/` 并插入 `![[文件名]]`；编辑模式下可拖图片右下角调大小。

接口：`files.read`、`files.write`

## 分享链接

- 文件菜单 →「分享链接」→ 可选「启用分享密码」（最多 64 字符）、「过期时间」（1 小时 / 1 天（默认）/ 7 天 / 30 天）→「创建链接」→ 点链接复制（有密码时连密码一起复制）。
- 链接是创建那一刻的只读副本：之后改原文件，链接里不变。收到的人能浏览、预览、下载里面的文件，不能上传、修改、删除。
- 限制：总大小约 2GB、一个文件夹最多 5000 项；`node_modules`、`.git` 不放进去；工作空间根目录本身不能分享。
- 删不掉、只能等过期：界面上没有撤销分享的按钮。
- 用临时地址时链接里也是临时地址，地址一变旧链接就打不开了；要长期分享先换成自己的域名。
- 输错密码太多次会锁 10 分钟。
- 对话本身不能分享：界面上没有「分享对话」的入口。

## 删除与恢复

- 工作空间里的删除是永久的，没有回收站——Muse Bridge 跑在 Linux 上，接口的 `files.delete` 同样永久删除（返回 recoverable=false）。删之前先征得用户同意。
- Claude 改坏 / 删掉的文件：Claude 页用户消息下的「回滚」可以把 Claude 之后的改动退回去。
- dimensio 改坏的：顶栏「回滚到检查点」，或工作区「审阅」里撤销单个文件。
- 位置的根目录本身不能删。

接口：`files.delete`

## 注册账号的边界

- 注册账号的工作空间根就是自己的文件夹：看不到别人和管理员的文件，没有别的位置可切。
- 自己文件夹根下的系统目录（存会话、上传、设置的 `.bridge`）在列表里隐藏，不能写入、移动或删除。
- 普通账号（没有命令行）不能往任何 `.git` 路径里上传、新建、改名或解压。
- 接口里的 `ws` 参数（换一个根目录）只给有命令行的身份，且必须是他有权访问的项目目录。
- 管理员没有路径边界。

## 常见问答

- 没有按内容的全文搜索：底部放大镜「搜索」只在当前文件夹里按文件名筛（不递归）；接口的 `files.search` 可以递归按名字找。
- 文件夹不能直接下载：先「压缩…」再下载，或让 Claude 在回答里把文件夹作为结果给出来（文件夹卡片的 Download 是 zip）。
- 有密码的压缩包解不开。
- agent 改了文件时，打开着的列表会自动刷新。

接口：`files.search`、`files.list`、`files.read`
