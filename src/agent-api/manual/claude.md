# Claude Code 页

Claude Code 页是 Muse Bridge 的主力工作区：在这台 Muse VM 上用官方 Claude Agent SDK 驱动的 Claude 写代码、改文件、跑命令、联网搜索，用的是服务器配好的 Claude 订阅；本章按「侧栏与会话 → 输入框 → 回答区 → 工作台 → 设置」讲清每项功能在哪、怎么用、有什么限制。

## 界面形态（手机 / 平板 / 电脑）

Claude Code 页按窗口宽度分三档布局，同一功能在不同档的入口不同。

| 档位 | 宽度 | 典型设备 | 侧栏 | 右侧工作台 |
|---|---|---|---|---|
| 手机 | 小于 700px | 手机浏览器、安卓 app | 抽屉：左上角「菜单」按钮打开 | 底部弹出的面板，一次只显示一个工具 |
| 中屏 | 700–1099px | 折叠屏展开、平板 | 点同一个按钮固定 / 收起 | 右侧列 |
| 大屏 | 1100px 及以上 | 电脑浏览器 | 常驻，可拖右缘调宽 | 右侧列，可同时开几张卡 |

- 进入：两个 agent 都开着时从主页的 Claude 方块进来；只能用 Claude 时打开网址直接就是这一页，没有主页。
- 手机上从屏幕左缘右滑是回主页；安卓返回键逐级关闭弹层、抽屉、工作台。
- 手机右上角是「工作台」按钮（两个点）；电脑上右上角是工具开关组：「会话信息」「终端」「审阅」，以及「更多」（⋮，里面有「文件」「任务」等）。
- 没有「浏览器」工具：这台 VM 起不了浏览器（平台限制）。
- Claude 的回答在服务器上跑：切会话、刷新、关掉浏览器都不会中断这一轮，回来自动接上。

## 侧栏结构

侧栏（手机是抽屉，电脑是常驻栏）从上到下大致是：

1. 「主页」——回主页；只能用一个 agent 时没有。
2. 「新对话」。
3. 「搜索」——登录后才有，快捷键 `Ctrl+K`（Mac `⌘K`）。
4. 「新建项目」、「新建临时对话」、「定时触发」（定时任务页）。
5. 「自定义」——技能、连接器、插件，只有管理员有。
6. 分区：「临时对话」、「收藏」（有收藏才出现）、「项目」（每个项目一组会话）。
7. 「已归档」入口（有归档会话才出现）。
8. 底部账户卡：设置、账户、关于、工作空间、扫一扫登录网页版（手机上）、退出登录。

- 会话行左侧的小点区分「正在回复」和「在等你回答」。
- 子会话缩进一级显示在父会话下面（见「子会话与会话协作」）。

## 项目：新建、改名、排序、删除

Claude 的项目就是服务器上的一个文件夹：在项目里开的对话，Claude 就在这个文件夹里干活。每个人都有一个默认项目「工作空间」（管理员是主工作空间，注册账号是自己的文件夹），删不掉。

- 新建：侧栏「新建项目」弹出文件夹选择器；单击文件夹是进入，**长按一个文件夹拖到底栏松手**才是选中。管理员能选整台服务器上的位置，其他人只能选自己工作空间里的。项目名默认取文件夹名，最多 200 个项目。
- 点项目行 = 在这个项目里开新对话；每组先显示若干条，「显示更多」继续展开。
- 项目菜单（行尾 ⋮，电脑上也可右键）：「重命名」（只改显示名，不动文件夹）、「归档全部会话」、「删除项目」（点两次；只是不再列出，文件夹和对话记录都还在）。
- 排序：拖动项目行（手机上长按再拖），顺序存在服务器上、各设备一致。
- 限制：项目文件夹被移动或改名后，旧会话会对不上（会话按文件夹的绝对路径存放）。

接口：`projects.list`、`sessions.list`

## 临时对话

临时对话是不属于任何项目的一次性对话：每条独占一个空文件夹，不带项目记忆，适合随手问问。以前叫「快照对话」。

- 新建：侧栏「新建临时对话」。侧栏「临时对话」分区默认只露最近一条，其余收在「显示更多」里。
- 输入框上方有一条提示带，写着多少天后清理，并带「存为工作空间」。
- 回收：最后一次活动超过 30 天移进回收站，回收站里再放 30 天永久删除（连同 Claude 在那个文件夹里写的文件）。快到期时会提示，菜单里有「继续保留」。分区末尾「回收站」里可以「恢复」。
- 「存为工作空间」：把它变成普通项目，之后不再自动清理。重要的东西做完记得存。
- 临时对话的菜单没有「收藏」「归档」。

## 会话行菜单：收藏、重命名、归档、删除

每条会话行尾 ⋮（电脑上右键、手机上长按）：

- 「收藏」/「取消收藏」：收进侧栏「收藏」分区，存在服务器上，各设备同步。
- 「重命名」：留空恢复自动标题；改名后旧名仍能被搜到。
- 「归档」：正在回复或在等回答的会话不能归档。
- 「删除」：点两次；连同子 agent 记录一起删，找不回来。
- 界面上没有导出对话的按钮。

接口：`sessions.list`、`sessions.read`

## 归档与已归档列表

归档是把会话从侧栏收起来：不停会话、不删记录，随时可取消。

- 手动：会话菜单「归档」，或项目菜单「归档全部会话」（收藏的、正在跑的不受影响）。有子会话时会问是全部归档还是只归档这一个。
- 查看：侧栏底部「已归档」，整个侧栏切成已归档列表；行菜单只有「取消归档」「删除」。打开已归档会话时输入框上方有「取消归档」。
- 自动归档：设置 ›「Claude」›「会话管理」›「归档不活跃的会话」：从不 / 1 / 2 / 7 / 14 / 30 天（默认从不，运行中或有后台任务的不归档）。手动取消过归档的以后不会再被自动归档。

## 全文搜索会话

搜索覆盖所有项目、worktree、临时对话和已归档会话，能搜标题、曾用名、项目名、分支名和对话正文。

- 入口：侧栏「搜索」或 `Ctrl+K`（Mac `⌘K`）。电脑上是居中浮层，手机上是全屏页。
- 先按标题即时过滤，停手片刻换成服务器全文结果；已归档的折在最后。↑↓ 选择、Enter 打开、Esc 关闭。
- 索引刚开始建时会提示结果可能不全。

接口：`sessions.search`、`sessions.read`

## 引用对话、分屏与独立窗口

- 引用对话：把侧栏里的一条会话**拖到输入框上**，它会变成一张「引用对话」附件卡，Claude 按需读取那段对话。手机上长按会话拖出侧栏、放到对话区。不能引用自己、空对话。
- 分屏（电脑 + 鼠标、窗口 ≥1100px）：把会话拖到对话区左半或右半，左右同时开两个会话；刷新后不保留。
- 独立窗口：把会话拖到浏览器窗口外松手，单独开一个只放这个对话的窗口（浏览器拦了弹窗时先允许本站弹窗）。

## worktree 会话

worktree 让 Claude 在 git 仓库的隔离副本（独立分支）里工作，不碰原来的文件，适合同一个项目同时开几个对话各改各的。

- 入口：git 仓库项目的新对话里，输入框上方分支胶囊右半边的「worktree」勾选框。勾上再发第一条消息，服务器切出一个新 worktree 和分支（前缀见设置「分支前缀」，默认 `claude`；起点见「工作树起点」）。
- 勾选会延续到下一个新对话；会话仍列在原项目下，工作台跟着 worktree 走。
- 仓库还没有任何提交时建不了；界面上没有合并或清理 worktree 的按钮，让 Claude 用 git 操作或走拉取请求。

## 子会话与会话协作

Claude 可以提议「另开一个会话」做一件子任务，形成父子会话；会话之间也能互相发消息。

- 消息流里出现「单独开一个会话来做？」卡片，可选「在这里做」「新会话」「开始」「在独立工作树里做」「不再询问」等。没有手动「新建子会话」的入口。
- 设置：设置 ›「Claude」›「会话协作」›「Claude 发起新会话」：先问我 / 直接开始 / 只在我要求时（只对有命令行的身份）。
- 会话信息面板的「相关会话」卡列出父、子、兄弟会话。
- 限制：每个会话最多派生 8 个子会话。

## 会话信息面板

电脑上右上角工具组第一颗「会话信息」按钮，打开右侧一列信息卡：

- 「环境」：工作目录、分支、是否 worktree。
- 「相关会话」：父 / 子 / 兄弟会话。
- 「上下文」：上下文用量与「压缩」按钮（这一轮结束后才能压缩）。
- 「连接器」：本会话可用的 MCP 连接器。
- 「输出内容」：本会话产出的文件。
- 「更改」：改动统计；「打开改动」跳到工作台「审阅」；「提交更改」让 Claude 自己提交。
- 「拉取请求」：见「拉取请求（PR）卡」。
- 手机上没有这颗按钮。

## 输入框总览

- 左侧：「+」（附件与功能）、Research 芯片（开着时出现）、权限模式芯片、用量环。右侧：模型芯片、思考强度芯片、发送 / 停止键。
- 上方可能出现：工作空间 / 分支胶囊（含 worktree 勾选）、临时对话提示带、已归档提示带、排队栏、工具审批卡、拦截换模型提示带。
- 电脑：Enter 发送、Shift+Enter 换行；手机：回车换行，点按钮发送。两边都认 `Ctrl/⌘+Enter`。
- 草稿：每个会话各存一份没发出的文字和附件，切会话、关窗口都不丢。

接口：`chat.send`、`chat.wait`、`chat.stop`

## 模型与思考强度

当前可选模型：{{models}}

- 模型：输入框右侧的模型名芯片（菜单是英文的）。「Models」下是主力模型，「More models」里是其余型号和管理员接的自定义模型。支持的型号自动用 1M 上下文；部分型号有「Fast mode」开关，开了芯片显示「· Fast」。
- 思考强度：模型芯片右边的档名芯片，拉条面板 Low / Medium / High / Extra / Max / Ultracode。Ultracode = Extra + 动态工作流，最慢、最费额度，只对当前会话生效，要 设置 ›「Claude」›「对话」›「动态工作流」开着；普通账号可能被限制到 Extra。
- 芯片带虚线下划线 = 会话实际用的和所选不一致（比如安全机制回退过模型），悬停看原因。
- 所选模型与强度会记住，并作为新对话的默认（多设备同步）。

## 权限模式与计划模式

权限模式决定 Claude 改文件、跑命令前要不要先问你。

| 模式 | 说明 | 谁能用 |
|---|---|---|
| 手动 | 做出更改前先询问 | 所有人 |
| 接受编辑 | 自动接受文件编辑，命令仍要问 | 所有人 |
| 计划 | 先只读调研、写出计划，批准后才动手 | 所有人 |
| 自动 | 由 Claude 判断要不要问 | 管理员，且「允许自动模式」开着 |
| 绕过权限 | 什么都不问（红色警示） | 管理员，且「允许绕过权限模式」开着（默认关） |

- 入口：输入框左侧权限模式芯片，快捷键 `Ctrl+Shift+M`。会话里改只影响这个会话；新会话的默认在 设置 ›「Claude」›「新会话默认」›「权限模式」。
- 计划模式：消息流里出现计划卡，可以「接受」（可选之后用什么模式）、「修改」（附意见）或「拒绝」。开了「批准计划时可清空上下文」还多一个「清空上下文后执行」。
- 允许自动 / 绕过的两个总开关在 设置 ›「Claude」›「安全」（只有管理员）。
- 注册账号的 Claude 不管什么模式都被服务器关在自己的文件夹里；普通账号没有命令行。

## 「+」菜单、附件与斜杠命令

- 「+」（附件与功能）菜单：「Add photos」「Add files」「挂载文件夹」、「Research」（深度研究开关）、「Use style」（回复语气，可自建，自建的只存在这台设备）、「输出风格 ›」（只改这个会话；新会话默认在设置里）。
- 附件：单个文件 20MB；挂整个文件夹最多 500 个文件、总共 300MB，会跳过 `node_modules`、`.git`。粘贴截图或文件自动变成附件；把文件 / 文件夹拖到输入框也行；从工作空间「发送给 AI」挂进来的文件不复制、不受大小限制。
- 斜杠命令：整段输入是 `/` 加命令名时弹出菜单（↑↓ 选，Enter / Tab 填入）。命令表来自最近一次会话报告的命令（内置 + 技能），一次都没跑过之前菜单不出现。`/compact` 压缩上下文。
- 没有 @ 提及文件，也没有语音输入。

接口：`files.write`、`chat.send`

## 插话、稍后发送与停止

Claude 工作时输入框不锁定。

- 输入框空着时只有停止键「停止生成」。有内容时主键是「插话发送」（Enter），下拉里有「稍后发送」（`Ctrl/⌘+Enter`）和「停止」。
- 插话：Claude 做完手头这一步就读到，不打断任务；它卡在审批时要先批准才读得到。
- 稍后发送：进服务器上的队列，这一轮结束后合并成一条发出；各设备看到同一份队列，关掉页面也照发。输入框上方的排队栏可以「立即发送」「放回输入框编辑」「移出队列」、拖动排序。
- 每个账号同时最多 3 个对话在跑；一个对话同一时间只跑一轮。

接口：`chat.send`、`chat.stop`、`chat.pending`

## 输入建议与用量环

- 输入建议：每轮回答完，输入框空着时用灰字猜你下一句；电脑按 Tab、手机点「填入」，Esc 收起。开关在 设置 ›「Claude」›「对话」›「输入建议」，每条建议多一次模型请求。
- 用量环（输入框左侧小圆环，「查看用量」）：上半是这个对话的上下文用量和「距自动压缩还有 …」，可拖动竖条调自动压缩点，「压缩会话」手动压缩；下半是订阅的「5 小时上限」「每周」各用了多少、多久后重置。订阅额度是整台服务器共用的一份。

接口：`usage`

## 回答区

- 思考：折叠按钮，点开看思考原文。工具调用合成一组，结束后汇总成一行，点开看每一步。
- 状态行：用时、token 数、在做什么（思考中、运行工具中、等待你的回答……）。
- 每条回复下：「复制」「重试」。你发的消息下：「回滚到这条消息之前」，可选「文件+对话」或「仅文件」（Claude 正在回复时不能回滚）。
- 产物文件卡：Claude 在最终回答里给出的文件 / 文件夹变成卡片，点开在工作台「文件」里预览，卡上有 Download（文件夹下载是 zip）。
- 回答里像文件路径的链接点了在应用里打开。
- 长对话先显示最近一部分，「查看更早的消息」往上加载。

接口：`sessions.read`、`chat.wait`

## 提问表单与工具审批卡

Claude 需要你做决定时会停下来等，同一账号的任何一台设备都能回答。

- 提问表单（消息流里）：选项按钮加自由输入「Something else」，「提交回答」或「Skip」。无人回答时怎么办在 设置 ›「Claude」›「对话」›「Claude 提问无人回答时」：一直等 / 5 / 10 / 30 分钟后继续（默认 10 分钟）。
- 工具审批卡（输入框上方）：「允许 Claude …？」，带命令、文件 diff、网址等预览；按钮「拒绝」、「本会话都允许」/「始终允许」、「允许一次」。高风险请求默认焦点在「拒绝」。
- 通知：权限请求、提问、任务完成三类浏览器通知在 设置 ›「Claude」›「通知」，只存在这台设备；总开关在 设置 ›「通用」。
- 定时任务里没人回答：提问会被自动拒绝，要它按合理默认继续。

接口：`chat.pending`、`chat.answer`

## 子 agent、工作流与后台任务

- 子 agent 在工具组里显示为一行，点开在工作台「任务」里看它的完整过程。
- 工作流卡：名称、状态、每个 agent 的状态点阵；点开在「任务」里看。动态工作流要 设置 ›「Claude」›「对话」›「动态工作流」开着（只对有命令行的身份），下面还有「子 agent 调度偏好」。
- 后台命令、子 agent、工作流在这一轮主回答写完后可以继续跑，这一轮「挂起」等它们，「任务」面板上方有「结束等待」；这时可以照常发新消息。

## 内嵌交互图表

Claude 可以在回答里直接画交互图表（流程图、数据图、小工具），渲染在安全沙箱框里。

- 边生成边画，完成后脚本才运行；「⋯」菜单可复制为图片、下载为 PNG；「查看代码」看源码。
- 图表想替你发消息时会弹确认条，可「发送」或「忽略」。
- 开关：设置 ›「Claude」›「对话」›「对话内交互图表」。
- 分享页不显示交互图表。

## 限额卡与重置后自动继续

Claude 撞上订阅限额时，回答区出现限额卡（「已达到 5 小时限额」等）并写明重置时间。

- 「限额重置后自动继续」：只对 5 小时限额、只在最后一条消息上出现；勾上后到点由服务器发「请从中断的地方继续」，页面关掉也照常继续。你先发了别的消息就取消。
- 默认值在 设置 ›「Claude」›「撞上限额时」。
- 被安全机制拦下的回复：开着「消息被拦时自动换模型」时自动换模型重试；关着时显示「Session paused」卡，选换模型继续或改提示词重试。
- 订阅额度所有人共用；用完了只能等恢复，或由管理员在服务端控制台「Claude 账号」里手动切到另一个号。

## 断线续传

- 切会话、刷新、断网、关掉浏览器，这一轮继续在服务器上跑；回来自动接上，已结束就回放完整结果。只有点停止才会停。
- VM 重启或更新切换时正在跑的一轮会被打断，提示「这一轮被中断」，说一句「继续」就行。
- 同一会话正在别处续聊时会提示先关掉那边。

接口：`chat.wait`、`chat.pending`

## 工作台

工作台是右侧（手机是底部面板）的工具区，都跟随当前会话的工作目录。

| 工具 | 作用 | 快捷键（电脑） | 谁能用 |
|---|---|---|---|
| 终端 | 工作目录里的 shell，与 Claude 共用 | ``Ctrl+` `` | 管理员、Pro 账号 |
| 审阅 | git 改动列表与 diff | `Ctrl+Shift+G` | 所有人 |
| 文件 | 工作目录的文件管理器与预览 | `Ctrl+Shift+E` | 所有人 |
| 任务 | 后台任务、子 agent、工作流 | 无（在 ⋮ 里） | 所有人 |

- 电脑上可以同时开几张卡，拖左缘调宽度；手机上点「工作台」从底部弹出，顶上切换工具。
- 终端：断线重连不丢输出；最多同时 6 个，1 小时没人看就关掉；手机上有 Ctrl+C、Tab、Esc、方向键快捷键。用临时地址时终端可能一直「连接终端…」（已知限制，换成自己的域名就好）。
- 没有浏览器面板。

接口：`ui.view`、`ui.open`、`files.list`

## 拉取请求（PR）卡

拉取请求卡显示当前会话分支在 GitHub 上的 PR 状态，能直接合并、重跑检查、同步基线。只对管理员显示，且项目要是 GitHub 仓库、服务器上装好并登录了 GitHub CLI（`gh`）——Muse 的 VM 默认不一定有，没装时卡片会提示「未安装 GitHub CLI（gh）」或「请运行 gh auth login 登录」。

- 入口：会话信息面板的「拉取请求」卡；分支胶囊旁的 PR 胶囊（`#编号`）。
- 显示 CI 状态、冲突、落后基线、审查状态；操作有「合并」（选合并方式后确认）、「重跑失败的检查」、「同步基线」、「转为草稿」等；还没有 PR 时可「创建拉取请求」（让 Claude 去建）。
- 开关：「就绪后自动合并」、「自动修复」（CI 失败、冲突、新评审时自动叫醒 Claude 处理）、「合并或关闭后自动归档」。
- 相关设置：设置 ›「Claude」›「Git 与拉取请求」。
- github.com 第一次访问会弹 Muse 的审核卡，选「总是允许此站点」。

## 模型服务（自定义 API）

模型服务让 Claude Code 接入别的模型接口（Anthropic API、DeepSeek、Kimi、智谱 GLM、百炼、OpenRouter 等，或任何 OpenAI 兼容服务），与订阅模型并列在模型菜单里。

- 只有管理员能配置和使用；入口在 设置 ›「模型服务」。
- 「＋ 添加服务」从预设选或从头配置；填接口地址、API Key（加密保存在服务器上，不发给浏览器）、拉取或手动添加模型，可「发送测试」。
- 每个服务可以启用 / 停用，可控制是否显示在模型列表。
- 使用：模型菜单「More models」里按服务分组选。
- 在 Muse 上添加前先让 Muse 跑 `allow-sites <接口地址>` 放行，提醒用户在审核卡上选「总是允许此站点」，不然会连接超时。

## Claude 设置项一览

Claude 的设置在 设置 ›「Claude」（按身份保存、多设备同步；标「本设备」的只存在这台设备）。标「只有管理员」「有命令行」的项其他身份看不到。

- 「撞上限额时」：「限额重置后自动继续」。
- 「新会话默认」：「权限模式」、「输出风格」、「新对话落点」（没有可接着看的对话时空白对话落在临时对话还是工作空间）。
- 「对话」：「输入建议」、「对话内交互图表」、「动态工作流」（有命令行）及「子 agent 调度偏好」、「消息被拦时自动换模型」、「批准计划时可清空上下文」、「Claude 提问无人回答时」、「回复语言」（跟随对话 / 简体中文 / English）、「自动压缩点」（在用量弹层里拖动设置，这里只能恢复默认）。
- 「会话协作」：「Claude 发起新会话」（有命令行）。
- 「Git 与拉取请求」（有命令行）：「分支前缀」、「工作树起点」、「自动修复拉取请求」、「拉取请求合并或关闭后自动归档」、「提交与拉取请求署名」。
- 「会话管理」：「归档不活跃的会话」。
- 「通知」（本设备）：「权限请求」「提问」「任务完成」。
- 「安全」（只有管理员）：「允许绕过权限模式」、「允许自动模式」。

## 各身份在 Claude Code 页的差异

| 功能 | 管理员 | Pro 账号 | 普通账号 |
|---|---|---|---|
| 命令行与工作台终端 | 有 | 有 | 无 |
| 项目位置 | 整台服务器 | 自己的文件夹内 | 自己的文件夹内 |
| 权限模式 | 五种（自动 / 绕过受总开关控制） | 手动 / 接受编辑 / 计划 | 手动 / 接受编辑 / 计划 |
| 「动态工作流」开关 | 有 | 有 | 无 |
| 拉取请求卡、自定义模型服务 | 有 | 无 | 无 |
| 技能 / 连接器 / 插件 | 生效 | 不生效 | 不生效 |
| 额度 | 不限 | 受管理员设的额度限制 | 同左 |

接口：`whoami`
