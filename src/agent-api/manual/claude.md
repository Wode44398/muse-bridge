# Claude 分页

Claude 分页是 bridge 的核心工作区：在服务端用与官方 Claude Code 同源的 agent 写代码、改文件、跑命令、联网、生成媒体，本章按「侧栏与会话 → 输入框 → 回答区 → 工作台 → 设置」讲清每项功能在哪、怎么用、有什么限制。

## Claude 分页的界面形态（手机 / 平板 / 桌面）

Claude 分页按窗口宽度分三档布局，同一功能在不同档的入口不同，本章各节都按这三档说明。

| 档位 | 宽度 | 典型设备 | 侧栏 | 右侧工作台 |
|---|---|---|---|---|
| 手机 | 小于 700px | 手机、手机浏览器 | 抽屉：左上角「菜单」按钮打开，盖在正文上 | 底部弹出的面板，一次只显示一个工具 |
| 中屏 | 700–1099px | 折叠屏展开、竖屏平板 | 点汉堡可让侧栏常驻；工作台打开时侧栏自动让位，关掉后回来 | 右侧列 |
| 大屏 | 1100px 及以上 | 电脑浏览器、Windows 桌面客户端 | 恒常驻，可拖右缘调宽 | 右侧列，可同时开多张卡 |

- 进入方式：主页点「Claude」入口；单 agent 模式（一个人只能用 Claude）下打开 app 就是 Claude 分页，没有主页。
- 手机上从屏幕左缘右滑是返回主页，不会拉出侧栏；侧栏只能点左上角「菜单」打开。安卓返回键逐级关闭弹层、抽屉、工作台。
- 手机顶栏右上角是一颗胶囊，三个按钮：「新对话」、「切换明暗主题」、「工作台」（两个点的图标）。
- 大屏/中屏的右上角是工具开关组：「会话信息」、「终端」、「审阅」、「浏览器」，以及「更多」（⋮，里面有「文件」「任务」「深色模式/浅色模式」「收起全部面板」）。桌面客户端里这组按钮在标题栏上。
- 右键菜单、快捷键提示、鼠标拖拽只在有鼠标的设备上出现；触屏用长按代替。
- Claude 的回答在服务端跑：切会话、刷新、关掉 app 都不会中断这一轮，回来自动接上（见「断线续传与后台任务」）。

## 侧栏结构

Claude 分页的侧栏（手机是抽屉，大屏是常驻栏，内容相同）从上到下依次是：

1. 「主页」——回主页；单 agent 模式下没有。
2. 「新对话」——有鼠标时行尾显示快捷键：网页 `Ctrl+Shift+O`（Mac `⇧⌘O`），桌面客户端 `Ctrl+N`（Mac `⌘N`）。
3. 「搜索」——登录后才有，快捷键 `Ctrl+K`（Mac `⌘K`）。
4. 「新建项目」。
5. 「新建临时对话」（虚线对话气泡图标）。
6. 「定时触发」——打开定时任务（Routines）页。
7. 「临时对话」分区。
8. 「收藏」分区——没有收藏的会话时不出现。
9. 「项目」分区——每个项目一组会话。
10. 「已归档」入口（带数量）——没有归档会话时不出现。
11. 底部账户卡（「设置与账户」）。

- 会话行左侧的状态点区分「正在工作」和「在等你回答」。
- 子会话缩进一级显示在父会话下面（见「子会话与会话协作」）。
- 「新对话」的另外两个入口：手机顶栏胶囊最前面那颗按钮；中屏侧栏没常驻时汉堡旁边的圆钮。

## 项目：新建、改名、排序、删除

Claude 的项目就是一个工作目录：Claude 在里面读写文件、跑命令，会话按项目分组。每个人都有一个默认项目「工作空间」（管理员是工作区，成员是自己的目录）。

### 新建项目

- 入口：侧栏「新建项目」。
- 桌面客户端（服务端在本机时）：直接弹系统文件夹选择器，选哪个文件夹就是哪个。
- 网页、手机：弹出「新建项目」选择器，顶部的「位置」栏切换起点。管理员可选「工作空间」、额外配置的位置、「主目录」、各个盘符（非 Windows 为 `/`）；成员只有「工作空间」（自己的目录内）。
- 选定方式：单击文件夹是进入它；要选中，长按一个文件夹，拖到底栏松手（底栏提示「拖入选为工作空间」→「拖到这里松手」→「松手即可创建」）。
- 建好后项目名默认取文件夹名，并直接在新项目里开一个对话。同一目录不会重复建项目，上限 200 个。

### 项目行与菜单

- 点项目行 = 在这个项目里开新对话。行上的 ▾ 折叠/展开它的会话。
- 每组先显示 10 条会话，「显示更多（{n}）」每次再放 20 条，放完变「收起」。
- 项目菜单：行尾 ⋮（「项目选项」），有鼠标时右键也可以。
  - 「重命名」：弹框「重命名工作空间」，只改显示名、不动目录；留空恢复为文件夹名；最长 80 字。
  - 「归档全部会话」：收藏的会话和正在工作的会话不受影响，可在「已归档」里找回。
  - 「删除项目」：点一次变「确认删除」再点才删。只是不再列出这个目录的会话，会话记录和文件都不删。默认的「工作空间」项目不能删。

### 排序

- 鼠标：直接拖动项目行（有插入线）；触屏：长按项目行拿起再拖。
- 顺序存在服务端，各设备一致。没有按名称/时间自动排序的选项；默认顺序是默认项目在首位，其余按最近更新。

### 限制

- 项目目录被移动或改名后，旧会话会对不上（会话按目录的绝对路径存放）；目录不存在时工作台提示「该工作空间的文件夹已不存在（可能被移动或删除）」。

接口：`projects.list`、`sessions.list`

## 临时对话、回收站与「存为工作空间」

临时对话是不属于任何项目的一次性对话：每条独占一个空目录，不带自动记忆，适合快问快答或不依赖本地文件的独立任务（如写一份研报）。界面上的「快照」指的是另一件事（公开聊天快照），不要混用。

- 新建：侧栏「新建临时对话」。
- 侧栏「临时对话」分区：默认只露最近一条，其余收在「显示更多（{n}）」里；只有文件没有对话的显示「{n} 个文件，还没有对话」。
- 输入框上方有一条「临时对话」提示带，写着多少天后清理，并带「存为工作空间」链接。
- 回收规则：最后一次活动超过 30 天，整只桶移进回收站；在回收站再放 30 天后永久删除。剩 3 天时行尾显示「剩 {n} 天」或「今天清理」，输入框上方变成警告条「这个临时对话 {n} 天后会移进回收站。」。
- 回收站：分区末尾「回收站（{n}）」，打开弹窗「临时对话回收站」，每条可「恢复」，恢复后对话和文件原样接上。
- 临时对话的会话菜单没有「收藏」「归档」，换成：
  - 「存为工作空间」：把这只桶变成普通项目（名字取对话标题），之后不再自动清理，目录会搬到固定的工作空间存放位置（有会话正在跑时推迟搬）。
  - 「继续保留」：快到期时出现，让回收计时从头算。
  - 「重命名」「删除」照常。
- 在临时对话里点「新对话」，会落到最近用过的真实项目；都没有就落默认「工作空间」。
- 冷启动时如果没有可接着看的对话：管理员默认落在临时对话，成员默认落在自己的工作空间。设置界面里没有这一项，但可以让 Claude 改：`settings.claude_set` 的 newChatLanding（auto 自动 / temp 临时对话 / workspace 工作空间），随账号同步。

## 会话行菜单：收藏、重命名、归档、删除

Claude 侧栏每条会话都有一个菜单，入口是行尾 ⋮（「更多」）；有鼠标时右键，触屏长按后原地松手也会打开。

- 「收藏」/「取消收藏」：收藏的会话移进侧栏「收藏」分区（相当于置顶），存在服务端，各设备同步。
- 「重命名」：弹框「重命名对话」，最长 120 字，留空恢复自动标题。
- 「归档」：正在工作或在等回答的会话不能归档（提示「正在工作的会话不能归档」）。
- 「删除」：点一次变「确认删除」再点才删；删掉会话记录、子 agent 记录以及收藏、改名、归档等附属信息，不可恢复。
- 菜单里没有「置顶」「分享」「导出」。

接口：`sessions.list`、`sessions.read`

## 会话标题

Claude 会话的标题由 bridge 按优先级自动取，不需要手动起名。

- 优先级：在 bridge 里改过的名 → 在官方 Claude Desktop / CLI 里改过的名 → 子会话派生时起的名 → Claude 自动生成的标题 → 第一条用户消息。
- 正在跑、还没标题的会话显示「（进行中…）」；没有标题显示「（无标题）」。
- 改名后旧名仍能被搜索到（搜索结果里显示「曾用名：…」）。

## 归档与已归档列表

归档是把 Claude 会话从侧栏收起来：不停会话、不删记录、不动 worktree，随时可取消。

- 手动归档：会话菜单「归档」，或项目菜单「归档全部会话」。会话有子会话时会问「归档会话？」，可选「全部归档（{n} 个会话）」或「仅归档此会话」（子会话移到顶层）。
- 查看：点侧栏底部「已归档」，整个侧栏切换成已归档列表（按归档时间倒序，每页 30 条），顶部返回按钮回到正常侧栏；行菜单只有「取消归档」「删除」。
- 打开已归档会话时，输入框上方显示「此会话已归档。」和「取消归档」链接。
- 自动归档（设置 › Claude ›「会话管理」）：「归档不活跃的会话」从不 / 1 / 2 / 7 / 14 / 30 天（默认从不，运行中或有后台任务的不归档）；「跟随 Claude Desktop 的归档」（仅管理员，默认开）；另在「Git 与拉取请求」里有「拉取请求合并或关闭后自动归档」。
- 手动取消过归档的会话以后不会再被自动归档。

## 全文搜索会话

Claude 分页的搜索覆盖所有项目、worktree、临时对话和已归档会话，能搜标题、曾用名、项目名、分支名和对话正文（双方说的话）。

- 入口：侧栏「搜索」或 `Ctrl+K`（Mac `⌘K`）。大屏是居中浮层，手机是全屏页。
- 用法：输入关键词，先按标题即时过滤，停手片刻后换成服务端全文结果。结果分「标题」「模糊匹配」「对话内容」三层，每层先显示 5 条；已归档的折在最后「显示已归档（{n}）」；空查询显示「最近」8 条。
- 键盘：↑↓ 选择，Enter 打开，Esc 关闭。
- 限制：搜索索引刚开始建时提示「搜索索引还在建立，结果可能不全。」。

接口：`sessions.search`、`sessions.read`

## 引用对话

引用对话是把另一条 Claude 会话的内容整理成一份 Markdown 附件挂进当前输入框，让 Claude 按需读取，用来跨会话接续上下文。

- 只能靠拖拽，没有菜单项：
  - 鼠标：把侧栏里的一条会话拖到输入框上（提示「放到输入框＝引用这段对话」）；或拖到侧栏另一条会话上，会切到那条会话并引用进去。
  - 触屏：长按会话行拿起，拖到正文或另一条会话上；手机上往右拖出抽屉边缘，抽屉会自己收起。
- 成功后输入框里出现附件卡「引用对话 · {n} 条消息」，提示「已引用对话「{title}」」。
- 限制：不能引用自己；同一条不能重复引用；空对话不能引用。

## 分屏与独立窗口（大屏）

Claude 分页在大屏上可以左右分屏同时开两个会话，或把会话拖成独立窗口。

- 分屏：用鼠标把侧栏里的会话拖到正文左半或右半（提示「在左边分屏打开」「在右边分屏打开」「左右对调」等）。要求窗口宽度 ≥1100px、每格至少 380px、有鼠标；手机和触屏没有分屏。分屏后每格有自己的工具开关和「关闭这一格」；刷新后不保留分屏。
- 独立窗口：把会话拖出浏览器/客户端窗口，开一个只放这个对话的新窗口。浏览器拦截弹窗时需允许本站弹出窗口；老版本桌面客户端要先更新。

## worktree 会话

worktree 会话让 Claude 在 git 仓库的隔离副本（独立分支）里工作，不碰主检出的文件，适合并行做多个改动。

- 入口：新对话还没发第一条消息时，输入框上方的分支胶囊右半有「worktree」勾选框（提示「在仓库的隔离副本里工作」）。只在项目是 git 仓库主检出时可用（快照访客没有）。勾选状态会延续到下一个新对话；设置 › Claude ›「新会话默认」›「用工作树」是同一个开关（设置里这一项只对有命令行的身份显示）。
- 效果：发第一条消息时服务端在仓库里切出一个新 worktree 和分支（分支名前缀见设置「分支前缀」，默认 `claude`；起点见设置「工作树起点」：「当前分支」或「远端默认分支」）。会话仍列在原项目下，工作台跟着 worktree 目录走；会话信息的「环境」里显示「分支 · worktree」。
- 限制：bridge 没有合并或清理 worktree 的按钮。删除、归档会话都不删 worktree；合并请让 Claude 用 git 操作，或走拉取请求（见「拉取请求（PR）卡」）。

## 子会话与会话协作

Claude 可以自己提议「另开一个会话」来做一件子任务，形成父子会话；会话之间也可以互相发消息。

- 发起：由 Claude 在回答中提出，消息流里出现卡片「单独开一个会话来做？」，按钮有「在这里做」「新会话」「开始」「全部开始」「在独立工作树里做」「不再询问」（之后可选「总是新建会话 / 总是在这里做」）。用户没有手动「新建子会话」的入口。
- 设置：设置 › Claude ›「会话协作」›「Claude 发起新会话」：先问我 / 直接开始 / 只在我要求时（仅有命令行的身份）；「其它会话发来的消息」：跟随 Claude 默认 / 直接接收 / 暂存等我确认 / 拒收（仅管理员）。
- 跨项目：子会话可以开到用户的另一个项目（工作空间）里，跟用户说「去 X 项目开个会话做……」即可。它在那个项目的目录里干活、用那个项目的 CLAUDE.md 与记忆，仍然是父会话的子会话：做完照样自动把汇报转回父会话，双方照样能互发消息。临时对话不能当目标项目。
- 查看：侧栏里子会话缩进在父会话下（开到别的项目的子会话列在那个项目下面）；会话信息面板的「相关会话」卡列出父会话、子会话、兄弟会话，点一行打开。
- 限制：每个会话最多派生 8 个子会话；同一身份同时最多 6 个会话间任务；连续自动续跑 6 轮后不再自动唤醒。

## 会话信息面板

会话信息面板是 Claude 分页右侧的一列信息卡（对标官方的 session rail），汇总当前会话的环境、上下文、产物与改动。

- 入口：大屏/中屏右上角工具组第一颗「会话信息」按钮（「显示会话信息 / 隐藏会话信息」）；正文够宽时停靠在右侧，否则弹层显示。手机上没有这颗按钮；会话有拉取请求时，点分支胶囊旁的 PR 胶囊（`#编号`）也会弹出它。
- 卡片：
  - 「环境」：工作目录（「这台电脑」）、分支、是否 worktree；点工作目录打开工作台「文件」。
  - 「相关会话」：父/子/兄弟会话。
  - 「上下文」：上下文用量，「压缩」按钮（压缩会话可腾出上下文空间，本轮结束后才能压缩）。
  - 「连接器」：本会话可用的 MCP 连接器。
  - 「输出内容」：本会话产出的文件。
  - 「更改」：工作区改动统计；「打开改动」切到工作台「审阅」；「提交更改」让 Claude 自己提交并写提交说明（没有改动时不可用）。
  - 「拉取请求」：见「拉取请求（PR）卡」。
- 聊天快照访客没有这个面板。

## 输入框总览

Claude 输入框在新对话时居中显示（大输入框），进入会话后贴在底部。工具条布局：

- 左侧：「+」（附件与功能）、Research 芯片（开启时出现）、回复语气芯片（非 Normal 时出现）、权限模式芯片、用量环。
- 右侧：模型芯片、思考强度芯片、发送/停止键。
- 输入框上方可能出现：工作空间/分支胶囊（含 worktree 勾选）、临时对话提示带、已归档提示带、排队栏、工具审批卡、拦截换模型提示带。
- 发送键位：有物理键盘的电脑上 Enter 发送、Shift+Enter 换行；触屏上 Enter 换行，点按钮发送。两边都认 `Ctrl/⌘+Enter`（空闲时即发送，Claude 工作中为「稍后发送」）。
- 草稿：每个会话各存一份未发出的文字和附件，切会话、关窗口、杀 app 都不丢；最多保留最近 60 份，30 天没动的草稿自动清除。

接口：`chat.send`、`chat.wait`、`chat.stop`

## 选择模型

Claude 分页每个会话可单独选模型，当前可选模型：{{models}}

- 入口：输入框右侧的模型名芯片（素文字，无箭头）。
- 菜单：「Models」下是主力模型，当前项打 ✓；「More models」子菜单里是其余模型和自定义 API 模型（按服务分组，条目多时有「搜索模型」框）。
- 当前模型支持快速模式时，菜单底部有「Fast mode」小节和「Enable fast mode」开关，开启后芯片显示「· Fast」。
- 1M 上下文没有单独开关：支持的模型自动使用长上下文。成员能否用 1M、快速模式、Ultracode 由管理员的额度策略决定。
- 芯片带虚线下划线 = 会话实际用的模型和所选不同（例如安全机制自动回退到别的模型），悬停看原因；所选模型从下一轮起生效。
- 所选模型会记住，并作为新对话的默认。

接口：`chat.models`（能填进 `chat.send` 的 model 的全部 id）

## 思考强度与 Ultracode

Claude 的思考强度（Effort）决定它想多深、多慢、多耗额度。

- 入口：模型芯片右边的灰色档名芯片，点开是拉条面板（「Faster」↔「Smarter」），可拖动、点档位、方向键调，Esc 关闭。
- 档位：Low / Medium / High / Extra / Max。默认档随模型而定（多数为 High）。
- Ultracode：拉条下面的独立勾选项，和档位互不影响（任意档位都能开）——勾上后拉条变成紫色能量效果，输入栏的档名芯片也变紫（不另写「Ultracode」）。它在所选档位上加动态工作流，最彻底、最慢、最耗额度；只对当前会话生效，新会话不带。需要 设置 › Claude ›「对话」›「动态工作流」开着，否则勾选项置灰。成员可能被额度策略关掉 Ultracode（档位不变）。`chat.send` 用 `ultracode: true` 开。
- 芯片虚线下划线 = 实际生效档与所选不一致（悬停显示「已选 X，本会话实际生效 Y」）；勾了 Ultracode 但这一轮没真开（工作流被关 / 模型不支持）时芯片褪回灰色并带虚线。
- 自定义 API 模型使用该服务自己的档位表，表为空时芯片隐藏。

## 权限模式与计划模式

Claude 的权限模式决定它改文件、跑命令前要不要问你。

| 模式 | 说明 | 谁能用 |
|---|---|---|
| 手动 | 做出更改前始终先询问（菜单里带「默认」徽标） | 所有人 |
| 接受编辑 | 自动接受所有文件编辑 | 所有人 |
| 计划 | 先制定计划再动手 | 所有人 |
| 自动 | 由 Claude 处理权限决策（审核请求计入用量） | 仅管理员，且需「允许自动模式」开着（默认开） |
| 绕过权限 | 接受所有权限请求（红色警示） | 仅管理员，且需「允许绕过权限模式」开着（默认关） |

- 入口：输入框左侧权限模式芯片，快捷键 `Ctrl+Shift+M`；菜单里数字键 1–9 直选。窄屏只显示图标。
- 作用范围：会话里改只影响这个会话（菜单底注「只改这个会话」）；新对话草稿里改会记成这个文件夹的默认（计划模式不记）。新会话的全局默认在 设置 › Claude ›「新会话默认」›「权限模式」。
- 首次选「自动」会确认「启用自动模式？」；每个文件夹首次选「绕过权限」会确认「要绕过所有权限吗？」。会话中途切到绕过可能延到这一轮结束后生效。
- 计划模式：Claude 先只读调研、写出计划，消息流里出现计划卡，可以选中计划里的文字留「批注」，然后选「接受」「接受并允许编辑」「接受并进入自动模式」「接受并绕过权限」「清空上下文后执行」，或「修改」「拒绝」。结果显示「已批准 / 已退回修改 / 已拒绝」。「清空上下文后执行」需设置「批准计划时可清空上下文」开着。
- 输入框上没有独立的计划模式开关，计划就是权限模式里的「计划」。
- 允许绕过/自动的两个总开关在 设置 › Claude ›「安全」（仅管理员）。

## 「+」菜单：附件、Research、回复语气、输出风格

Claude 输入框左侧「+」（附件与功能）菜单的项目依次是：

- 「Add photos」：只选图片（手机上打开系统相册）。
- 「Add files」：任意文件。
- 「挂载文件夹」：把整个文件夹作为附件挂进来（按需读取）。

- 「回复语气」：内置 Normal / Learning / Concise / Explanatory / Formal，可「Create & edit styles」自建（名称最长 20 字、指令最长 4000 字）。自建语气只存在本设备上，不跨设备同步。
- 「输出风格 ›」：Claude Code 的输出风格，只改这个会话、下一条消息起生效；首项「跟随默认」。新会话默认在 设置 › Claude ›「新会话默认」›「输出风格」（默认 / 主动 / 简洁 / 讲解 / 学习）。

聊天快照访客看不到 Research 和输出风格。

## 附件：上传、粘贴、拖拽、挂载文件夹

Claude 的附件会上传到服务端（你的上传目录），Claude 按需读取。

- 大小：每个文件最多 20MB，超出提示「超过 20MB，暂不支持」。例外：桌面客户端且服务端就在本机时，非图片文件直接引用本机路径，不复制、不受 20MB 限制。
- 粘贴：`Ctrl+V` 粘贴截图或文件自动变成附件；粘贴文字时去掉格式。
- 拖拽（有鼠标）：把文件或文件夹拖到输入框（「拖到此处添加附件 · 文件夹会整个挂载」）。桌面客户端里文件夹零拷贝挂载（「本机引用 · 按需读取」），其他情况整棵目录上传。手机没有文件夹拖拽，用「挂载文件夹」。
- 从工作空间拿文件：在文件管理器里把文件拖进对话，或用文件菜单发给 Claude，原文件留在工作空间。
- 附件上传中发送键不可用；附件卡右上角 × 移除。
- 没有 @ 提及文件的补全，也没有语音输入。

接口：`files.write`、`chat.send`

## 斜杠命令

Claude 输入框支持 Claude Code 的斜杠命令和已安装技能。

- 用法：输入框整段内容是 `/` 加一个词时弹出命令菜单，↑↓ 选择，Enter 或 Tab 填入，Esc 关闭。
- 命令表来自服务端最近一次会话报告的可用命令（内置命令在前，插件技能在后，最多显示 40 条）；还没跑过任何一轮时菜单不出现。终端专用命令被隐藏。
- `/compact`：压缩会话，腾出上下文空间（用量面板里的「压缩会话」按钮也发它）。
- 新对话的大输入框占位文字是「Type / for skills」。

## 插话、稍后发送与停止

Claude 工作时输入框不锁定，可以插话或排队消息。

- 输入框为空时只显示停止键（「停止生成」）。
- 有内容时是分体按钮：主键「插话发送」（Enter），下拉里有「稍后发送」（`Ctrl/⌘+Enter`）和「停止」。
- 插话：Claude 做完手头这一步就读到，不打断任务。气泡标「插话 · 等 Claude 做完这一步就读」；Claude 卡在审批时提示要先批准才会读到。
- 稍后发送：消息进服务端队列，本轮结束后合并成一条发出；手机和电脑看到同一份队列，关掉页面也照发。
- 排队栏（输入框上方）：「{n} 条排队消息」「下一条：…」；每条可「立即发送」「放回输入框编辑」「移出队列」、拖动排序；「全部清除」。输入框为空时按 ↑（或工作中按 Esc）取回最后一条排队消息编辑。
- 聊天快照访客没有插话和排队。

接口：`chat.send`、`chat.stop`、`chat.pending`

## 输入建议（Tab 填入）

Claude 每轮回答完会预测你下一句可能说什么，输入框空着时以灰字显示。

- 填入：电脑按 Tab（键帽显示「Tab」），触屏点「填入」；填入后可修改，不会自动发送；Esc 收起。
- 开关：设置 › Claude ›「对话」›「输入建议」，默认开；每条建议多一次模型请求。
- 运行中、新对话、快照访客不显示。

## 用量环：上下文与套餐额度

Claude 输入框左侧的小圆环（「查看用量」）同时显示上下文用量和订阅额度。

- 上半「Context window」：已用 / 上限和分段计量条，展开看 MCP tools、Memory files、Custom agents 等占用；提示「距自动压缩还有 …」「即将自动压缩」。可拖动竖条调整自动压缩点（最低 100k，下条消息起生效）。「压缩会话」按钮手动压缩（运行中、离线时不可用）。
- 下半「Plan usage limits」：「5 小时上限」「每周 · 所有模型」及按模型的周额度，各带重置时间和百分比。
- 手机账户卡里也能看 5 小时额度 / 本周额度。
- 快照访客没有这个环。

接口：`usage`

## 回答区：思考、工具调用与消息操作

Claude 回答区按官方 Claude Code 的样式展示一轮里的思考、工具调用和正文。

- 思考：折叠按钮，生成中显示「Thinking」，结束后显示「想法」，点开看思考原文。
- 工具调用：连续的工具调用合成一组，运行中显示当前动作，结束后汇总成一行（如读了几个文件、跑了几条命令），失败部分标红；点开看每一步。对同一文件的连续读写合并成一行。
- 状态行（最后一条回复下方，生成中）：已用时间、token 数和提示（「思考中…」「运行工具中…」「等待你的回答…」「压缩会话中…」等）；遇到限流/过载显示「重试中（a/m）」。
- 回复操作（回复结束后）：「复制」、「重试」（以新一轮重发上一条用户消息和附件，Claude 忙时不可用）。
- 用户消息操作：回滚图标（「回滚到这条消息之前」），可选「文件+对话」或「仅文件」，把文件改动和/或对话退回到这条消息之前。快照访客没有。
- 长对话先显示最近 20 条，「查看更早的 {n} 条消息」每次加载 60 条。
- 没有编辑已发消息、点赞点踩、在消息处分叉的按钮。
- 回答里写到的文件路径可点击，在应用内预览。

接口：`sessions.read`、`chat.wait`

## 提问表单与工具审批卡

Claude 需要你做决定时会停下来等：提问表单出现在消息流里，工具审批卡贴在输入框上方。

### 提问表单（Claude 主动提问）

- 编号选项按钮（单选或多选），外加自由输入框「Something else」。
- 按钮「Skip」和「提交回答」（每个问题都答了才能提交）。答完变只读并留在历史里；跳过显示「已跳过」。
- 无人回答时的行为在 设置 › Claude ›「对话」›「Claude 提问无人回答时」：一直等 / 5 / 10 / 30 分钟后继续。

### 工具审批卡（权限请求）

- 标题「允许 Claude …？」，带命令、文件 diff（最多显示 40 行）、网址或 MCP 调用内容的预览；多个请求排队时显示「+N」。
- 按钮：「拒绝」（Esc）、「始终允许」（写进这个项目的设置）或「本会话都允许」（`Ctrl+Shift+Enter`）、「允许一次」（主按钮，`Ctrl+Enter`）；下拉里可选「允许，并切换到自动模式」（自动模式可用时）。
- 安全规则：在沙箱外运行的命令要把整条命令滚动看完才能允许；高风险请求默认焦点在「拒绝」且禁用快捷键；卡片刚出现的 0.4 秒内按 Enter 无效。
- 子 agent 发起的请求、计划模式下的请求会在卡上注明。
- 通知：等待审批或提问时会发系统通知（「Claude 需要你批准」「计划等你审批」），开关在 设置 › Claude ›「通知」。
- 快照访客没有审批卡（快照里固定为手动模式且无命令行）。

接口：`chat.pending`、`chat.answer`

## 工作流面板与子 agent

Claude 并行派出子 agent 或运行动态工作流（Workflow）时，回答区和工作台「任务」会显示每个子任务的状态。

- 子 agent：工具组里显示为一行（「Running agent」/「Ran agent」），点开在工作台「任务」里看它的完整子转录。
- 工作流卡：显示工作流名称、状态（「Starting workflow」/「Workflow · Completed|Failed|Stopped · {n} agents · 时长」）、每个 agent 的状态点阵和失败原因；结束后卡片保留。点卡片在工作台「任务」里打开该工作流。
- 动态工作流需 设置 › Claude ›「对话」›「动态工作流」开着（仅有命令行的身份），开着才能用 Ultracode；「子 agent 调度偏好」随之出现。
- 子 agent 选模型：bridge 按随版本发布的模型性价比快照（智力指数 + 每任务成本），把这个会话能派的模型排成「最难 / 难 / 常规 / 机械」四档，每档给 Claude 一个首选和一个备选；官方订阅会话里 Claude 模型按订阅等效成本算，第三方和自定义 API 按官方 API 价算。配了但快照里没有的模型标「未评分」，只在你点名时用。动态工作流里 Claude 可以直接写 `auto:top` / `auto:hard` / `auto:normal` / `auto:light`，请求时自动换成那一档的首选；工作流卡显示实际用的模型，如「Opus 5.5（自动·难）」。
- 后台任务芯片：最后一轮状态行旁显示「{n} 个后台命令运行中」「{n} 个子 agent运行中」「{n} 个工作流运行中」等，点开工作台「任务」。

## 限额卡与重置后自动继续

Claude 撞上订阅用量限额时，回答区出现限额卡，并可在额度重置后自动接着干。

- 标题：「已达到 5 小时限额」「已达到每周限额」「已达到 {model} 限额」等，并写明重置时间。
- 「限额重置后自动继续」勾选框：只对 5 小时限额、只在最后一条消息上出现。勾上后显示「将于 … 自动继续」，到点由服务端发「请从中断的地方继续」——手机锁屏、页面关掉也照常继续。每个限额窗口最多尝试 3 次，重置后超过 6 小时放弃；你先发了别的消息就取消。
- 「查看详情」看原始报错，「重试」手动重发。
- 默认值：设置 › Claude ›「撞上限额时」›「限额重置后自动继续」。同组还有「额度用尽自动换号」（需号池有多个账号，可再开「额度恢复后回到首选号」「会话中无缝换号」）。
- 被安全机制拦下的回复：开着「消息被拦时自动换模型」时自动换模型重试，输入框上方显示「Switched to …」提示带，可「Edit prompt and retry」用原模型改了再试；关着时显示「Session paused」卡，手动选择换模型或改提示词。

## 断线续传与后台任务

Claude 的每一轮都在服务端执行，与界面是否在线无关。

- 切会话、刷新、断网、杀掉 app，这一轮继续跑；回来时自动接上：还在跑就续上流式输出，已结束就回放完整结果。
- 重连期间状态行显示「重连中…」。
- 切会话、冷启动、从后台切回来时，界面先摆出缓存的对话，但最后一轮在不在跑要等服务端确认：确认之前最后一条回复下不出「复制」「重试」，状态行显示「正在同步状态…」（离线时是「连不上服务器，这一轮的状态暂时未知」），发送键换成缓冲圈、暂不放行（真在跑时贸然发出会顶掉在跑的那轮）。局域网下几百毫秒就确认完，基本看不到；网络慢时会多停一会儿。不会再出现「明明在跑却显示已结束」。
- 后台命令、子 agent、工作流在这一轮结束后可继续运行，在工作台「任务」里看；模型已停笔、只等后台任务时，输入框照常可发。
- 同一会话在别处打开着续聊时会提示「这个会话正在别处打开，请先关掉再续聊」。
- 服务本身中途退出（崩溃、被结束、电脑重启）时，这一轮末尾会留一句「这一轮没跑完」。开着设置 › Claude ›「服务意外重启时」›「自动继续被中断的对话」（默认开）时，服务恢复后约 15 秒由服务端替你发一句「请从中断的地方继续」，正看着这个会话的设备会弹「服务刚才意外重启，正在继续会话」并接上直播；手机锁屏、页面关着也照常续。同一件事连续自动继续最多 3 次（你发一条新消息即清零），中断超过 12 小时、你已经先发了消息、或会话正在别处打开时不自动发——这时说一句「继续」即可。
- 任务完成时可发系统通知（设置 › Claude ›「通知」›「任务完成」；手机需在系统设置里允许后台运行）。

接口：`chat.wait`（被中断时 status=interrupted，排上自动继续时会等它开跑）、`chat.pending`、`overview`（claude.interrupted 列出被中断、还没人看过的会话）；「自动继续被中断的对话」开关用 `settings.claude` / `settings.claude_set`（键 autoResumeOnRestart）

## 右侧工作台总览

工作台是 Claude 分页右侧（手机为底部面板）的工具区，有五个工具，都跟随当前会话的工作目录。

| 工具 | 作用 | 快捷键（大屏） | 谁能用 |
|---|---|---|---|
| 终端 | 工作目录里的命令行，与 Claude 共用同一个终端 | ``Ctrl+` `` | 有命令行的身份（管理员、完全信任成员） |
| 审阅 | git 改动列表与 diff | `Ctrl+Shift+G` | 所有人 |
| 浏览器 | 与 Claude 共用的浏览器，实时看它操作 | `Ctrl+Shift+B` | 有命令行的身份；快照访客只读观看 |
| 文件 | 工作目录的文件管理器与预览 | `Ctrl+Shift+E` | 所有人 |
| 任务 | 本会话的后台任务、子 agent、工作流 | 无 | 所有人 |

- 大屏/中屏打开：右上角工具开关「终端」「审阅」「浏览器」，「更多」（⋮）里有「文件」「任务」。每个工具是一张卡，卡头有「放大铺满 / 还原」和「关闭」；拖左缘调宽度，双击复原。大屏单屏时可同时开多张卡（左列终端/审阅/任务，右列浏览器/文件）；分屏、中屏一次只显示一张。
- 手机打开：顶栏胶囊里「工作台」按钮，底部面板顶上是工具切换条（任务 / 审阅 / 终端 / 浏览器 / 文件，没权限的隐藏），点遮罩或下拉关闭。Claude 用了浏览器或终端时按钮上有提示点。
- 其他入口：输入框上方工作空间胶囊 → 「文件」；分支胶囊（「分支 · 点开审阅变更」）→「审阅」；后台任务芯片、工作流卡 →「任务」；文件卡 →「文件」。
- Claude 使用浏览器或终端时，窗口宽度 ≥1024px 且工作台关着会自动打开（分屏时不自动开，改为按钮上的呼吸点）。
- 快捷键只在 Claude 分页内有效。

接口：`ui.view`、`ui.open`

## 工作台：终端

工作台「终端」是会话工作目录里的真实命令行，Claude 跑的命令也在同一个终端里，你能看到并接着操作。

- 只有有命令行的身份能用（管理员、完全信任成员）；普通成员和快照访客没有，服务端会拒绝。
- 运行位置菜单：「服务器」（工作空间，Claude 的命令也在这里跑），或你的某台在线电脑（「我的电脑」，需新版桌面客户端在线）；选择按浏览器记住。
- 「重启终端」重开；断线自动重连且不丢回滚内容。手机上有快捷键行（Ctrl+C、Tab、Esc、方向键）。

接口：`devices.run`

## 工作台：浏览器

工作台「浏览器」与 Claude 的浏览器工具是同一个浏览器实例：Claude 打开网页、点击、输入时你实时看到，也可以自己操作（登录网站后 Claude 就能用这份登录状态）。

- 控件：后退、前进、刷新、地址栏（「输入网址」）、标签页（「新建标签」）。
- 视口菜单：「桌面 / 平板 / 手机」预设或自定义尺寸（200–4000），横竖屏、触屏仿真、配色（跟随 / 深色 / 浅色），「关闭浏览器」。手机上有「键盘」按钮手动弹键盘。
- 管理员在桌面客户端里看到的是嵌在窗口里的原生浏览器（用客户端的持久登录状态）；其他情况（手机、网页远程、Docker / Linux 服务器、成员）是服务端的无头浏览器画面直播。
- 登录状态会保留：无头浏览器也用持久配置档，同一个人的所有会话、所有项目共用一份登录（Cookie），关掉浏览器、闲置回收、服务重启后都还在；每人一份互不相通（管理员的在服务端数据目录，成员的在他自己的目录里，删号随之删除）。快照访客仍是用完即弃的临时配置。
- 需要你在浏览器里登录或过验证时，Claude 会先看你此刻能不能看到浏览器（工作台「浏览器」开没开着）；都没开着时它会请你先打开再动手。它不会替你登出或改账号凭据。
- 限制：普通成员没有浏览器；成员的浏览器是服务端无头浏览器，不进管理员的桌面客户端；快照访客只能「只读直播」。

## 工作台：审阅、文件、任务

工作台的「审阅」「文件」「任务」三个工具所有人都能用。

- 审阅：当前工作目录的 git 改动列表（新增 / 删除 / 改名 / 未跟踪），点一行看统一 diff；大文件默认折叠；二进制文件不显示 diff。不是 git 仓库时提示「该工作空间不是 git 仓库」，没改动时「工作树很干净，没有改动」。
- 文件：在工作台里嵌入工作空间文件管理器，起点是会话工作目录；有鼠标的侧列是资源管理器式界面，手机/触屏是列表式界面。可预览图片、视频、音频、PDF、Markdown、Office、HTML、文本代码。
- 任务：本会话的后台任务列表（分 Running / Finished），子 agent 和工作流里的 agent 可点开看子转录（「返回任务列表」回来）。一轮挂起等后台任务时顶部显示「本轮挂起中 · 等待 …」和「结束等待」按钮，此时可单独停止某个任务。

接口：`files.list`、`files.read`、`files.search`

## 拉取请求（PR）卡

拉取请求卡显示当前会话分支在 GitHub 上的 PR 状态，并能直接合并、修 CI、同步基线。只对主机管理员显示，且项目要是 GitHub 仓库、服务端装好并登录 GitHub CLI（`gh`）。

- 入口：会话信息面板里的「拉取请求」卡；分支胶囊旁的 PR 胶囊（`#编号` 加状态点）点开即跳到它。快照里没有。
- 显示：PR 编号、标题、状态；CI 状态（「检查失败 / 检查通过 / 检查运行中 / 尚未上报任何检查」等，展开看每项检查并链到 GitHub）；「合并冲突」「落后于基线分支」标签；审查状态（「已批准 / 需修改 / 待审查」）；从父会话继承的标「继承自父会话」。
- 操作：「标为可审查」「合并」（选「压缩合并 / 合并提交 / 变基合并」后「确认合并」）、「重跑失败的检查」、「同步基线」（在服务端 fetch 并合并基线、不推送，有冲突交给 Claude 解决）、「转为草稿」「移出」。
- 还没有 PR 时：「创建拉取请求」「创建草稿拉取请求」（让 Claude 执行创建）、「在 GitHub 上手动创建」、「跟踪已有的拉取请求…」。
- 开关：「就绪后自动合并」（仓库不支持 GitHub 自动合并时由 bridge 代为合并，需服务端在线）、「自动修复」（CI 失败、冲突、新评审时自动唤醒 Claude 处理；连续多次或当天次数到上限会暂停，可「恢复自动修复」）、「合并或关闭后自动归档」。
- 相关设置：设置 › Claude ›「Git 与拉取请求」：「分支前缀」「工作树起点」「自动修复拉取请求」「拉取请求合并或关闭后自动归档」「提交与拉取请求署名」。
- GitHub 未就绪时卡片提示「未安装 GitHub CLI（gh）」「请运行 gh auth login 登录」等。

## 公开聊天快照

公开聊天快照是一个可以公开访问的临时 Claude 对话空间，链接形如 `/c/<令牌>`，拿到链接的人都能和 Claude 聊。

- 创建：目前只能通过 QQ 群机器人（群里 @机器人 发 `/chat`）生成；主界面里没有创建快照的按钮。铸快照的账号需要管理员授予权限，每个账号最多同时 10 个有效快照，所有快照合计最多同时跑 4 轮。
- 访客能做：在简化的 Claude 页面里继续对话（没有侧栏、会话列表、设置），可选模型和思考强度；多个访客实时看到彼此的消息。工作台只有审阅、文件（锁在快照自己的目录）和只读浏览器直播；没有终端。
- 访客没有：回滚、工具审批卡（固定手动模式）、排队与插话、会话信息面板、交互图表、Research、输出风格。
- 结束：超过 1 小时没有新消息自动销毁（目录删除）；Claude 判断内容恶意时可关停快照；管理员停用铸快照的账号也会让它失效。创建者没有手动撤销按钮。
- 额度记在铸快照的账号上。
- 另有「只读分享链接」（`/w/<令牌>`）用于分享文件，入口在工作空间文件菜单「分享链接…」，不属于 Claude 分页。

## 模型服务（自定义 API）

模型服务让 Claude 分页接入你自己的模型接口（如 DeepSeek、Kimi、GLM、百炼、OpenRouter、本机 Ollama 等），与订阅模型并列在模型菜单里。

- 谁能用：主机管理员和能用 Claude 的成员（普通档、完全信任档都算）各管各的一份，互相看不到；聊天快照访客和分享链接没有。
- 成员自带 Key：成员接的服务只有他自己能用，API Key 加密存在服务器上、不显示给任何人，费用走他自己的账户、不占用本站额度（自定义 API 的轮不计入管理员给他设的额度）；接口地址只能是公网地址（不能接本机或局域网服务，没有「本机模型」预设）；最多 10 个服务。面板顶部写着这些说明。
- 入口：设置 › Claude ›「模型服务」›「自定义 API」（显示「{p} 个服务 · {m} 个模型」）。手机/网页在设置的「Agent › Claude」页，桌面客户端在设置侧栏「Claude」。点开是「模型服务」管理器：大屏为居中弹窗，手机为全屏页。
- 添加：「＋ 添加服务」，从预设（Anthropic API、DeepSeek、Kimi · Moonshot、智谱 GLM、阿里云百炼、MiniMax、小米 MiMo、OpenRouter、硅基流动、OpenAI、本机模型）选，或「从头配置」。成员的预设里没有「本机模型」。
- 编辑器分节：
  - 「连接」：名称、接口协议（Anthropic 或 OpenAI 兼容，后者由 bridge 转换）、接口地址（「检测连接」自动探测）、API Key（加密保存在服务端，不发给手机或网页）、鉴权方式、请求头、超时、失败重试、是否走出站代理（部署方声明强制走代理时——环境变量 BRIDGE_PROXY_FORCED=1 或 config.json 的 proxyForced——没有这个开关，一律走代理）。
  - 「模型」：「从服务拉取」或「手动添加」；设默认模型、设小任务模型；每个模型的显示名、上下文窗口、输出上限、是否支持图片、思考档位；「探测能力」。
  - 「调用参数」「兼容」：提示缓存、去掉 beta 请求头、精简请求、去掉历史思考块等兼容选项。
  - 「测试与日志」：「发送测试」、「最近请求」、「删除服务」。
- 服务卡上：「显示在模型列表」眼睛开关（只影响菜单）、启用开关（关掉后用它的会话会报已停用）、「缺 Key」等标签。
- 使用：在输入框模型菜单「More models」里按服务分组选择；选中后作用于当前会话并成为新对话默认。
- 接口：`chat.models` 列出这个身份能选的订阅模型和自定义模型（id 形如 `custom:<服务>:<模型>`，填进 `chat.send` 的 model）；看不到 Key。接新服务、填 Key、改服务配置只能在这个面板里做，接口不提供。

## 成员与访客在 Claude 分页的差异

Claude 分页对不同身份开放的功能不同，指路前先确认对方身份。

| 功能 | 管理员 | 完全信任成员 | 普通成员 | 快照访客 |
|---|---|---|---|---|
| 命令行（Bash 等）与工作台终端 | 有 | 有 | 无 | 无 |
| 工作台浏览器 | 有（桌面客户端里为原生视图） | 有（服务端无头） | 无 | 只读直播 |
| 项目位置 | 本机任意目录 | 自己目录内 | 自己目录内 | 快照目录 |
| 权限模式 | 五种（自动/绕过受总开关控制） | 手动 / 接受编辑 / 计划 | 手动 / 接受编辑 / 计划 | 固定手动 |
| worktree 会话 | 有 | 有 | 有 | 无 |
| 「动态工作流」设置开关 | 有 | 有 | 无（只随 Ultracode 档启用，受额度策略限制） | 无 |
| 拉取请求卡 | 有 | 无 | 无 | 无 |
| 自定义 API 模型 | 有 | 有（自带 Key，只许公网地址） | 有（自带 Key，只许公网地址） | 无 |
| 1M 上下文、快速模式、Ultracode | 有 | 按额度策略 | 按额度策略 | 不含 Ultracode |
| 额度 | 不受限 | 按策略计在本人名下 | 按策略计在本人名下 | 计在铸快照的账号 |

- 管理员默认看不到成员的对话内容；成员允许后，管理员可在服务端控制台「会话 / 续聊」里查看或代发（代发的消息标「【管理员代发】」）。

接口：`whoami`
