# 设置

本章按分区列出 Muse Bridge 设置里每一项的作用和谁看得到。设置在电脑上是居中对话框（左栏搜索 + 分区列表），在手机上是整页、点分区从右侧推入。

## 怎么打开设置

- 侧栏最底下的账户卡 →「设置」；主页右上账户胶囊里也有「设置」。dimensio 侧栏底部的设置直接打开 dimensio 分区。
- 电脑上左上的「搜索」能按名字或关键词搜设置项（界面是英文时用英文搜），点结果跳过去并闪一下那一行；按 Esc 或点背景关闭。
- 手机上最上面是账户卡（点进去是「账户」），下面是各分区，左上角返回。
- 「通用」里的设置只存在当前这个浏览器 / 设备里，换设备要重新设；Claude 的设置按账号存在服务器上、多设备同步（标「本设备」的除外）。

接口：`ui.open`（`page: settings`，可带 `section`）

## 分区一览

| 分区 | 谁能看到 | `ui.open` 的 section |
|---|---|---|
| 「通用」 | 所有人 | `general` |
| 「账户」 | 所有人（内容按身份不同） | `account` |
| 「Agent」 | 只有管理员 | `agents` |
| 「Claude」 | 能用 Claude 的人 | `claude` |
| 「模型服务」 | 只有管理员 | `providers` |
| 「Agent 接入」 | 登录了的人 | `agentapi` |
| 「连接」 | 所有人（控制台入口只有管理员有） | `connection` |
| 「dimensio」 | 能用 dimensio 的人 | `dimensio` |
| 「安卓 app」 | 所有人 | `android` |
| 「反馈」 | 登录了的人 | `feedback` |
| 「关于」 | 所有人 | `about` |
| 「自定义」分组：技能 / 连接器 / 插件 | 只有管理员 | — |

## 通用

- 「外观 › 主题」：跟随系统 / 浅色 / 深色，默认深色；只管 Claude 页和主页，dimensio 的明暗在 dimensio 分区单独设。
- 「语言」：简体中文 / English，没设过时跟浏览器语言；改了页面会重新加载。地址加 `?lang=en` 可临时看英文。
- 「通知 › 任务通知」：总开关，默认开。浏览器不会自动问权限：收不到通知就关掉再打开一次，浏览器询问时选允许（已知问题）。
- 「思考动画」：Claude 回复时那个动态标记的样式。
- 「图片 › 原图加载」：开了看图直接加载原图（费流量）。

## 账户

- 「个人资料」：用户名、身份（管理员 / Pro 用户 / 普通用户）。
- 「用量」：共享 Claude 订阅的 5 小时窗口和本周用量、多久后重置。大家共用这一份。
- 「我的额度」（注册账号）：今天和最近 7 天跑了几轮、花了多少，有上限时显示「已用 / 上限」。
- 「密码」（注册账号）：改密码；改完别的设备要重新登录，名下的 agent 密钥也全部失效。
- 「工作空间」→「文件与分享」→ 打开文件管理器；手机上还有「登录网页版」（扫码帮电脑登录）。
- 「退出登录」：只退出这台设备。

## Agent（只有管理员）

- 每个 agent（Claude Code、dimensio）一个「启用」开关；关掉后所有人都看不到这个页面。只剩一个开着时，打开网址直接就是那一页。
- 状态：可用 / 还没配认证（Claude 没配令牌时有「去配置」直达服务端控制台「Claude 账号」；dimensio 没配任何 key）/ 这台机器上没装（让 Muse 跑 `set-agents claude,dimensio` 加装）。

## Claude

Claude Code 的设置，按账号保存。标「只有管理员」「有命令行」的项其他身份看不到。各项含义见 claude 章「Claude 设置项一览」。

- 「撞上限额时」：「限额重置后自动继续」。
- 「新会话默认」：「权限模式」、「输出风格」、「新对话落点」。
- 「对话」：「输入建议」、「对话内交互图表」、「动态工作流」（有命令行）与「子 agent 调度偏好」、「消息被拦时自动换模型」、「批准计划时可清空上下文」、「Claude 提问无人回答时」、「回复语言」、「自动压缩点」。
- 「会话协作」：「Claude 发起新会话」（有命令行）。
- 「Git 与拉取请求」（有命令行）：「分支前缀」、「工作树起点」、「自动修复拉取请求」、「拉取请求合并或关闭后自动归档」、「提交与拉取请求署名」。
- 「会话管理」：「归档不活跃的会话」。
- 「通知」（本设备）：「权限请求」「提问」「任务完成」。
- 「安全」（只有管理员）：「允许绕过权限模式」（打开前要确认）、「允许自动模式」。

## 模型服务（只有管理员）

- 给 Claude Code 接自定义模型接口（Anthropic 兼容或 OpenAI 兼容）：「＋ 添加服务」、填接口地址与 API Key（加密保存）、拉取或手动添加模型、「发送测试」；每个服务可启用 / 停用、控制是否显示在模型列表。
- 接好的模型出现在 Claude 输入框模型菜单的「More models」里。
- 在 Muse 上先让 Muse 跑 `allow-sites <接口地址>` 放行，再在审核卡上选「总是允许此站点」。
- dimensio 的厂商与 key 不在这里，在 dimensio 分区和 dimensio 页的模型胶囊里。

## Agent 接入：给外部 agent 的密钥

「Agent 接入」管理 agent 密钥：别的 agent（包括部署它的 Muse、Claude Code、脚本等）拿着它直接调用这台 Muse Bridge 的接口（读项目手册、给 Claude 派活、管文件和定时任务、看谁在跑），不用开浏览器模拟点击。每个登录身份都有，各管各的。

- 「地址」：「Agent 入口」（`…/agent`，复制给 agent 当起点）与「项目手册」（`…/agent/manual`，可打开、可复制）。
- 「生成密钥」：填一个名字（如「我的 Muse」）点「生成」。明文密钥（`bak_` 开头）只在这一刻显示一次，旁边有「复制给 agent 的说明」（地址 + 密钥 + 怎么开始，直接粘给 agent）、「复制密钥」、「我已保存好」；离开这一页就再也看不到。
- 「密钥」列表：名字、创建时间、最近使用、到期时间；「吊销」点两下确认，吊销后用它的 agent 立刻失去访问。
- 规则：密钥等同你的登录，能做你能做的一切；每把 90 天后过期；每人最多 20 把；注册账号改密码、管理员重置访问令牌会让名下全部密钥立即失效。接口怎么调见 api 章。
- 接口：`keys.list`、`keys.revoke`（接口不能生成新密钥）。

## 连接

- 「这台设备」：「服务器地址」、「连接状态」（在线 / 离线）。
- 「管理」（只有管理员）：「服务端控制台」→「打开」，见 accounts 章。
- 公网地址、隧道、域名不在这里改，由 Muse 用 `bootstrap.sh` 管。

## dimensio

能用 dimensio 的人才有这一节。改了 API Key、权限规则、工作空间之后，点「访问范围」下面的「保存」才生效；「显示」里的两项改了立即生效。

- 「模型服务」：当前厂商和型号、是否已配 key、API Key 输入框（在 Muse 上内置厂商的 key 优先让 Muse 用 `set-api-key` 写进服务器）。
- 「记忆」›「记忆管理」。
- 「权限规则」：「每次问我」「从不允许」。
- 「工作空间」：「默认工作空间」与「访问范围」（注册账号看不到访问范围）。
- 「显示」：「dimensio 外观」、「显示全部工作过程」。
- 「诊断」：导出当前对话的诊断包。

## 安卓 app

- 在浏览器里：「下载 apk」、安卓手机上的「在 app 里打开」（自动填好地址）、GitHub 发布页；电脑上显示下载二维码；iPhone 上提示用 Safari 添加到主屏幕。
- 在 app 里：app 版本；「服务器地址」→「更换」；服务器上有新版 app 时出现下载按钮。
- app 是在线 WebView 壳：界面跟服务器走，新功能不用更新 app。

## 反馈

- 「报告问题或提建议」→「报告」：选「出问题了」/「功能建议」/「安全问题」，写一句发生了什么，点「发送」。不用 GitHub 账号；会自动附上版本、服务状态、程序自己的报错位置和出错前几步操作，不含对话、文件、key 和地址；「查看会发送的内容」可先看全文。
- 普通问题提交到项目公开的 GitHub Issues（别人报过同一个问题会变成 +1）；安全问题私下发给维护者。
- 「出错时自动发送错误报告」（只有管理员能改）：服务崩溃、接口出错、更新失败时自动发，同一个错误每个版本只报一次。
- 「发过的报告」：发过的报告和对应的 GitHub 编号。

## 关于
