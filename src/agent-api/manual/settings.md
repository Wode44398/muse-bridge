# 设置

设置页有两套外观：Windows 桌面客户端里是 macOS 风的「侧栏 + 分区」，手机 app 和浏览器（含电脑浏览器）里是 iOS 风的「逐级推入」页面；两套读写同一份数据。本章按分区列出每一项的作用、在哪一套里出现、谁看得到。

## 怎么打开设置、两套外观的区别

设置从 Claude 页侧栏底部的账户卡菜单「设置」打开（菜单里还有「关于与更新」直达关于页）；桌面客户端主页、命令面板里也有入口。对话里的提示条（如「去设置」链接）会直达对应分区。

- 桌面客户端（Windows）：左侧栏顶部是「搜索」框（按名称和关键词搜任意设置项，点结果跳过去并高亮那一行）和账户行，下面是分区：「通用」「外观」「快捷键」｜各 agent（Claude 等）与「Agent 接入」｜「扩展」「额度与注册」「设备」「壁纸」｜插件的控制面板（装了带面板的插件才有，一个插件一行）｜「连接与更新」「反馈」。顶部有前进/后退按钮。
- 手机 app / 浏览器：根页从上到下是账户卡、「Agent」组（每个 agent 一行，末尾是「Agent 接入」）、「插件」组（插件的控制面板，一个插件一行；没有时不出现）、「服务器」组（扩展、额度与注册、服务端控制台；只有管理员看得到）、「偏好」组（通用、外观、壁纸、流体壁纸）、「这台设备」组（手机操控、设备）、「软件更新」（只在安卓 app）、「提交反馈」、「关于」。点行推入子页，左上返回或侧滑返回。
- 有插件可以更新时，「扩展」那一行带「{n} 个插件有更新」（桌面侧栏是角标）。
- 在 设置 › 扩展 › 功能扩展 里关掉的内置功能，对应的设置入口一起消失：如关了「自定义壁纸」没有「壁纸」，关了「设备」没有「设备」，关了「反馈」没有「提交反馈 / 反馈」，关了「给 agent 的接口」没有「Agent 接入」。
- 手机 / 网页主页右上角的账户胶囊点开是账户卡，卡上也有「设置」按钮。
- 单 agent 模式（对你只开了一个 agent——Claude 或 dimensio——app 直接落在那一页、没有主页）：壁纸、流体壁纸、「分页跟随主页明暗」不出现。只开 dimensio 时 bridge 的设置从 dimensio 侧栏底部账户行的菜单进（dimensio 自己的设置面板照旧在它页面里）。
- 带「这台设备」小标签的项只存在当前设备上，其余随账号同步到所有设备。项名旁的小圆点表示「已改过默认值」，可点「恢复默认」。

## 账户

账户区是登录状态入口：没登录时就是登录页，登录后显示身份、用量和账号操作。

- 入口：桌面客户端侧栏顶部账户行；手机/网页根页顶部账户卡。
- 没登录：账号密码登录（下方有「最近登录」可快速选账号）、「扫码登录」（电脑上出码给手机扫）、「注册新账号」（需要邀请码，服务器关注册时不出现）、「用访问令牌登录」（管理员）。详见「账号与管理」章。
- 登录后：身份标签（管理员 / 完全信任用户 / 普通用户）；用量（当前会话 5 小时 / 本周，或桌面的「订阅额度」）；注册用户另有「我的额度」（每天/最近 7 天的轮数与花费等，「不限」表示没设上限）和「管理员可见性」三个开关及「管理员的访问记录」；「工作空间」入口；注册用户可「修改密码」；手机形态有「扫一扫 · 登录网页版」；底部「切换账号」「退出登录」（只退出这台设备）。

## 通用

通用分区放与具体 agent 无关的基础偏好。

- 「通知」：系统通知总开关（关掉后各类提醒都不弹）。
- 「语言」/「界面语言」：简体中文或 English，切换后整个界面（含手机通知、悬浮胶囊、桌面托盘）跟着变。
- 「原图加载」：图片与媒体按原图加载（耗流量）。
- 「开机自动启动」：只在桌面客户端。
- 「后台运行」：只在安卓 app，让 app 不受系统省电限制，后台也能收到任务进度与完成通知。

## 外观、壁纸与流体壁纸

外观类设置只影响界面显示。

- 「外观」：明亮 / 深色；手机用「跟随系统明暗」开关，桌面三选一（明亮 / 深色 / 跟随系统）。「分页跟随主页明暗」：各分页跟主页同一套明暗（单 agent 模式没有）。「禁用系统转场动画」/「禁用转场动画」。
- 「壁纸」（单 agent 模式没有）：明亮、深色两套主题各选一张壁纸，可「相册上传」自定义图片；手机上长按自己上传的壁纸可删除；点上方预览进入实景舞台边看边换。上传时同时选中原图和它的深度图（文件名带 depth）可开「空间壁纸」（随视角产生景深，电脑跟指针、手机跟重力），并调「景深运动幅度」。
- 「流体壁纸」：流体动态壁纸的颜色与模拟参数滑杆，可恢复默认；只在对应玻璃模式下出现。
- 「思考动画」：Claude 工作时的动画样式，只在有多套可选时出现，存这台设备。

## 快捷键（桌面客户端）

快捷键分区只在 Windows 桌面客户端里有，设置系统级全局快捷键。

- 「呼出」组：「快速提问」（任意时刻呼出输入条，打完直接进会话，回答就地浮出，默认 Ctrl+Shift+Space）。
- 「导航」组：「显示 / 隐藏主窗」（默认 Ctrl+Alt+B）、「跳到在等你回答的那一轮」（多个在等时逐个轮换，默认 Ctrl+Alt+Q）、「新建会话」（默认 Ctrl+Alt+N）。
- 「急停」组：「本机 Agent 急停」（默认 Ctrl+Alt+Shift+F11）、「远程被控急停」（默认 Ctrl+Alt+Shift+F12），都是切断 agent 对这台电脑的操作；组合刻意设得难按。
- 点键位录新组合，按 Backspace 关掉这一条；冲突或注册失败会标红说明；「全部恢复默认」。

## Agent 分区：开关与认证

每个 agent（Claude、Gemini · Vertex、ChatGPT · Codex、dimensio）在设置里各有一页，页首是它的开关与认证状态。

- 入口：桌面侧栏中间一组；手机根页「Agent」组。行尾显示状态（不可用 / 关闭 / 未认证，Claude 有号池时显示当前号）。
- 「启用 {名称}」：这个 agent 的全服总开关，即时生效；关最后一个开着的 agent 前会确认。只有管理员能改，其他人看到「只有管理员能改这里」。
- 页首状态文字：可用 / 可用 · 仅管理员 / 关闭 / 还没配认证 / 这台机器上不可用；没认证时给出提示（Claude：在「订阅号池」里添加账号；Gemini：在服务器配置里填 API Key 或 Vertex 凭据；Codex：在服务器上运行一次 codex login；dimensio：在它的配置里填一家模型厂商的 API key）。
- 在「扩展 › 功能扩展」里卸掉或关掉的 agent 不列出；Claude 是核心，始终列出。

## Agent 接入：给外部 agent 的密钥

「Agent 接入」分区管理 agent 密钥：别的 agent（Claude Code、Codex、脚本等）拿着它直接调用这台 bridge 的接口（读项目手册、给 Claude 派活、管文件和定时任务），不用开浏览器模拟点击。每个登录身份都有，各管各的。

- 入口：手机 / 网页 设置根页「Agent」组末尾；桌面客户端侧栏 agent 那一组末尾；设置搜索「agent / 接口 / API / 密钥 / 手册」也能直达。
- 「地址」：「Agent 入口」（`…/agent`，复制给 agent 当起点）与「项目手册」（`…/agent/manual`，可打开、可复制）。
- 「生成密钥」：填一个名字（如「家里的 Codex」）点「生成」。明文密钥（`bak_` 开头）只在这一刻显示一次，旁边有「复制给 agent 的说明」（地址 + 密钥 + 怎么开始，直接粘给 agent）、「复制密钥」、「我已保存好」；离开这一页就再也看不到。
- 「密钥」列表：名字、创建时间、最近使用、到期时间；「吊销」点两下确认，吊销后用它的 agent 立刻失去访问。
- 规则：密钥等同你的登录，能做你能做的一切；每把 90 天后过期；每人最多 20 把；成员改密码、管理员换访问令牌会让名下全部密钥立即失效。接口怎么调见 api 章。
- 接口：`keys.list`、`keys.revoke`（接口不能生成新密钥）。

## Claude 设置页：号池、模型服务与限额

Claude 页最上面是模型来源和限额相关设置（主要给管理员）。

- 「Claude Code 运行组件」状态卡（只管理员看到）：首次使用时服务端从官方源下载运行组件，显示下载进度；失败给原因与「重试」；就绪时不显示。
- 「订阅号池」（只管理员）：列出号池里的 Claude 订阅账号，每个显示套餐（Max / Pro）、「使用中」标记和 5 小时 / 每周 / Fable 额度用量与重置时间；右上刷新用量。可「添加账号」、点账号进去「切到此号」「编辑账号」、调整「顺序」、「删除账号」。详见「账号与管理」章的号池一节。
- 「模型服务」›「自定义 API」（管理员与能用 Claude 的成员各一份）：接入第三方模型服务（Anthropic 或 OpenAI 兼容），在模型列表里显示更多模型；点开是单独的管理面板。成员用自己的 API Key、费用走自己的账户、不占本站额度，接口地址只能是公网地址，最多 10 个服务（详见 Claude 章「模型服务」）。具体模型见 {{models}}。
- 「撞上限额时」：「限额重置后自动继续」（每个账号自己设：撞上 5 小时限额时，等额度恢复后自动接着跑完这一轮，默认开）；管理员另有「额度用尽自动换号」及其子项「额度恢复后回到首选号」「会话中无缝换号」，号池至少两个账号才用得上；开着时下面列「最近的自动切换」。
- 「服务意外重启时」：「自动继续被中断的对话」（每个账号自己设，默认开）：bridge 服务中途崩溃、被结束或电脑重启，打断了正在跑的对话时，服务恢复后自动让 Claude 从中断的地方接着做。
- 接口：本页存在服务端的项（不含号池、模型服务）都能用 `settings.claude` 看、`settings.claude_set` 改，如 autoResumeOnRestart、autoContinueOnLimit；号池与智能路由只在设置页 / 控制台里改。

## Claude 设置页：新会话默认与对话

这两组决定新会话的默认行为和对话里的辅助功能，按账号保存、多设备同步。

- 「新会话默认」：「权限模式」（Claude 改文件、跑命令前要不要先问；普通档成员只能选手动、接受编辑、计划三种，绕过与自动只给管理员）、「输出风格」（回复的组织方式，单个会话可另选）、「用工作树」（新会话开在 git 工作树里，只对能跑命令的身份出现，存这台设备）。
- 「对话」：「输入建议」（回复完猜你下一句，灰字显示，每条多一次模型请求）、「对话内交互图表」、「动态工作流」（复杂任务并行调度多个 agent，很快用掉额度；只对能跑命令的身份）、其下「子 agent 调度偏好」（文字描述派子 agent 时怎么挑模型和推理强度，空着按难度自动）、「消息被拦时自动换模型」（关着时会话暂停让你选）、「批准计划时可清空上下文」、「Claude 提问无人回答时」（一直等 / 5 / 10 / 30 分钟后继续，默认 10 分钟）、「回复语言」（跟随对话 / 简体中文 / English）、「自动压缩点」（上下文用到多少时自动压缩，在用量弹层的计量条上拖动设置，这里只能恢复默认）。
- 「会话协作」：「Claude 发起新会话」（先问我 / 直接开始 / 只在我要求时；只对能跑命令的身份）；「其它会话发来的消息」（同一台机器上别的 Claude 会话——官方 Claude Desktop、终端或这里的其它会话——发来的消息：跟随 Claude 默认 / 直接接收 / 暂存等我确认 / 拒收；只管理员）。
- 接口：这几组同样经 `settings.claude` / `settings.claude_set` 读写（「用工作树」「思考动画」只存在各台设备上，接口里没有）。

## Claude 设置页：Git、会话管理、通知、这台电脑、扩展与安全

这些是不常改的组；手机上折成推入行，桌面直接展开。

- 「Git 与拉取请求」（只对能跑命令的身份）：「分支前缀」（新会话工作树分支名前缀，默认 claude）、「工作树起点」（当前分支 / 远端默认分支）、「自动修复拉取请求」（会话建的拉取请求 CI 失败、冲突或有评审意见时自动叫醒会话处理）、「拉取请求合并或关闭后自动归档」、「提交与拉取请求署名」（带 Claude 署名 / 不署名）。
- 「会话管理」：「归档不活跃的会话」（从不 / 1 / 2 / 7 / 14 / 30 天；运行中或有后台任务的不归档）、「跟随 Claude Desktop 的归档」（只管理员）。
- 「通知」：「权限请求」「提问」「任务完成」三类通知各自开关，只存这台设备；通用里的通知总开关关着时这三项不可用。
- 「这台电脑」（只管理员，指服务端那台机器）：「Claude 工作时保持唤醒」（有会话在跑时不让电脑睡眠，屏幕照常关闭）、「使用电池时也保持唤醒」。这台机器做不到时（非 Windows 且没有 systemd-inhibit、虚拟机 / 云主机、保持唤醒功能关着）整组不出现；找不到官方 Claude Desktop 的数据目录时（Linux 服务器、没装 Desktop）「会话管理」里也没有「跟随 Claude Desktop 的归档」。
- 「扩展与记忆」（只管理员）：「技能」「连接器」「插件」三个入口跳到扩展中心对应类型，「定时任务」跳到定时任务页。
- 「安全」（只管理员）：「允许绕过权限模式」（打开前要确认）、「允许自动模式」。

## 扩展

扩展分区是扩展中心：管理 Claude 等 agent 用的技能、连接器、插件和功能扩展。只有管理员看得到。

- 入口：桌面侧栏「扩展」；手机根页「服务器」组 ›「扩展」。
- 顶部按类型分「技能」「连接器」「插件」「功能扩展」，每类有「我的 / 发现」两栏、搜索、筛选、排序和「添加」菜单；「我自用 / 全服统一」两个范围（没开多用户且没装过全服扩展时不显示这个切换）。
- 「功能扩展」页就是 bridge 的插件管理（详见「插件（功能扩展）」章），从上到下：
  - 有插件可更新时最上面一条「{n} 个插件有更新」（「只提示，不会自动装」），每个一行带「更新」按钮。
  - 「Agent」：Gemini · Vertex / ChatGPT · Codex / dimensio 三个 agent 扩展，每个一张卡片：可装时卡片上有「安装」（没装）或「更新到 x」（装着的和主程序对不上）按钮，点了从 GitHub 下载并显示进度；不能装时卡片上写着原因。底部「安装离线包」手动上传 .zip。卡片开关 = 这个 agent 的总开关。
  - 「功能」：随 bridge 装好、默认开着的内置功能（内置浏览器、共享终端、工作区协同、会话协作、内嵌图表、定时任务、自动归档、拉取请求、设备、手机操控、手机文件、分享链接、快照对话、给 agent 的接口、反馈、公网预览、公网访问、自定义壁纸、保持唤醒……），按分类排，每张卡片右上一个开关。关掉后它的界面入口（如设置里的壁纸、定时任务，Claude 工作台的终端 / 浏览器，文件的「分享链接」，PR 卡）、接口和 Claude 的对应工具一起消失；卡片底下写着「已开启 / 已关闭」，要重启才生效的写「改动重启生效」，出错 / 缺依赖也写在这里。
  - 「插件市场」（右侧「检查更新」）：bridge 官方发布、验过签名的插件里还没装的，点卡片看说明与各版本，「安装 v…」；内置功能的市场版显示「换上市场版 v…」（盖住内置实现，起不来自动退回内置版）。部署方在 config.json 关了市场时写「插件市场在这台服务器上关着」；拉取失败写原因；底部是索引版本与上次检查时间。
  - 「已安装的插件」：装的第三方插件与登记的本机目录；底部「上传 zip」「登记本机目录」「GitHub 地址」（从 GitHub 仓库装）。还没装时有一句提示：直接跟 Claude 说想要什么插件，它能帮你写好并登记上。
  - 点卡片进详情：按插件声明的配置项自动生成的设置表单（改完点「保存」，热插件当场生效）、来源 / 目录 / 依赖等信息；有市场新版时「更新到 v…」，装的插件与市场版可「回退到 v…」（回收区里的上一版），内置功能用着市场版时有「恢复内置版」；插件自报的状态块、动作按钮、托管子进程（可看日志）与回调地址；带控制面板的有「打开「面板名」」，带设置页的把它嵌在详情里（手机 App 里是「打开设置页」）；从 GitHub 装的有「检查更新」；第三方插件另有「重新加载」「卸载」（本机目录是「取消登记」）。
  - 有要重启才生效的改动时顶部出现「有改动等重启生效」和「立即重启」（空闲时重启）。
- 详见「账号与管理」章的扩展中心一节；接口见 plugins 组（`plugins.list`、`plugins.market`、`plugins.market_install` 等）和 `modules.list`。

## 插件的控制面板

带控制面板的插件（清单里声明了 ui.panel）在设置里多出一行，点进去全幅显示插件自己的页面。

- 入口：手机 / 网页 设置根页「插件」组；桌面客户端设置侧栏「连接与更新」上面那一组。行名是插件给的标题（英文界面用它的英文标题）。
- 谁看得到：插件声明只给服务器主机的（缺省）只有管理员有这一行；声明给成员的，成员也有，面板里看到的是他自己的数据。
- 手机 App 里面板在单独的干净页面里打开。插件被关掉或卸载后，这一行跟着消失（开着的页面提示「这个插件面板不在了（插件被关掉或卸载了）」）。
- 插件的配置表单不在这里，在 设置 › 扩展 › 功能扩展 › 点插件卡片的详情里。

## 额度与注册

额度与注册分区设置注册开关和注册用户的默认额度。只有管理员、且服务器开着多用户时出现。

- 入口：桌面侧栏「额度与注册」；手机根页「服务器」组 ›「额度与注册」（行尾显示「开放注册」或「注册已关」）。
- 「凭邀请码注册」开关。
- 「注册用户的默认额度」：「每天最多几轮」「最近 7 天最多几轮」「每天最多花多少」「最近 7 天最多花多少」（美元）、「全服同时最多几轮（注册用户合计）」、「「每天」按哪个时区换日」。留空或 0 = 不限；只算 Claude，管理员不受限。
- 更完整的额度项（媒体次数、视频条数、每人并发、定时任务数、成员高消耗功能）在服务端控制台的「额度与注册」页，见「账号与管理」章。

## 设备

设备分区管理登记到这个账号下的电脑和端口转发；所有登录用户都能看到自己的设备。

- 入口：桌面侧栏「设备」；手机根页「这台设备」组 ›「设备」（行尾显示在线台数）。
- 三组：「这台电脑」（只在桌面客户端：「Claude 能用这台电脑吗」关 / 只看 / 操作，以及被操作时的「立即停止本轮操作」）、「我的设备」（改名、断开、吊销、删除）、「端口转发」（新建、复制地址、打开、删除）。
- 详见「设备」章。

## 手机操控（安卓 app）

手机操控分区只在安卓 app 里出现，控制 Claude 能否操作这台手机以及悬浮胶囊。

- 入口：手机根页「这台设备」组 ›「手机操控」。
- 「允许 Claude 操控这台手机」总开关；打开后「权限」组：「无障碍权限」「保持后台运行」「自启动 / 后台活动」「Bridge 输入法」，未授权的标「未开启」，点它跳系统设置。
- 「悬浮外壳」组：「悬浮外壳 · Agent 模式」开关（悬浮胶囊）、「挖孔定位诊断」、「校准挖孔位置」。
- 详见「安卓 app」章。

## 连接与更新（桌面客户端）

桌面客户端的「连接与更新」分区集中放服务器连接、本机服务端管理和客户端更新。

- 「服务器」组：服务器地址输入框 +「连接」（换连另一台服务器）、「当前线路」（局域网直连 / 隧道 / 同源）、「后端」（服务端已运行多久、Node 版本）。
- 本机托管服务端时多出：「bridge 服务」（服务进程状态，点开可启停、看日志，服务停着也能用）、「退出前确认」（点退出先问，默认隐藏到托盘、服务端照常运行；关掉后退出即停止本机服务端）、「插电时保持在线」、「本机服务端访问信息」（访问令牌、局域网与公网地址）、「重新配置本机服务端」（工作空间、端口、Claude 账号）。
- 「服务端控制台」：管理员入口（服务在跑时才显示）。
- 「公网」组：「公网地址」（可复制）、「地址类型」（临时地址会在重启后更换 / 固定地址）。
- 「手机扫码连接」：「显示配对二维码」让手机 app 扫码连上这台服务器并以你的身份登录。
- 「手机 App」：手机相机扫码下载与服务器同版本的安卓 app，可切换局域网 / 公网地址。
- 「更新」：「软件更新」（检查、下载、安装客户端新版；有对话在跑时可等空闲再装或「立即安装（会中断）」）、「自动检查更新」（启动时检查，后台下载好，装不装由你决定）。

## 关于（手机 / 网页）

手机和网页的「关于」页对应桌面的「连接与更新」，放服务器连接、配对和更新。

- 「服务器地址」：点开「更换服务器地址」填新地址再「连接」。
- 「当前线路」（只在安卓 app）：局域网直连 / Cloudflare 隧道。「扫码连接服务器」（只在安卓 app）：扫电脑上的配对二维码换连那台服务器。
- 「让另一台设备扫码连接」（登录后）：「显示二维码」出示配对码，3 分钟内有效、只能用一次。
- 「服务器」组（登录后）：「公网地址」（可复制）、「地址类型」、「后端」运行时长。
- 「更新」组（只在安卓 app）：「软件更新」「自动检查更新」「安装权限」、取消下载 / 丢弃已下载的新版本、「去发布页下载」；网页版显示「网页版总是最新的」。
- 「版本历史」：服务器发过的每一版与说明。
- 「设备」组（只在安卓 app）：系统版本、机型、首次安装、最近更新日期。

## 反馈

反馈入口让任何登录用户把问题、建议连同截图或视频提交到这台服务器的反馈库。

- 入口：桌面侧栏「反馈」（页内直接是表单）；手机根页「提交反馈」（弹出表单）。
- 写文字、「添加图片 / 视频」后「提交反馈」/「提交」。反馈默认只记在这台服务器上，管理员能看到。
- 管理员打开了推送时，表单多一个「这条也发给 bridge 开发者」勾选（默认不勾）：勾上才同时发给 bridge 开发者，带文字、所在界面、版本和系统，不带账号名和服务器地址；图片最多 3 张，视频不发。
- 管理员在反馈页（手机在反馈表单里）有「把用户反馈同时发给 bridge 开发者」开关，默认关；关掉后已排队没发出去的也一并取消。发行版可以声明别的去向（比如发成公开 Issue），以界面和 feedback.status 的说法为准。
- 也可以不填表：直接跟 Claude（或 dimensio）说「是不是出 bug 了」。Claude 先看现场（版本；管理员还能看服务端报错日志和崩溃记录），认定是 bug 后跟你确认报告内容和去向，你同意了才上报（操作 feedback.diagnose / feedback.report）。去向和表单一样：本机反馈库总有一份，管理员开着推送、你同意时才发给 bridge 开发者；管理员本人同意时 Claude 可以顺手打开推送开关。
- 界面上弹出红字报错提示时，提示条右侧有「问 Claude」：点了会开一个新的 Claude 对话，把报错和所在界面填进输入框，你补一句再发。
