# ChatGPT 分页（Codex）

ChatGPT 分页用 OpenAI 的 Codex 当 agent，在服务端某个项目文件夹里读写代码、跑命令，并能用上 bridge 自己的工具（浏览器、终端、工作区、媒体、设备等）；这是功能扩展「ChatGPT · Codex」，没装、没开或没有权限时主页上没有这个入口。

## ChatGPT 分页是什么

ChatGPT 分页（agent id `codex`，界面名 ChatGPT · Codex）是 bridge 里由 Codex 驱动的编程/通用 agent 对话页。

- 它属于可选功能扩展：服务端要装上「ChatGPT · Codex」扩展，并且找得到 Codex 运行组件（本机装的 Codex 桌面版，或服务端自己下的官方包——Linux 服务器第一次启动会在后台下载）。
- 谁能用：管理员；以及被管理员勾选了 Codex 的「完全信任」档成员。Codex 的命令在它自己的进程里执行、绕过 bridge 的沙箱守卫，相当于命令行权限，所以普通档成员勾了也不生效。
- 成员用的是管理员共享出来的 Codex 账号（号池里标了「共享」的号）或模型中心里共享给成员的服务；会话按各人隔离，工作目录只能在自己的工作空间里，审批卡只给本人。
- 界面本体由维护者另行部署：公开发布的版本可能不带这一页的界面，打开时显示「此版本未包含 ChatGPT 页面」。此时扩展的服务端能力仍在，经接口照样能驱动 Codex。
- 与 Claude 分页的区别：Claude 是核心 agent，定时任务、扩展中心技能（成员）更完整；ChatGPT 分页适合想用 OpenAI 模型（或模型中心里接入的其他模型）写代码、做对比的场景。

## ChatGPT 分页的入口

- 手机：主页入口方块「ChatGPT」，点进全屏分页；返回回到主页。
- 桌面：主页底部 Dock 上的 ChatGPT 图标。
- 管理员在设置的「Agent」页可开关 Codex；找不到 Codex 运行组件时显示不可运行。
- 从工作空间把文件拖到 ChatGPT 入口或对话里，松手提示「挂进这个对话」，文件作为附件放进输入栏。

接口：`ui.open`

## ChatGPT 分页的项目与会话

ChatGPT 分页是项目制：每个会话绑定一个项目，项目 = 服务端上的一个文件夹 = 这次对话里 Codex 的工作目录。

- 发消息前必须先选择或创建项目，否则服务端报「请先选择或创建项目」。项目名固定取文件夹名。
- 会话建好后不能换到另一个项目（报「不能把已有会话切换到另一个项目」）。
- 同一个人可以同时跑多个会话；同一个会话同时只跑一轮。成员同时能跑几轮由管理员设置（默认 1）。
- 离开页面或断网不中断：回到页面会接上正在跑的那一轮。
- 会话操作：分叉（从某一轮或整段开一个新会话，同号同项目）、回退到某一轮之前（不撤销已经改动的文件）、压缩上下文（耗一次模型调用）、在跑时插话（内容并进当前这一轮）、排队消息（这一轮结束后 Codex 自动接着跑）、改名、归档、删除（同时删掉 Codex 那边的线程）。
- Codex 自己接着跑的轮（排队消息、目标续跑）也会出现在会话里，能接上看、能停。
- 页面上显示当前会话的上下文占用，以及所用 Codex 账号的用量窗口（各限额桶的已用百分比与重置时间）。

接口：`projects.list`、`sessions.list`、`sessions.read`、`sessions.search`（都带 `agent:"codex"`）

## ChatGPT 分页的模型与思考强度

- 每个 Codex 账号能用的模型不一样（免费号只有几个），模型菜单按账号的实际目录给；目录还没拉到时退回内置清单：{{models}}
- 发送时服务端按这一轮所用账号的目录校验：模型不在目录里换成那个号的默认模型，思考强度不在该模型支持的档里换成它的默认档，Fast（优先档）只在模型支持时生效。
- 模型中心：管理员在模型中心给服务勾上「Codex」去向后，那些模型也出现在菜单里（模型 id 形如 `<服务>/<模型>`）。走模型中心的会话跑在单独的进程里，不耗 ChatGPT 额度；成员只看得到「共享给成员」的服务。
- 选型思路：日常编程用默认主力模型 + 中等强度；复杂推理/大改动调高强度；简单清晰的小任务选快速模型。

## ChatGPT 分页的 Codex 账号（号池）

- 本机账号：服务器上 Codex 桌面版登录的那个号，始终在池里，不能删除、不能从 bridge 登出（会把桌面版一起登出）。
- 管理员可以再加号：ChatGPT 号用设备码登录（bridge 给出网址与验证码，在任意浏览器打开输入即可；该 ChatGPT 账号要先在「设置 › 安全」里打开设备码登录），或者加 OpenAI API key。同一个 ChatGPT 账号不会重复入池。
- 每个号可以改名、停用、共享给成员、调整顺序；管理员可以手动给号用「重置卡」（Codex 的额度重置，花掉就没了，要确认）。
- 选号：默认一律用当前号。打开「选号」后新会话按策略挑号（primary 按顺序、fill 当前号用到撞线再往下、smart 挑剩余额度多的）；已有会话固定在它的号上。打开「无缝换号」时，一轮因额度用尽失败会把会话迁到下一个可用的号自动重跑一次；没开时错误里带撞线信息，可以手动把会话换到别的号再发。
- 不常用的号空闲一段时间（默认 60 分钟）后停掉进程，下次用时自动启动。

## ChatGPT 分页的审批与提问

- 审批策略：管理员默认不审批、不进沙箱（Codex 直接执行）；成员默认「需要时问」+ 只能写工作区。管理员可以在设置里改两档身份的默认值，每次发送也可以在允许的范围里覆盖。
- 要审批时对话里出现审批卡（与 Claude 页同一种卡）：运行命令、改文件（带 diff）、申请额外权限、调用 MCP 工具、调用 bridge 工具里会改东西的那些（终端、写操作、动手操作电脑等）。可以「允许这一次」「本会话都允许」或拒绝；管理员对命令还可以选「按前缀规则允许」。
- Codex 也会向用户提问（选项卡，与 Claude 的提问同一种卡），MCP 服务器要填的表单也走提问卡。
- 成员的改文件、权限申请越出自己工作空间的直接拒绝，并在对话里说明原因。
- 没有人在看的轮（会话协作转来的、Codex 自己续跑的）卡片 30 分钟没人答就拒掉并停下这一轮。

接口：`chat.pending`、`chat.answer`（带 `agent:"codex"`）

## ChatGPT 分页的附件与产物

- 附件：在输入栏上传文件，或从工作空间拖文件进来；附件与项目文件夹里的文件都能被 Codex 读到，图片直接作为图片输入。
- 产物：Codex 生成的图片、以及最终回复里以 Markdown 链接给出的文件，会以附件卡显示在回答里，点开用 bridge 的统一预览器查看，可下载。

## ChatGPT 分页的工作区

工作区是对话右侧的一叠卡片，和 Claude、Antigravity、dimensio 分页是同一套：「更改」（git 改动审阅）、「终端」、「文件」（定位在当前项目文件夹）、「浏览器」（与 Codex 共享的同一个浏览器实例，每个对话各开一份）。桌面可同时开几张卡，手机是覆盖整屏的独立页面。

## ChatGPT 分页里 Codex 能做什么

- 在项目文件夹里读写文件、执行命令（在服务端机器上执行，不是在手机上）。
- 用 bridge 自己的工具（与 Claude 页同一套，按身份与开关给）：bridge 手册与操作、共享浏览器、共享终端、工作区（看用户正在看的文件、把成品弹到用户眼前）、对话内图表、媒体生成（图像 / 视频 / 配音 / 音乐，按 Media Studio 的放行）、操作用户登记的电脑、手机操控与手机文件、拉取请求、开 Claude 子会话协作、项目记忆、插件给的工具。
- 扩展中心里管理员托管的技能与连接器（只给管理员的会话）。
- 新会话建好时工具清单就定下了：之后打开或关闭的功能在调用时现判，用不了会说明原因；新版本加的工具，老会话拿不到。

## ChatGPT 分页的限制

- 不能用于定时触发（定时触发只有 Claude 与 dimensio 引擎）。
- 会话绑定项目后不可换项目；走模型中心的会话不能换到 ChatGPT 账号上，反之亦然。
- 界面需要维护者部署的页面包，公开版可能没有。
- 找不到 Codex 运行组件或设置里关闭时，入口不出现。

接口：`chat.send`、`chat.wait`、`chat.stop`、`overview`（带 `agent:"codex"`；`chat.send` 新会话要给 `project`：Codex 项目 id 或文件夹绝对路径；会话在跑时 `whenBusy` 可选 `steer` 插话、`queue` 排队、`replace` 停掉重发）
