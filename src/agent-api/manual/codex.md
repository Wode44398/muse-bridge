# ChatGPT 分页（Codex）

ChatGPT 分页用 OpenAI 的 Codex 当 agent，在服务端某个项目文件夹里读写代码、跑命令、开浏览器；这是功能扩展「ChatGPT · Codex」，没装、没开或没有权限时主页上没有这个入口。

## ChatGPT 分页是什么

ChatGPT 分页（agent id `codex`，界面名 ChatGPT · Codex）是 bridge 里由 Codex 驱动的编程/通用 agent 对话页，外观仿照官方 ChatGPT。

- 它属于可选功能扩展：服务端要装上「ChatGPT · Codex」扩展，并且服务端机器上装有 Codex CLI、登录过 ChatGPT 账号；服务端常驻一个 Codex 进程，首条消息不用等启动。
- 只给管理员：Codex 的工具调用在它自己的进程里执行，绕过 bridge 的沙箱守卫，所以注册成员恒拿不到这个分页，管理员勾选了也不生效。
- 界面本体由维护者另行部署：公开发布的版本可能不带这一页的界面，打开时显示「此版本未包含 ChatGPT 页面」，点「返回」回主页。此时扩展的服务端能力仍在，但手机/网页上用不了。
- 与 Claude 分页的区别：Claude 是核心 agent，工具、扩展中心、定时任务、多用户都更完整；ChatGPT 分页适合想用 OpenAI 模型写代码、做对比的场景。

## ChatGPT 分页的入口

- 手机：主页四个入口方块之一「ChatGPT」（与 Claude、dimensio、Vertex 并列），点进全屏分页；返回回到主页。
- 桌面：主页底部 Dock 上的 ChatGPT 图标。
- 管理员在设置的「Agent」页可开关 Codex；没装 Codex CLI 时显示不可运行。
- 从工作空间把文件拖到 ChatGPT 入口或对话里，松手提示「挂进这个对话」，文件作为附件放进输入栏。

接口：`ui.open`

## ChatGPT 分页的项目与会话

ChatGPT 分页是项目制：每个会话绑定一个项目，项目 = 服务端上的一个文件夹 = 这次对话里 Codex 的工作目录。

- 发消息前必须先选择或创建项目，否则服务端报「请先选择或创建项目」。
- 新建项目：在页面里发起新建后，桌面客户端（本机托管服务端时）直接弹系统文件夹选择器；其他端打开项目选择器（工作空间文件管理器，底部有拖入栏）。项目名固定取文件夹名。
- 会话建好后不能换到另一个项目（报「不能把已有会话切换到另一个项目」）。
- 历史会话可打开继续聊、可删除；删除会同时删掉 bridge 的记录和 Codex 那边的对话线程。
- 离开页面或断网不中断：回到页面会接上正在跑的那一轮。
- 页面上显示 Codex 账号的用量窗口（各限额桶的已用百分比与重置时间），以及当前会话的上下文占用。

接口：`projects.list`、`sessions.list`、`sessions.read`

## ChatGPT 分页的模型与思考强度

模型、思考强度、服务档都由服务端能力表白名单校验，具体清单：{{models}}

- 思考强度档位从 Light 到 Ultra，不同模型支持的档不同（例如有的模型没有 Ultra）；传了不支持的档，服务端回落到默认档。
- 服务档：部分模型可选优先档（priority），输出更快、按更高单价计费；不支持的模型自动忽略。
- 选型思路：日常编程用默认主力模型 + 中等强度；复杂推理/大改动调高强度；简单清晰的小任务选快速模型省时间。

## ChatGPT 分页的附件与产物

- 附件：在输入栏上传文件，或从工作空间拖文件进来；附件与项目文件夹里的文件都能被 Codex 读到。
- 产物：Codex 生成或修改的图片、PDF、文档、表格、音视频、压缩包等，会以附件卡显示在回答里，点开用 bridge 的统一预览器查看，可下载；图片可以直接拖出页面。

## ChatGPT 分页的工作区

工作区是对话旁边的项目工具面板：桌面是可拖宽的右栏（双击拖柄恢复默认宽度），手机是覆盖整屏的独立页面（左上「对话」返回）。

工作区有四个工具标签：

- 「更改」：项目文件夹的 git 改动审阅——列出改动文件与增删行数，点文件展开逐行 diff；不是 git 仓库时显示「该工作空间不是 git 仓库」，没改动显示「工作树很干净，没有改动」。
- 「终端」：在项目文件夹里的交互终端。
- 「文件」：嵌入的工作空间文件管理器，定位在当前项目文件夹。
- 「浏览器」：与 Codex 共享的同一个浏览器实例，Codex 用浏览器工具导航、截图、测网页时，用户在这里实时看到。

## ChatGPT 分页里 Codex 能做什么

- 在项目文件夹里读写文件、执行命令（在服务端机器上执行，不是在手机上）。
- 浏览器：用共享浏览器打开网页、检查页面、截图、交互测试。
- 操作管理员登记的电脑（设备）：查看设备在线状态与权限档，按设备的「仅观察 / 可操作」档位截图、读界面控件树、点按输入。设备权限由设备端强制执行，用户可随时紧急停止。
- 扩展中心里管理员托管的技能与连接器也会提供给 Codex。

## ChatGPT 分页的限制

- 仅管理员可用；不能用于定时触发（定时触发只有 Claude 与 Gemini 引擎）。
- 会话绑定项目后不可换项目。
- 界面需要维护者部署的页面包，公开版可能没有。
- 服务端没装 Codex CLI 或设置里关闭时，入口不出现。
- 经接口驱动 ChatGPT 分页的会话是否可用，以 `overview` 返回的能力为准。
