# 定时触发（Routines）

定时触发让 Claude 按固定频率无人值守地执行一段指令，结果存成一条会话事后回看；每个账号各有自己的一份定时任务。

## 定时触发是什么

定时触发（界面上也叫「定时任务」，英文 Routines）是按计划自动执行的一段提示词：到点后服务器自己开一轮新的 Claude 对话把指令发出去，没有任何人在线也照样跑。

- 每次运行都是一条全新的会话，不接续上一次的上下文；需要「接着上次做」时，让指令自己去读上次留下的文件。
- 运行在任务主人自己的身份和权限里：管理员的任务能动整台服务器；注册账号的任务只能在自己的文件夹里活动，普通账号在定时任务里也没有命令行。
- 无人值守：Claude 提问会被自动拒绝并要求它按合理默认继续；需要批准的调用直接放行。指令要写成「一次说清、可自主完成」的形式。
- 只有 Claude 能跑定时任务；dimensio 不能。
- 适合：每天早上汇总笔记、每小时检查某个目录、每周生成报告。不适合：需要人中途确认的操作、要求精确到秒的任务。

## 入口

- Claude 页侧栏「定时触发」（手机上先点左上角「菜单」拉出侧栏）。
- 全屏页面，标题「Routines」；左上「‹」返回。

接口：`routines.list`、`ui.open`

## 列表页

- 每条一张卡片：名称（没填显示未命名）、「频率 · 模型」、上次结果或「运行中…」。
- 卡片右侧：「立即运行」、「启用」开关、删除按钮。点卡片主体进编辑；右上「＋ 新建」新建。

## 新建与编辑

1. 名称：可留空，最长 120 字。
2. 「指令」（Instructions）：必填，每次运行发给 Claude 的完整提示词。
3. 模型与思考强度：不选就用服务器默认；**不能选 Ultracode**（无人值守跑动态工作流成本不可控），选了保存会被拒。
4. 「频率」（Frequency）：每天 / 每工作日 / 每周某一天 / 每小时的第几分钟，再加上时间。
5. 「启用」：关着保存 = 存下但不自动触发（仍可手动「立即运行」）。

接口：`routines.create`、`routines.update`

## 频率与时区

| 频率 | 需要设置 |
|---|---|
| 每天 | 时:分 |
| 每工作日 | 时:分（周一到周五，不识别节假日） |
| 每周 | 星期几 + 时:分 |
| 每小时 | 第几分钟（0–59） |

- 不支持 cron 表达式，也不支持「每 N 分钟」。
- **时间按服务器的时区算**：页面上写的「服务器时区 GMT+8」不准，Muse 的 VM 默认是 UTC（比北京时间晚 8 小时）。想北京时间 9 点跑就填 01:00；不确定就让 Muse 在 VM 上跑 `date`。这是已知问题。
- 调度精度约 30 秒；改频率或重新启用时，下次运行时间从当前时刻重新算。

## 立即运行、启停与删除

- 「立即运行」：马上跑一次，不影响下次计划时间；同一条正在跑时不会重复开跑；同样计入额度。
- 「启用」开关：关掉后不再自动触发。注册账号启用中的任务数有上限（管理员在控制台设），到上限时打开会被拒。
- 删除：确认后删掉，已经产生的历史会话不受影响。

接口：`routines.run`、`routines.update`、`routines.delete`

## 结果去哪看

- 卡片上的上次结果；服务器还为每条记录上次运行时间、结果会话 id 和前 200 字摘要（接口 `routines.list` 能取到）。
- 完整过程：每次运行是一条普通 Claude 会话，出现在 Claude 页侧栏的默认项目下面，可以打开、接着聊。
- 管理员在服务端控制台「定时任务」页能只读看到所有人的任务。

接口：`routines.list`、`sessions.list`、`sessions.read`

## 限制与规则

- 宕机不补跑：VM 重启、服务停着期间错过的那次不会补跑，直接跳到下一次。
- 不重叠：同一条上一次还没跑完，到点不会再开一次。
- 额度：注册账号每次运行（含立即运行）算一轮额度，额度用完这次不跑；管理员不限。
- 账号停用后，它的定时任务不再运行；管理员关掉 Claude 后，所有定时任务都不会运行。

## 用接口管理定时任务

外部 agent（包括 Muse 自己）可以经接口完成与界面相同的操作，作用范围是调用身份自己的定时任务。

- 查看：`routines.list`。
- 新建：`routines.create`，必填 prompt 与 schedule（`{ type: daily | weekdays | weekly | hourly, hour, minute, weekday? }`），可选 name、model、effort、enabled。
- 修改：`routines.update`，只传要改的字段；`enabled: false` 停用。
- 立即运行：`routines.run`，异步返回；之后用 `routines.list` 看状态，用 `sessions.read` 读结果会话。
- 删除：`routines.delete`（⚠ 先问用户）。
- 替用户建任务前先确认时间（按服务器时区换算好），指令里写清输出放哪个文件、什么格式。
