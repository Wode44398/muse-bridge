# 设备

「设备」是登记到某个账号下的电脑（装了 bridge Windows 桌面客户端并登录）；Claude 跑在服务端，经设备通道看这台电脑的屏幕、操作它的桌面、在上面跑命令、读写文件、用它的浏览器、开它的终端、把它的本机端口转到服务器。本章讲设备怎么来、在哪管、权限档、急停、能做什么、审计和限制。

## 设备是什么、和服务端是什么关系

设备是一台登记过的用户电脑，它把「能被 agent 操作」这件事带给 bridge。

- Claude 的读写文件、跑命令默认作用在**服务端那台机器**上，不是用户的电脑；用户电脑上的事（看他的屏幕、点他的程序、读写他电脑上的文件、在他电脑上跑命令、用他已登录的浏览器）一律经设备完成。
- 设备只归它的主人：一台设备只给登记它的那个账号用。别的成员看不到、也用不了；管理员要碰成员的设备必须该成员授权（见「管理员与设备」）。
- 设备通道是电脑主动连向服务端的一条出站长连接，电脑上不开任何入站端口；电脑在 NAT、公司网络后面都能用。
- 服务端可以整体关闭设备功能（管理员在服务器配置里关）；关闭后设备连不上，Claude 也拿不到设备工具，控制台「设备」页会提示。

## 服务端所在的那台电脑

服务端装在用户自己电脑上时（桌面客户端安装时选「服务端」角色，或同机另装服务端），这台电脑本身也会以设备身份登记。

- 列表里会标「与服务器是同一台」（手机设置的设备详情）/「与服务器同机」（控制台），agent 工具里标「与 bridge 同一台机器」。
- 对这台电脑，Claude 自己的读写文件、命令本来就作用在它上面；设备工具额外提供看屏幕、操作桌面程序、用桌面客户端内置浏览器这些能力。
- 设备终端菜单不列这台（服务器终端就是它）。

## 一台电脑怎么成为设备（登记）

登记是自动的：在电脑上装 bridge Windows 桌面客户端，连上服务端并用账号登录，客户端就把这台电脑登记到这个账号下。

- 没有单独的「配对设备」步骤，也不再有远程协助配对码（已下线）。管理员用访问令牌登录、成员用账号密码或扫码登录都会登记。
- 设备名默认取电脑的主机名，可改名；同一台电脑重新登录复用原来的设备记录。
- 客户端没登录时不登记，登录后自动补登；服务端没起来时每分钟重试一次。
- 设备凭据跟着那次登录走：在那台电脑上退出登录、登录过期或被管理员踢下线，设备随之失效，重新登录后自动重新登记。
- 被吊销的设备不会自动登记回来：要在那台电脑的客户端上重新登录。所属账号被停用或删除时同样连不上。
- 一个账号可以登记多台电脑。

接口：`devices.list`

## 设备列表与管理入口

用户在设置里管理自己的设备，入口在两端都有。

- 桌面客户端：设置 › 侧栏「设备」。分三组：「这台电脑」（只在桌面客户端里出现，见权限档）、「我的设备」、「端口转发」。点某台设备展开，可改「名字」并「保存」，在线时可「断开」，未吊销时可「吊销」，已吊销的可「删除」。
- 手机 / 网页：设置 › 「设备」行（行尾显示「{n} 台在线」）→ 设备页，同样三组；点某台进详情页，看「系统」「主机名」「客户端版本」「类型」（桌面客户端 / 老客户端），操作同上。
- 状态文字：「在线 · 可操作」「在线 · 只看，动手前问你」「在线」「离线」「还没连上过」「已吊销」。
- 「断开」= 立刻断掉这台的通道并中止它正在执行的操作，客户端会自动重连；「吊销」= 设备凭据立即作废、通道当场断开、它的设备终端关掉，要在那台电脑上重新登录才能再连；「删除」= 删掉已吊销设备的记录，连带删掉它的端口转发。
- 设备状态实时推到各端，上下线不用刷新。
- 只有登录的管理员或注册用户能管理设备；访客、分享链接、聊天快照身份不能。

接口：`devices.list`

## 会话连哪台电脑（电脑芯片）

每个 Claude 会话可以「连接」一台设备，Claude 的设备操作默认作用在它上面。

- 入口：Claude 输入框上方归属栏最左边的「电脑」芯片。点开是「这个会话连哪台电脑」（新对话为「新对话连哪台电脑」），选项：「自动」、各台设备（在线状态 + 档位）、「不连电脑」（Claude 只在服务器上干活），底部「管理设备…」跳设置。
- 「自动」：从哪台桌面客户端发的消息就连哪台；不在桌面客户端里发时，账号下恰好只有一台在线设备就用它，多台在线要 Claude 明确指定。
- 老会话第一次从桌面客户端发话时会自动连上这台，之后从手机接着聊仍是它。
- 进行中的会话改选立刻生效；新对话的选择随第一条消息带上。
- 账号下没有任何设备、又不在桌面客户端里时，芯片不出现。
- Claude 也能在对话里按用户口头要求（「用我的笔记本」）切换会话连接的设备，或断开。
- 选了「不连电脑」的会话不加载设备工具。
- dimensio 的输入框左下（档位胶囊旁边）也有一颗「电脑」胶囊，菜单「这个会话连哪台电脑」：「自动」（只有一台在线时就用它）、各台设备、「不连电脑」。与 Claude 不同，dimensio 的「自动」不看是从哪台桌面客户端发的消息。账号下没有设备、或这台服务器关了设备通道时胶囊不出现。

## 权限档：关闭 / 只看 / 操作

权限档是每台电脑自己决定、自己把关的开关，服务器改不了；它是设备能力的硬边界。

| 档 | 桌面客户端设置里的叫法 | 托盘里的叫法 | 效果 |
|---|---|---|---|
| off | 关 / 关闭 | 关闭 | 设备通道断开，服务器上看这台是离线，agent 看不到也动不了 |
| observe | 只看 | 观察 | 能看屏幕、读界面、用客户端内置浏览器；要动鼠标键盘、跑命令、读写文件、开终端、转发端口时先在电脑上弹窗问用户 |
| control | 操作 | 控制 | 全部放行，不再逐次询问（屏幕上方的状态条与急停一直在） |

- 入口：桌面客户端 设置 › 设备 ›「这台电脑」组的「Claude 能用这台电脑吗」（关 / 只看 / 操作）；托盘菜单「这台电脑」›「agent 权限」（关闭 / 观察 / 控制）。手机和网页上看不到也改不了别的电脑的档。
- 从没设过的电脑默认「观察」。
- 切到「操作」/「控制」会先弹警告「允许 agent 直接操作这台电脑」，点「我明白，允许操作」才生效。
- 「观察」档的逐次授权弹窗：标题「{name} 想操作这台电脑」，写明来自哪个会话、要做什么（如「执行命令「…」」「写入文件 …」「访问本机端口 …」）；按钮「本会话允许」（同一会话 1 小时内同类请求不再问）、「一直允许」（把这台电脑改成「控制」）、「拒绝」（agent 收到「用户拒绝了这一步」的说明）。弹窗 90 秒无人理会按拒绝处理。
- 状态汇报、客户端远程更新、往已经开着的终端里打字不受档位询问约束；开一个新终端仍要过档位这一关。

## 急停与「正在被操作」提示

设备被 agent 操作时用户随时能看见、随时能叫停。

- 开始操作时系统通知「{source} 开始使用这台电脑」；操作期间屏幕上方有状态条，显示正在做什么。端口转发、分块传文件这类高频操作也会定期点亮提示。
- 急停入口：状态条上的「停止」、托盘「立即停止」（agent 正在使用这台电脑时出现在托盘顶部）、桌面客户端 设置 › 设备 ›「立即停止本轮操作」、全局快捷键「本机 Agent 急停」（默认 Ctrl+Alt+Shift+F11；另有「远程被控急停」默认 Ctrl+Alt+Shift+F12，现在两把键效果相同）。快捷键可在 设置 › 快捷键 改，组合刻意设得难按。
- 急停 = 把这台电脑的档位直接落到「关闭」：设备通道断开、正在跑的桌面动作当场中止，agent 工具收到「设备已断开」。之后要用户自己把档位调回来。
- 遇到 UAC 安全桌面、锁屏、受保护内容或截图黑屏，agent 不应绕过，应交还用户。

## 设备上能做什么

设备连上后，会话里的 Claude 能对它做以下几类事（分别受权限档约束）。

| 能力 | 说明 | 需要的档 |
|---|---|---|
| 看桌面 | 前台窗口、窗口列表、进程、显示器、光标位置、截图（可选显示器、叠坐标网格）、放大局部、读 UI Automation 控件树、等某个窗口出现/消失 | 只看 |
| 操作桌面 | 启动程序/打开文件或网址、聚焦/移动/改大小/关闭窗口、鼠标移动/单击/双击/三击/右键/滚轮、输入文本（直接输 Unicode，不受输入法影响）、组合键、按控件语义操作（点击、填值、选择、勾选、展开折叠等）、等待、批量连续动作（最多 30 步） | 操作 |
| 设备浏览器 | 驱动桌面客户端里的内置浏览器：打开网址、点、输入、读页面、截图、执行脚本、看网络请求、上传文件、多标签等；带用户的登录态，操作对用户实时可见 | 只看 |
| 跑命令 | 在设备上执行一条命令（Windows 是 PowerShell），返回退出码、标准输出与错误；默认超时 120 秒，最长 300 秒，输出超过约 200KB 截断 | 操作 |
| 读写文件 | 读、写、列目录、按模式搜索、查文件信息、建目录、移动、删除（删除进回收站）；路径必须是设备上的绝对路径；单次读写上限 10MB | 操作 |
| 两台机器之间搬文件 | 把设备上的文件拷到服务器，或把服务器上的产物拷到设备；自动分块，上限 512MB | 操作 |
| 端口转发 | 把设备上 127.0.0.1 的某个端口接到服务器，见下节 | 操作 |
| 设备终端 | 用户在终端面板里直接开设备的终端，见下节 | 操作 |

- 桌面操作建议路线：先读前台窗口和控件树，按控件操作；读不到再截图按坐标操作。
- 高风险动作（发消息、删除、下单、改安全设置、关掉有未保存内容的窗口）Claude 应先向用户确认。
- 老版本客户端可能缺部分能力（批量动作、等窗口、放大、端口转发、终端、大文件分块），工具会提示「请对方更新客户端」。

接口：`devices.list`、`devices.run`

## 端口转发

端口转发把用户电脑上某个本机端口（dev server、本机模型的接口）接到服务器上，服务器、手机和 Claude 都能访问。

- 入口：设置 › 设备 ›「端口转发」组。桌面客户端在「新的转发」行选电脑、填「端口」和「备注（可选）」点「接通」；手机/网页点「新的转发…」进页面选「哪台电脑」、填「本机端口」再「接通」。每条转发可「复制地址」/「复制」、「打开」、「删除」。
- Claude 也能在对话里自己建、列、删转发；它拿到的服务器内地址可以直接用命令或浏览器工具访问。
- 地址是能力链接：持有地址的人都能访问，不用了就删掉；删掉立即失效。转发会持久保存，服务端重启不丢。
- 每个账号最多 20 条。只转设备的 127.0.0.1；WebSocket（如热更新）暂不转，页面照常能用。
- 服务器配了预览域名时，网页应用走独立子域完整显示；没配时走路径入口，适合接口类服务，部分网页应用可能显示不全。
- 设备在「观察」档时，第一次访问会在那台电脑上弹窗问用户；设备上没有服务监听时访问会报「没有服务在监听」。
- 需要新版桌面客户端在线；没有符合条件的电脑时显示「没有能转发端口的电脑」。

## 设备终端

设备终端让用户在 bridge 的终端面板里直接打开自己电脑上的命令行。

- 入口：Claude 页右侧工作台的「终端」面板，底栏左侧的目标菜单（「终端开在哪台机器上」）里选「服务器」或某台标「我的电脑」的设备。只列在线、支持终端、且不是服务器本机的设备。
- 一台设备一个终端；设备掉线终端不算结束，重新连上后自动接回原来的 shell。多个页面可同时看同一个终端。
- 只有设备主人自己能开，管理员也不能开别人电脑的终端；Claude 的工具不能往设备终端里打字。
- 开终端要过一次权限档（观察档会弹窗问）；之后在已打开的终端里打字不再逐次询问。
- 没人看、也没有输入输出 1 小时后自动收掉。

## 管理员与设备（控制台「设备」页）

管理员在服务端控制台的「设备」页看全服所有设备，做只读探查和维护，但不能把控制台当远程 shell。

- 入口：设置 › 服务器 ›「服务端控制台」›「设备」（桌面客户端在 设置 › 连接与更新 ›「服务端控制台」）。远程管理也能进。
- 能看到：每台设备的主人、在线状态、客户端版本（标「最新」或「落后」）、档位、能力、最近操作、端口转发、最近审计记录；可显示已吊销的设备。
- 能做：「系统信息」「查看屏幕」（截屏）、「远程更新」客户端、改名、「断开通道」、「吊销」、删除记录、删端口转发；轮换主机密钥（同机工具用的那把，设备不受影响）；出示扫码配对卡（让手机扫码连接）。
- 对成员的设备做系统信息、截屏等操作，必须该成员在自己的 设置 › 账户 ›「管理员可见性」里打开「允许查看我的电脑」；每次操作都会记进他的「管理员的访问记录」。唯一例外是「远程更新」客户端（只让客户端自己升级），不需要授权但同样留记录。
- 管理员代某成员发的对话轮，不会挂那个成员的电脑。

## 审计与护栏

设备上发生的每件事都有记录，并有防失控的频率护栏。

- 服务端审计：设备登记、上下线、每次操作（谁发的、哪个会话、耗时、成败）、改名/断开/吊销/删除、未授权访问等都记进设备审计日志；管理员在控制台「设备」页查看。终端里的每次按键、端口转发的每个请求不逐条记（开终端、建转发各记一条）。
- 桌面客户端本地也记操作与急停。
- 频率护栏：每台设备每分钟最多 240 次操作；同一个动作带同样参数连续超过 20 次判为死循环并拦截（读文件、列目录、浏览器、命令等天然会重复的不算）。
- 单次操作默认 60 秒超时；设备回传上限 16MB（大截图、大文件块走这条）。

## 限制与常见问题

设备功能的边界和排错要点。

- 只支持 Windows 桌面客户端作为设备；桌面操作能力基于 Windows UI Automation。
- 「设备离线」= 桌面客户端没开，或那台电脑把档位设成了「关闭」（或刚被急停）。
- 「这台设备不属于你」= 想操作别人的设备；「设备不存在或已被吊销」= 设备被吊销/删除。
- 多台设备在线又没连会话时，agent 必须指定设备名或 id。
- 普通档成员也能登记并操作**他自己的**电脑（这不涉及服务器）；访客、聊天快照、分享链接身份没有设备能力。
- 截图黑屏、锁屏、UAC 弹窗属于系统保护，不能绕过。
