# 安卓 app

bridge 的安卓 app 是一个「离线壳」：界面内置在 app 里，只有数据走网络连服务端；它比网页版多出一组手机专属能力——让 Claude 操控这台手机、悬浮胶囊、手机文件、原生上传下载、后台通知、扫码登录与配对。本章逐项说明这些能力在哪、怎么用、有什么限制。

## 离线壳是什么

安卓 app 把整套界面打包在安装包里，打开即显示，不从服务器下载界面；聊天、文件等数据才走网络打到服务端。

- 第一次打开要连服务器：首屏「扫码连接」扫电脑上的配对二维码（见「扫码连接服务器」），或手动填服务器地址后登录。
- 服务器换了地址（例如临时隧道重启）时 app 会自动跟过去：在线时立即收到新地址，离线时回家连上同一个 Wi-Fi 就会更新。没跟上或要改连另一台服务器：设置 ›「关于」›「服务器地址」填新地址再「连接」。
- 在家与服务器同一 Wi-Fi 时自动走局域网直连，外出走隧道；设置 ›「关于」›「当前线路」显示「局域网直连」或「Cloudflare 隧道」。
- 下列能力只在安卓 app 里有，网页版（包括手机浏览器打开）没有：手机操控、悬浮胶囊、手机文件（本地位置）、原生上传下载器、后台任务通知、系统返回键逐级返回、「扫码连接服务器」。

## App 更新

安卓 app 由所连的那台服务器自己发包，app 只认这台服务器发的版本，不去别处找。

- 入口：设置 ›「软件更新」行（根页）或 设置 ›「关于」›「更新」组。显示检查中 / 下载进度 / 「一键更新」状态；有新版时「关于」页下方显示「新版本说明」。
- 「自动检查更新」开关：开着时自动检查并在后台下载好新版，装不装由用户决定。
- 「安装权限」：首次安装更新需要在系统设置里允许「安装未知应用」，未开启时显示「未开启」，点它跳系统设置。
- 下载中可「取消下载」，已下载可「丢弃已下载的新版本」；「版本历史」列出服务器发过的每一版与说明。
- 服务器上的包与手机上的 app 签名不同或包名不同（来自别的发行渠道或自己编译）时不能覆盖安装，页面会说明要先卸载再装（本机缓存的聊天会清空，服务器上的数据不受影响）。
- 服务器没有可发的版本时显示说明，有发布页时给「去发布页下载」。手机 app 比服务器新时照常能用，个别新功能要等服务器更新。
- 网页版没有这一项：界面由服务器直接提供，刷新即最新。
- 电脑上的桌面客户端 设置 › 连接与更新 ›「手机 App」组有一张二维码，用手机相机扫就能下载与这台服务器同版本的安卓 app。

## 手机操控是什么

手机操控让 Claude 直接操作这台安卓手机：打开 app、读屏幕、点按、滑动、输入、发短信、拨号等。它基于安卓无障碍服务，属实验性功能。

- 前提：①服务器开启了手机操控功能（服务器配置项，默认关闭，由管理员打开）；②手机 app 里打开「允许 Claude 操控这台手机」并授予无障碍权限。
- 打开后手机上常驻一个前台服务（通知栏一直显示，点「停止操控」随时关闭），它自己和服务器保持连接，所以 Claude 把别的 app 切到前台、bridge 退到后台甚至被系统回收时，操控照常进行。
- Claude 在哪些对话里能用：从这台手机 app 发起的对话，或者这个账号有手机正开着操控服务时（从电脑上发起的对话也能用）。两者都不满足时 Claude 会被告知「本轮没有手机操控」，请用户改在手机 app 里发起或先打开操控。
- 能做的事分两类：系统意图类（打开 app、打开网址、打开某个系统设置页、分享文字、读写剪贴板、弹通知、预填短信 / 直接发短信、预填拨号 / 直接拨打、震动、朗读文字、向用户确认）和屏幕操作类（看屏幕：元素清单 + 带编号框的截图；点击、长按、滑动、滚动、往输入框写文字、按系统键返回/桌面/最近任务/通知栏/回车、等待）。
- 动作做完手机会等界面稳定后直接带回新画面，并如实回报：输入是否真的写进去、提交是否生效、画面有没有变化。
- 多步任务（在某个 app 里搜东西、发消息、找设置项、填表）Claude 会交给专门的「手机操作员」子 agent 在独立上下文里做，截图不塞满主对话。
- 操作经验：Claude 可以把某个 app 的非显然操作经验记下来（特性、验证有效的步骤、坑），下次操作同一 app 自动带回；这台服务器上所有会话共享。

## 手机操控的界面入口与权限

手机操控的开关和所需系统权限都在一页里。

- 入口：设置 ›「这台设备」组 ›「手机操控」（行尾显示打开/关闭）。只在安卓 app 里出现。
- 页内：「允许 Claude 操控这台手机」总开关；打开后出现「权限」组：
  - 「无障碍权限」：必需，未开启显示「未开启」，点它跳系统无障碍设置。
  - 「保持后台运行」：把 app 加进电池优化白名单，防止系统在后台掐掉服务。
  - 「自启动 / 后台活动」：跳系统的应用详情页，部分厂商系统要在这里允许自启动和后台活动。
  - 「Bridge 输入法」：bridge 自带的输入法，让 Claude 能可靠地往输入框写整串文字（含中文）；未启用时点它去系统输入法设置启用，启用后点它弹输入法选择器切换。没有它时退回无障碍方式输入，部分 app 可能写不进去。
- 页内还有「悬浮外壳」组（见「悬浮胶囊」）。
- Claude 可以用就绪自检列出每台手机的状态：无障碍、截图、Bridge 输入法、是否亮屏解锁、前台 app、有没有悬浮窗权限。

## 手机操控：多台手机与安全护栏

同一账号可以有多台手机同时开着操控，Claude 按设备分开下命令，并受一组硬护栏约束。

- 多台手机：每条命令只发给指定的那一台。Claude 不指定时按「本轮已选定的 → 发起这轮对话的那台 → 唯一在线的那台」挑；多台在线又判断不了时会让用户指定。本轮一旦选定就锁住，不会出现读屏在 A、点按在 B。
- 高危确认：直接发短信、直接拨打电话调用时自动弹确认卡片，用户点确认才执行，取消就不执行（可改用只预填不发出的方式）。发消息、发帖、下单、删除、改账号或安全设置等不可撤回动作，Claude 必须先确认：优先在那台手机的悬浮胶囊上弹 ✕/√ 卡片，没有悬浮窗权限时在聊天里弹选择卡；用户拒绝或超时就不执行。
- 金融红线：Claude 绝不完成支付、转账、下单结算、借贷、理财购买，带到付款/确认页就停，弹通知请用户自己操作。
- 急停：手机通知栏操控服务通知上的「停止操控」，或在设置里关掉总开关；服务器立即拒掉这台手机正在执行和排队的命令。
- 频率护栏：每台手机每分钟最多 90 个动作；同一动作同样参数连续超过 15 次判为死循环拦下（看屏幕、等待、滚动、滑动不算）。
- 所有操控命令记操作审计。
- 系统限制：部分界面不开放无障碍信息，只能看截图按坐标点；有的 app 页面禁止截图；锁屏时无法操作。

## 悬浮胶囊（把 Claude 挂进胶囊）

悬浮胶囊是浮在任何 app 之上、贴着手机顶部摄像头挖孔的一枚黑色胶囊；把 Claude「挂」进去后，不用回到 bridge 就能下拉胶囊给 Claude 下指令，Claude 用手机操控在当前手机上办事。

- 开启：设置 ›「手机操控」页 ›「悬浮外壳」组 ›「悬浮外壳 · Agent 模式」开关。首次需要授予「显示在其它应用上层」（悬浮窗）权限，会跳系统设置。服务开着胶囊就一直在，bridge 退后台或被划掉也在。
- 挂载：在 Claude 页长按「菊花」（星标）拖到屏幕顶部挖孔附近松手。新对话空白页上的菊花 = 用当前模型和推理强度开一个新会话挂进去；对话里某条 Claude 回复旁的菊花 = 把这条对话续接进去。挂载后胶囊先短暂预热（思考动画，Claude 进入操控角色并建好会话），完成后挖孔中央亮起待命辉光并震动一下。
- 下指令：在待命胶囊上往下拉，胶囊变成输入条，输入后提交；Claude 的思考、动手、回复都显示在胶囊上（思考动画、行动心跳、回复卡片），需要确认的高危动作在胶囊上弹 ✕/√ 卡片。
- 打断：双击胶囊（挖孔处）停止当前这一轮，回到待命，仍保持挂载。
- 卸载：快速连点胶囊 5 次，断开并清掉挂载的会话，辉光渐暗消失。
- 挖孔位置不准时：同组的「校准挖孔位置」手动校准，「挖孔定位诊断」显示定位信息。
- 限制：只在安卓 app 里、悬浮外壳开着时才能拖菊花挂载；胶囊里的 Claude 要操作手机仍需手机操控已打开、无障碍已授权。

## 手机文件：本地位置

手机文件让用户在 bridge 里浏览自己手机上的文件，并让 Claude 在用户授权的范围内读写这些文件。

- 入口：工作空间（文件面板）切到「本地」。首次使用点「选择手机文件夹」授权（系统文件夹选择器），或「授权整个手机存储」（要在系统设置里打开「所有文件访问」）。
- 可以授权多个文件夹，列在「本地位置」里（标「手机文件夹」或「整机存储」），可随时用「＋」（「添加本地位置」）增加、撤销授权（不删除手机上的文件）。
- 在本地位置里能浏览、预览（文本类可在预览里编辑后保存回手机）、删除、重命名、移动、复制、用其它 app 打开、分享文件。
- 范围是 Android 系统硬限制：只能访问用户授权过的文件夹 / 媒体库；各 app 的私有数据区（Android/data、Android/obb，即「手机管家清缓存」的地方）任何普通 app 都看不到。
- 只在安卓 app 里可用；网页版显示「本地工作空间需在手机 App 内使用」。

## Claude 的手机文件工具

在本地位置授权之后，Claude 可以经手机文件工具在这些位置里列目录、读文件、写文件、扫描大文件、把手机文件完整拉到服务器、删除文件。

- 前提：服务器开启了手机文件功能（服务器配置项，默认关闭），且这轮对话是从安卓 app 发起的。从电脑网页发起的对话没有这组工具。
- 读写单文件上限 8MB；更大的文件用「拉到服务器」（流式，上限约 2GB），再在服务器上处理（解压、转换、分析）。
- 扫描大文件：按体积降序列出候选（默认 20MB 以上），常用于「清理占地方的文件」；是否没用由 Claude 结合路径和时间判断，给用户列建议后再删。
- 删除是不可撤销的：Claude 必须先把要删的文件（路径和体积）列给用户并得到明确确认。

## 原生上传与下载

安卓 app 用自己的原生上传器和下载器传文件，退到后台、锁屏也能传完。

- 下载：工作空间里对文件选「下载到本地」，文件直接下到手机的「下载」(Download) 文件夹；断网、切线路自动重试并断点续传，局域网地址失败就换隧道地址接着下，大文件分段并行；通知栏显示进度，完成后发一条可点开的通知。
- 上传：工作空间「上传文件」走系统文件选择器（可多选），原生分块上传到服务器；断网等网络回来续传，失败的可重试并从已传完的部分接着传。
- 进度、速率、状态都显示在工作空间的「传输」面板。

## 后台通知与「在等你回答」

安卓 app 在后台也能告诉用户 Claude 跑到哪了。

- 发送消息时 app 拉起一个原生前台服务跟踪这一轮：通知栏显示「Claude · 处理中」和进度，跑完弹「Claude · 完成」（「回复已生成，点击查看」）。即使 app 退后台、锁屏、被系统回收也照常。
- Claude 提问（等用户选择或回答）时弹横幅「Claude 在等你回答」；问题答掉或这一轮结束后自动撤掉。Claude 主动推送的提醒也走这条横幅通道。点通知回到 app。
- dimensio 分页的对话也有类似的后台通知（「等你处理」、跑完）。
- 开关：设置 ›「通用」›「通知」总开关；设置 › Claude ›「通知」组里分别控制「权限请求」「提问」「任务完成」（这三项只存这台设备）。
- 设置 ›「通用」›「后台运行」：让 app 不受系统省电限制，否则切到后台可能收不到任务进度与完成通知；未开启时显示「未开启」，点它申请。

## 系统返回键

在安卓 app 里，系统返回（返回键或侧滑手势）逐级关闭当前最上层的界面，不会误退出 app。

- 关闭顺序大致是：弹出菜单/灯箱 → 预览查看器 → 抽屉 → 设置 → 登录 → 各分页回主页。
- 已经在主页（或单 agent 模式的首页）再按返回，app 退到后台而不是被关掉，回来时原样接上。
- 网页版靠浏览器历史模拟同样的逐级返回。

## 扫码登录网页版

已登录的安卓 app 可以扫电脑浏览器上的二维码，让那个网页直接以 app 当前的身份登录，不用输密码。

- 网页端：登录页选「扫码登录」，出现二维码（提示「打开手机上的 The Bridge，在设置 › 账户点「扫一扫」」）。
- 手机端：设置 › 账户 ›「扫一扫 · 登录网页版」，扫码后在手机上确认。只在手机形态（安卓 app 或触屏设备）显示。
- 二维码 3 分钟内有效，确认后网页 60 秒内完成登录，否则作废；只有扫码并确认的手机能放行，拍下二维码的人拿不到登录态。
- 管理员扫码会给那个网页单独发一张管理员登录，可在控制台单独吊销。

## 扫码连接服务器（配对）

扫码连接是反方向的配对：已登录的一方出示二维码和 8 位数字配对码，还没登录的手机 app 扫一下就连上那台服务器，并以出码人的身份登录，不用抄地址和令牌。

- 出码的地方：桌面客户端安装向导的完成页、桌面客户端 设置 › 连接与更新 ›「手机扫码连接」›「显示配对二维码」、服务端控制台「设备」页的配对卡、手机/网页 设置 ›「关于」›「让另一台设备扫码连接」›「显示二维码」。
- 扫码的地方：手机 app 首屏（未登录）的「扫码连接」；已在用的 app 里 设置 ›「关于」›「扫码连接服务器」（只在安卓 app 里有）。没有相机时在 app 里填服务器地址和 8 位配对码。没装 app 的人用相机扫码也能打开网页版。
- 每张码 3 分钟有效、只能用一次；只给自己的设备扫——扫到的人会以出码人的身份登录。出码方能看到「已连接：哪台设备」，不是自己时可以当场撤销刚发出去的登录。
- 管理员可在控制台查看最近的配对记录。
