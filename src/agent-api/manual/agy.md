# Antigravity 分页

Antigravity 分页用 Google 的 Antigravity（agy）当 agent，在服务端某个文件夹里读写代码、跑命令，并能用上 bridge 自己的工具；这是功能扩展「Antigravity」，没装、没开或没有权限时主页上没有这个入口。

## Antigravity 分页是什么

Antigravity 分页（agent id `agy`）是 bridge 里由 Antigravity CLI 驱动的编程 / 通用 agent 对话页，模型是 Gemini 系列以及 Antigravity 账号里可选的其它模型。

- 属于可选功能扩展：服务端机器上要装有 Antigravity CLI 并登录过 Google 账号；服务端常驻一个 agy 进程，首条消息不用等启动。
- 与 Claude 分页的区别：Claude 是核心 agent，定时任务、项目模式、号池都只有它有；Antigravity 分页适合想用 Gemini 写代码、做对比，或用它自带的生图与子代理的场景。
- 用的是服务端主机上登录的那一个 Google 账号，所有人共用它的额度。

## Antigravity 分页的入口

- 手机：主页入口方块里的 Antigravity 图标（彩色拱形），点进全屏分页；返回回到主页。
- 桌面：主页上的同一个图标。
- 进分页一律落在新对话首页，要看哪个历史对话从左侧栏点。
- 管理员在设置的「Agent」页可开关 Antigravity；没装 CLI 时显示不可运行。
- 从工作空间把文件拖到入口或对话里，文件作为附件放进输入框。

接口：`ui.open`

## Antigravity 分页的会话与文件夹

每个会话绑定一个文件夹，就是这次对话里 agy 的工作目录。

- 文件夹在页面顶栏左侧、紧挨侧栏按钮的位置选；没选时落到工作空间根。会话建好后不能换文件夹。在文件夹列表或侧栏文件夹组上长按（桌面亦可右键或点行尾 `…`）可置顶或移除工作空间（已保存项目与「最近用过」均可移除，只移出列表、不删本地文件夹和历史对话）；侧栏文件夹组长按还支持「隐藏全部对话」，一键将该组对话移入「已隐藏」（可随时恢复）。
- 左侧栏按文件夹分组列出会话；最上面是「收藏」组（收藏的会话不在下面重复出现）。
- 行菜单：重命名、收藏 / 取消收藏、隐藏对话、彻底删除。隐藏的可以在「已隐藏」里恢复；彻底删除点两次确认，删掉后不可恢复（对话记录文件一并删除）。
- 搜索：侧栏搜索框里输入，标题与文件夹名立刻过滤；下面另有一段「对话内容」，是按对话正文搜到的结果，带命中的片段，点了打开那个对话。刚装好或对话很多时正文索引要建一会儿，过几秒再搜就全了。
- 离开页面或断网不中断：回到页面会接上正在跑的那一轮。
- 手机上一轮做完后，思考与工具调用的步骤行会收走、只留回答（在跑、被停下或出错时照常显示）；过程在右上角工作区的「活动」「审阅」里看。电脑上步骤行一直保留。
- 在 Antigravity 桌面版里建的会话也会列出来，可以打开接着聊。

接口：`sessions.list`、`sessions.search`、`sessions.read`

## Antigravity 分页的模型、思考深度与运行模式

输入框底栏依次是模型、思考深度（紧跟模型名的淡色小字）、连哪台电脑；右端的开口仪表点开是运行模式与用量。手机上底栏没有「连哪台电脑」这一项，它在仪表菜单里叫「运行环境」，点开就地选。

- 模型清单来自 agy 实时下发的目录：{{models}}
- 思考深度用调用原名 `low` / `medium` / `high` / `xhigh`，各模型支持的档不同。
- 运行模式：默认（改文件和跑命令前都要问）、接受编辑（工作目录里改文件不问）、自动（改文件和安全的命令不问）、计划（只先做规划）、完全放行（一律不问，bridge 替你点允许）。
- 开口仪表：中间的数字是上下文占用，环的填充是周额度，环上的点是 5 小时额度，开口里的图标是当前运行模式。

## 插话、稍后发送与停止

Antigravity 工作时输入框不锁定。

- 输入框空着时只有停止键。
- 写了东西时，回车（或点发送键）是插话：它做完手头这一步就读到这条，不打断任务；这条消息以用户气泡的样子夹在回答中间。
- 要等这一轮结束再发：点输入框上方那行右边的「稍后发送」，或按 `Ctrl+Enter`。排着的消息显示在输入框上方，可以立即发送（会停下手头这一步）或撤回到输入框；人按了停止则整队退回输入框。
- 停止：输入框空着时点停止键；写着东西时按 `Shift+Esc`。

接口：`chat.send`、`chat.stop`、`chat.pending`

## Antigravity 分页生成图片与其它媒体

出图有两条路，两条都能用：

- 自带生图：普通出一张图时，agy 把画图交给它自己的生图子代理，在后台画。对话里会出现一行「生成图片中 · 12s…」读秒，画完原地换成图片，agy 接着把话说完——中间不用再发消息催。这条路算 Antigravity 账号的额度。
- bridge 的媒体工具：要选模型、给参考图或改图、调尺寸画质，或者要生成视频、配音、音乐时，agy 改用 Media Studio 那套（与 Claude 分页同一个执行器）。同样有读秒的进度卡；视频、音乐要等一两分钟，期间 agy 会分段去取结果。
- 生成的图片、视频、音频以附件卡显示在回答里，点开在右侧工作区预览，可以下载、拖出页面。

## Antigravity 分页的工作区

工作区是对话右侧的一列卡片（手机上是覆盖整屏的独立页）：文件、审阅、终端、浏览器、活动。

- 顶带右侧一排图标各管一张卡；桌面上可以同时开几张（够宽时摆成两列），拖标题行排顺序、换列，拖两张卡之间的缝调高度，标题行双击放大。
- 桌面快捷键：`Ctrl+Shift+E` 文件、`Ctrl+Shift+G` 审阅、`` Ctrl+` `` 终端、`Ctrl+Shift+B` 浏览器（活动卡没有快捷键）。
- 「文件」定位在当前会话的文件夹；回答里的文件链接、附件卡点开都在这张卡里预览。
- 「浏览器」「终端」与 agy 用的是同一个实例：它操作时你实时看得见，你也可以自己动手。
- 「活动」列出这一轮做过的每一步，点一条跳到对话里对应的位置。

## Antigravity 能用哪些 bridge 工具

除了它自带的读写文件、跑命令、搜索、子代理，Antigravity 还挂着名为 bridge 的工具服务，在 设置 › Antigravity › Bridge 工具 里按组开关：

- 媒体生成、界面引导（带你去某个页面、在右侧工作区打开某个文件）、手机上已授权文件夹的读写。
- 侧边浏览器、共享终端、工作区协同（看你正开着的文件）、内嵌图表、bridge 手册与操作、你登记的电脑。
- 会话协作（另开 Claude 子会话、给别的会话发消息）、手机操控、拉取请求、项目记忆、插件提供的工具、扩展中心里的远程连接器。
- 没有对外副作用的工具（查手册、看页面、画图表、生成媒体等）不弹审批；共享终端、会改东西的 bridge 操作、动手操作电脑或手机、远程连接器照常问你。
- agy 对单次工具调用有 3 分钟上限，等得久的动作（终端等待、视频生成）会分段返回，由它接着取。

## Antigravity 分页的调试模式

设置 › Antigravity 最底部「调试」里有「调试模式」开关，只有主机管理员看得到。

- 打开后，Antigravity 把找 harness（它手上的工具、系统提示、审批、bridge 注入的机制）的毛病当成这一轮的首要产出：工具报错先判断是不是工具本身的锅，遇到多余的设计、缺的功能、不得不绕的路都当场记一条反馈。
- 反馈存在服务端根目录的 `harness-feedback/agy/<日期>/` 下，每条一份 Markdown，另有一份总索引；回答末尾会附一行「本轮调试反馈：N 条」。
- 开关改动后，下一次空闲时 agy 进程会重启一次，新的对话才带上这段要求。

接口：`feedback.harness`

## 经接口操作 Antigravity 的对话

bridge 的会话类操作默认管 Claude 分页；带上参数 `agent` 且值为 `agy` 时，管的是 Antigravity 的对话。

- `sessions.list`、`sessions.search`、`sessions.read`：列出、搜索、读取 Antigravity 的会话。
- `chat.send`：给某个 Antigravity 会话发消息（它正在跑时这条会排队，等这一轮结束再发）；`chat.wait` 等这一轮结束，`chat.stop` 停止，`chat.pending` 与 `chat.answer` 查看并应答它在等的审批或提问。
- `overview` 里在跑的 Antigravity 轮与「在等你」的卡片单列一项。

## Antigravity 分页给谁用

- 管理员：用服务端主机上的那个 agy 进程，能看到主机上全部 agy 会话，能管理 agy 的账号登录、全局 MCP 服务与插件。
- 注册成员：只有「完全信任」档的成员可以被授权（服务端控制台 › 用户里按人勾选 Antigravity）。每个成员用自己单独的一个 agy 进程和自己的一份会话库，看不到管理员和别人的对话；它读写文件只能在成员自己的文件夹里，跑命令过与 Claude 分页同一套筛查。
- 普通档成员不能用：agy 会执行工作目录里的钩子脚本，等于有了命令行权限，所以只开给本来就有命令行权限的档位。
- 成员不能登出账号、不能增删 agy 的 MCP 服务与插件、不能升级 CLI；这些只有管理员能做。
- 成员的进程闲置约 10 分钟自动退出，下次发消息再起；同时在用的成员进程默认最多 8 个，满了会提示「稍后再试」。
- 成员的账号被停用、删除或降成普通档时，他在跑的 Antigravity 对话当场中止、进程收掉；删号并选择删除数据时，他的 Antigravity 会话也一起删。
- 成员看到「工具调用守卫没有生效，已停用你的 Antigravity」：bridge 发现 Antigravity 执行了工具却没先来问它（多半是 Antigravity 升级后改了机制），为安全起见停掉了他的进程；这要管理员处理（重启 bridge 会重装守卫再试，仍不行就是 bridge 需要适配新版 Antigravity）。

## Antigravity 分页的限制

- 不能用于定时触发（定时触发只有 Claude 与 dimensio 引擎）；服务重启后不会自动续跑。
- 会话建好后不能换文件夹。
- 所有人共用服务端主机上登录的那一个 Google 账号的额度。
- agy 单次工具调用最长约 3 分钟。
- 服务端没装 Antigravity CLI 或设置里关闭时，入口不出现。
