# 没有的功能与过时说法

bridge 没有的功能、还没做完的占位，以及网上或旧资料里已经过时的说法；被问到时照实说「没有」，别推测。本手册其他章没写到的功能，一律当作没有。

## 明确没有的功能

- **语音输入**：Gemini 对话输入条上的麦克风还是占位（提示「即将上线」）；其他地方也没有语音转文字。
- **音频转文字 / 会议录音整理**：语音模块只做文字→语音，没有语音→文字。可以建议用户先在别处转成文字，再交给 Claude 整理。
- **全局助手（玻璃球）**：已经删除。它做的事——答用法、找入口、带你去某页、查任务、管定时任务、找文件和会话——现在由 Claude 会话里的 `mcp__bridge__manual` / `mcp__bridge__call` 两件工具和本接口承担；直接问 Claude 就行。
- **两个人实时共驾同一个会话**：不支持。多用户之间互相看不到对方的会话与文件（主机管理员经对方授权才能查看）。
- **组、团队、共享空间、角色管理**：没有；多用户就是「一个主人 + 若干互不往来的成员」。
- **iOS 专用 app**：没有；iPhone / iPad 用浏览器打开服务器地址。
- **定时任务**：不支持 cron 表达式（只有每天 / 工作日 / 每周 / 每小时）；不能用 Ultracode；服务端停机期间错过的不补跑。
- **分享链接**：发出去的文件 / 文件夹分享链接没有手动撤销入口，只能等到期失效；工作空间多选工具栏里的「分享」仍是占位。
- **会话导出**：服务端有导出能力，但界面上没有入口。
- **接口相关**：接口不能铸新的 agent 密钥（只能在设置页里生成）；不能跨身份操作别人的会话、文件、设备；没有账号管理、号池、服务控制这类控制台操作；成员拿不到 ChatGPT（Codex）分页。

## 已经过时的说法（以本手册为准）

旧资料（包括早期的全局助手知识库）里这些说法已经不对：

- 「退出登录在主页账户卡上」→ 手机 / 网页主页右上角的账户胶囊与账户卡还在（工作空间、额度、「账户」「设置」），但退出登录、切换账号在 设置 › 账户 里；桌面客户端没有账户胶囊，账户在设置侧栏顶部。
- 「设置分通用 / 壁纸 / 帮助三段」→ 现在手机 / 网页的设置根页是账户卡、Agent、服务器、偏好、这台设备、软件更新、提交反馈、关于；桌面客户端是另一套侧栏布局（见 settings 章）。
- 「只有中文、不能切语言」→ 有英文：设置 › 通用 › 语言。
- 「提交反馈是占位」→ 能用：反馈存到服务器给管理员看，可选同时发给 bridge 开发者（要管理员开、提交人自己勾）。
- 「手机操控开关在 设置 › 通用」→ 在 设置 › 这台设备 › 手机操控。
- 「主页入口是 Claude / ChatGPT / Harness / Vertex」→ Harness 现在叫 dimensio；入口按 agent 开关和个人授权显示，没开的不出现。
- 「ChatGPT 页给管理员和完全信任成员」→ 只给服务器主机；成员勾了也不生效。
- 「普通成员的 Gemini、图像、视频、语音、音乐全可用」→ 按人授权（新账号默认 Claude + Gemini），媒体与视频生成可被管理员单独关闭或限每日次数。
- 「完全信任成员的数据和别人隔离」→ 完全信任档有命令行，能读到服务器上所有人的数据和全部凭据，等同管理员。
- 「临时对话原名快照对话」→ 界面上只叫「临时对话」；「快照」专指公开聊天快照（/c/ 链接）。
- 「工作空间只能预览图片和文本」→ 还能预览视频、音频、PDF、Office、HTML，Markdown 有阅读 / 编辑 / 源码三态。
- 「手机『本地』文件只读、只能授权一个文件夹」→ 可授权多个位置或整机存储，能编辑保存、重命名、移动、复制、删除。
- 「定时任务结果在会话列表里标紫色『路由』标签」→ 前端已不显示这个标签，结果会话按普通会话列出。
- 「Claude 回复下方的紫色工作流胶囊」→ 改成了工作流卡片，详情在工作台「任务」里看。
- 「召唤 Claude 操作手机要经全局助手」→ 现在直接在 Claude 对话里说（它有手机操控工具），或在安卓 app 里把 Claude 拖进顶部悬浮胶囊。
