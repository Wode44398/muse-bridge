# 没有的功能与过时说法

Muse Bridge 没有的功能，以及从别的资料（包括 Muse Bridge 所源自的满配版）里可能看到、但这里不成立的说法；被问到时照实说「没有」，别推测。本手册其他章没写到的功能，一律当作没有。

## 明确没有的功能

- **别的 agent**：只有 Claude Code 和 dimensio。没有 ChatGPT / Codex 页、Gemini / Vertex 页、Antigravity，也没有 Gemini CLI。想用别家模型，在 dimensio 里配那家的 key，或用「自定义服务」接 OpenAI 兼容接口。
- **生成图片、视频、语音、音乐**：没有媒体生成功能和对应工具。
- **浏览器**：这台 Muse VM 起不了浏览器沙箱，没有工作台「浏览器」面板，agent 不能打开网页、截图、操作浏览器，也没有 Claude in Chrome。联网搜索和抓网页文字照常可用；做网页时用户可以在工作空间里点 html 预览。
- **设备 / 我的电脑**：没有把用户自己的电脑登记成设备、远程看屏幕、操作键鼠、在电脑上跑命令、端口转发、远程协助；终端只在服务器上。
- **手机操控与手机文件**：安卓 app 只是在线 WebView 壳，没有手机操控、无障碍、悬浮胶囊、手机本地文件夹（「本地」标签）、原生通知栏进度。
- **桌面客户端**：没有 Windows / Mac 桌面客户端、全局快捷键、托盘；电脑上用浏览器。
- **iPhone app**：没有；用 Safari 打开地址 → 分享 → 添加到主屏幕。
- **功能扩展的安装 / 卸载**：没有「功能扩展」注册表和离线包；装哪个 agent 由 Muse 用 `set-agents` 决定。「自定义」里的技能 / 连接器 / 插件是另一回事，照常可用（只对管理员生效）。
- **公网访问设置**：界面里没有「公网访问」「临时地址 / 隧道」的设置；地址与域名由 Muse 用 `bootstrap.sh` 管。
- **界面里的更新按钮、软件更新页**：更新跟 Muse 说「更新」；安卓 app 不用跟着更新。
- **Claude 号池智能路由**：没有按额度自动换号、会话中无缝换号；控制台「Claude 账号」里可以加几个号、手动「切到此号」。
- **全局助手（玻璃球）**：没有。用法、找入口、带你去某页、查任务、管定时任务、找文件和会话，直接问 Claude（它有 `mcp__bridge__manual` / `mcp__bridge__call`）或用本接口。
- **壁纸、流体壁纸、空间壁纸**：没有。
- **回收站**：工作空间的删除是永久的。
- **对话的公开分享、聊天快照**：界面上没有分享对话、公开聊天快照的入口；只有文件 / 文件夹的只读分享链接。
- **导出对话**：界面上没有导出按钮；可以让 Claude 把要点整理成文件再下载。
- **语音输入、语音转文字**：没有。
- **组、团队、共享空间**：没有；多人用就是「一个管理员 + 若干互不往来的注册账号」。
- **定时任务**：不支持 cron 表达式；不能用 Ultracode；不能用 dimensio；停机期间错过的不补跑。
- **分享链接**：发出去的链接没有手动撤销入口，只能等到期失效。
- **Docker**：这台 VM 跑不了容器。
- **接口相关**：接口不能铸新的 agent 密钥（只能在设置页里生成）；不能跨身份操作别人的会话和文件；没有服务端控制台（账号、邀请码、额度、Claude 账号、服务控制）的操作；不驱动 dimensio；没有装、更新、回滚、换域名这些运维操作（它们在 `bootstrap.sh` 里）。

## 可能看到的过时 / 不适用说法

- 「设置在 设置 › Agent › Claude 页」→ Muse Bridge 里 Claude 的设置是 设置 ›「Claude」分区，「Agent」分区只有管理员的开关。
- 「完全信任档」→ Muse Bridge 里叫「Pro 账号」，意思一样（有命令行、只给完全信任的人）。
- 「新账号默认有 Claude 和 Gemini」→ 新账号默认只有 Claude，dimensio 要管理员在控制台按人勾选。
- 「快照对话只保留最近 10 个」→ 现在叫「临时对话」，最后活动超过 30 天进回收站、再过 30 天才删，可以「存为工作空间」长期保留。
- 「Claude 页没有搜索 / 不能排队 / 不逐条问批准」→ 现在有全文搜索、插话与「稍后发送」队列、权限模式与工具审批卡、计划审批卡。
- 「收藏和改名只存在这台设备」→ 现在存在服务器上，各设备同步。
- 「反馈存在服务器上给管理员看」→ Muse Bridge 的反馈直接提交到项目公开的 GitHub Issues（安全问题私下发给维护者），见 overview 章「问题反馈」。
- 「定时任务按 GMT+8」→ 页面上的「服务器时区 GMT+8」不准，Muse 的 VM 一般是 UTC。
