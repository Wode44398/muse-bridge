# Vertex 分页（Gemini 对话与媒体生成）

Vertex 分页把 Google 的 Gemini 对话和图像、视频、语音、音乐生成放在一个页面的五个模块里；这是功能扩展「Gemini · Vertex」，没装、没开或没有授权时主页上没有这个入口。

## Vertex 分页是什么

Vertex 分页（agent id `gemini`，界面名 Vertex / Gemini）经 Google Vertex AI 提供五个模块：对话、图像、视频、语音、音乐。

- 它属于可选功能扩展：服务端要装上「Gemini · Vertex」扩展并配好 Google 云凭据；部分模型与档位还需要 Gemini API Key（界面上会注明「扣预付费额度」）。
- 五个模块都跟着 Gemini 这个 agent 的开关走：管理员关掉 Gemini 或没给某个成员授权，整个分页就不出现。成员默认有 Gemini。
- 成员的图像/语音/音乐与视频生成可被管理员分别关闭或限每日次数（控制台「额度与注册」）；被拦时会提示原因。
- 已生成的作品在 Gemini 关掉后仍能查看和删除，只是不能再生成。
- 媒体生成花钱且慢：视频、音乐一次约 1–2 分钟。

模型与参数的可选值（由服务端按能力表现填）：

{{vertex.params}}

## 配置 Google 云凭据（设置 › Agent › Vertex）

管理员在设置里直接给 Gemini · Vertex 配凭据，不用登录服务器、不用改环境变量或 config.json，VPS / Docker 部署也一样。

- 入口：设置 › Agent › Vertex（显示为 Gemini 那一行），开关下面的「Google 云凭据」卡。只有管理员看得到；Gemini · Vertex 扩展没装或跑不起来时没有这张卡。
- 凭据：拖入 JSON 文件、「选择文件」或「粘贴内容」。认两种常见的：
  - 服务账号密钥（推荐，适合服务器）：Google Cloud 控制台启用 Vertex AI API → IAM 和管理 › 服务账号里创建服务账号、角色选「Vertex AI 用户」→ 这个服务账号 › 密钥 › 添加密钥 › 创建新密钥 › JSON。
  - 自己的 Google 账号：在自己电脑上运行 `gcloud auth application-default login`，上传生成的 `application_default_credentials.json`（Windows 在 `%APPDATA%\gcloud\`，macOS / Linux 在 `~/.config/gcloud/`）。这种不带项目，项目 ID 要自己填。
  - 也认工作负载身份联合、模拟服务账号；OAuth 客户端 ID 文件（含 installed / web）不是凭据，会被拒。
- 项目 ID：服务账号密钥里带的会自动带出。Gemini API Key 可选（部分模型与 2K/4K 图像要用），保存后只显示末 4 位，可勾「清除已保存的 API Key」。「区域」里可改对话区域（默认 global）与媒体区域（默认 us-central1），一般不用动。
- 「保存并测试」：即时生效、不用重启，并真打一次 Google（countTokens，不计费；填了 API Key 再列一次模型），结果显示「✓ Vertex 已连通」或一句能照着改的原因（没开 Vertex AI API、缺「Vertex AI 用户」角色、没开结算、项目 ID 不对、凭据被吊销、连不上 Google）。「测试连接」只测不改；「移除凭据」删掉上传的那份。
- 优先级：这里上传的 > 服务器环境变量 GOOGLE_APPLICATION_CREDENTIALS > 服务器上的 gcloud 登录。环境变量设了 VERTEX_PROJECT / VERTEX_LOCATION / VERTEX_MEDIA_LOCATION / GEMINI_API_KEY 的那一项在卡片上是灰的（「由服务器环境变量指定」）。
- 存放：凭据只存在服务器数据目录的 `secrets/vertex-credentials.json`，成员看不到、也不进任何人的工作区；接口只回服务账号邮箱等摘要，不回密钥。
- 经家里主机中继使用 Vertex 的 Windows 客户端上，卡片只提示「凭据在主机上配置」。
- 接口（管理员）：`GET /api/vertex/credentials` 看现状；`POST /api/vertex/credentials` 传 `credentials`（JSON 文本，null = 删除）、`project`、`location`、`mediaLocation`、`apiKey`（'' = 清除）、`test`；`POST /api/vertex/credentials/test` 只测。

## Gemini 设置：别的 agent、能生成什么、内容安全过滤（设置 › Agent › Gemini）

「Google 云凭据」卡下面三组，管理员才看得到，改了即时生效（主机级，存 config.json 的 vertexHost）。只管 agent 自己调用，用户在 Vertex 页里手动生成不受影响。

- 「让别的 agent 生成媒体」：
  - 「Claude」（默认开）：Claude 对话和定时任务里的 mcp__media__* 生成工具。关掉就没有这组工具，也没有对应提示。
  - 「需要素材时主动生成」（默认开，跟在 Claude 下面）：开着时 Claude 做网页、文档会不等用户开口就配图配乐；关掉后只在用户明确要求时生成。
  - 「dimensio」（默认关）：打开后 dimensio 能经 BridgeCall 调 media.image / media.speech / media.music / media.video；图片和语音按 dimensio 的权限档审批，视频和音乐每次弹卡。dimensio 没装或跑不起来时没有这一行。
  - 「ChatGPT · Codex」（默认关，只在有 Codex 的服务器上出现）：同上，经 Codex 的 bridge 接口。
  - 「外部 agent（Agent 接入）」（默认开）：拿 agent 密钥调 /agent/v1/media.* 的 agent 和脚本。
- 「agent 能生成什么」：「图片」「语音」「音乐」「视频」各一个开关（对上面开着的 agent 都生效）；「视频最高分辨率」720p / 1080p / 4K（默认 4K = 不封顶），agent 要更高会降到这一档。成员另受「额度与注册」里的媒体开关与每日次数限制。
- 「内容安全过滤」：「骚扰」「仇恨言论」「色情内容」「危险内容」四类，每类「Google 默认」「不过滤」「只拦高风险」「拦中风险及以上」「拦低风险及以上」，即 Google AI Studio 的 Safety settings（Vertex safetySettings）。对 Gemini 对话和 Gemini 图像模型生效；全是「Google 默认」时不发这个参数（Google 对较新模型默认不过滤）。被拦下时对话里会出一句「被 Google 的内容安全过滤拦下了（原因）」，出图失败也写明原因。
- 关掉的调用方或种类：agent 接口目录里对应的 media.* 标不可用，原因写着「管理员没让 … 生成媒体（设置 › Agent › Gemini）」；Claude 从下一条消息起没有那几个工具（已经在跑的这一轮调用时也会被拒）。
- 卡片里有项目 ID 时还有「在 Google Cloud 查看：账单 · 配额 · 用量」三个直达链接（费用在用户自己的 Google Cloud 里）。
- 接口（管理员）：`media.settings` 看全部项与当前值，`media.settings_set` 改（values = { key: 值 }，null = 恢复默认）；同机 agent 实例（dimensio、Codex）不能改这组。HTTP：`GET / POST /api/vertex/settings`。

## Vertex 分页的入口与模块切换

- 手机：主页入口方块「Vertex」。顶部左侧「≡」打开历史抽屉；对话模块时左上是模型选择（显示「Gemini / 当前模型」）；右上「＋」新对话；右上图标按钮是「功能模块」菜单，在「对话 / 图像 / 视频 / 语音 / 音乐」间切换。
- 桌面：主页 Dock 上的 Vertex（Gemini 图标）。页面是三栏结构：左侧边栏可收起/展开（「收起边栏」/「展开边栏」），展开时列出「最近」对话；底部「主页」「设置」；对话模块的模型选择在输入框右侧的胶囊里（向上弹出）。
- 媒体模块在桌面宽屏下是工作室布局：左栏是模型卡和「参数」，中间是画布与历史，输入框钉底；手机上参数收在输入框上方的摘要标签里，点开是参数面板。
- 从工作空间把文件拖进来，松手提示「挂进这个对话」。

接口：`ui.open`

## Gemini 对话模块

Gemini 对话是普通的多轮问答，适合日常问答、查最新资讯、读图读 PDF。

- 输入框占位「问问 Gemini」，左侧「＋」上传文件：只收图片（PNG/JPEG/WebP/GIF/HEIC）和 PDF，单个不超过 7 MB。麦克风按钮是占位（「语音输入（即将上线）」），没有语音输入。
- 回答可「复制」「重试」；运行中可「停止」。
- 模型菜单（手机左上 / 桌面输入框右侧）里包含这一轮的全部设置：
  - 模型列表。
  - 「思考等级」：部分模型不支持最低档，菜单里自动隐藏。
  - 「工具」：「联网搜索」（Google 搜索增强，回答附来源，默认开）、「读取网址」（读消息里贴的网页）、「代码执行」（运行代码、可画图表）。某些模型开代码执行会关掉联网和读取网址，菜单里有提示。
  - 「识图清晰度」：图片按多少细节送给模型，低档最省。
  - 「系统提示词」：对之后每条消息都生效；只存在这台设备上（换设备不跟随）；最长约 8000 字。
- 设置（手机抽屉底部 / 桌面左下「设置」）：主题浅色/深色、「快速识图」（图片自动降画质、识图更快；关掉发原图更清晰但更慢，默认开）。
- 历史：手机「≡」抽屉里「历史对话」，桌面侧边栏「最近」；可打开、删除。

选型思路：要快、日常问答用默认模型；复杂推理、长文档分析换更强的模型并调高思考等级；问时事、价格、新闻务必开联网搜索。

接口：`sessions.list`、`sessions.read`

## 图像模块

图像模块（标题「图片」，副标题「Nano Banana · 对话式生成修改」）是对话式出图：先描述生成，再继续说「改成…」逐轮修改。

- 输入框：首轮占位「描述你想要的图像…」，有结果后变「继续修改这张图…」；按「生成」出图。
- 「＋」（「添加要编辑的图片」）：从「工作空间」或「手机存储」选一张图作为编辑底图；也可直接拖入或粘贴。单张不超过 7 MB；Imagen 系列模型不吃底图，没有这个入口。
- 参数（随模型显隐）：「输出格式」（「图文」/「仅图」）、「比例」（部分超宽比例只对个别模型可用，换模型后回到「自动」）、「分辨率」1K/2K/4K（个别模型只出 1K；个别模型的 2K/4K 走 Gemini API、扣预付费额度、返回 JPEG）、「思考强度」、Temperature、Top P、「人物生成」、「工具」里的「联网搜索」与「图片搜索」。
- 历史：空画布时下方显示「历史会话」缩略图网格，点开还原整条修改链，右上角可删除；也可在「≡」抽屉看「历史图片」。
- 本机模型：若管理员在本机部署了本地出图模型，模型列表里会多一个本机模型（副标题变为本机生成与编辑），支持最多 10 张参考图（总计 20 MB）、自定义宽高、步数和种子，结果可「用作下一轮参考」；管理员还能看到「本机部署」按钮。

选型思路：要最高画质选质量档模型；要画真实存在或最新的事物（人物、品牌、地标）选支持联网与图片搜索的模型并打开搜索；图标、小装饰选最省的轻量档；横幅/长条选支持超宽比例的模型。提示词写清主体、风格、构图、光线。

接口：`media.image`

## 视频模块

视频模块（副标题「Veo · 文字与图片生成视频」）把文字或图片生成几秒的短视频，约需 1–2 分钟。

- 任务类型由素材自动决定：只有文字 = 文生视频；加「首帧」= 图生视频；首帧 + 「尾帧」= 首尾插值；加「参考图」= 带入主体/风格（需要文字描述）。参考图与首尾帧互斥。
- 「＋」（「添加图片」）或拖入图片后选「把图片用作」首帧 / 尾帧 / 参考图；首尾帧可「互换首尾帧」。只有尾帧没有首帧会提示「首尾插值还差首帧」。哪些模型支持尾帧与参考图（及最多几张）以模型为准。
- 参数：「比例」、「时长」（不同模型档位不同，例如 4/6/8 秒或 3–10 秒逐秒）、「分辨率」（切模型时自动落回合法档）、「声音」（「生成音频」为视频配环境声与音效；原生带音轨的模型没有这个开关）。部分模型独有：「负面提示词」（不想出现的内容）、「画质」、「提示词」·「自动增强」（先把描述改写得更具体再生成）。
- 结果在「本次生成」里播放，点开全屏播放器；历史在「历史视频」。

选型思路：默认快速档性价比最高；要带对白/原生音轨或低价预览选原生带音轨的模型；要高分辨率再选高档并调高分辨率。提示词写清画面、主体运动、镜头运动、光线；用首帧控制开场画面最稳。

接口：`media.video`

## 语音模块

语音模块（副标题「Gemini TTS · 文本朗读合成」）把文字朗读成语音（只有文字转语音，没有语音转文字）。

- 在钉底输入框输入要朗读的文本（回车换行，Ctrl/⌘+Enter 或点「合成语音」），点「选音色」从音色网格挑一个（每个音色带特质说明）。
- 参数：「风格」（用一句自然语言前缀控制语气，没有独立的语速/情绪滑块）、「说话人」·「多人对白」（最多 2 人；正文按「名字：台词」分行，每位说话人都要填名字和音色）。
- 文本里可嵌入语气标签，例如 [laughs]、[whispers]。
- 结果在「本次合成」里播放；历史在「历史语音」，可删除。

接口：`media.speech`

## 音乐模块

音乐模块（副标题「Lyria · 文字生成配乐」）根据描述生成一段配乐，约需 1–2 分钟。

- 在输入框描述风格、乐器、情绪、节奏（英文描述更准，例如「calm lo-fi hip hop, mellow piano, 80 bpm」），点「生成音乐」。空画布有「试试这些」灵感标签，点一下填入。
- 「负面提示」（想排除的元素，如人声、鼓点）只有个别模型支持；其他模型的设置里写明「没有额外参数」。
- 不同模型长度不同：默认模型约 30 秒；部分模型能生成一分钟以上的完整歌曲并可演唱歌词（在描述里用 [Verse]/[Chorus] 标注歌词），这些模型需要 Gemini API Key。
- 结果在「本次生成」里播放；历史在「历史音乐」。

接口：`media.music`

## Vertex 作品的历史与归属

- 每个模块有自己的历史：对话 = 会话列表；图像 = 修改链会话；视频 / 语音 / 音乐 = 作品列表。手机经「≡」抽屉打开（标题分别为「历史对话」「历史图片」「历史视频」「历史语音」「历史音乐」），各项可删除。
- 作品按账号隔离：成员生成的东西只在他自己的空间里，别人看不到。
- 作品可从画布或历史里直接拖出页面（如拖进 Claude 对话或工作空间）。

## 在 Claude 和定时触发里用 Gemini

- Claude 分页：Gemini 对该账号开着（成员还需管理员开放媒体生成）时，Claude 自带图像、视频、语音、音乐四个生成工具，用户直接对 Claude 说「画一张…」「配一段音乐」即可，作品内联显示在对话里，文件可被 Claude 拿去当素材。管理员可以在 设置 › Agent › Gemini 关掉 Claude 的这组工具、关掉「主动生成」、只留某几种（见上面「Gemini 设置」）。
- dimensio：管理员在 设置 › Agent › Gemini 打开「dimensio」后，它经 BridgeCall 的 media.* 生成，产物用 saveTo 放进工作区。
- 定时触发：可选 Gemini 引擎做定时问答（可开联网搜索），结果进 Gemini 对话历史；定时触发不能直接调用媒体生成模块，需要定时出图时用 Claude 引擎并在指令里让它生成。

## Vertex 分页的限制

- 对话附件只收图片和 PDF（≤7 MB），不收音频、视频、Office 文档。
- 没有语音输入、没有语音转文字。
- 系统提示词与对话工具开关只存在当前设备。
- 媒体生成按次计费且较慢；成员受管理员设置的媒体/视频开关与每日次数限制。
- 部分模型/档位依赖 Gemini API Key，服务端没配时用不了。
