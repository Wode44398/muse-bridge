# dimensio 分页

dimensio 是一个可接多家模型厂商的通用编程 agent，以分页形式嵌在 bridge 里；这是功能扩展「dimensio」，没装、没开或没有授权时主页上没有这个入口。

## dimensio 是什么

dimensio（agent id `dimensio`）是 bridge 自带的另一套 agent 工作台：自己选模型厂商、填自己的 API Key，在项目文件夹里读写文件、跑命令、开浏览器、管理记忆。

- 与 Claude 分页的区别：Claude 分页固定用 Claude；dimensio 可以换厂商与模型（Anthropic、OpenAI、Gemini、通义千问、智谱、Kimi、MiMo 等，以及任何 OpenAI 兼容的自定义服务），适合想用别家模型、或用自己的 Key 计费的场景。
- 它属于可选功能扩展，服务端要装上「dimensio」扩展；它在服务端另起独立进程，bridge 负责转发与鉴权。
- 可以开给成员：每个获授权的成员有自己独立的 dimensio 实例，会话、配置、记忆都在他自己的文件夹里，工作区只能是他自己文件夹里的目录。成员默认没有 dimensio，需管理员在控制台按人勾选。

## dimensio 的入口

- 手机：主页入口方块「dimensio」，点进全屏分页；分页内顶栏返回钮或安卓返回键回主页。
- 桌面：主页 Dock 上的 dimensio 图标。
- 管理员在设置的「Agent」页开关 dimensio，并能看到它能否运行、Key 配没配。
- 从工作空间把文件拖进来，会投给当前这个 dimensio 会话。

接口：`ui.open`

## dimensio 的项目与会话

- 「项目与会话」侧栏：按项目列出会话，支持「搜索项目或对话」（项目名、标题与正文）、置顶项目、重命名、隐藏项目（只是不在侧栏显示，文件夹与历史不删）、删除会话。
- 「新建项目」：选一个文件夹作工作空间。桌面客户端（本机）弹系统文件夹选择器，其他端打开 bridge 的工作空间文件管理器选目录。
- 「新建快照」：一次性空间，不属于任何项目，只保留最新一条；聊过后可「存为工作空间」变成普通项目。
- 首次使用若「还没填 API Key」，侧栏会提示，需先在设置里配好模型服务。

## dimensio 的模型与模型服务

- 输入框处的模型菜单：选型号（可搜索）、「思考深度」；标注「会思考」「视觉」等能力；部分型号有更快输出档（按更高单价计费）。
- 「模型服务」：选择厂商并粘贴该厂商的 API Key；Key 加密存在服务端，不回传浏览器。
- 「添加自定义服务」：接任何兼容 OpenAI Chat Completions 的接口（中转站、OpenRouter、自己部署的 vLLM / Ollama 等），填「接口地址」（填到 /v1 这一级）与 API Key；接口不列模型清单时可手填「模型 ID」。
- 「本地 AI」：管理员的实例可以在本机显卡上启动/停止本地大模型（需事先在本机部署好模型文件），并调上下文长度、缓存精度等启动参数。成员实例没有本地 AI。

## dimensio 的运行档位与访问范围

输入框左下的档位胶囊打开「运行档位、访问范围与目标」菜单，对当前会话当场生效（运行中也算数），同时成为新对话的默认。

- 运行档位：「自主执行」（直接执行，可用规则把个别高危调用改成每次询问）、「只读」（只放行读取类工具，写文件与执行命令一律拒绝）、「先出计划」（只读研究 → 提交计划 → 批准后转自主开工）。
- 访问范围：「整机可访问」（可用绝对路径读写工作空间外的文件，密钥文件始终封锁）、「仅工作空间」（路径越界就拦下）。成员实例恒为仅工作空间，不显示此项。
- 「目标模式」：这条消息当作目标，没达成就自动一轮轮接着做；可给一条验证命令（如 npm test）并设最多轮数。
- 「离开模式」：出门前打开，提问按合理默认继续并写明假设，要批准的调用直接拒、计划留着等你；发新消息自动关闭。

## dimensio 的检查点与回滚

- 每条消息发出前自动留检查点；「回滚到检查点」可回到发某条消息之前的状态，工作空间文件与对话一起还原，之后还能再前滚回来。
- 「轮内快照」：agent 删文件、丢弃 git 改动之前自动拍的快照，回到那里只还原文件、对话不动。
- 若有文件不是这个对话改的（手改或别的对话改的），回滚前会列出来，确认才覆盖；有会话正在运行时不能回滚。

## dimensio 的工作区面板与记忆

- 工作区面板五个工具：「任务」（后台任务、子 agent、工作流的进度，点开看详情）、「审阅」（本会话或项目 git 的改动与 diff）、「终端」（没有命令行权限的成员不显示）、「浏览器」（可切桌面/平板/手机视口，与 agent 共享）、「文件」（当前工作空间的文件管理器）。
- 「记忆」：模型跨对话记住的事，分「全局记忆」（关于你和这台机器，每个项目都用）与「项目记忆」；可以查看、确认、驳回、清理，只有生效的记忆会进提示。
- 设置里还有：外观（浅色/深色）、界面语言、「显示全部工作过程」开关、权限规则（「每次问我」「从不允许」，逐行写如 Bash(git push:*)）、导出当前对话的诊断包（不含对话正文和 Key）。

## dimensio 操作你的电脑

- 和 Claude 一样：账号下登记过的电脑（装了桌面客户端并登录）都能让 dimensio 看屏幕、操作桌面程序、用那台电脑上带登录态的浏览器、在那台电脑上跑命令、读写那里的文件、在电脑和服务器之间拷文件、把那台电脑上的本机端口接到服务器。
- 默认操作的是输入框左下「电脑」胶囊选中的那台（见「设备」一章「会话连哪台电脑」）；也可以在对话里口头指定（「用我的笔记本」）。
- 管理员和成员都能用，各自只能操作自己名下的电脑；权限档（关闭 / 只看 / 操作）照样由那台电脑自己把关。

## dimensio 的限制

- 需要自备模型厂商的 API Key（或本机模型）；没配 Key 无法对话。
- 成员实例：访问范围锁死在自己的文件夹，没有本地 AI，没有命令行权限的成员也没有命令行与网页预览工具（操作自己电脑的设备工具照常有）。这是应用层护栏，不是系统级沙箱。
- 不能用于定时触发（定时触发只有 Claude 与 Gemini 引擎）。
- dimensio 的会话不在 Claude 会话列表里，接口的会话类操作是否覆盖 dimensio 以 `overview` 返回的能力为准。
