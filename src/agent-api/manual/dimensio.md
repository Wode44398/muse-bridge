# dimensio 页

dimensio 是 Muse Bridge 的第二个 agent：一个能接各家模型 API 的 agent 工作台，用用户自己的 API key 像 Claude Code 一样读写文件、跑命令、做项目。装的时候可以不装它；没装、没开或没给这个人勾时，主页上没有这个入口。这套接口不驱动 dimensio，用户要用就请他打开 dimensio 页。

## dimensio 是什么、和 Claude Code 页的区别

- 用的是各家的 API key（Anthropic、OpenAI、Gemini、DeepSeek、Kimi、智谱、通义、小米 MiMo，或任何 OpenAI 兼容服务），按各家价格计费；dimensio 里不显示花了多少钱。
- 有运行档位（自主执行 / 只读 / 先出计划）、访问范围、权限规则和批准卡片。
- 每个注册账号有自己独立的 dimensio 实例，会话、配置、记忆都在自己的文件夹里；同时最多 4 个人在用，20 分钟不用自动停，再打开会自动启动。
- 额度只算 Claude，dimensio 不计。
- 不能用于定时触发。

## 入口与页面布局

- 主页的 dimensio 方块；只装了 dimensio 时打开网址直接就是这一页。
- 左侧栏：「新对话」、搜索、快照对话、项目和对话列表；最底下「设置」（直达 设置 › dimensio）。
- 中间是对话，底部输入框左下是档位胶囊、右下是模型胶囊。
- 右侧工作区（顶栏「工作区」按钮）：「任务」「审阅」「终端」（没有命令行的账号没有）「文件」。没有浏览器面板。

接口：`ui.open`

## 模型与厂商

- 内置厂商的 key 让 Muse 写进服务器：`bootstrap.sh set-api-key <名字> <key>`（如 `ANTHROPIC_API_KEY`、`DEEPSEEK_API_KEY`、`GEMINI_API_KEY`、`KIMI_API_KEY`、`ZHIPU_API_KEY`、`QWEN_API_KEY`、`MIMO_API_KEY`），存在磁盘上，重启也在。
- 网页里 设置 › dimensio ›「模型服务」也能填，但以 Muse 部署说明为准：在 Muse 上优先让 Muse 跑 `set-api-key`。
- 模型胶囊菜单：选型号、「思考深度」；最下面「切换模型服务…」换厂商。
- 「添加自定义服务」：接任何 OpenAI 兼容接口（填到 `/v1` 那一级 + API Key），key 加密存在服务器上。添加前先让 Muse 跑 `allow-sites <接口地址>` 放行，不然会连接超时。注册账号不能加自定义服务。
- 在 Muse 上，新加一家厂商第一次访问时会弹审核卡，提醒用户选「总是允许此站点」。

## 档位、访问范围与权限

- 档位胶囊菜单：「运行档位」（「自主执行」默认 /「只读」/「先出计划」）、「访问范围」（「整机可访问」默认 /「仅工作空间」；注册账号固定仅工作空间、不显示这一项）、「离开模式」（出门前打开，不会卡在没人点的卡片上；发消息自动关）、「目标模式」（把目标发出去，它一轮接一轮做到达成，可设验证命令）。
- 权限规则：设置 › dimensio ›「权限规则」，「每次问我」「从不允许」两个框，一行一条（如 `Bash(git push:*)`）。
- 批准卡片 / 问题卡片 / 计划卡片出现在输入框上方；10 分钟没人批就按拒绝处理（计划 60 分钟）。任何一台登录着的设备都能处理。

## 对话、插话与回滚

- 它在干活时可以插话：直接发送，进「待送达的插话」，下一步时读到；可「撤回」或「立即中断并发送」。
- 停止：对话末尾状态行旁的「停止」。
- 斜杠命令：`/new`、`/compact`、`/handoff`、`/goal <目标>`，以及装过的技能。
- 「回滚到检查点」（顶栏历史图标）：每条消息都是检查点，文件和对话一起退回；「从这里改写」只退对话不退文件。
- 关掉浏览器、断网，任务照样在服务器上跑；VM 重启后会自动接着做（要等有人打开一次 dimensio 页）。

## 记忆、设置与限制

- 「记忆」：设置 › dimensio ›「记忆」›「记忆管理」，可以查看、确认、驳回、清理。
- 设置 › dimensio 还有「工作空间」（默认工作空间、访问范围）、「显示」（dimensio 外观、显示全部工作过程）、「诊断」（导出当前对话的诊断包）。
- 没有浏览器：不能打开网页、截图；联网搜索和抓网页文字照常可用（各家自带搜索优先，失败自动换下一家）。
- 用临时地址时回复可能要等整段做完才出来（已知限制，换成自己的域名就好）。
- dimensio 的对话不在 Claude 的会话列表里，接口的 `sessions.list`、`chat.send` 只管 Claude。
