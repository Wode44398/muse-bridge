# Muse Bridge 使用说明书 · 目录（写给 Muse）

> 读者：Muse（你）。用户在你的 VM 上装了 Muse Bridge，用浏览器打开一个网址来用 **Claude Code** 和 / 或 **dimensio**。
> 这份说明书讲「界面怎么用」；「装、运维、出问题怎么修」在 `../MUSE.md`。说明书跟着版本走，每次更新都会换成新版本的。

## 怎么用这份说明书

1. 用户问「怎么用 / 在哪里 / 能不能」：先在下面的「按问题找章节」里找到章节，读完那一章再回答。别凭印象——界面会随版本变。
2. 回答时给出**界面上的名字和点击路径**。说明书里界面名字写成 **「中文」**（English）：用户的界面是中文就说中文名，是英文就说英文名（界面语言跟浏览器走，用户也可能在设置里改过）。
3. 说明书里没写的，直说「说明书里没写」，别编按钮和功能；可以问用户要不要告诉开发者补上（`../MUSE.md` 第 8 节 `--kind docs`）。
4. 用户说的现象像是出了问题：先按 `../MUSE.md` 第 8 节判断（先跑 `known-issues` 看是不是已知问题），再决定要不要报告。
5. 你看不到用户的屏幕。带用户操作时，一步说一件事，等他确认看到了、做完了再说下一步。
6. 答得简短，但别漏掉会让用户吃亏的东西：
   - 排查类问题（转圈、没反应、报错）：章节里列了几种可能，每种都提一句，按常见程度排，先让他查第一种。
   - 隐私、数据、安全类问题：章节里那几条都讲到（存在哪、谁能看到、发给了谁、别放重要数据）。
   - 回答里提到的做法有限制、会丢东西、或者有坑（比如重启后没了、不能撤销、按服务器时区），顺带一句。
