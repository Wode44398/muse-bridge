# 文件、预览与分享

## 文件放在哪

| 身份 | 「工作空间」里看到的 | 在 VM 上的位置 |
|---|---|---|
| 管理员 | 服务器的主工作空间（还能切到整台机器的其他位置） | `/home/hatch/bridge-srv/workspace` |
| 注册账号（完全信任 / 普通） | 只有自己的文件夹 | `/home/hatch/bridge-srv/users/<账号名>` |

- Claude / dimensio 在项目里写的文件，就在那个项目的文件夹里，工作空间里能看到。
- 在对话里**直接上传的附件**不放在工作空间里（管理员的在 `bridge-srv/uploads`，注册账号的在自己文件夹下的隐藏目录 `.bridge` 里；dimensio 的附件在项目里的 `.dimensio/uploads/`）。
- 没有存储空间配额，受 VM 磁盘大小限制。删账号时管理员可以选择归档或连文件夹一起删。

## 打开工作空间

- 侧栏账户卡菜单 → **「工作空间」**（Workspace）；或主页右上账户胶囊里的 **「工作空间」**；或 **「设置 → 账户 → 工作空间」**（Settings → Account → Workspace）。
- Claude 页工作台里的 **「文件」**（Files）面板（电脑上快捷键 Ctrl+Shift+E，在右上 ⋮「更多」菜单里）也是文件管理器，直接打开当前项目的文件夹。
- 管理员的工作空间顶部有位置切换：**「工作空间」**、**「主目录」**（Home folder）、`/`（整台机器）。其他人只有自己的空间。管理员在「主目录」和 `/` 里删除时，按钮写的是 **「移到回收站」**（Move to Recycle Bin）。

## Windows 客户端里的电脑文件

Windows 客户端连接 Muse 服务端时，工作空间底部的 **「这台电脑」**（This computer）用于浏览本机授权的文件夹；点 **「添加文件夹」**（Add folder）通过系统窗口授权。浏览与预览在电脑本机完成，文件不会为了预览先上传到 Muse。Claude 工作台侧栏的位置也区分服务器和这台电脑。把文件发给 AI 会上传一份；文件夹默认只引用，Claude 按需读取，见 02-claude-code.md。

## 浏览和搜索

- 当前文件夹里分三块：**「最近」**（Recents）、文件夹、文件。「最近」只在最顶层出现，列最近的 6 个文件。图片和视频有缩略图，视频标着时长。
- **显示方式和排序**：右上角 ⋯ 按钮 **「显示方式」**（View Options）里可以切 **「列表」**（List）/ **「图标」**（Icons）/ **「大图标」**（Large Icons），下面一组按 **「名称」**（Name）/ **「修改日期」**（Date Modified）/ **「大小」**（Size）/ **「种类」**（Type）排序，同一项再点一下就在升序和降序之间切换。选择记在这台设备上；像相册的文件夹（名字是 DCIM、截图、照片这类，或者里面大多是图片和视频）单独记一份，没选过时默认用图标。
- 一个文件夹最多列出 1500 项；再多时顶部会提示「这里一共 N 项，只列出了前 M 项」，其余的用搜索按名字找。
- **隐藏项默认收起**：名字以点开头的文件 / 文件夹（`.git`、`.env` 之类）不直接列出。「文件夹」那一组标题的右边有 **「显示隐藏项」**（Show hidden）和数量（「显示方式」菜单里也有这一项），点开显示，再点 **「收起隐藏项」**（Hide hidden）收回去。「显示方式」菜单最后还有 **「多选」**（Select）。
- **搜索**：底部放大镜 **「搜索」**（Search），框里写着 **「搜索文件」**（Search files）。**只在当前文件夹里按文件名筛选**，不搜子文件夹、不搜文件内容。
- **手机上拖动**：长按文件后不松手直接拖，拖到某个文件夹上松手就移进去。拎着文件在文件夹上停一会儿**不会**自动钻进那个文件夹；想放进更深的目录，先打开那一层再拖。电脑上用鼠标拖还是会悬停展开。
- **电脑上用鼠标时**，Claude 工作台里的文件面板是电脑资源管理器的样子：右键菜单、Ctrl+C / Ctrl+X / Ctrl+V、F2 改名、Delete 删除、框选、拖到文件夹上移动（按住 Ctrl 是复制）。这一套里没有「显示隐藏项」这一行。另外：
  - 工具栏切 **「列表视图」**（Details）和 **「图标视图」**（Large icons）；列表视图点列标题排序。图标视图下，底部状态栏右边的滑块调 **「图标大小」**（Icon size），也可以用 Ctrl+滚轮、Ctrl+= / Ctrl+−。
  - 选中文件按空格 **「快速查看」**（Quick Look）：再按空格或 Esc 关掉，方向键切到上一个 / 下一个。
  - 工具栏的 **「预览窗格」**（Preview pane）按钮（Alt+P）在右边显示选中文件的大图和信息，默认关；窗口太窄时会自动收起。

## 文件 / 文件夹的操作菜单

手机上**长按**一个文件再松手（不移动）弹出菜单；网页里也可以点文件行右边的 ⋯。

| 菜单项 | 做什么 |
|---|---|
| **「发送给 AI」**（Send to AI…） | 选一个对话（或新对话），把它挂到输入框里，直接问 AI。文件不复制，没有大小限制 |
| **「分享链接」**（Share link…） | 生成一个只读的公开链接，见下面「分享链接」 |
| **「下载到本地」**（Download） | 只有文件能下载，**文件夹不能直接下载**——先「压缩…」成一个包再下载 |
| **「压缩…」**（Compress…） | 把选中的文件 / 文件夹打成压缩包：在弹出的框里填 **「存档名称」**（Archive name），选 **「格式」**（Format）（有 ZIP，其余格式取决于服务器装了什么）和 **「压缩级别」**（Compression level）：**「仅存储」**（Store）/ **「快速」**（Fast）/ **「标准」**（Normal）/ **「最小体积」**（Smallest），点「压缩」。在后台进行（可以点 **「后台继续」**（Run in background）关掉窗口），完成后压缩包出现在原文件夹里 |
| **「解压」**（Extract） | zip / 7z / tar / gz 这类压缩包，解压到旁边一个同名文件夹。带密码的压缩包不支持 |
| **「移动到」**（Move to…）、**「复制」**（Copy to…）、**「重命名」**（Rename…） | 名字里不能有 `: * ? " < > \|`；重名会自动加 (1) |
| **「显示简介」**（Get Info） | 类型、大小、修改时间、位置 |
| **「多选」**（Select） | 选几个一起移动 / 删除 |
| **「删除」**（Delete） | 工作空间里是**永久删除，没有回收站，找不回来** |
| 用「应用名」打开（Open with “…”） | 装了能打开这类文件的插件应用时才有：把文件交给那个应用打开（见 05-customize.md「插件做成的应用」） |
| **「分享」**（Share） | 调手机系统的分享，只在安卓 App 里能用（Muse 用的就是 bridge 的安卓 App）；网页里点了只会提示要在手机 App 里用 |

- 电脑上用鼠标时右键菜单的叫法略有不同：「解压到当前文件夹」（Extract here）、「剪切」「复制」「重命名」、**「简介」**（Properties），多选时是「压缩 N 项…」「删除（N 项）」；没有「移动到」和「多选」（用拖动和框选）。
- 想下载整个文件夹：先对它点「压缩…」，再下载生成的压缩包；也可以让 Claude 在回答里把这个文件夹作为结果给出来——回答里的文件夹卡片点 Download 就是一个 zip。
- 删错了文件：没有回收站。如果是 Claude 改坏 / 删掉的，可以用 Claude 页消息上的「回滚」（只能退回 Claude 自己的改动）；dimensio 有检查点回滚（见 03-dimensio.md）。

## 上传

- 文件管理器右上角 **「添加」**（Add）按钮（＋ 号）菜单里有 **「上传文件」**（Upload files）（可以一次选多个）、**「新建文件夹」**（New folder）和 **「新建 Markdown 文件」**（New Markdown file）（弹框里起个名字）。也可以直接把文件 / 文件夹拖进来（拖到某个文件夹图标上就传进那个文件夹）。
- 电脑上用鼠标时，工作台文件面板的 ＋ 按钮是 **「新建 / 导入」**（Create or import），空白处右键还有 **「上传文件夹…」**（Upload folder…）、粘贴、全选。
- 单个文件最大约 2GB；拖整个文件夹最多 5000 个文件、总共 8GB，会跳过 `node_modules`、`.git` 这类目录。
- 大文件分块传、断网会自动接着传；进度在右上角 **「传输」**（Transfers）里看，可以取消、失败了可以重试。
- 同名文件不会覆盖，新的会自动改名成 `名字 (1).扩展名`。
- 在对话里直接加附件是另一套限制（Claude 单个 20MB，dimensio 单个 30MB），见各自的章节。

## 预览

点一下文件就在查看器里打开（电脑上双击或回车）。图片、视频、音频、PDF、Office、代码和文本用的是同一个查看器：

- **翻看**：同一文件夹里的图片和视频按当前排序连成一组，左右翻（电脑上 ← / →）——正在看视频时左右滑和 ← / → 是拖进度，换文件改用顶上的上一个 / 下一个按钮（电脑上 PgUp / PgDn）；文档可以前后翻到同文件夹的上一个 / 下一个文件；音频会接着放同文件夹的下一首。Esc 或手机的返回键关掉。
- **右上角 ⋮ 菜单**：下载、**「复制路径」**（Copy path）、**「文件信息」**（File info）（类型、大小、修改时间、位置；照片还有拍摄时间、相机、拍摄参数）；从工作空间打开的还有 **「发送给 AI…」**（Send to AI…）、**「重命名…」**（Rename…）、删除；图片多一项 **「复制图片」**（Copy image）。安卓 App 里还有 **「分享」**（Share）和 **「打开方式…」**（Open with…），看手机本机的文件时还能 **「存到相册」**（Save to Photos）、**「设为壁纸…」**（Set as wallpaper…）。
- 聊天里的图片、附件和 Media Studio 生成的视频、音频，点开也是这个查看器。

| 类型 | 怎么看 |
|---|---|
| 图片 | 手机上左右滑翻，双指缩放、双击放大，往下拉关闭，单击切成纯黑底只看图。电脑上滚轮缩放、放大后按住拖动，底部浮条有缩放、**「实际大小」**（Actual size）、**「向左旋转」**（Rotate left）/ **「向右旋转」**（Rotate right）和 **「缩略图条」**（Thumbnails），双击或按 F 全屏。默认先显示约 1280 像素宽的轻量图，放大到看不清时自动加载原图细节；**「设置 → 通用 → 原图加载」**（Settings → General → Load full-resolution images）打开后一律直接看原图（更清楚但费流量）。原图特别大时会提示「原图过大，已显示高清预览」。HEIC 照片由服务端转换后显示；TIFF、相机 RAW 不能预览，可以下载 |
| 视频 | 电脑上鼠标一动出控制条，单击播放 / 暂停、双击全屏，空格、J / K / L、F、M 等快捷键都能用，← / → 后退 / 前进 10 秒（按住 Shift 是 30 秒），进度条悬停能看到画面缩略图，拖进度条时画面实时跟着变。手机上双击左右两侧（或点中间的两个圆环按钮）快退 / 快进 10 秒：那一侧的按钮原地长成一枚玻璃胶囊，报出一共跳了多少秒，连着点会累加，不到一秒就收起（不会顺带弹出进度条）；长按 2 倍速，左右滑拖进度（划过整个屏幕宽度是 90 秒），全屏会铺满整个屏幕、退出后回到原来的窗口接着放，全屏时左半边上下滑调亮度、右半边调音量，可以 **「锁定」**（Lock）防误触。底栏齿轮里有 **「播放速度」**（Playback speed）、画质、**「字幕」**（Subtitles）（读同名的 .vtt / .srt 文件）、**「循环播放」**（Loop）；还有 **「画中画」**（Picture in picture）。看过 30 秒以上的视频，下次打开会提示从上次的位置继续；播完会倒数几秒自动放同文件夹的下一个。画质默认「原画」；网不好真卡顿时（一分钟里卡三次，或一次卡住超过 6 秒；自己拖进度、快进快退带出来的短暂缓冲不算），画面上方会出一条提示「当前网络较慢 · 切换到流畅画质」（Slow connection · Switch to Smooth），点了切到「流畅」（服务端转成不超过 1080p，更省流量）；提示 10 秒后自己消失，同一个视频最多提示两次 |
| 音频 | 有封面（取自文件里的专辑图）、标题 / 艺人 / 专辑和波形进度条，能调倍速、循环、快退 / 快进 15 秒，**「上一首」**（Previous track）/ **「下一首」**（Next track）在同一文件夹里切，放完自动接下一首；切到后台不暂停 |
| PDF | 文字能选中复制，**「查找」**（Find）能搜全文；侧栏有页面 **「缩略图」**（Thumbnails）和 **「书签」**（Bookmarks），能输页码跳转。⋮ 里有 **「适应宽度」**（Fit width）、**「适应页面」**（Fit page）等缩放档、旋转、**「双页视图」**（Two-page view）和 **「打印」**（Print），深色主题下还有 **「深色页面」**（Dark pages）。加密的 PDF 会弹出密码框；扫描件没有可搜索的文字 |
| Excel（xlsx / xls / ods） | 带行号列标的真表格：**「工作表」**（Sheets）标签切换、**「冻结窗格」**（Freeze panes）、**「网格线」**（Gridlines）、**「公式栏」**（Formula bar），能选格子复制，选中区域时底部显示求和 / 平均值 / 计数。只能看不能改。加了密码的表格打不开（要下载后用 Excel / WPS 打开）；特别大的表只显示前面一部分 |
| Word（docx） | Muse 上默认没有装 LibreOffice，所以显示的是**快速预览**：由浏览器直接排版，纸张版面 + 左侧「导航」（标题目录）+ 查找，字体和分页可能和原文件不同，页面下方有一行说明。手机竖屏默认是 **「阅读视图」**（Reading view），按屏幕宽度重排 |
| PowerPoint（pptx） | 同样是快速预览：按原版式一张张画出来，有缩略图，能左右翻、**「放映」**（Present）（F5），有备注的可以在 ⋮ 里打开 **「演讲者备注」**（Speaker notes）。动画不播放，不常见的图表类型只画一个占位框 |
| 旧格式 doc / ppt、rtf、odt / odp | 要服务端的 LibreOffice 转换才能看，Muse 上默认没装，会显示 **「服务端没有安装 LibreOffice」**（LibreOffice isn’t installed on the server）。可以下载后用本机的 Office / WPS 打开，或者另存成 docx / pptx 再传上来；要在网页里直接看，见下面「Office 文件的说明」 |
| 网页（html） | 直接渲染，里面的脚本、动画也会跑；页面里用相对路径引用的**同目录（及子目录）的 js / css / 图片**也会按路径加载，所以带资源文件的小网站能完整预览。工具栏能切到源码（Ctrl+U），再切回 **「查看页面」**（View Page） |
| Markdown | 阅读 / 编辑都行，见下面 |
| 代码和文本（txt / js / json / py / yaml / log…） | 先以只读方式打开：语法高亮、行号，**「查找…」**（Find…）（Ctrl+F，可区分大小写、全字匹配、正则）、**「跳到行…」**（Go to Line…）（Ctrl+G）、**「自动换行」**（Word Wrap）、字号缩放、**「复制全文」**（Copy All）。要改就点 **「编辑」**（Edit），改完 **「保存」**（Save）。GBK 等中文编码会自动识别，认错了可以 **「通过编码重新打开」**（Reopen with Encoding）；这类文件保存时会转成 UTF-8（会先提示）。json 默认排好版显示，可以 **「查看原文」**（View Raw）；csv / tsv 默认显示成表格，能 **「筛选行…」**（Filter Rows…），点格子看完整内容。大文件手机上只读前 4MB、电脑上前 10MB，超过 5MB 或没读全的文件不能编辑 |
| 其他（zip 等） | 显示 **「该类型暂不支持内嵌预览」**（Can’t preview this file type），压缩包可以 **「解压到当前文件夹」**（Extract here），或者 **「下载文件」**（Download file） |

### Office 文件的说明

- **Excel 一直在浏览器里直接显示**，跟服务端装没装什么无关。
- **Word、PowerPoint**：装了 LibreOffice 的服务器会先把文件转成 PDF 再显示（版式和原文件一样，第一次打开要等转换，会显示「正在转换 · 已用 N 秒」，等得久可以点 **「先看快速预览」**（Show quick preview））。**Muse 上默认不装 LibreOffice**，docx / pptx 直接用快速预览，doc / ppt / rtf / odt / odp 打不开。这是 Muse 的安装选择，不是故障。
- 用户确实需要在网页里看旧格式、或者想要和原文件一样的版式时，可以请 Muse 在 VM 上装 LibreOffice（体积有几百 MB，下载要一段时间），装完**要重启一次服务**才认得出来（只重新打开文件不够）。具体做法见 `../MUSE.md` 第 6 节。

## Markdown 笔记

- 打开 `.md` 文件，顶部切换 **「阅读」**（Read）/ **「编辑」**（Edit）/ **「源码」**（Source）。编辑时停手约 1 秒就自动保存，也可以 Ctrl+S。单个文件最大 5MB。
- Claude 或别的设备改了同一篇：你没在改就自动同步；你也有没保存的改动时会自动合并，合并不了会提示选 **「保留我的」**（Keep mine）还是 **「用最新版」**（Use latest）。
- 支持 Obsidian 的写法：`[[笔记名]]` 双链（输入 `[[` 会提示）、`![[图片]]` 嵌入、笔记属性（文件开头的 YAML）、`#标签`；文末有反向链接。
- **插图片 / 附件**：直接粘贴截图，或把文件拖进正文，会存到笔记旁边的 `attachments/` 文件夹并插入 `![[文件名]]`。图片在编辑模式下可以拖右下角调大小。

## 把文件交给 AI

- 文件菜单里的 **「发送给 AI」**（Send to AI…）：选一个已有对话或开新对话，文件会挂到输入框，接着输入问题就行。文件夹也可以发。
- 也可以按住文件拖到对话里，或拖到主页的 Claude 方块上。
- 这样挂的文件不复制、不受附件大小限制，AI 直接读服务器上的原文件。

## 分享链接

- 文件菜单 → **「分享链接」**（Share link…）→ 弹出对话框：
  - **「启用分享密码」**（Require password）：可选，最多 64 个字符；
  - **「过期时间」**（Expiration）：1小时、1天（默认）、7天、30天（电脑上用鼠标的那一版对话框只有这四个按钮，没有标题）；
  - 点 **「创建链接」**（Create link）→ 出现 **「链接已创建」**（Link created），点 **「复制链接」**（Copy link）。有密码时，复制的内容会把密码一起带上。
- 链接是**创建那一刻的只读副本**：之后你再改原文件，链接里不会变。收到链接的人能浏览、预览、下载里面的文件，不能上传、修改、删除，也下载不了整个文件夹。
- 限制：总大小约 2GB 以内、一个文件夹最多 5000 项；`node_modules`、`.git` 这类目录不会放进去；工作空间根目录本身不能分享。
- **删不掉、只能等过期**：界面上没有撤销分享的按钮，到期自动失效。
- 用临时地址时，链接里带的也是临时地址：地址一变，旧链接就打不开了。要长期分享，先换成自己的域名。
- 设了密码的链接，输错太多次会锁 10 分钟。
- 「公开的对话快照」（`/c/` 开头的链接）在界面上**没有入口**，别答应用户能分享对话。
