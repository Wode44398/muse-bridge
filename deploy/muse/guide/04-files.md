# 文件、预览与分享

## 文件放在哪

| 身份 | 「工作空间」里看到的 | 在 VM 上的位置 |
|---|---|---|
| 管理员 | 服务器的主工作空间（还能切到整台机器的其他位置） | `/home/hatch/bridge-srv/workspace` |
| 注册账号（完全信任 / 普通） | 只有自己的文件夹 | `/home/hatch/bridge-srv/users/<账号名>` |

- Claude / dimensio 在项目里写的文件，就在那个项目的文件夹里，工作空间里能看到。
- 在对话里**直接上传的附件**不放在工作空间里（管理员的在 `bridge-srv/uploads`，注册账号的在自己文件夹下的隐藏目录 `.bridge` 里；dimensio 的附件在项目里的 `.dimensio/uploads/`）。
- 没有存储空间配额，受 VM 磁盘大小限制。删账号时管理员可以选择归档或连文件夹一起删。

## 打开工作空间

- 侧栏账户卡菜单 → **「工作空间」**（Workspace）；或主页右上账户胶囊里的 **「工作空间」**；或 **「设置 → 账户 → 工作空间」**（Settings → Account → Workspace）。
- Claude 页工作台里的 **「文件」**（Files）面板（电脑上快捷键 Ctrl+Shift+E，在右上 ⋮「更多」菜单里）也是文件管理器，直接打开当前项目的文件夹。
- 管理员的工作空间顶部有位置切换：**「工作空间」**、**「主目录」**（Home folder）、`/`（整台机器）。其他人只有自己的空间。管理员在「主目录」和 `/` 里删除时，按钮写的是 **「移到回收站」**（Move to Recycle Bin）。

## 浏览和搜索

- 当前文件夹里分三块：**「最近」**（Recents）、文件夹、文件。「最近」只在最顶层出现，列最近的 6 个文件。图片和视频有缩略图。
- 一个文件夹最多列出 1500 项；再多时顶部会提示「这里一共 N 项，只列出了前 M 项」，其余的用搜索按名字找。
- **隐藏项默认收起**：名字以点开头的文件 / 文件夹（`.git`、`.env` 之类）不直接列出，列表底部有一行 **「显示隐藏项」**（Show hidden）和数量，点开显示，再点 **「收起隐藏项」**（Hide hidden）收回去。
- **搜索**：底部放大镜 **「搜索」**（Search），框里写着 **「搜索文件」**（Search files）。**只在当前文件夹里按文件名筛选**，不搜子文件夹、不搜文件内容。
- **电脑上用鼠标时**，Claude 工作台里的文件面板是电脑资源管理器的样子：右键菜单、Ctrl+C / Ctrl+X / Ctrl+V、F2 改名、Delete 删除、框选、拖到文件夹上移动（按住 Ctrl 是复制）。这一套里没有「显示隐藏项」这一行。

## 文件 / 文件夹的操作菜单

手机上**长按**一个文件再松手（不移动）弹出菜单；网页里也可以点文件行右边的 ⋯。

| 菜单项 | 做什么 |
|---|---|
| **「发送给 AI」**（Send to AI…） | 选一个对话（或新对话），把它挂到输入框里，直接问 AI。文件不复制，没有大小限制 |
| **「分享链接」**（Share link…） | 生成一个只读的公开链接，见下面「分享链接」 |
| **「下载到本地」**（Download） | 只有文件能下载，**文件夹不能直接下载**——先「压缩…」成一个包再下载 |
| **「压缩…」**（Compress…） | 把选中的文件 / 文件夹打成压缩包：在弹出的框里填 **「存档名称」**（Archive name），选 **「格式」**（Format）（有 ZIP，其余格式取决于服务器装了什么）和 **「压缩级别」**（Compression level）：**「仅存储」**（Store）/ **「快速」**（Fast）/ **「标准」**（Normal）/ **「最小体积」**（Smallest），点「压缩」。在后台进行（可以点 **「后台继续」**（Run in background）关掉窗口），完成后压缩包出现在原文件夹里 |
| **「解压」**（Extract） | zip / 7z / tar / gz 这类压缩包，解压到旁边一个同名文件夹。带密码的压缩包不支持 |
| **「移动到」**（Move to…）、**「复制」**（Copy to…）、**「重命名」**（Rename…） | 名字里不能有 `: * ? " < > \|`；重名会自动加 (1) |
| **「显示简介」**（Get Info） | 类型、大小、修改时间、位置 |
| **「多选」**（Select） | 选几个一起移动 / 删除 |
| **「删除」**（Delete） | 工作空间里是**永久删除，没有回收站，找不回来** |
| **「分享」**（Share） | 调手机系统的分享，只在 bridge 自己的手机 App 里能用；网页和 Muse 的安卓 App 里点了只会提示要在手机 App 里用 |

- 电脑上用鼠标时右键菜单的叫法略有不同：「解压到当前文件夹」（Extract here）、「剪切」「复制」「重命名」、**「简介」**（Properties），多选时是「压缩 N 项…」「删除（N 项）」；没有「移动到」和「多选」（用拖动和框选）。
- 想下载整个文件夹：先对它点「压缩…」，再下载生成的压缩包；也可以让 Claude 在回答里把这个文件夹作为结果给出来——回答里的文件夹卡片点 Download 就是一个 zip。
- 删错了文件：没有回收站。如果是 Claude 改坏 / 删掉的，可以用 Claude 页消息上的「回滚」（只能退回 Claude 自己的改动）；dimensio 有检查点回滚（见 03-dimensio.md）。

## 上传

- 文件管理器右上角 **「添加」**（Add）按钮（＋ 号）菜单里有 **「上传文件」**（Upload files）（可以一次选多个）、**「新建文件夹」**（New folder）和 **「新建 Markdown 文件」**（New Markdown file）（弹框里起个名字）。也可以直接把文件 / 文件夹拖进来（拖到某个文件夹图标上就传进那个文件夹）。
- 电脑上用鼠标时，工作台文件面板的 ＋ 按钮是 **「新建 / 导入」**（Create or import），空白处右键还有 **「上传文件夹…」**（Upload folder…）、粘贴、全选。
- 单个文件最大约 2GB；拖整个文件夹最多 5000 个文件、总共 8GB，会跳过 `node_modules`、`.git` 这类目录。
- 大文件分块传、断网会自动接着传；进度在右上角 **「传输」**（Transfers）里看，可以取消、失败了可以重试。
- 同名文件不会覆盖，新的会自动改名成 `名字 (1).扩展名`。
- 在对话里直接加附件是另一套限制（Claude 单个 20MB，dimensio 单个 30MB），见各自的章节。

## 预览

点一下文件就能预览（电脑上双击或回车）：

| 类型 | 怎么看 |
|---|---|
| 图片 | 同一文件夹里的图片可以左右翻，双指 / 双击放大，下滑关闭。默认先加载轻量图，放大再换原图（**「设置 → 通用 → 原图加载」**（Settings → General → Load full-resolution images）打开后直接看原图） |
| 视频 | 播放器：双击快进 / 快退 10 秒，长按 2 倍速；网不好时可以切「流畅」画质 |
| 音频 | 带波形的播放器 |
| PDF | 适应宽度，可以缩放、翻页 |
| Word / Excel / PowerPoint | Excel 按工作表显示表格；Word、PowerPoint 是**近似预览**，排版以下载的原文件为准 |
| 网页（html） | 直接渲染，里面的脚本、动画也会跑；页面里用相对路径引用的**同目录（及子目录）的 js / css / 图片**也会按路径加载，所以带资源文件的小网站能完整预览 |
| Markdown | 阅读 / 编辑都行，见下面 |
| 代码和文本（txt / js / json / py / yaml / log…） | 可以直接改，点保存 |
| 其他（zip 等） | 显示 **「该类型暂不支持内嵌预览」**（Can’t preview this file type），可以解压或 **「下载文件」**（Download file） |

## Markdown 笔记

- 打开 `.md` 文件，顶部切换 **「阅读」**（Read）/ **「编辑」**（Edit）/ **「源码」**（Source）。编辑时停手约 1 秒就自动保存，也可以 Ctrl+S。单个文件最大 5MB。
- Claude 或别的设备改了同一篇：你没在改就自动同步；你也有没保存的改动时会自动合并，合并不了会提示选 **「保留我的」**（Keep mine）还是 **「用最新版」**（Use latest）。
- 支持 Obsidian 的写法：`[[笔记名]]` 双链（输入 `[[` 会提示）、`![[图片]]` 嵌入、笔记属性（文件开头的 YAML）、`#标签`；文末有反向链接。
- **插图片 / 附件**：直接粘贴截图，或把文件拖进正文，会存到笔记旁边的 `attachments/` 文件夹并插入 `![[文件名]]`。图片在编辑模式下可以拖右下角调大小。

## 把文件交给 AI

- 文件菜单里的 **「发送给 AI」**（Send to AI…）：选一个已有对话或开新对话，文件会挂到输入框，接着输入问题就行。文件夹也可以发。
- 也可以按住文件拖到对话里，或拖到主页的 Claude 方块上。
- 这样挂的文件不复制、不受附件大小限制，AI 直接读服务器上的原文件。

## 分享链接

- 文件菜单 → **「分享链接」**（Share link…）→ 弹出对话框：
  - **「启用分享密码」**（Require password）：可选，最多 64 个字符；
  - **「过期时间」**（Expiration）：1小时、1天（默认）、7天、30天（电脑上用鼠标的那一版对话框只有这四个按钮，没有标题）；
  - 点 **「创建链接」**（Create link）→ 出现 **「链接已创建」**（Link created），点 **「复制链接」**（Copy link）。有密码时，复制的内容会把密码一起带上。
- 链接是**创建那一刻的只读副本**：之后你再改原文件，链接里不会变。收到链接的人能浏览、预览、下载里面的文件，不能上传、修改、删除，也下载不了整个文件夹。
- 限制：总大小约 2GB 以内、一个文件夹最多 5000 项；`node_modules`、`.git` 这类目录不会放进去；工作空间根目录本身不能分享。
- **删不掉、只能等过期**：界面上没有撤销分享的按钮，到期自动失效。
- 用临时地址时，链接里带的也是临时地址：地址一变，旧链接就打不开了。要长期分享，先换成自己的域名。
- 设了密码的链接，输错太多次会锁 10 分钟。
- 「公开的对话快照」（`/c/` 开头的链接）在界面上**没有入口**，别答应用户能分享对话。
