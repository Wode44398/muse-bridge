# 文件、预览与分享

## 文件放在哪

| 身份 | 「工作空间」里看到的 | 在 VM 上的位置 |
|---|---|---|
| 管理员 | 服务器的主工作空间（还能切到整台机器的其他位置） | `/home/hatch/bridge-srv/workspace` |
| 注册账号（Pro / 普通） | 只有自己的文件夹 | `/home/hatch/bridge-srv/users/<账号名>` |

- Claude / dimensio 在项目里写的文件，就在那个项目的文件夹里，工作空间里能看到。
- 在对话里**直接上传的附件**不放在工作空间里（管理员的在 `bridge-srv/uploads`，注册账号的在自己文件夹下的隐藏目录 `.bridge` 里；dimensio 的附件在项目里的 `.dimensio/uploads/`）。
- 没有存储空间配额，受 VM 磁盘大小限制。删账号时管理员可以选择保留或连文件夹一起删。

## 打开工作空间

- 侧栏账户卡菜单 → **「工作空间」**（Workspace）；或主页右上账户胶囊里的 **「工作空间」**；或 **「设置 → 账户 → 文件与分享」**（Settings → Account → Files & sharing）→ **「打开」**（Open）。
- Claude 页工作台里的 **「文件」**（Files）面板（电脑上快捷键 Ctrl+Shift+E）是同一个文件管理器，只是直接打开当前项目的文件夹。
- 管理员的工作空间顶部有位置切换：**「工作空间」**、**「主目录」**（Home folder）、Dimensio Projects、`/`（整台机器）。其他人只有自己的空间。

## 浏览和搜索

- 当前文件夹里分三块：**「最近」**（Recents）、文件夹、文件。「最近」只在最顶层出现，列最近的 6 个文件。图片和视频有缩略图。
- 一个文件夹最多列出 1500 项，再多的看不到（没有提示）。
- **搜索**：底部放大镜 **「搜索」**（Search）。**只在当前文件夹里按文件名筛选**，不搜子文件夹、不搜文件内容。
- 在 Claude 工作台里用鼠标时，文件面板是电脑资源管理器的样子：右键菜单、Ctrl+C / Ctrl+X / Ctrl+V、F2 改名、Delete 删除、框选、拖到文件夹上移动（按住 Ctrl 是复制）。

## 文件 / 文件夹的操作菜单

手机上**长按**一个文件再松手（不移动）弹出菜单；电脑上右键，或者点文件行右边的 ⋯。

| 菜单项 | 做什么 |
|---|---|
| **「发送给 AI」**（Send to AI…） | 选一个对话（或新对话），把它挂到输入框里，直接问 AI。文件不复制，没有大小限制 |
| **「分享链接」**（Share link…） | 生成一个只读的公开链接，见下面「分享链接」 |
| **「下载到本地」**（Download） | 只有文件能下载，**文件夹不能直接下载** |
| **「解压」**（Extract） | zip / 7z / tar / gz 这类压缩包，解压到旁边一个同名文件夹。带密码的压缩包不支持 |
| **「移动到」**（Move to…）、**「复制」**、**「重命名」** | 名字里不能有 `: * ? " < > \|`；重名会自动加 (1) |
| **「显示简介」**（Get Info） | 类型、大小、修改时间、位置 |
| **「多选」**（Select） | 选几个一起移动 / 删除 |
| **「删除」**（Delete） | **永久删除，没有回收站，找不回来** |

- 想下载整个文件夹：让 Claude 把它打包，或者让 Claude 在回答里把这个文件夹作为结果给出来——回答里的文件夹卡片点 Download 就是一个 zip。
- 删错了文件：没有回收站。如果是 Claude 改坏 / 删掉的，可以用 Claude 页消息上的「回滚」（只能退回 Claude 自己的改动）；dimensio 有检查点回滚（见 03-dimensio.md）。

## 上传

- 文件管理器右上角 **「添加」**（Add）按钮（＋ 号）→ **「上传文件」**（Upload files），可以一次选多个；或者直接把文件 / 文件夹拖进来（拖到某个文件夹图标上就传进那个文件夹）。
- 单个文件最大约 2GB；拖整个文件夹最多 5000 个文件、总共 8GB，会跳过 `node_modules`、`.git` 这类目录。
- 大文件分块传、断网会自动接着传；进度在右上角 **「传输」**（Transfers）里看，可以取消、失败了可以重试。
- 同名文件不会覆盖，新的会自动改名成 `名字 (1).扩展名`。
- 在对话里直接加附件是另一套限制（Claude 单个 20MB，dimensio 单个 30MB），见各自的章节。

## 预览

点一下文件就能预览（电脑上双击或回车）：

| 类型 | 怎么看 |
|---|---|
| 图片 | 同一文件夹里的图片可以左右翻，双指 / 双击放大，下滑关闭。默认先加载轻量图，放大再换原图（设置里可改成直接看原图） |
| 视频 | 播放器：双击快进 / 快退 10 秒，长按 2 倍速；网不好时可以切「流畅」画质 |
| 音频 | 带波形的播放器 |
| PDF | 适应宽度，可以缩放、翻页 |
| Word / Excel / PowerPoint | Excel 按工作表显示表格；Word、PowerPoint 是**近似预览**，排版以下载的原文件为准 |
| 网页（html） | 直接渲染，里面的脚本、动画也会跑 |
| Markdown | 阅读 / 编辑都行，见下面 |
| 代码和文本（txt / js / json / py / yaml / log…） | 可以直接改，点保存 |
| 其他（zip 等） | 显示「暂不支持预览」，可以下载或解压 |

## Markdown 笔记

- 打开 `.md` 文件，顶部切换 **「阅读」**（Read）/ **「编辑」**（Edit）/ **「源码」**（Source）。编辑时停手约 1 秒就自动保存，也可以 Ctrl+S。单个文件最大 5MB。
- Claude 或别的设备改了同一篇：你没在改就自动同步；你也有没保存的改动时会自动合并，合并不了会提示选 **「保留我的」**（Keep mine）还是 **「用最新版」**（Use latest）。
- 支持 Obsidian 的写法：`[[笔记名]]` 双链（输入 `[[` 会提示）、`![[图片]]` 嵌入、笔记属性（文件开头的 YAML）、`#标签`；文末有反向链接。
- **插图片 / 附件**：直接粘贴截图，或把文件拖进正文，会存到笔记旁边的 `attachments/` 文件夹并插入 `![[文件名]]`。图片在编辑模式下可以拖右下角调大小。

## 把文件交给 AI

- 文件菜单里的 **「发送给 AI」**（Send to AI…）：选一个已有对话或开新对话，文件会挂到输入框，接着输入问题就行。文件夹也可以发。
- 也可以按住文件拖到对话里，或拖到主页的 Claude 方块上。
- 这样挂的文件不复制、不受附件大小限制，AI 直接读服务器上的原文件。

## 分享链接

- 文件菜单 → **「分享链接」**（Share link…）→ 弹出对话框：
  - **「启用分享密码」**（Require password）：可选，最多 64 个字符；
  - **「过期时间」**（Expiration）：1 小时、1 天（默认）、7 天、30 天；
  - 点 **「创建链接」**（Create link）→ 点链接复制。有密码时，复制的内容会把密码一起带上。
- 链接是**创建那一刻的只读副本**：之后你再改原文件，链接里不会变。收到链接的人能浏览、预览、下载里面的文件，不能上传、修改、删除，也下载不了整个文件夹。
- 限制：总大小约 2GB 以内、一个文件夹最多 5000 项；`node_modules`、`.git` 这类目录不会放进去；工作空间根目录本身不能分享。
- **删不掉、只能等过期**：界面上没有撤销分享的按钮，到期自动失效。
- 用临时地址时，链接里带的也是临时地址：地址一变，旧链接就打不开了。要长期分享，先换成自己的域名。
- 设了密码的链接，输错太多次会锁 10 分钟。
- 「公开的对话快照」（`/c/` 开头的链接）和单文件直链（`/s/`）在界面上**没有入口**，别答应用户能分享对话。
