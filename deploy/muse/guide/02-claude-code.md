# Claude Code 页

Claude Code 是 Anthropic 的编程 / 通用 agent，在这台 VM 上替用户读写文件、跑命令、做项目，用的是用户（服务器）配好的 Claude 订阅。这一章讲它的页面怎么用。没配 Claude 令牌时怎么配，见 `../MUSE.md` 4.4。

## 谁能用、能做到什么程度

| 身份 | 怎么登录 | 能动哪些文件 | 有没有命令行（终端、让 Claude 跑命令） |
|---|---|---|---|
| 管理员 | 管理员令牌 | 整台服务器 | 有 |
| Pro 账号 | 账号密码（Pro 邀请码注册的） | 只有自己的文件夹 | 有 |
| 普通账号 | 账号密码 | 只有自己的文件夹 | **没有**：Claude 不能跑命令，也没有终端 |

- Claude 做事**不会逐条问你批准**：没有「每次问我」这类开关，它直接读写文件、跑命令。普通账号、Pro 账号由服务器把它关在自己的文件夹里（越界的操作会被拒，Claude 自己会看到拒绝原因）。
- 所有人共用服务器上配的那份 Claude 订阅的额度（见下面「用量」）。
- 只装了 Claude Code 时没有主页，打开网址就是这一页；两个 agent 都装了时从主页的 Claude 方块进来。

## 页面布局

- **左侧栏**：项目和历史对话。电脑上一直在（拖右边缘调宽度）；手机上点左上角 **「菜单」**（Menu）拉出来；中等宽度（平板、折叠屏）点同一个按钮固定 / 收起。
- **中间**：对话和下面的输入框。
- **右侧工作台**：终端、审阅、文件、任务（见「工作台」）。电脑上在右上角工具条打开；手机上点右上角两个点的 **「工作台」**（Workbench）按钮，从底部弹出。
- 侧栏从上到下：
  - **「主页」**（Home）：回主页。只装一个 agent 时没有这一项。
  - **「新建项目」**（New project）、**「新建快照」**（New snapshot）、**「定时触发」**（Routines）。
  - **「自定义」**（Customize）：装技能、连接器、插件，只有管理员有（见 05-customize.md）。
  - 分组：**「快照」**（Snapshot）、**「收藏」**（Starred）——收藏过对话才出现、**「项目」**（Projects）。
  - 最底下是账户卡：点开有设置、账户、关于、工作空间、扫一扫登录网页版（手机上）、退出登录。
- 手机上从屏幕左边缘往右滑回主页；返回键会先关掉弹出的东西，再一层层退。

## 开始一个对话

- **没有单独的「新对话」按钮**：在侧栏**点一个项目**，就在那个项目（文件夹）里开一个新对话；或者点 **「快照对话」**（Snapshot chat）。
- 新对话沿用你上次用的模型、思考深度（多台设备同步）。
- 欢迎页的标题和输入框提示是英文的（Hey there…、Type / for skills），中英文界面都一样。

### 项目 = 文件夹

- 每个项目就是服务器上的一个文件夹，在项目里开的对话，Claude 就在这个文件夹里干活；对话列在它所属的项目下面。
- 默认项目是你的工作空间根目录，删不掉。项目名就是文件夹名，**不能改名**。最多 200 个项目。
- **新建项目**：点 **「新建项目」**（New project），弹出一个文件浏览器。**按住一个文件夹（约半秒）拖到底部那条栏上松手**，它就成了新项目；单击文件夹只是打开它，不会选中。可以先在里面新建文件夹再拖。管理员能选整台服务器上的位置，其他人只能选自己工作空间里的。
- **排序**：拖动项目行（手机上长按再拖），顺序存在服务器上、各设备一致。
- **删除项目**：项目行的 ⋮ → **「删除项目」**（Delete project）→ 再点一次确认。只是从列表里拿掉，文件夹和对话记录都还在磁盘上（但这些对话就不再列出来了）。

### 快照对话（一次性的空白对话）

- 侧栏 **「快照」**（Snapshot）分组里那一条：不属于任何项目的临时对话，在一个空的临时文件夹里跑，不带项目记忆。适合随手问问。
- **「新建快照」**（New snapshot）：换一个全新的空文件夹、开一个空白对话。旧的从列表消失。
- **只保留最近 10 个快照对话**，更早的会被自动删除——**连同 Claude 在那个临时文件夹里写的文件**。重要的东西别放在快照对话里做。
- 注意别跟「分享对话的公开链接」混淆，那是另一回事（见 04-files.md）。

## 历史对话

- 侧栏按项目分组，最新活动的在上面；只列**最近 60 个**对话。没有搜索。
- 标题取第一条消息的前 80 个字。对话旁边的小点：橙色在闪 = Claude 正在回复；黄色在闪 = 在等你回答问题。
- 每一行的 ⋮（手机上也可以长按）：**「收藏」**（Star）、**「重命名」**（Rename）、**「删除」**（Delete）——点两次才删。
  - 收藏和重命名**只存在这台设备上**，换设备看不到。
  - 删除是**真删**：服务器上的对话记录（含子 agent 的记录）一起删掉，找不回来。
- 重新打开一个旧对话只加载最后 80 条消息，往上翻点 **「查看更早的 {n} 条消息」** 也只能看到这 80 条以内的。
- 导出对话：界面上**没有**导出按钮。

## 发消息

- 电脑：Enter 发送，Shift+Enter 换行。手机：回车是换行，点发送按钮发送。
- 粘贴图片、文件会直接变成附件。

### 附件

- 输入框左下角的 ＋ 按钮 **「附件与功能」**（Add files and more）菜单：**「Add photos」**、**「Add files」**——这两项中英文界面都是英文、**「挂载文件夹」**（Attach folder）。
- 也可以把文件 / 文件夹拖到输入框上；从「工作空间」文件管理器里拖文件到对话里也行（文件留在原处，只是挂给这个对话）。
- 限制：**单个文件 20MB**；挂整个文件夹最多 500 个文件、总共 300MB、单个 100MB，会跳过 `node_modules`、`.git` 这类文件夹。
- 图片（PNG / JPEG / GIF / WebP，单张 3.5MB 以内、最多 8 张、合计 12MB 以内）会直接给模型看；更大的图 Claude 也能按路径去读。

### Research 和回复风格

- **「附件与功能」** 菜单里的 **「Research」** 开关：让 Claude 先拆角度、多轮联网搜索、最后写一份带来源的报告。
- **「Use style」**：Normal / Learning / Concise / Explanatory / Formal，也可以自己建风格（自建的只存在这台设备上）。
- 这两项刷新页面后会恢复默认。

### 斜杠命令

- 输入框里只输入 `/` 加命令名时弹出菜单（↑↓ 选，Enter / Tab 填进去，Esc 关）。列表来自这个账号最近一次对话时 Claude 报告的命令（内置命令 + 技能），**一次对话都没跑过之前，菜单是空的、不会弹出来**。
- `/compact` 会压缩对话上下文，对话里显示一行压缩记录。

### 输入建议（Tab 填入）

- 每轮结束后，输入框里会用灰字给出「你可能想说的下一句」。电脑上按 Tab 填入，手机上点 **「填入」**（Insert）；Esc 收起。
- 在 **「设置 → 通用 → 输入建议」**（Settings → General → Prompt suggestions）里开关，默认开。

## 模型、思考深度

- 输入框里右下角、发送按钮左边有两个芯片。第一个是模型（显示型号名，比如 Opus 5.5），点开选（菜单是英文的）。主列表：Fable 5.1、Opus 5.5、Sonnet 5.5、Haiku 5.5；**「More models」** 里还有更早的型号（Haiku 4.5、Opus 5 等）。**默认是 Opus 5.5。**
- Fable 5.1、Opus 5.5 等新型号自动用 1M 上下文。
- **Fast mode**（只有部分 Opus 型号有）：更快、更费额度，开了芯片上显示 · Fast。
- 第二个芯片（显示 Medium、High 这类字样）是思考深度（Effort）：Low · Medium · High · Extra · Max · Ultracode。没选时 Opus 5.5 和 Haiku 5.5 默认 Medium，大多数型号默认 High。**Ultracode** 会动用大量子 agent，最慢、最费额度；普通账号用不了（会自动降成 Extra）。选过的深度会带到新对话里。
- 模型和深度按对话记住，也会作为新对话的默认值（多设备同步）。芯片带虚线下划线 = 这个对话实际用的和你选的不一样（比如安全回退换过模型），鼠标悬停看说明。

## Claude 在干活的时候

- 回复下面一行状态：用时 · token 数 · 在做什么（思考中、运行工具中、等待你的回答……）。
- **停止**：发送按钮会变成 **「停止生成」**（Stop response）。没有停止的快捷键。
- **不能排队发消息**：Claude 还在回复时，这个对话里发不了新消息（回车没反应）。要么等它说完，要么先停止。
- **关掉浏览器、断网、切到别的对话，Claude 都会在服务器上接着干**。回来打开这个对话会接上，整轮过程会重放。只有点停止才会停。
- **同时最多 3 个对话在跑**（每个账号）；一个对话同一时间只跑一轮。
- 开了任务通知的话，Claude 一轮做完时浏览器会提醒；Claude 在等你回答问题时**不会**发通知（见 07-settings.md「通用」，收不到通知的处理见 08-faq.md）。

### 后台任务和「本轮挂起」

- Claude 可能把活交给后台：子 agent、工作流（一大批子 agent）、后台命令。对话里会出现 agent 行、工作流卡片，点开在工作台的「任务」里看实时过程。
- 主回答写完、后台任务还在跑时，这一轮会「挂起」等它们：任务面板上方显示 **「结束等待」**（Stop waiting）按钮。后台跑完 Claude 会自动接着汇报。这时你**可以发新消息**，会接进同一轮。
- 自动收尾：后台命令单个最多 60 分钟；只剩子 agent 时 15 分钟没动静就收尾。

### Claude 问你问题时（问题卡片）

- Claude 有时会弹出带选项的问题卡片：选好后点 **「提交回答」**（Submit），不想答点 **「Skip」**。还可以在「Something else」里自己写。
- 同一个账号的任何一台设备都能回答。**10 分钟不答，就当跳过**，Claude 会按没回答继续。

### 安全暂停（Session paused）

- 某个型号的安全机制拦下消息时，这一轮会暂停，输入框上方出现一张英文卡片 Session paused，三个选择：改写消息后用原型号重试、换成备用型号继续、或者关掉（按拒答结束这一轮）。10 分钟不选就当关掉。

## 回答里的东西

- 每条回复下面：**「复制」**（Copy）、**「重试」**（Retry）：用上一条消息重新问一遍。
- **回滚**：你发的消息下面的 ↺ **「回滚到这条消息之前」**（Rewind to before this message）→ 选 **「文件+对话」**（Code and conversation）或 **「仅文件」**（Code only）。会把 Claude 之后改过的文件退回去；对话从下一条消息起分叉。Claude 正在回复时不能回滚。
- **产物文件卡片**：Claude 在最终回答里用链接给出的文件 / 文件夹（文档、表格、图片、网页、压缩包等），会变成卡片，点开在工作台「文件」里预览，卡片上有 Download 按钮；文件夹下载是 zip（不含 `node_modules`、`.git`）。源码文件不会变成卡片。
- 回答里像文件路径的链接点了会在应用里打开，不会跳走。

## 工作台（右侧面板）

| 面板 | 做什么 | 谁有 |
|---|---|---|
| **「终端」**（Terminal） | 这个项目文件夹里的一个 shell，**跟 Claude 共用**：Claude 在里面敲的你都看得见，你敲的它也看得见。断线重连不丢（保留最近约 400KB 输出）。手机上有 Ctrl+C、Tab、Esc、方向键快捷键 | 管理员、Pro |
| **「审阅」**（Review） | 这个项目的 git 改动（跟主分支 / 上次提交比），点文件看 diff。不是 git 仓库就显示不是仓库 | 所有人 |
| **「文件」**（Files） | 这个项目文件夹的文件管理器（跟「工作空间」一样，见 04-files.md） | 所有人 |
| **「任务」**（Tasks） | 后台任务、子 agent、工作流的实时过程和记录；子 agent 可以点进去看它收到的提示词和每一步 | 所有人 |

- 电脑上：右上角工具条按钮；快捷键 Ctrl+` 终端、Ctrl+Shift+G 审阅、Ctrl+Shift+E 文件；任务在 ⋮ **「更多」**（More）菜单里。可以同时开几个，拖左边缘调宽度。
- 手机上：右上角 **「工作台」**（Workbench）→ 底部弹出，点芯片切换面板；下拉把手或点空白处关掉。
- Claude 在终端里干活时：窗口够宽会自动打开终端，不然终端按钮上亮一个绿点。
- 没有「浏览器」面板：这台 VM 上没有浏览器。
- 终端最多同时 6 个，1 小时没人看就关掉。用临时地址时终端可能一直显示「连接终端…」——这是已知问题，见 08-faq.md。

## worktree（在仓库的隔离副本里工作）

- 只在**git 仓库项目的新对话**里出现：输入框上方的分支芯片右半边有个 worktree 小方框。勾上再发第一条消息，Claude 会从当前分支复制出一份独立的副本（在项目的 `.claude/worktrees/` 下，新建一个 `claude/` 开头的分支），整段对话都在副本里改，原来的文件一点不动。适合同一个项目同时开几个对话各改各的。
- 勾选会被记住，下次新对话还是勾着。对话开始后工作台的终端、审阅、文件都指向这份副本；这个对话仍然列在原项目下面。
- 仓库还没有任何提交时建不了 worktree。

## 引用另一个对话

- 把侧栏里的一个对话**拖到输入框上**：它会变成一张「引用对话」卡片，发送时 Claude 先读完那段对话的全文（不含工具调用细节）再回答。手机上长按对话、拖出侧栏、放到对话区。
- 拖到侧栏另一个对话上 = 切到那个对话再引用。

## 分屏和单独窗口（电脑 + 鼠标）

- 屏幕够宽（约 1100px 以上）时，把侧栏里的对话拖到对话区左半边 / 右半边，就能左右分屏同时看两个对话；拖中间分隔条调比例。刷新页面后分屏不保留。
- 把对话拖到浏览器窗口外面松手，会单独弹出一个窗口只放这个对话（浏览器拦了弹窗的话，允许本站弹窗后再拖一次）。

## 用量

- 输入框左下角 ＋ 旁边的小圆环（悬停显示 **「查看用量」**，View usage）：显示这个对话的上下文用了多少；点开看详细占比，以及订阅的用量上限（5 小时上限、每周所有模型 / 各型号）和多久后重置。75% 变黄、90% 变红。
- 弹层里还有一行「距自动压缩还有 …」和 **「压缩会话」**（Compact session）按钮：对话太长、回答变慢或快到上限时点它，等于发一次 `/compact`。Claude 正在回复或离线时按钮是灰的。
- 订阅上限是**整台服务器共用的**（大家用的是同一份 Claude 订阅）。
- 用到上限时，对话里会显示「5 小时使用额度已达上限」之类的提示和恢复时间，等恢复就能继续。

## 定时任务（定时触发）

- 侧栏 **「定时触发」**（Routines）：让 Claude 按时间表在你的工作空间里无人值守地跑一件事，比如每天早上汇总笔记。
- 点 **「＋ 新建」** 要填：
  - 名称；
  - **「指令」**（Instructions）：每次让 Claude 做什么；
  - 模型和思考深度（不能选 Ultracode）；
  - **「频率」**（Frequency）：每天、每工作日、每周某一天、或每小时的第几分钟；再加上时间。
- 列表里每一条都有 **「立即运行」**（Run now）、**「启用」**（Enable）开关和删除按钮。
- **时间按服务器的时区算**：页面上写的「服务器时区 GMT+8」不准，Muse 的 VM 默认是 UTC（比北京时间晚 8 小时）。想确认就让 Muse 在 VM 上跑 `date`。这是已知问题。
- 每次运行的结果是一条普通对话，出现在默认项目下面。服务器宕机期间错过的那次**不会补跑**。Claude 在定时任务里提问会被自动拒绝（没人回答）。

## Claude 页常见提示

| 看到的 | 意思 / 怎么办 |
|---|---|
| 服务端还没配置 Claude 认证…（Claude sign-in isn't set up on the server…） | 还没配 Claude 令牌：只有发了消息才会出现。按 `../MUSE.md` 4.4 配 |
| 登录已失效 — 令牌过期或被撤销…（Sign-in expired…） | 令牌失效，在自己电脑上重新 `claude setup-token`，再按 4.4 换上 |
| 5 小时 / 本周使用额度已达上限 + 恢复时间 | 订阅用量到顶，等到恢复时间 |
| 同时最多 3 个对话在跑… | 等一个跑完，或在侧栏带闪烁点的对话里停止一个 |
| 今天已经跑了 N 轮…（普通账号） | 管理员给这个账号设的额度用完了，找管理员 |
| 出海请求被网关拒绝（不是账号问题）… | 服务器的出口网络被拒，不是令牌问题；稍后再试，持续的话按 `../MUSE.md` 第 7 节查 |
| 连不上 Claude 服务器… / Claude 服务器暂时不可用… | 网络或 Claude 那边临时问题，稍后重试 |
| 所选模型不可用… | 换一个模型（模型芯片在输入框里右下角、发送按钮旁边，不在右上角） |
| 回答达到长度上限… | 说一句「继续」 |
| 这一轮被中断 / ⚠️ 这一轮没跑完… | 服务重启了（比如 VM 重启、更新切换）：说一句「继续」 |
| 一直停在「等待 Claude…」不动 | 多半是 Muse 里有一张审核卡没批（api.anthropic.com），见 08-faq.md |
| 离线 · 连不上服务器… | 网络断了或地址变了；见 01-access.md |

## 没有的功能（别答应用户）

对话搜索、导出对话按钮、排队发消息、逐条批准命令的权限模式、计划审批卡片、浏览器 / 截图、生成图片视频音乐、收藏和改名跨设备同步——这些在 Claude 页都没有。
