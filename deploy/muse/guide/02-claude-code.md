# Claude Code 页

Claude Code 是 Anthropic 的编程 / 通用 agent，在这台 VM 上替用户读写文件、跑命令、做项目，用的是用户（服务器）配好的 Claude 订阅。这一章讲它的页面怎么用。没配 Claude 令牌时怎么配，见 `../MUSE.md` 4.4。

## 谁能用、能做到什么程度

| 身份 | 怎么登录 | 能动哪些文件 | 有没有命令行（终端、让 Claude 跑命令） |
|---|---|---|---|
| 管理员 | 管理员令牌 | 整台服务器 | 有 |
| 完全信任账号 | 账号密码（完全信任邀请码注册的） | 只有自己的文件夹 | 有 |
| 普通账号 | 账号密码 | 只有自己的文件夹 | **没有**：Claude 不能跑命令，也没有终端 |

- Claude 要不要先问你，由 **「权限模式」**（Permission mode）决定——在输入框左下角的小圆环里选，见下面「权限模式和批准」：管理员默认是 **「自动」**（Auto），普通账号、完全信任账号默认是 **「接受编辑」**（Accept edits）。成员的 Claude 还由服务器关在自己的文件夹里（越界的操作会被拒，Claude 自己会看到拒绝原因）。
- 所有人共用服务器上配的那份 Claude 订阅的额度（见下面「用量」）。
- 只装了 Claude Code 时没有主页，打开网址就是这一页；两个 agent 都装了时从主页的 Claude 方块进来。

## 页面布局

- **左侧栏**：项目和历史对话。电脑宽窗口上默认展开（拖右边缘调宽度），最顶上「Claude Code」那一行不随列表滚走，行的右端是侧栏开关——悬停提示 **「收起侧栏」**（Collapse sidebar）；点一下侧栏整块滑出去，开关留在正文左上角——提示变成 **「展开侧栏」**（Open sidebar），旁边多一颗 **「新对话」** 按钮，再点一下滑回来。收起还是展开会记在这台设备上。中等宽度（平板、折叠屏展开）是同一个开关，默认收起。手机上点左上角 **「菜单」**（Menu）拉出来。
- **中间**：对话和下面的输入框。
- **右侧工作台**：终端、审阅、文件、任务（见「工作台」）。电脑上在右上角工具条打开；手机上点右上角的 **「工作台」**（Workbench）按钮，从底部弹出。
- 侧栏从上到下：
  - **「主页」**（Home）：回主页。只装一个 agent 时没有这一项。
  - **「新对话」**（New session）：在当前项目里开一个新对话（在临时对话里就落到最近用过的项目）。电脑上右边标着快捷键。
  - **「搜索」**（Search）：搜会话，电脑上 Ctrl+K（见「历史对话」）。
  - **「新建项目」**（New project）、**「新建临时对话」**（New temporary chat）、**「定时触发」**（Routines）。
  - 分组：**「临时对话」**（Temporary chats）、**「收藏」**（Starred）——收藏过对话才出现、**「项目」**（Projects）。项目列表最底下有 **「已归档」**（Archived）入口——归档过会话才出现。
  - 最底下是账户卡（悬停提示 **「设置与账户」**（Settings & account））。点开的菜单：**「设置」**（Settings）、**「工作空间」**（Workspace）；只装一个 agent 时还有 **「关于与更新」**（About & updates），两个都装了时第一项是 **「主页」**；手机上（触屏）还有 **「扫一扫登录网页版」**（Scan to sign in on the web）。账户、退出登录在 **「设置 → 账户」**（Settings → Account）里。
- 技能、连接器、插件的管理不在侧栏里，在 **「设置 → 扩展」**（Settings → Extensions），只有管理员有（见 05-customize.md）。
- 手机上从屏幕左边缘往右滑回主页；返回键会先关掉弹出的东西，再一层层退。

## 开始一个对话

- 点侧栏的 **「新对话」**（New session）：在当前项目（文件夹）里开一个新对话。也可以点一个项目，或者点 **「新建临时对话」**（New temporary chat）开一个不属于任何项目的。
- 新对话沿用你上次用的模型、思考深度（多台设备同步）；权限模式用「设置 → Claude → 新会话默认」里设的（见 07-settings.md）。在还没发消息的新对话里点输入框左下角的小圆环选一个，菜单顶上会写 **「记成这个文件夹的默认」**（Saved as this folder’s default）：之后这个文件夹的新会话沿用它；对话开始后再改，写的是 **「只改这个会话」**（Applies to this session only）。
- 打开 Claude 页、没有可以接着看的对话时：管理员落在临时对话，其他成员落在自己的工作空间。设置里没有改这个的选项。
- **新对话的落地页**：一句问候，下面是你的用量统计卡——**会话**（Sessions）、**消息**（Messages）、**Token 总数**（Total tokens）、**活跃天数**（Active days）、**高峰时段**（Peak hour）、**收藏的模型**（Favorite model），还有一张**每日活跃热力图**，可以切「概览 / 模型」和时间范围。只是统计，不影响任何功能。
- 输入框里没发出去的**草稿按会话分别保存**：切到别的对话再回来，草稿还在。
- **新对话发出第一条消息的那一刻就出现在侧栏里**；别的设备、子会话、定时任务新开的对话也是一开跑就列出来，只在侧栏亮起圆点——页面不会自己跳过去，看哪个对话只由你点。

### 项目 = 文件夹

- 每个项目就是服务器上的一个文件夹，在项目里开的对话，Claude 就在这个文件夹里干活；对话列在它所属的项目下面。
- 默认项目是你的工作空间根目录，删不掉。最多 200 个项目。
- **新建项目**：点 **「新建项目」**（New project），弹出一个文件浏览器。**按住一个文件夹（约半秒）拖到底部那条栏上松手**，它就成了新项目；单击文件夹只是打开它，不会选中。可以先在里面新建文件夹再拖。管理员能选整台服务器上的位置，其他人只能选自己工作空间里的。
- **排序**：拖动项目行（手机上长按再拖），顺序存在服务器上、各设备一致。
- 项目行的 ⋮ 菜单：
  - **「重命名」**（Rename）：弹出 **「重命名工作空间」**（Rename workspace），只改显示名，文件夹本身不动；留空恢复成文件夹名。默认项目也能改。
  - **「归档全部会话」**（Archive all sessions）：把这个项目下的会话一次收起来（见「历史对话」的归档）。
  - **「删除项目」**（Delete project）→ 再点一次确认。只是从列表里拿掉，文件夹和对话记录都还在磁盘上（但这些对话就不再列出来了）。默认项目没有这一项。

### 临时对话（原来叫「快照」）

- 侧栏 **「临时对话」**（Temporary chats）分组：不属于任何项目的对话，在一个空的临时文件夹里跑，不带项目记忆。适合随手问问。分组里先只列最新一条，点 **「显示更多」**（Show more）（后面带剩余条数）再展开。
- **「新建临时对话」**（New temporary chat）：开一个全新的空文件夹、空白对话。每个临时对话各有各的文件夹，旧的不会消失。
- **30 天没动会自动清理**：输入框上方有一枚「临时对话」芯片，旁边写着多久没动会清理；对话行的 ⋮ 菜单里有 **「存为工作空间」**（Save as workspace）——点了先弹一个小框让你取名（默认填对话标题，清空就自动编号），保存后它就变成一个永久的工作空间（像项目一样一直留着）。离清理只剩几天时，输入框上方会变成一条提示「这个临时对话 N 天后会移进回收站」，给 **「继续保留」**（Keep it）和「存为工作空间」两个选择。
- 清理不是马上删：到期先进 **「回收站」**——临时对话分组底下一行，后面带数量——再放 30 天才永久删除——**连同 Claude 在那个临时文件夹里写的文件**。在回收站里点 **「恢复」**（Restore）能原样拿回来。重要的东西还是存成工作空间更稳。
- 临时对话可以用 ⋮ → **「重命名」**（Rename）改名。
- 注意别跟「分享对话的公开链接」混淆，那是另一回事（见 04-files.md）。

## 历史对话

- 侧栏按项目分组，最新活动的在上面。每个项目先列最新的 10 个，点 **「显示更多」**（Show more）（后面带剩余条数）每次再展开 20 个，全展开后变成「收起」。
- **搜索**：侧栏的 **「搜索」**（Search）（电脑上 Ctrl+K）打开搜索面板，按标题（含改过的旧标题）找，也搜对话全文；覆盖所有项目、临时对话和已归档的会话。结果分层显示，已归档的折在 **「显示已归档」**（Show archived）（后面带条数）里。索引还在建立时会提示结果可能不全。
- 标题取第一条消息的前 80 个字。对话旁边的小点：橙色在闪 = Claude 正在回复；黄色在闪 = 在等你回答问题。项目对话那一行有讨论串在等你处理时也会亮一个点（见「项目对话」）。
- 每一行的 ⋮（手机上也可以长按）：**「收藏」**（Star）、**「重命名」**（Rename）、**「归档」**（Archive）、**「删除」**（Delete）——点两次才删。
  - **收藏和自定义标题存在服务端**，换设备、换浏览器看到的一样。
  - **归档**：把不想再看到的会话收起来，不删数据。正在工作（或有后台任务）的会话不能归档。有子会话的会话归档时会问：只归档它自己（子会话移到顶层），还是连子会话一起归档。归档后的会话从列表消失，在侧栏底部 **「已归档」**（Archived）视图里找：能打开看、**「取消归档」**（Unarchive）、删除；视图底部的 **「显示更多」** 往后翻。
  - **自动归档**：**「设置 → Claude → 会话管理 → 归档不活跃的会话」**（Settings → Claude → Session management → Archive inactive sessions）选 1 / 2 / 7 / 14 / 30 天，默认从不。收藏的会话和正在工作的会话不受影响。
  - 删除是**真删**：服务器上的对话记录（含子 agent 的记录）一起删掉，找不回来。归档才是「先收起来」。
- 重新打开一个旧对话只加载最后 80 条消息，往上翻点 **「查看更早的 {n} 条消息」** 也只能看到这 80 条以内的。
- 导出对话：界面上**没有**导出按钮。

## 发消息

- 电脑：Enter 发送，Shift+Enter 换行。手机：回车是换行，点发送按钮发送。
- 粘贴图片、文件会直接变成附件。
- 草稿按会话保存（见「开始一个对话」）。Claude 正在回复时也能发消息，见「Claude 在干活的时候」。

### 附件

- 输入框左下角的 ＋ 按钮 **「附件与功能」**（Add files and more）菜单：**「Add photos」**、**「Add files」**——这两项中英文界面都是英文、**「挂载文件夹」**（Attach folder）。
- 也可以把文件 / 文件夹拖到输入框上；从「工作空间」文件管理器里拖文件到对话里也行（文件留在原处，只是挂给这个对话）。
- 输入框里放好的图片，点缩略图——悬停提示 **「预览图片」**（View image）——能全屏看大图，附了几张可以左右切，关掉后照常发送。Claude 正在干活时插话带的图片，也和普通消息一样显示缩略图。
- **用 Windows 桌面客户端时挂电脑上的文件夹**：Muse Bridge 在 VM 上、不在你这台电脑上，所以在客户端里选或拖进来的文件夹默认**只引用、不上传**——卡片上写着 **「在「{device}」上 · 按需读取」**（On {device} · Read as needed），Claude 通过这台电脑按需查找、搜索、读取里面的文件，大文件夹也不用等上传。要传一份副本到服务器，点卡片上的 **「改为上传」**（Upload instead）。前提是这台电脑已经登记成设备（见 07-settings.md「设备」，要绑了自己的域名），并且 Claude 用的时候客户端开着；没登记的电脑照旧整个上传。
- 限制：**单个文件 20MB**；挂整个文件夹最多 500 个文件、总共 300MB、单个 100MB，会跳过 `node_modules`、`.git` 这类文件夹。
- 图片（PNG / JPEG / GIF / WebP，单张 3.5MB 以内、最多 8 张、合计 12MB 以内）会直接给模型看；更大的图 Claude 也能按路径去读。

### Research、回复语气、输出风格

- **「附件与功能」** 菜单里的 **「Research」** 开关：让 Claude 先拆角度、多轮联网搜索、最后写一份带来源的报告。
- **「回复语气」**（Tone）：Normal / Learning / Concise / Explanatory / Formal，也可以自己建（菜单底部「Create & edit styles」，自建的只存在这台设备上）。Research 和回复语气刷新页面后会恢复默认。
- **「输出风格」**（Output style）：只给这个会话换 Claude Code 的输出风格；第一项 **「跟随默认（{name}）」** 用的是「设置 → Claude → 新会话默认 → 输出风格」里设的。

### 斜杠命令

- 输入框里只输入 `/` 加命令名时弹出菜单（↑↓ 选，Enter / Tab 填进去，Esc 关）。列表来自这个账号最近一次对话时 Claude 报告的命令（内置命令 + 技能），**一次对话都没跑过之前，菜单是空的、不会弹出来**。
- `/compact` 会压缩对话上下文，对话里显示一行压缩记录。

### 输入建议（Tab 填入）

- 每轮结束后，输入框里会用灰字给出「你可能想说的下一句」。电脑上按 Tab 填入，手机上点 **「填入」**（Insert）；Esc 收起。
- 在「对话」那一组的 **「设置 → Claude → 输入建议」**（Settings → Claude → Prompt suggestions）里开关，默认开。

## 模型、思考深度

- 输入框里右下角、发送按钮左边有两个芯片。第一个是模型（显示型号名，比如 Opus 5.5），点开选（菜单是英文的）。主列表：Fable 5.2、Opus 5.5、Sonnet 5.5、Haiku 5.5；**「More models」** 里还有更早的型号（Fable 5.1、Haiku 4.5、Opus 5 等），以及模型中心里加给 Claude 的别家模型；模型多的时候里面有 **「搜索模型」**（Search models）。**默认是 Opus 5.5。**
- Fable 5.2、Opus 5.5 等新型号自动用 1M 上下文。Fable 5.2 比 Fable 5.1 便宜两成，单次最多能写 128K。
- **Fast mode**（Fable 5.2 和部分 Opus 型号有）：更快、更费额度，开了芯片上显示 · Fast；账号没开通 Fast 时开关打开了也不会生效。
- 第二个芯片（显示 Medium、High 这类字样）是思考深度（Effort）：Low · Medium · High · Extra · Max。没选时 Fable 5.2、Opus 5.5 和 Haiku 5.5 默认 Medium，大多数型号默认 High。选过的深度会带到新对话里。
- **Ultracode** 不是一档深度，是拉条下面单独的一个勾选：勾上后拉条变成紫色，任何一档都能配 Ultracode，芯片上的档名也变成紫色。它会动用大量子 agent，最慢、最费额度；只对当前对话生效，新对话从关着开始。要「设置 → Claude」里的 **「动态工作流」**（Dynamic workflows）开着（关着时面板里会提示）；账号用不了时这一轮照常按所选深度跑，芯片的紫色会褪掉。以前选过 Ultracode 的对话会自动变成 Extra + Ultracode。
- **接别家的模型**：现在统一在 **「设置 → 模型中心」**（Settings → Model Hub）里加——DeepSeek、Kimi、OpenRouter 这类 Anthropic / OpenAI 兼容接口，管理员添加时勾上给 Claude 用；管理员配了 Google 云凭据的话，还能把 Vertex 上的 Gemini 型号开给 Claude。原来「设置 → Claude」里的「自定义 API」入口已经挪到这一页：管理员以前加的服务，更新后自动并进模型中心，正在用它的老对话照常能接着聊；成员在同一页里管自己的那一份（用自己的 Key，只有自己能用）。加好的模型出现在模型菜单的 **「More models」** 里，按服务分组；管理员共享给成员的服务，组名后面写着 **「管理员共享」**（Shared by admin）。怎么加、怎么分给各个 agent、在 Muse 上要先放行哪些网站，见 10-model-hub.md。
- 模型和深度按对话记住，也会作为新对话的默认值（多设备同步）。芯片带虚线下划线 = 这个对话实际用的和你选的不一样（比如安全回退换过模型），鼠标悬停看说明。

## Claude 在干活的时候

- 回复下面一行状态：用时 · token 数 · 在做什么。想事情时按时长依次写「思考中…」「仍在思考…」「深入思考中…」，跑工具时写「运行工具中…」，在等你批准、回答或审计划时写「需要你的输入」（英文界面是 Needs your input）。
- 对话里的工具步骤行：一段步骤跑满 2 秒，行尾开始显示用了几秒；同时派出了几个子 agent 会标出「N 个子 agent」；读了图片或截了图的步骤，右边直接排出小缩略图（最多三张，更多的写 +N），鼠标停上去看预览，点开全屏翻看。
- **停止**：发送按钮会变成 **「停止生成」**（Stop response）。没有停止的快捷键。
- **Claude 回复时也能继续发消息**：输入框有内容时，发送键变成两半。
  - **「插话发送」**（Send now (steer)）：电脑按 Enter（或点主键）。Claude 做完手上这一步就读到这条，用来纠偏、补充。
  - **「稍后发送」**（Queue for later）：电脑按 Ctrl+Enter（Mac 是 Cmd+Enter），手机点发送键右半的下拉。消息排进队列，这一轮结束后再发出去。输入框上方的队列条显示「N 条排队消息」，每条可以编辑、移出队列、拖动调顺序；输入框空着时按 ↑ 能把排队的消息拿回来改。
  - Claude 正在等你批准或回答时，插话要等你处理完那张卡才会被读到。
- **关掉浏览器、断网、切到别的对话，Claude 都会在服务器上接着干**。回来打开这个对话会接上，整轮过程会重放。只有点停止才会停。
- **切回一个对话、或从后台切回页面 / App 时**，在跟服务器确认这一轮还在不在跑之前，最后一轮下面只显示 **「正在同步状态…」**（Syncing status…），发送键换成一个转圈（悬停提示 **「正在同步会话状态…」**（Syncing session status…））。确认还在跑就直接接上直播，确认结束了才出现复制、重试和发送键——不会先显示成「已结束」。网络卡住时这一行写「连不上服务器，这一轮的状态暂时未知」，连上后自动核对。
- **服务意外重启也不用你管**：VM 被平台重启、看门狗重启了服务、Muse 跑了 `switch-now` / `rollback` 时，正在跑的那一轮会被打断；服务恢复后约 15 秒，服务器会自动让 Claude 从中断的地方接着做（正看着这个对话时弹 **「服务刚才意外重启，正在继续会话」**（The service restarted unexpectedly — resuming session），手机锁屏、网页关着也照样续）。同一件事最多连着自动继续 3 次；中断超过 12 小时、或者你已经先发了新消息，就不自动续。不想要可以在 **「设置 → Claude → 自动继续被中断的对话」**（Settings → Claude → Resume interrupted conversations）里关掉（见 07-settings.md）。正常的更新切换会等没人在聊时才重启，不会打断对话。
- **同时最多 3 个对话在跑**（每个账号）；一个对话同一时间只跑一轮。
- **会话消息通知**：哪个会话在等你回答、需要你批准、跑完了或出错了，就单独来一条通知，标题是会话名，同一个会话后来的消息叠在同一条里，点一下直接打开那个会话；正看着的那个会话不提醒。
  - 页面开着、在看别处时：滑出一张横幅（手机上从顶部滑下，电脑上在右上角），带提示音。
  - 页面在后台时：网页靠浏览器的系统通知，要先在 **「设置 → 通用 → 通知」**（Settings → General → Notifications）里点 **「允许浏览器通知」**（Allow browser notifications）；安卓 App 里是手机通知栏里每个会话一条，会响也会振，跟着手机的静音、振动模式和免打扰走。App 里打开 **「后台保持接收」**（Stay connected in background）后，电脑上或定时任务发起的会话有动静也能马上收到，会多耗一点电。
  - 总开关 **「接收通知」**（Allow notifications）、提醒哪几类（在等你回答 / 需要你批准 / 完成 / 出错）、横幅、**「显示内容详情」**（Show previews）——关掉后通知只写「你有一条新消息」——、提示音和振动，都在「设置 → 通用 → 通知」里；四类开关和「设置 → Claude → 通知」里的是同一份，只管这台设备。见 07-settings.md，收不到通知的处理见 08-faq.md。
- 单击 Claude 的星标能切换明暗（Claude 正在回复时那颗会动的标记也能点）：新的明暗从标志那一点铺满整页，主页和其它页面一起变。见 01-access.md。

### 后台任务和「本轮挂起」

- Claude 可能把活交给后台：子 agent、工作流（一大批子 agent）、后台命令。对话里会出现 agent 行、工作流卡片，点开在工作台的「任务」里看实时过程。
- 工作流卡下面有一行写着各个子 agent 用的模型，比如「DeepSeek-V4-Pro ×2 · Sonnet 5.5 ×2」；「任务」里每个阶段列出每个 agent 的模型和推理强度（比如「DeepSeek-V4-Pro · Medium」），跑完的小工作流直接展开。模型中心里加的模型显示你在那里起的名字。工作流脚本里写的是难度档（比如「自动·难」）的 agent，这一栏直接显示它实际用的模型和推理强度（比如「Opus 5.5 · High」），跑着的时候就能看到；档位名在鼠标悬停的提示里。
- **子 agent 用哪个模型，Claude 按「难度档」挑**：Muse Bridge 随版本带一份模型性价比数据（智力分数和每次任务大约花多少钱），把这台服务器上配好的模型排成「最难 / 难 / 常规 / 机械」四档，每档一个首选、一个备选；Claude 只判断活有多难，再照档位选。Claude 订阅的成本按号池里各个号的套餐取平均；模型中心里的别家服务，认得出是套餐专属端点的按套餐价、其余按 API 价算；没配的模型不会出现，配了但没有数据的标「未评分」，只在你点名时用。
- **这套选法叫「子 agent 调用策略」**——原来的「子 agent 调度偏好」升级成了它，在「对话」那一组的 **「设置 → Claude → 子 agent 调用策略」**（Settings → Claude → Subagent dispatch policy）里，管理员和完全信任账号有这一行：
  - 行右边是总开关，默认开；关掉就完全走 Claude Code 原生的调用方式，不再按档位挑模型。
  - 点进去能勾生效范围：**「工作流 / Ultracode」**（Workflows / Ultracode）和 **「普通子 agent」**（Regular subagents）默认勾着，**「发起新会话」**（Start new sessions）默认不勾。
  - 可以建多套策略、起名字，只有设为生效的那一套起作用。每套里四档各用哪个模型和推理强度都看得见，也能直接指定；下面的性价比图上四条横线是四档的判定线，拖一下线，这一档就改选线以上最便宜的模型，双击恢复默认。
  - 不想派给别家模型，关掉 **「调用非 Claude 模型」**（Use non-Claude models）；**「口述备注」**（Notes）里写的话优先级最高。以前写在「子 agent 调度偏好」里的话，已经自动成了默认策略的备注。
  - 也可以直接跟 Claude 说「看看 / 改一下子 agent 调用策略」。逐项说明见 07-settings.md。
- 主回答写完、后台任务还在跑时，这一轮会「挂起」等它们：任务面板上方显示 **「结束等待」**（Stop waiting）按钮。后台跑完 Claude 会自动接着汇报。这时你**可以发新消息**，会接进同一轮。
- 自动收尾：后台命令单个最多 60 分钟；只剩子 agent 时 15 分钟没动静就收尾。

### Claude 问你问题时（问题卡片）

- Claude 有时会弹出带选项的问题卡片：选好后点 **「提交回答」**（Submit），不想答点 **「Skip」**。还可以在「Something else」里自己写。
- 同一个账号的任何一台设备都能回答。**默认 10 分钟不答就当跳过**，Claude 会按没回答继续；在 **「设置 → Claude → Claude 提问无人回答时」**（Settings → Claude → When Claude’s question goes unanswered）里能改成一直等 / 5 分钟 / 30 分钟。

### 安全暂停（Session paused）

- 某个型号的安全机制拦下消息时，这一轮会暂停，输入框上方出现一张英文卡片 Session paused，三个选择：改写消息后用原型号重试、换成备用型号继续、或者关掉（按拒答结束这一轮）。10 分钟不选就当关掉。
- 想让它直接换型号、不停下来：打开 **「设置 → Claude → 消息被拦时自动换模型」**（Settings → Claude → Switch models when a message is flagged），默认关。

## 权限模式和批准

- **「权限模式」**（Permission mode）决定 Claude 改文件、跑命令前要不要先问你。它不再是单独的芯片，和用量环合成了一颗：输入框左下角（＋ 按钮之后）的小圆环，**环的颜色就是当前的权限模式**——手动灰、接受编辑紫、计划青、自动橙、绕过权限红；环填了多少是上下文用量。点圆环（电脑上也可以按 Ctrl+Shift+M）打开一张面板，上半选权限模式，下半看用量（见「用量」）；面板开着时按数字键能直接选。每个会话可以单独改：
  - **「手动」**（Manual）：每一步都先问你；
  - **「接受编辑」**（Accept edits）：自动接受文件改动，跑命令等仍会问；
  - **「计划」**（Plan）：先出计划，等你批准再动手；
  - **「自动」**（Auto）：由 Claude 判断哪些要问你，较长的任务不容易被打断。只有管理员能选；
  - **「绕过权限」**（Bypass permissions）：什么都不问——Claude 会不经询问地读取、编辑和执行文件，包括可能有破坏性的命令。只有管理员能选，而且要管理员先在设置里允许（见 07-settings.md「Claude」→「安全」）；每个文件夹第一次选时会再确认一次。
- 第一次选「自动」会弹一次确认，说明 Claude 会自行判断哪些操作不经询问直接执行；在会话里从「自动」切回「手动」也会先问一句。选项灰着、写着「在设置里开启」= 管理员在「安全」里把这一档关了。
- 五档下面还有一项 **「项目」**（Project）——只在新对话里能选，管理员和完全信任账号才有：把这条对话开成「项目对话」，见下面「项目对话」一节。已经开始的普通对话里，这一项是 **「转成项目」**（Turn into project）。
- 新会话的默认模式在「新会话默认」那一组的 **「设置 → Claude → 权限模式」** 里设。管理员默认「自动」；普通账号、完全信任账号只有手动 / 接受编辑 / 计划三档，默认「接受编辑」。
- **批准卡**：Claude 要做需要批准的事时，输入框上方弹一张卡「允许 Claude …？」，按钮有 **「允许一次」**（Allow once）（右边的下拉里还有「允许，并切换到自动模式」）、**「始终允许」**（Always allow）（写进这个项目的设置；写不了时这颗按钮是 **「本会话都允许」**（Allow for this session））和 **「拒绝」**（Deny）。同时有好几个请求时会写「还有 N 个请求在排队」。
- **计划卡**：计划模式下 Claude 提出计划后出一张「Claude 提出了一个计划」的卡，可以展开看全文、选中文字留批注；按钮 **「接受」**（Accept）（可选「接受并允许编辑」等）、**「修改…」**（Revise…）退回去改，或 **「拒绝」**（Reject）。在设置里开了 **「批准计划时可清空上下文」**（Offer to clear context when approving a plan）时，还有「清空上下文后执行」。
- 手机上批准卡、计划卡和问题卡片一样，同一个账号的任何设备都能处理。Claude 在等你批准时，通知（**「权限请求」**（Permission requests））会提醒你。

## 回答里的东西

- 每条回复下面：**「复制」**（Copy）、**「重试」**（Retry）：用上一条消息重新问一遍。
- **回滚**：你发的消息下面的 ↺ **「回滚到这条消息之前」**（Rewind to before this message）→ 选 **「文件+对话」**（Code and conversation）或 **「仅文件」**（Code only）。会把 Claude 之后改过的文件退回去；对话从下一条消息起分叉。Claude 正在回复时不能回滚。
- **产物文件卡片**：Claude 在最终回答里用链接给出的文件 / 文件夹（文档、表格、图片、网页等），会变成回答下方的卡片，点开在工作台「文件」里预览，卡片上有 Download 按钮；文件夹下载是 zip（不含 `node_modules`、`.git`）。`.tgz`、`.7z`、`.rar`、`.apk`、`.exe` 这类压缩包和安装包也会出卡片，可以直接下载。源码文件不会变成卡片。
- 回答正文里引用的文件，点了会在右侧工作台的文件夹里打开，能看到它在哪个目录，不会跳走，也不再一律全屏预览。
- **对话内交互图表**：Claude 可以直接在对话里画图表、示意图和小工具，出现在回答中间的一个框里。框旁边有 **「查看代码」**（View code）按钮；⋯ **「更多操作」**（More actions）里能 **「复制为图片」**（Copy as image）、**「下载为 PNG」**（Download as PNG）。手机上是静态预览，分享出去的对话里不显示。在 **「设置 → Claude → 对话内交互图表」**（Settings → Claude → Inline visualizations）里可以关。

## 工作台（右侧面板）

| 面板 | 做什么 | 谁有 |
|---|---|---|
| **「终端」**（Terminal） | 这个项目文件夹里的一个 shell，**跟 Claude 共用**：Claude 在里面敲的你都看得见，你敲的它也看得见。断线重连不丢（保留最近约 400KB 输出）。手机上有 Ctrl+C、Tab、Esc、方向键快捷键 | 管理员、完全信任账号 |
| **「审阅」**（Review） | 这个项目的 git 改动（跟主分支 / 上次提交比），点文件看 diff。不是 git 仓库就显示不是仓库 | 所有人 |
| **「文件」**（Files） | 这个项目文件夹的文件管理器（跟「工作空间」一样，见 04-files.md） | 所有人 |
| **「任务」**（Tasks） | 后台任务、子 agent、工作流的实时过程和记录；子 agent 可以点进去看它收到的提示词和每一步 | 所有人 |
| **「记忆」**（Memory） | Claude 在这个项目里记下的东西：电脑上是一张思维导图（项目名在中间，各组记忆分在两边，点字打开那一篇、能直接阅读和修改，悬停显示简介并用虚线连出相关的几篇）；手机和窄屏默认一层一层地看。右上角切换两种看法；搜索是单独一页，还能只看链接失效或没被索引的；⋯ 菜单里能切到别的项目的记忆，dimensio 也对你开着时还能在 **「记忆来自」**（Memory from）里切到 dimensio 在这个项目记下的记忆。Claude 刚记下新东西时会自己更新 | 所有人 |

- 电脑上：右上角工具条上常驻的是 **「会话信息」**（Session details）、终端、审阅；文件和任务在 ⋮ **「更多」**（More）菜单里。快捷键 Ctrl+` 终端、Ctrl+Shift+G 审阅、Ctrl+Shift+E 文件。可以同时开几个，拖左边缘调宽度；「更多」菜单里还有 **「收起全部面板」**（Hide all panels）。
- 电脑上卡片能拖着排：按住卡片的标题行拖动，可以在同一列里上下换位、拖到另一列；只有一列时拖到右边停一下就分成两列，顺序会记住。双击标题行放大或还原。用 Windows 客户端时，把卡片拖到窗口外面松手会变成一个独立小窗口，点 **「放回工作台」**（Move back to workbench）回到原处。
- 手机上：右上角 **「工作台」**（Workbench）→ 底部弹出，点芯片切换面板（任务 / 审阅 / 终端 / 文件 / 记忆）；下拉把手或点空白处关掉。
- Claude 在终端里干活时：窗口够宽会自动打开终端，不然终端按钮上亮一个绿点。
- 没有「浏览器」面板：这台 VM 上没有浏览器。
- 终端最多同时 6 个，1 小时没人看就关掉。用临时地址时终端可能一直显示「连接终端…」——这是已知问题，见 08-faq.md。

## worktree（在仓库的隔离副本里工作）

- 只在**git 仓库项目的新对话**里出现：输入框上方的分支芯片右半边有个 worktree 小方框。勾上再发第一条消息，Claude 会从当前分支复制出一份独立的副本（在项目的 `.claude/worktrees/` 下，新建一个分支，前缀默认是 `claude/`），整段对话都在副本里改，原来的文件一点不动。适合同一个项目同时开几个对话各改各的。
- 勾选会被记住，下次新对话还是勾着（同一个开关也在 **「设置 → Claude → 用工作树」**（Settings → Claude → Use a worktree），只管这台设备）。对话开始后工作台的终端、审阅、文件都指向这份副本；这个对话仍然列在原项目下面。
- 分支前缀、副本从哪个分支切出来，在「设置 → Claude → Git 与拉取请求」里改（见 07-settings.md）。
- 仓库还没有任何提交时建不了 worktree。

## 会话协作：子会话和会话之间互发消息

- **Claude 提议另开会话**：你提了和当前任务无关的事，或 Claude 发现值得单独做的活时，对话里会出现卡片「单独开一个会话来做？」，选 **「新会话」**（New session）另开一个（可以勾在独立的 git 工作树里做），或 **「在这里做」**（Do it here）。可以选「总是新建会话」「总是在这里做」让它以后不再问。Claude 一次提出几个任务时是「N 个建议任务」的卡，可以 **「全部开始」**（Start all）或逐个 **「开始」** / **「忽略」**（Dismiss）。
- 这个行为由 **「设置 → Claude → 会话协作 → Claude 发起新会话」**（Settings → Claude → Session collaboration → New sessions started by Claude）控制：先问我（默认）/ 直接开始 / 只在我要求时。能跑命令的身份（管理员、完全信任账号）才有这一项。
- 开出来的子会话完成后，会把汇报以一张「子会话的汇报」卡发回原会话；会话之间也能互发消息，显示为「来自……」的会话消息卡，点 **「打开这个会话」** 跳过去。
- **和 dimensio 互相派活**：两个 agent 都对你开着时，你明说「让 dimensio 去做」，Claude 可以把子会话开成一个 dimensio 会话（在 dimensio 页的侧栏里，用 dimensio 那边选的模型），做完同样回来汇报；反过来 dimensio 也能开 Claude 子会话、给 Claude 的会话发消息。每个账号只能动自己的会话。
- **会话信息面板**：电脑 / 平板上对话右上角的 **「会话信息」**（Session details）按钮打开右侧面板，里面有 **「环境」**（Environment）、**「相关会话」**（Linked sessions）（父 / 子 / 兄弟会话，哪些在干活）、**「建议的任务」**（Suggested tasks）、**「上下文」**（Context）、**「连接器」**（Connectors）（每个连接器的状态；要登录的远程连接器这里有「授权」按钮，见 05-customize.md「远程连接器授权」）、**「输出内容」**（Outputs）、**「拉取请求」**（Pull request）等卡片，还有一张「更改」卡，上面有 **「提交更改」**（Commit changes）按钮。手机上没有这个按钮，点 PR 芯片能打开；项目对话里点输入框左下角的小圆环，菜单里的 **「项目概览」**（Project overview）也打开它。
- 官方 Claude Desktop 或终端里的 Claude 会话发来的消息，管理员可以在设置里选直接接收、暂存等确认、拒收。这台 VM 上一般用不到。

## 项目对话（协调者派活、讨论串去做）

适合一件要拆成好几块、可以分头做的事：开一条「项目对话」，里面的 Claude 当协调者——只负责拆任务、派活、跟进和汇总；要动手的活由它开成一条条「讨论串」，每条是一个真会话，各做各的，做完自动回来汇报。

- **谁有**：管理员和完全信任账号——讨论串要靠会话协作来开，普通账号没有这一项。
- **怎么开**：在**新对话**里（还没发消息）点输入框左下角的小圆环，五档权限模式下面有一项 **「项目」**（Project），勾上再发第一条消息。形态只能在新对话里定，开始之后改不了。
  - 勾上「项目」后，上面选中的那一档变成 **「讨论串权限」**（Thread permissions）：讨论串开出来时用这一档。之后在项目对话里点圆环，改的也是这个项目的讨论串权限。
  - 项目对话的圆环中间多一颗点；菜单顶上一行写着「项目对话」，下面有 **「项目概览」**（Project overview）。
  - **已经聊了一半的普通对话**：同一个位置是 **「转成项目」**（Turn into project）——以这段对话为背景**另开**一个项目对话，协调者先读原对话，再和你确认怎么分讨论串；原对话还在。Claude 正在回复时要等这一轮结束再转。
- **协调者能做什么**：看代码、搜代码、联网查资料、向你提问，小问题当场回答；跑只读的 git / gh 命令核对讨论串交回来的成果（提交了什么、PR 和 CI 怎么样）。它**不改文件**，改文件、跑测试、构建、提交推送这类命令会被拦下。
- **讨论串**：
  - 项目文件夹是 git 仓库时，每条讨论串默认在自己的工作树（worktree，见上面一节）里干活，互不干扰；不是 git 仓库就和项目对话共用一个文件夹。
  - 挂在侧栏的项目对话下面，点开就能直接和它聊、批它的权限请求、停下它。有讨论串在等你时，项目对话那一行亮一个点——悬停提示 **「有讨论串在等你」**（A thread is waiting for you）。
  - 做完把汇报发回项目对话（「讨论串的汇报」卡），协调者接着汇总或再派活。跑偏的讨论串协调者能直接停下，做完的能标为已解决。
  - 默认协调者判断该开就直接开；想每条都先过目，打开 **「设置 → Claude → 项目对话」**（Settings → Claude → Project conversation）里的 **「开讨论串前先问我」**（Ask before starting a thread），每条先弹一张「开一条讨论串来做？」的卡等你点。
- **项目概览**：电脑 / 平板上点右上角的 **「会话信息」**（Session details），手机上点圆环 → 「项目概览」。里面有：
  - **「讨论串」**（Threads）卡：按 **「待评审」**（Ready for review）——讨论串开了拉取请求、**「等你」**（Waiting on you）、**「进行中」**（Working）、**「合并中」**（Landing）——开了自动合并、**「空闲」**（Idle）、**「已解决」**（Resolved）六组列出，「已解决」默认收起。每行能点开那条讨论串、停下它、**「标为已解决」**（Mark resolved）或 **「重新打开」**（Reopen）；带 PR 的行后面有 PR 号，点了去 GitHub 看。空闲满 7 天、或它的 PR 合并了，会自动算已解决。卡头写着「在跑 N/上限」，鼠标停上去能看到这个项目和每条讨论串大约花了多少——按 API 价折算，只是估算。
  - 卡头的 **「暂停」**（Pause）：停下项目对话和所有在跑的讨论串，恢复前不开新的；暂停后同一个按钮变成 **「恢复」**（Restore），点了协调者接着派活，攒着的汇报一起送到。
  - **「模型」**（Model）卡：协调者用输入框里选的模型和思考深度；讨论串的模型和推理强度在这里另选——比如协调者用 Opus 拆任务、讨论串用 Sonnet 干活。只影响之后新开的讨论串，已经开出来的在它自己的输入框里换。
  - **「项目说明」**（Project instructions）：写下这个项目里协调者和每条讨论串都要遵守的规矩，比如「所有改动都要带单测」。
  - **「项目记忆」**（Project memory）：协调者把需求、决定和你的偏好记在这里，讨论串也读得到；你能看、能改、能删、能新建。
- **上限和默认值**在 **「设置 → Claude → 项目对话」** 里（见 07-settings.md）：**「同时在跑的讨论串」**（Threads running at once）默认 4 条，多出来的等前面的停下；**「每天最多新开讨论串」**（New threads per day）默认 100 条，所有项目合计；**「讨论串模型」**（Thread model）默认跟协调者一样；**「讨论串推理强度」**（Thread effort）默认高。另外一个项目对话累计最多 30 条讨论串。
- **费用和并行**：每条讨论串都是一个完整的 Claude 会话，几条同时跑，订阅额度消耗比单个对话快得多。这台 Muse 上每个账号同时最多 3 个对话在跑，协调者和讨论串都算在内，所以「同时在跑的讨论串」设成 2 或 3 比较合适；想省额度就再调小，或给讨论串选便宜一点的模型。
- 讨论串开了拉取请求才会进「待评审」「合并中」两组，前提和下面「拉取请求」一节一样（VM 上 gh 已登录）。
- 定时任务也能以项目对话运行，见「定时任务」。

## 拉取请求（PR）

- 前提：这个会话的项目是 git 仓库、有 GitHub 远程，并且**这台 VM 上 `gh` 已安装并登录**（`gh auth login`）；没装或没登录时 PR 卡会提示「未安装 GitHub CLI（gh）」或「请运行 gh auth login 登录」。拉取请求相关功能只对管理员开放。让 Muse 在 VM 上装好 gh、帮用户登录后再用。
- 会话里建出（或手动跟踪）一个 PR 后，输入框上方出现 **PR 芯片**（#编号 + 检查状态），会话信息面板里有 **「拉取请求」**（Pull request）卡，显示检查通过 / 失败 / 运行中、评审状态、合并冲突等。
- 卡上能做的：**「合并」**（Merge）（选 **「压缩合并」**（Squash and merge）/ **「合并提交」**（Create a merge commit）/ **「变基合并」**（Rebase and merge），会先确认）、**「同步基线」**（Sync base）、**「重跑失败的检查」**（Re-run failed checks）、**「就绪后自动合并」**（Auto-merge when ready）、**「标为可审查」**（Mark ready）/ **「转为草稿」**（Convert to draft）、**「移出」**（Remove）。没有 PR 时有 **「创建拉取请求」**（Create PR），旁边的下拉里还能建草稿、跟踪已有的拉取请求。
- **「自动修复」**（Auto-fix）：开了之后，这个 PR 的 CI 失败、出现冲突或有新评审意见时，会自动叫醒那个会话去处理，连续处理几次会暂停，可以点「恢复自动修复」。总开关 **「自动修复拉取请求」**（Auto-fix pull requests）和 **「拉取请求合并或关闭后自动归档」**（Auto-archive after PR merge or close）在 **「设置 → Claude → Git 与拉取请求」**（Settings → Claude → Git and pull requests）里。
- Claude 自己想开自动合并 / 自动修复时，会先弹一张确认卡问你。
- 访问 GitHub 要过 Muse 的审核卡：提前让 Muse 跑 `allow-sites github.com`。

## 引用另一个对话

- 把侧栏里的一个对话**拖到输入框上**：它会变成一张「引用对话」卡片，发送时 Claude 先读完那段对话的全文（不含工具调用细节）再回答。手机上长按对话、拖出侧栏、放到对话区。
- 拖到侧栏另一个对话上 = 切到那个对话再引用。

## 分屏和单独窗口（电脑 + 鼠标）

- 屏幕够宽（约 1100px 以上）时，把侧栏里的对话拖到对话区左半边 / 右半边，就能左右分屏同时看两个对话；拖中间分隔条调比例。刷新页面后分屏不保留。
- 把对话拖到浏览器窗口外面松手，会单独弹出一个窗口只放这个对话（浏览器拦了弹窗的话，允许本站弹窗后再拖一次）。

## 用量

- 输入框左下角（＋ 按钮之后）的小圆环——悬停提示里有 **「查看用量」**（View usage）——既是权限模式也是用量环：环填了多少 = 这个对话的上下文用了多少，环的颜色表示权限模式（见「权限模式和批准」），不再随用量变色。点开面板的下半：Context window 看上下文的详细占比，Plan usage limits 看订阅的用量上限（5 小时上限、每周所有模型 / 各型号）和多久后重置；面板里的条 75% 变黄、90% 变红。当前在用的订阅号没有 5 小时限额时（部分 Ultra 号），5 小时那一行写 **「无限制」**（Unlimited）。
- 弹层里还有一行「距自动压缩还有 …」和 **「压缩会话」**（Compact session）按钮：对话太长、回答变慢或快到上限时点它，等于发一次 `/compact`。Claude 正在回复或离线时按钮是灰的。自动压缩点可以在弹层的计量条上拖动改（设置里只有一个「恢复默认」）。
- 订阅上限是**整台服务器共用的**（大家用的是同一份 Claude 订阅）。
- 用到上限时，输入框上方出现**限额卡**：「已达到 5 小时限额」（Session limit reached）（每周或某个型号的限额同理），写着重置时间，也建议你换个型号继续。卡上有 **「限额重置后自动继续」**（Auto-continue when limits reset）开关：开了，额度恢复后自动接着跑完这一轮（默认就是开的，也可以在「设置 → Claude → 撞上限额时」里改），卡上会写「将于 … 自动继续」。这一轮还开着后台任务时同样会续。管理员在订阅号池里放了不止一个号时，不用等撞墙的那个号自己重置：号池里最先恢复额度的那个号一恢复就接着做。同一个限额窗口最多自动续 3 次，过了重置时间 6 小时、或你已经先发了新消息就不续；只有 5 小时限额有自动继续，每周和按型号的限额没有。
- **用量环的数字最多约 10 分钟刷新一次**（服务器不再主动去探测），刚用完额度时环上的读数可能比实际慢一点。

## 定时任务（定时触发）

- 侧栏 **「定时触发」**（Routines）：让 Claude 按时间表在服务器上跑一件事，比如每天早上汇总笔记、回看昨天的提交。服务器在线就会按时跑，你的手机和电脑不用开着。
- 页面跟官方 Claude 桌面端的定时任务一样：任务排成卡片，顶上能搜索、筛选、排序；点一张卡进详情——左边是状态、文件夹、频率、模型和权限，右边是指令和 **「运行记录」**（History），点一条记录就打开那次的会话。
- 点 **「新建任务」**（New routine）要填：
  - 名称、**「描述（可选）」**（Description (optional)）；
  - **「指令」**（Instructions）：每次让 Claude 做什么；
  - **「文件夹」**（Folder）：在哪个项目文件夹里跑（把文件夹拖进底栏也行）；可以打开 **「每次切新 worktree」**（New worktree each run），每次先切一个新分支和工作目录，改动不碰你手上的检出，还能选从哪个分支切；
  - 权限模式、模型和思考强度；权限选项里还能勾 **「以项目对话运行」**（Run as a project conversation）：每次由协调者收到指令后自己开讨论串去做，上面选的那一档就是讨论串权限；再配「接着上次的会话」，就是一个按时巡检、长期挂着的项目（见「项目对话」）；
  - **「频率」**（Frequency）：**「手动」**（Manual）——只在点「立即运行」时跑、**「一次」**（Once）——选一个以后的时间、**「每小时」**（Hourly）、**「每天」**（Daily）、**「工作日」**（Weekdays）、**「每周」**（Weekly）——可以勾几天，或者自己写 cron（5 段数字：分 时 日 月 周，周日写 0，最多每小时一次）；
  - 会话方式：每次开一个干净的新会话，或 **「接着上次的会话」**（Continue the previous session）；还可以勾 **「跑完通知我」**（Notify me）——通知标题写的是定时任务的名字。
- 也可以直接跟 Claude 说「帮我建一个定时任务：…」，让它替你建。
- 卡片的更多操作里有 **「立即运行」**（Run now）、**「暂停」**（Pause）和删除；删除任务不会删掉已经跑出来的会话。
- **每次运行就是一条普通 Claude 会话**：跑的时候侧栏能看到，点进去能看直播、能停止；跑完留在历史对话里。遇到要你批准的操作（取决于选的权限模式）会停下来等你，详情页显示 **「等你处理」**（Needs input）；想全程自己跑完，权限模式选「自动」。
- **时间按服务器的时区算**，页面上会写出服务器时区（Muse 的 VM 一般是 UTC，比北京时间晚 8 小时，想北京时间 9 点跑就填 01:00）。服务器宕机期间错过的那次**不会补跑**。

## 调试模式（只有管理员）

- **「设置 → Claude → 调试」**（Settings → Claude → Debug）里的 **「调试模式」**（Debug mode），在那一页最底下「安全」下面，默认关。它是给想帮忙改进这个软件的人用的，平时不用开。
- 打开后，Claude 会把「挑软件本身的毛病」放在第一位：工具报错先判断是不是工具自己的问题，遇到多余的设计、缺的功能、不得不绕的路，都当场写成一条问题说明，回答末尾附上这一轮记了几条。**开着时你交代的任务排在第二位**，会更慢、更费额度。
- 记下的内容只存在这台 VM 上：数据目录的 `harness-feedback/` 文件夹（`/home/hatch/bridge-srv/harness-feedback/`），按 agent 和日期分好，另有一份总索引。不会自动发给任何人；想交给开发者，走 07-settings.md「提交反馈」或 `../MUSE.md` 第 8 节。
- dimensio 那边也有一个同名的开关，在 dimensio 自己的设置里（见 03-dimensio.md）。

## Claude 页常见提示

| 看到的 | 意思 / 怎么办 |
|---|---|
| 服务端还没配置 Claude 认证…（Claude sign-in isn't set up on the server…） | 还没配 Claude 令牌：只有发了消息才会出现。按 `../MUSE.md` 4.4 配 |
| 登录已失效 — 令牌过期或被撤销…（Sign-in expired…） | 令牌失效，在自己电脑上重新 `claude setup-token`，再按 4.4 换上 |
| 5 小时 / 本周使用额度已达上限 + 恢复时间 | 订阅用量到顶，等到恢复时间 |
| 同时最多 3 个对话在跑… | 等一个跑完，或在侧栏带闪烁点的对话里停止一个 |
| 状态行写「需要你的输入」 | Claude 在等你：输入框上方有批准卡、计划卡或问题卡片，处理完它才继续 |
| 协调者说这个项目的讨论串到上限了 | 一个项目对话累计最多 30 条讨论串，另开一个新的项目对话接着做；说的是今天的上限，就是「每天最多新开讨论串」到了，在设置里调高或等明天（见「项目对话」） |
| 今天已经跑了 N 轮…（普通账号） | 管理员给这个账号设的额度用完了，找管理员 |
| 出海请求被网关拒绝（不是账号问题）… | 服务器的出口网络被拒，不是令牌问题；稍后再试，持续的话按 `../MUSE.md` 第 7 节查 |
| 连不上 Claude 服务器… / Claude 服务器暂时不可用… | 网络或 Claude 那边临时问题，稍后重试 |
| 所选模型不可用… | 换一个模型（模型芯片在输入框里右下角、发送按钮旁边，不在右上角） |
| 回答达到长度上限… | 说一句「继续」 |
| 这一轮被中断 · 服务已恢复，马上自动继续 / ⚠️ 这一轮没跑完…马上会自动让 Claude 从中断的地方接着做 | 服务意外重启打断了这一轮（VM 重启、看门狗重启服务、`switch-now` / `rollback`）。不用做什么：约 15 秒后自动接着做（见「Claude 在干活的时候」） |
| ⚠️ 这一轮没跑完…说一句「继续」就能从这里接着往下做 | 同样是被重启打断，但这次没自动续（关了「自动继续被中断的对话」、连着续了 3 次、中断超过 12 小时，或续不上）：说一句「继续」 |
| 正在同步状态… | 正在跟服务器核对这一轮的状态，一两秒就好；一直这样多半是网络断了（见 01-access.md） |
| 一直停在「等待 Claude…」不动 | 多半是 Muse 里有一张审核卡没批（api.anthropic.com），见 08-faq.md |
| 离线 · 连不上服务器… | 网络断了或地址变了；见 01-access.md |
