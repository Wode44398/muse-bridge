# dimensio 页

dimensio 是一个能接各家模型 API 的 agent 工作台：用户自己的 API key（Claude、DeepSeek、Gemini、通义、智谱、Kimi、小米 MiMo，或任何 OpenAI 兼容接口），像 Claude Code 一样读写文件、跑命令、做项目。跟 Claude Code 页最大的不同：

- 用的是**各家的 API key**，不是 Claude 订阅；按各家的价格计费，dimensio 里**不显示花了多少钱**。
- 有**运行档位**和**权限卡片**：可以设成只读、先出计划再干、某些操作每次问你。
- 它在干活时**可以插话纠偏**（Claude 页不行）。

## 页面布局

- 左侧栏：**「新对话」**（New chat）、搜索、快照对话、项目和对话列表；最底下 **「设置」**（Settings）。
- 中间：对话；底部输入框，左下是档位胶囊，右下是模型胶囊。
- 右侧工作区：顶栏的面板按钮 **「工作区」**（Side panel）打开，里面有任务、审阅、终端、文件。
- 宽屏三栏并排；窄一点打开工作区时侧栏会收起；手机上侧栏是抽屉（从左边缘往右滑、或点顶栏标题），工作区是从底部弹出的整页。
- 两个 agent 都装了时，侧栏有 **「主页」**（Home）回主页；只装了 dimensio 时打开网址直接就是这一页。

## 模型和厂商

### 有哪几家、key 叫什么

| 厂商（界面上的名字） | 默认型号 | 让 Muse 配 key 用的名字 |
|---|---|---|
| Claude（Anthropic） | Sonnet 4.6（还有 Opus 5.5、Opus 5、Sonnet 5.5 等） | `ANTHROPIC_API_KEY` |
| DeepSeek | V4.1 Flash | `DEEPSEEK_API_KEY` |
| Gemini（Google） | Gemini 3.5 Flash | `GEMINI_API_KEY` |
| Qwen（阿里云 · 通义） | Qwen3.8 Max | `QWEN_API_KEY` |
| GLM（智谱 · Z.ai） | GLM-5.2 | `ZHIPU_API_KEY` |
| Kimi（月之暗面） | K3 | `KIMI_API_KEY`（只认 Kimi for Coding 订阅 key，`sk-kimi-` 开头） |
| MiMo（小米） | MiMo V2.6 Pro | `MIMO_API_KEY`（`tp-` 开头的 Token Plan key 也行） |
| 自定义服务 | 你填的接口里的第一个对话模型 | 在界面上加（见下面） |

- 型号列表是内置的，各家新出的型号要等 Muse Bridge 更新才会出现；想用列表里没有的型号，可以用「自定义服务」接。
- 第一次打开时，自动选第一家配了 key 的厂商。

### 配 key：让 Muse 用 set-api-key

- **内置的这几家，key 让 Muse 写进服务器**：`bash /home/hatch/bridge-ops/bootstrap.sh set-api-key <名字> <key>`（`../MUSE.md` 4.5）。写进去的 key 存在磁盘上，重启也在。跑之前提醒用户：马上会弹审核卡，选「总是允许此站点」。
- 网页里也能填：**「设置 → dimensio → 模型服务」**（Settings → dimensio → Provider）的 API Key 框——但**内置厂商的 key 填在这里只存在内存里，服务一重启就没了**（VM 每几小时重启一次、更新、set-api-key 都会重启）。只适合临时试试。这是已知问题，见 08-faq.md。
- 设置里那一行会显示 **「已配 Key」**（Key set）或 **「缺 Key」**（No key），只看当前选中的那一家。厂商面板的方块上**看不出**哪家配了 key。
- 当前厂商没配 key 时：侧栏底部「设置」旁边有个橙点，新对话页输入框上方有一条提示「先在设置里填 <厂商> 的 API Key」，点了会打开设置。**在 Muse 上别照着在网页里填**（内置厂商的 key 填在网页里重启就没了），让 Muse 跑 `set-api-key`。
- 没配 key 就发消息：消息会被退回输入框，提示里带着 `No API key for provider …`。

### 选型号、思考深度

- 输入框右下的**模型胶囊**（显示厂商标志 + 型号 + 思考档位）→ 菜单里 **「模型」**（Model）选型号，**「思考深度」**（Effort）选 off / low / medium / high / max（各型号支持的不一样；只有一档的型号不显示这一栏）。
- 对话进行中也能换：空闲时马上生效；正在跑的话，这一轮跑完、下一条消息起用新的。换的同时也成为新对话的默认。
- 各家的特别提醒：
  - GLM-5.3 系列要账户里有覆盖 5.3 的资源包，不然报错 1113（会被当成余额问题）；
  - MiMo UltraSpeed 需要单独开通，而且 Token Plan 的 key 用不了它；
  - 有些型号只能看文字不能看图（比如 DeepSeek V4 Pro、部分通义和 GLM 型号），发图会让你换多模态型号。

### 换厂商

- 模型胶囊菜单最下面 **「切换模型服务…」**（Switch provider…）→ 弹出 **「模型服务」**（Provider）面板，点一家。
- **换厂商一定会开一个新对话**；旧对话还在，打开旧对话时会自动切回它原来的厂商和型号。正在跑的任务转到后台继续跑。

### 加一个自定义服务（OpenAI 兼容接口）

- 模型服务面板里最后的 **「添加自定义服务」**（Add custom provider）：中转站、OpenRouter、自己部署的 vLLM / Ollama 这类兼容 OpenAI Chat Completions 的接口都能接。
- 填：备注名、接口地址（填到 `/v1` 那一级，贴完整的 `…/chat/completions` 也会自动收好）、API Key → **「连接并添加」**（Connect and add）。服务器会去这个地址拿模型列表（12 秒超时）；接口没列出模型时会让你手填一个模型 ID。
- **在 Muse 上要先放行这个网站**：添加前让 Muse 跑 `allow-sites <接口地址>`，提醒用户把审核卡选成「总是允许此站点」，不然会连接超时（`../MUSE.md` 第 6 节）。
- 自定义服务的 key **加密存在服务器上，重启也在**（跟内置厂商不一样）。
- 自定义服务固定不开思考、上下文按 128K 算、没有自带的联网搜索（搜索会用别家备用）。最多 24 个。
- 方块上的铅笔图标可以编辑；删除要点两次。删掉正在用的那个会自动换回默认厂商、开新对话。
- 注册账号（不是管理员）不能加自定义服务。
- 常见错误：「API key 被拒绝（HTTP 401）」、「接口没有返回 JSON——地址是不是少了 /v1？」、「连接超时（12 秒没有响应）」、「接口没列出任何模型」。

## 发消息、插话、停止

- 电脑：Enter 发送，Shift+Enter 换行；手机：回车换行，点发送按钮。
- **它在干活时可以插话**：直接输入发送，这条会进 **「待送达的插话」**（Queued messages），在它下一步时读到。排队的插话可以 **「撤回」**（Unsend）放回输入框，或者 **「立即中断并发送」**（Send now）。插话只能是文字，不能带附件。
- **停止**：对话末尾那行状态旁边的 **「停止」**（Stop），不在输入框上。有工作流或子 agent 在跑时要点两次。停止会把这个对话的后台命令也一起停掉。
- 同一个浏览器里最多同时跑 3 个对话。
- **关掉浏览器、断网，任务照样在服务器上跑**，回来会自动接上；只有停止才会停。

### 斜杠命令

- 在开头输入 `/` 弹出命令面板：`/new` 新对话、`/compact` 压缩上下文、`/handoff` 带摘要开新对话、`/goal <目标>` 开目标模式；装过的技能也会列在这里（技能要管理员在「自定义」里装、给 dimensio 打开，新对话生效）。

### 附件

- 输入框的 ＋ **「添加文件」**（Add files）：**「从设备上传」**（Upload from device）选文件或文件夹，或者从 **「工作空间」** 里挑已有文件。也可以粘贴、拖到页面上，或从文件管理器拖进对话。
- 限制：单个文件 30MB，一条消息最多 10 个附件；图片只收 PNG / JPEG / WebP（单张 8MB、一条合计 16MB），GIF、HEIC 这类会让整条消息发不出去；视频 MP4 / WebM / MOV（能看视频的型号）；音频只有 MiMo 能听。
- 附件存在项目里的 `.dimensio/uploads/` 下，删对话时一起删掉。
- 把侧栏里另一个对话拖到输入框上，可以**引用那个对话**（一条消息最多 3 个）。

## 档位、访问范围、权限

输入框左下、＋ 旁边的**档位胶囊**点开。胶囊上写着当前档位：默认是「自主」、不高亮；改过的设置会接在后面并高亮，比如「只读 · 仅工作空间」「自主 · 离开」（手机上胶囊只剩图标）。菜单里有：

- **「运行档位」**（Mode）：
  - **「自主执行」**（Auto）：默认档，直接干，不问；
  - **「只读」**（Read-only）：只能读，不能写文件、不能跑会改东西的命令；
  - **「先出计划」**（Plan first）：先只读调研、交一份计划，你批准后才切到自主执行开始干。
- **「访问范围」**（Access）：**「整机可访问」**（Full access）——默认，或 **「仅工作空间」**（Workspace only）。「仅工作空间」挡的是明显越界的路径和命令，防手滑，不是严格隔离。
- **「离开模式」**（Away mode）：出门前打开，这一轮不会卡在没人点的卡片上——提问按合理假设继续、要批准的操作直接拒绝、计划先放着等你。你一发消息它就自动关掉。**对话开始后（发出第一条消息后）菜单里才有这一项**，新对话的空白页上没有。
- **「目标模式」**（Goal mode）：在菜单里勾上，再把目标当成消息发出去，它自己一轮接一轮做到达成（输入框上方可以填一条验证命令，比如 `npm test`；最多 1–50 轮，默认 10 轮，最长 2 小时）。连续 3 轮没动手、轮数或时间用完会暂停，顶部有目标条可以继续 / 结束。它正在干活、或者在等你回卡片时，菜单里没有这一项。
- 注册账号（不是管理员）的菜单里没有「访问范围」，固定是仅工作空间。
- 改档位和范围对正在跑的一轮也立刻生效（从下一次工具调用起）。

### 权限规则

- **「设置 → dimensio → 权限规则」**（Settings → dimensio → Permission rules）：两个框，一行一条：
  - **「每次问我」**（Always ask），比如 `Bash(git push:*)`；
  - **「从不允许」**（Never allow），比如 `Bash(rm -rf:*)`。
- 写法：`工具名` 匹配这个工具的所有调用，`工具名(前缀:*)` 匹配以前缀开头的命令或路径。点 **「保存」**（Save）后，所有对话从下一次工具调用起按新规则走，重启也保留。

### 卡片：它在等你

卡片出现在输入框上方，一次只显示一张，别的排队。

- **批准卡片**：命中「每次问我」、高危命令、不能撤回的操作（强推、发布、全局安装……）、启动工作流、改 AGENTS.md 这类控制文件时出现。按钮：**「拒绝」**（Deny）、**「拒绝并停止」**（Deny and stop）、**「本会话都允许」**（Allow for this session）、**「允许一次」**（Allow once）。**10 分钟没人批就按拒绝处理。**
- **问题卡片**：它问你问题（最多 4 题，可以选「其他…」自己写）。**10 分钟不答（先出计划档位下是 60 分钟），它就按合理假设继续。**
- **计划卡片**：**「批准并执行」**（Approve and run）；**「退回修改」**（Request changes），可以附上要改什么；也可以选在新会话里实施。**60 分钟没人审，计划保持未批准。**
- 卡片在的时候直接在输入框里打字：批准卡片 = 拒绝并把这段话告诉它；问题卡片 = 当作回答；计划卡片 = 退回并附上意见。
- 任何一台登录着的设备都能处理卡片。
- 怕卡在卡片上：出门前开「离开模式」。

## 对话里的东西

- **工作过程**：默认把连续的工具调用折叠成一行（「读取了 3 个文件，执行了 2 条命令」），点开看细节；想全部展开，打开 **「设置 → dimensio → 显示全部工作过程」**（Settings → dimensio → Show all work steps）。之前的轮次会折叠成「处理过程 · n 次工具」。
- 跑了超过 10 秒的命令有 **「转后台」**（Move to background）按钮。
- **生成的文件**：最终回答下面最多 12 张文件卡片，点开在工作区「文件」里预览。
- **验收提示**：改了代码却没有通过的验证时，它会先自己补跑检查（最多 3 次）；还不行就在回答末尾附上「⚠️ 未验证…」之类的提示（只有中文）。
- **出错卡片**：一句话说明原因（key 无效、余额不足、被限流、上下文太长……），**「原始报错」** 可以展开原文，最后一次失败上有 **「接着做」**（Continue），还能 **「导出诊断包」**（Export diagnostic report）。限流、上游忙、超时这类会自动重试。
- **从这里改写**：电脑上鼠标悬停（手机上点）你发的某条消息 → **「从这里改写」**（Edit from here）：对话退回到那条消息之前、文字放回输入框。**文件不会跟着退**，8 秒内可以撤销。

## 撤销改动：检查点和审阅

- 顶栏的历史图标 **「回滚到检查点」**（Rewind to checkpoint）：你发的每条消息都是一个检查点，**「回滚到这里」**（Rewind to here）把文件和对话一起退回去；它删文件、丢弃 git 改动之前也会自动拍一个快照，可以只回滚文件。回滚前的状态也会存成检查点，回滚本身也能撤销。
- 只保留最近 30 个对话的检查点，50MB 以上的文件不记录。正在跑的时候不能回滚。
- 工作区的 **「审阅」**（Review）：看这个对话（或整个项目 git）改了哪些文件，可以单独撤销某个文件的改动（之后还能「找回」）。

## 子 agent、工作流、任务

- 它会派子 agent 去调研、写代码；大任务会启动**工作流**（一批子 agent，启动前要你批准）。对话里显示 agent 卡片和工作流卡片。
- 工作区的 **「任务」**（Tasks）：进行中 / 已完成的子 agent、工作流、后台命令；点开子 agent 看它收到的提示词、每一步、改了哪些文件、结果。
- 后台命令每个对话最多 8 个，默认 30 分钟超时。

## 右侧工作区

| 面板 | 快捷键 | 说明 |
|---|---|---|
| **「任务」**（Tasks） | — | 见上 |
| **「审阅」**（Review） | Ctrl+Shift+G | 见上 |
| **「终端」**（Terminal） | Ctrl+` | 每个工作空间一个 shell，最多 6 个；没有命令行权限的账号没有这一页 |
| **「文件」**（Files） | Ctrl+Shift+E | 跟「工作空间」一样的文件管理器（见 04-files.md） |

- **没有浏览器面板**：这台 VM 上没有浏览器，它也就不能打开网页、截图（联网搜索和抓网页内容照常）。做网页时它会用 curl 检查，并在回答里说明没在真浏览器里测过。
- 第一次打开工作区可能直接显示「文件」、没有哪个标签亮着，正常。

## 上下文、压缩、用量

- 顶栏的圆环：上下文用了多少（显示的上限是自动压缩的触发点，不是模型的全部窗口）。超过 82% 变色。
- 点开圆环：**「立即压缩」**（Compact now）、**「带摘要开新会话」**（New session with summary）——都要调一次模型，慢的模型可能要一两分钟。还有这个对话按任务分的 token 用量表（没有金额）。
- 长对话隔了一阵子再发消息时，输入框上方可能提示缓存已经凉了，建议压缩或开新会话；不管它也能继续。

## 联网搜索

- 先用当前这家自带的搜索，搜不了再按顺序换别家配了 key 的（智谱 → Kimi → DeepSeek → 通义 → Gemini → Claude → 小米），最后用免费的 DuckDuckGo 兜底。同一把 key，不用另外申请。
- **小米搜索要多一步**：要在小米控制台「插件管理」里开「联网搜索」插件（按次计费，约 ¥16 / 千次），而且只有按量付费的 key 能用。用户的聊天 key 是 Token Plan（`tp-` 开头）的话，再建一把按量付费的 key，让 Muse 配成 `MIMO_SEARCH_API_KEY`。不配也行，会自动换别家。
- 搜索结果行显示来源，比如「8 条结果（DuckDuckGo）」。

## 记忆

- **「设置 → dimensio → 记忆管理」**（Settings → dimensio → Manage memory），或项目菜单里的 **「项目记忆」**（Project memory）。
- 两层：全局记忆（关于你和这台电脑的，总共 2000 字以内）和每个项目的记忆。
- 每条有四种状态：待确认、被隔离（过期 / 冲突，暂不使用）、生效（进每个新对话）、已退场。可以确认、编辑、驳回（可以写理由）、删除。全局记忆都要你确认才生效；读过网页 / 搜索结果的对话写的记忆也要你确认。
- 它也会读项目里的 `AGENTS.md`、`CLAUDE.md`、`GUIDE.md` 当常驻指令。

## 项目和对话列表

- **项目 = 文件夹**。项目旁边 ＋ **「新建项目」**（New project）→ 文件选择器里**按住文件夹拖到底部那条栏**上。
- 项目菜单（…）：在这个项目里新建对话、**「置顶项目」**（Pin project）、**「项目记忆」**、**「隐藏项目」**（Hide project）——只是不显示，文件和对话都不删，在列表最底下「已隐藏的项目」里恢复。拖动项目可以排序。
- **搜索**：侧栏搜索框 **「搜索项目或对话」**（Search projects and chats），搜项目名和对话标题；输入 2 个字以上还会搜消息正文。
- 删对话：电脑上点垃圾桶再点「删除」（3 秒内），手机上左滑。**删了找不回来**，会停掉它的任务、删掉对话记录、附件和检查点；它在项目里写的文件不删。
- **快照对话**（闪电图标那一条）：不属于任何项目的一次性空间，只保留最新一条；＋ 开一个全新的。
- 列表每页 100 个对话，底部可以加载更早的。
- 电脑上宽屏可以把对话拖到对话区左 / 右半边分屏。

## 重启、断网之后

- 服务重启（VM 重启、更新）打断的一轮，会提示「服务重启打断了这一轮」并自动接着做；连续被打断两次后不再自动续，说一句「继续」就行。
- **VM 重启后，要有人打开一次 dimensio 页面，它才会启动并接着做**之前被打断的任务。
- 网页里填的内置厂商 key 重启后就没了，对话会因为没 key 停住——用 set-api-key 配就没这个问题。

## 诊断包

- **「设置 → dimensio → 诊断」**：先在 dimensio 里打开一个对话，再点 **「导出」**（Export）。生成的诊断包不含对话内容和 key，可以发给开发者排查（报告问题见 `../MUSE.md` 第 8 节）。

## 多人使用时（注册账号）

- 新账号默认没有 dimensio，管理员在控制台按人打开（06-users-admin.md）。
- 每人一个独立的 dimensio，访问范围锁死在自己的文件夹（「仅工作空间」，不能改）。同时最多 4 个人在用，20 分钟没动静会自动停掉（再用时自动启动）。
- 他们用的是**管理员配的 key**，不能加自定义服务。没有命令行权限的账号没有终端。
- 人太多时会提示「同时在用 dimensio 的人太多了（上限 4），请稍后再试」。

## 常见提示

| 看到的 | 意思 / 怎么办 |
|---|---|
| 一直停在「等待模型回复」 | 多半是 Muse 里有一张这家接口网站的审核卡没批：让用户去批（选「总是允许此站点」），或者让 Muse 跑 `allow-sites`。见 08-faq.md |
| 消息被退回输入框，带 `No API key for provider` | 这家没配 key（或者网页里填的 key 重启后没了）：让 Muse 用 set-api-key 配 |
| API key 无效、过期或没有这个模型的权限 | key 填错了或没开通这个型号：换 key 或换型号 |
| 账户欠费或额度用完 | 去厂商控制台充值，或换一家；重试没用 |
| 被限流 / 上游繁忙 / 超时，n 秒后重试 | 会自动重试，等着就行 |
| 等待网络恢复（已等 …） | 服务器连不上这家接口，最多等 30 分钟；多半也是审核卡没批 |
| 上下文超出了模型窗口 | 会自动压缩一次；还不够就「带摘要开新会话」 |
| 连不上 dimensio 服务 | dimensio 没启用或没装、或者正在重启；管理员在设置 → Agent 里看状态，没装的话让 Muse 跑 `set-agents claude,dimensio` |
| 服务正在重启（部署中），这一条没有发出 | 等一会儿再发 |
| 最多同时运行 3 个对话 | 等一个跑完 |

## 没有的功能（别答应用户）

浏览器 / 截图 / 打开网页、连接你自己的浏览器、本机模型、控制你的电脑桌面、显示花了多少钱、内置厂商的 key 在网页里永久保存——这些在 Muse Bridge 的 dimensio 里都没有。
