# dimensio 页

dimensio 是一个能接各家模型 API 的 agent 工作台：用户自己的 API key（Claude、DeepSeek、Gemini、通义、智谱、Kimi、小米 MiMo，或任何 OpenAI / Anthropic / Gemini 兼容接口），像 Claude Code 一样读写文件、跑命令、做项目。跟 Claude Code 页最大的不同：

- 用的是**各家的 API key**，不是 Claude 订阅；按各家的价格计费，dimensio 里**不显示花了多少钱**。
- 有**工作档位**和**权限卡片**：可以设成只读、先出计划再干、某些操作每次问你。
- 它在干活时**可以插话纠偏**，也可以把下一条消息先排队。
- **模型和 key 不在 dimensio 里配**：管理员在 **「设置 → 模型中心」**（Settings → Model Hub）里添加和修改（见 10-model-hub.md）；dimensio 里只负责选用哪一个。
- **dimensio 的设置在总设置里**：侧栏最底下的 **「设置」**（Settings）直接打开 **「设置 → dimensio」** 那一页（见下面「dimensio 的设置」）。当前对话的档位、权限这些运行设置在右上角的用量环里。

## 页面布局

- 左侧栏：最上面是月桥标志（点一下切换明暗）、**「新对话」**（New chat）、搜索、快照对话、项目和对话列表、**「已归档」**（Archived）；最底下 **「设置」**（Settings）。
- 中间：对话；底部输入框只有三样——左下 ＋ 添加文件，右下模型胶囊和发送键。
- 右上角：**用量环**——上下文用了多少，点开是这个对话的运行设置（工作档位、工作权限、运行环境）和上下文操作；旁边是 **「工作区」**（Side panel）按钮，打开右侧的任务、审阅、终端、文件、记忆（按钮的悬停提示里写着「浏览器」，这台 VM 上其实没有浏览器面板）。
- 宽屏三栏并排；窄一点打开工作区时侧栏会收起；手机上侧栏是抽屉（从左边缘往右滑、或点顶栏标题），工作区是从底部弹出的整页。
- 两个 agent 都装了时，侧栏有 **「主页」**（Home）回主页；只装了 dimensio 时打开网址直接就是这一页。
- 侧栏的对话行：转圈 = 正在跑，**「等你」**（Needs input）= 在等你处理卡片；顶栏会显示有几个对话在后台运行。子会话缩进挂在开出它的那个对话下面（见「会话协作」）。
- **切换明暗**：点新对话页中间的大月桥标志，或侧栏左上角的小标志。明暗是全站统一的：在这里切，主页、Claude 页、设置一起变；也可以在总设置的「外观」里改（见 07-settings.md）。

## dimensio 的设置

侧栏最底下 **「设置」**（Settings）会直接打开总设置的 **「设置 → dimensio」** 那一页——「Agent」分组里的 dimensio 一行，和从主页进设置是同一页。管理员看到全部；被授权用 dimensio 的成员也有这一页，只出他自己能改的。从上到下：

| 分组 | 里面有什么 |
|---|---|
| 页头 | 「启用 dimensio」开关——只有管理员能改 |
| **「模型」**（Model） | **「模型服务」**（Model providers）、**「型号」**（Model）、**「思考深度」**（Effort），部分型号还有 Fast mode 开关。是**新对话的默认**；对话里随时可以在输入框的模型胶囊改 |
| **「模型服务」**（Model providers）——管理员 | 只有一行 **「模型中心」**（Model Hub），点了进 **「设置 → 模型中心」**：dimensio 能用的模型都在那里添加和修改 |
| **「API Key」**（API key）——成员 | 内置的每家厂商一行，标着 **「已配 Key」**（Key set）或 **「缺 Key」**（No key），点进去填自己的 key；最后一行「自定义模型服务」打开 dimensio 里的模型服务面板 |
| **「权限与安全」**（Permissions and security） | **「默认运行档位」**（Default mode）——自主执行 / 只读 / 先出计划三选一、**「访问范围」**（Access）、**「每次问我」**（Always ask）、**「从不允许」**（Never allow）两张规则表（见「权限规则」）。成员的访问范围写着「这台服务器把访问范围锁定了，改不了。」 |
| **「工作空间」**（Workspace） | 新对话没选项目时在哪个文件夹干活；点了选文件夹。已经开着的对话不受影响 |
| **「记忆」**（Memory） | **「记忆管理」**（Manage memory）：回到 dimensio 页打开记忆面板（见「记忆」），有待处理的会标出条数 |
| **「对话」**（Chat） | **「显示全部工作过程」**（Show full work process）——只存在这台设备上，默认关；**「输入建议」**（Prompt suggestions）；「AI 起标题」（AI titles）；「离开模式下的批准请求」（Approval requests in away mode）——默认不同意（默认）/ 默认同意；「后台任务跑完自动接着做」（Continue when a background task finishes）；「空闲时赶在缓存过期前压缩」（Compact idle conversations before the cache expires）和它的起点；「空闲时整理记忆」（Tidy up memory while idle）；「不常用的工具按需加载说明」（Load instructions for rarely used tools on demand）；「对话内交互图表」（Inline interactive charts）。这些开关默认都开着 |
| **「子 agent 调度」**（Subagent dispatch） | **「按难度选型阶梯」**（Difficulty-based model ladder）、「子 agent 调度偏好」（Sub-agent dispatch preferences）——见「子 agent、工作流、任务」 |
| **「会话协作」**（Session collaboration） | 「dimensio 发起新会话」（When dimensio starts new sessions）——先问我（默认）/ 直接开始 / 只在我要求时；**「其它会话发来的消息」**（Messages from other sessions）——直接接收（默认）/ 先存着 / 拒收；「会话之间连续自动续的上限」（Limit on automatic back-and-forth between sessions）——默认 6 轮 |
| **「工作区协同」**（Workspace awareness） | 「让 agent 看到我正在看的文件」（Let the agent see the file I'm viewing）、「允许 agent 读取未保存的草稿」（Allow the agent to read unsaved drafts），默认都开；「agent 使用共享终端」（Agent use of the shared terminal）——可以读屏和打字（默认）/ 只能读屏 / 不允许 |
| **「Git 与拉取请求」**（Git and pull requests）——只有管理员 | **「自动修复拉取请求」**（Auto-fix pull requests）——默认关、**「评审回复署名」**（Review reply attribution）、**「分支前缀」**（Branch prefix）——默认 dimensio |
| **「会话管理」**（Session management） | **「归档不活跃的会话」**（Archive inactive sessions）：从不（默认）/ 1 / 2 / 7 / 14 / 30 天 |
| **「通知」**（Notifications） | **「权限请求」**（Permission requests）、**「提问」**（Questions）、**「任务完成」**（Task complete），默认都开；总开关在「通用」里 |
| **「调试」**（Debug）——只有管理员 | **「调试模式」**（Debug mode），默认关（见本章最后「调试模式」） |
| **「诊断」**（Diagnostics） | **「导出诊断包」**（Export diagnostic report）：选一个最近的对话导出；在 dimensio 里聊过才有这一组 |

- 这一页每项**改了就生效**，没有「保存」按钮；改过默认值的偏好项旁边有个小点，单选项点进去底部能 **「恢复默认」**（Reset to defaults）。
- 管理员这一页还有一组「本机模型」，是给自带显卡、在本机跑模型的电脑用的，**这台 Muse 上用不了**，别动它。
- 页面写着「dimensio 的设置暂时读不到」：dimensio 没启用 / 没装 / 正在重启，点「重试」；还不行见本章最后「常见提示」。
- 语言在总设置的「通用」里，明暗在「外观」里，和整个网页共用。

## 模型和厂商

### 有哪几家、key 叫什么

| 厂商（界面上的名字） | 默认型号 | 让 Muse 配 key 用的名字 |
|---|---|---|
| Claude（Anthropic） | Opus 5.5（还有 Fable 5.2、Opus 5、Sonnet 5.5、Haiku 5.5 等） | `ANTHROPIC_API_KEY` |
| DeepSeek | V4.1 Flash | `DEEPSEEK_API_KEY` |
| Gemini（Google） | Gemini 3.5 Flash（还有 Gemini 4 Argon 等） | `GEMINI_API_KEY` |
| Qwen（阿里云 · 通义） | Qwen3.8 Max | `QWEN_API_KEY` |
| GLM（智谱 · Z.ai） | GLM-5.2 | `ZHIPU_API_KEY` |
| Kimi（月之暗面） | K3.1 Pro（还有 K3.1 Pro Highspeed、K3 等） | `KIMI_API_KEY`（只认 Kimi for Coding 订阅 key，`sk-kimi-` 开头） |
| MiMo（小米） | MiMo V2.6 Pro | `MIMO_API_KEY`（`tp-` 开头的 Token Plan key 也行） |
| 别的服务（中转站、OpenRouter、自己部署的接口等） | 你在模型中心里勾给 dimensio 的模型 | 在模型中心里加（见 10-model-hub.md） |

- 这几家在 dimensio 里有专门的适配（思考档位、型号规格），但**它们的 key 也在模型中心里**：每家是模型中心里的一个服务，换 key、增减型号、停用都在那里做。
- 管理员的「模型服务」面板和型号菜单**只列模型中心里已经加好的那几家和它们勾给 dimensio 的型号**；想多一家或多一个型号，去模型中心加。
- 第一次打开时，自动选第一家配了 key 的厂商。

### 配 key

- **管理员**：在网页里加——**「设置 → 模型中心」**（Settings → Model Hub）→ **「添加服务」**（Add provider），步骤见 10-model-hub.md。**在 Muse 上要先放行这个网站**：加之前让 Muse 跑 `allow-sites <接口地址>`，用户在 Muse 里批这个地址的审核卡（各选项的后果见 `../MUSE.md` 2.0，由他选）；没放行的话识别模型、对话都会超时（`../MUSE.md` 第 6 节）。
  - 以前让 Muse 跑 `set-api-key` 代填 key 的做法，在模型中心接管之后对管理员的 dimensio 不再生效（命令输出会照实说），key 一律在模型中心里加、换（`../MUSE.md` 4.5）。
- **从旧版本升上来的**：以前配过的 key——让 Muse 用 set-api-key 写的、在 dimensio 里填的——更新后第一次启动会自动搬进模型中心，每家一个服务；思考档位、旧对话和默认模型都不变。以前在 dimensio 里自己加的自定义服务也一样并了进去，正在用它的老对话照常能接着聊。
- **成员**：没有模型中心。自己的 key 在 **「设置 → dimensio」** 的 **「API Key」**（API key）一组里一家一家填，加密存在服务器上、不回传浏览器；自己填了就用自己的（见「多人使用时」）。
- 当前厂商没配 key 时：侧栏底部「设置」旁边有个橙点；新对话页输入框上方有一条提示——管理员看到的是「先在模型中心添加 <厂商> 的服务」，点了直接打开模型中心的添加页；成员看到的是「先在设置里填 <厂商> 的 API Key」，点了打开设置。
- 没配 key 就发消息：消息会被退回输入框，提示里带着 `No API key for provider …`。

### 选型号、思考深度

- 输入框右下的**模型胶囊**（显示厂商标志 + 型号 + 思考档位）→ 菜单里 **「模型」**（Model）选型号（上面有 **「搜索型号」**（Search models）框，型号旁标着能不能看图、会不会思考），**「思考深度」**（Effort）选档位（各型号支持的不一样，比如 Claude 的新型号是 low / medium / high / xhigh / max；只有一档的型号不显示这一栏）。
- 对话进行中也能换：空闲时马上生效；正在跑的话，这一轮跑完、下一条消息起用新的。换的同时也成为新对话的默认。新对话的默认也可以在 **「设置 → dimensio」** 的「模型」一组里改。
- 部分型号的菜单里还有 **Fast mode** 开关（说明是「输出更快，按更高单价计费」）：开了输出更快，但按更高的单价计费；被限流时会自动退回普通速度并提示几分钟内不再尝试。
- 各家的特别提醒：
  - GLM-5.3 系列要账户里有覆盖 5.3 的资源包，不然报错 1113（会被当成余额问题）；
  - MiMo UltraSpeed 需要单独开通，而且 Token Plan 的 key 用不了它；
  - 有些型号只能看文字不能看图（比如 DeepSeek V4 Pro、部分通义和 GLM 型号），发图会让你换多模态型号。

### 换厂商

- 模型胶囊菜单最下面 **「切换模型服务…」**（Switch provider…）→ 弹出 **「模型服务」**（Provider）面板，点一家。
- **在已有对话里换厂商 / 型号，不会开新对话**：直接在当前对话里生效，聊过的内容接着用（正在跑的话，这一轮跑完后换），同时成为新对话的默认。还没有对话（空白页）时只是改默认。
- 管理员的面板里还有一张「本机」，是在自带显卡的电脑上跑本地模型用的，这台 Muse 上用不了。

### 模型服务面板：只管切换，添加和修改在模型中心（管理员）

- 面板最后一张虚线卡 **「添加服务」**（Add provider）——副标题写着「模型中心」——点了直接打开模型中心的添加页；面板底下还有一行 **「在模型中心管理全部模型服务」**（Manage all model providers in Model Hub）。
- 卡片上的铅笔：打开它在模型中心里的那个服务，在那里改地址、key、型号。还留在 dimensio 里的老服务点铅笔会先问一句，确认后搬进模型中心。
- 这张面板里**没有填 key、填地址的表单**。添加、识别模型、勾选给 dimensio、挂多把 key、共享给成员，都见 10-model-hub.md。
- 模型中心里加的服务，在模型中心把模型勾给 dimensio 之后，回到 dimensio 页它就出现在这张面板和型号菜单里。
- **管理员共享给成员**：在模型中心里那个服务上打开 **「共享给成员」**（Share with members），卡片上写「N 个模型 · **已共享**（Shared）」。成员的面板里会出现这张卡，能直接选用，用的是管理员的 key；成员看不到地址和 key，卡上也没有铅笔。管理员关掉共享后，成员那边立刻没了，正选着它的会换回默认厂商。

### 成员自己加自定义服务

多人模式下，注册账号没有模型中心，仍在 dimensio 的模型服务面板里加自己的服务，每人各存各的、key 也各自加密保存，互相看不到。

- 面板最后的 **「添加自定义服务」**（Add custom provider）——说明写着「OpenAI / Anthropic / Gemini 接口」。
- 填：**「备注」**（Note）、**「接口地址」**（Base URL）（填到 `/v1` 那一级，贴完整的 `…/chat/completions` 也会自动收好）、**「接口协议」**（API protocol）、API Key。地址和协议对不上时编辑器会提示，有 **「检测连接」**（Check connection）可以看哪个组合能通。点 **「连接并添加」**（Connect and add）后，服务器会去这个地址拿模型列表；接口没列出模型时让你手填一个模型 ID。
- 展开某个模型可以单独设它的思考档位，或点 **「探测能力」**（Probe capabilities）让服务器自己试出支持哪几档。
- 成员自己加的**只能连公网地址**（本机、内网地址会提示「自己添加的服务只能连公网地址」），最多 24 个。**也要先让管理员请 Muse 放行这个网站**（`allow-sites <接口地址>`），不然添加时连接超时。
- 方块上的铅笔可以编辑（Key 留空 = 不改）；删除要点两次。删掉正在用的那个会自动换回默认厂商、开新对话。
- 常见错误：「API key 被拒绝（HTTP 401）」、「接口没有返回 JSON——地址是不是少了 /v1？」、「连接超时（12 秒没有响应）」、「接口没列出任何模型」。

## 发消息、插话、排队、停止

- 电脑：Enter 发送，Shift+Enter 换行；手机：回车换行，点发送按钮。
- **它在干活时可以插话**：直接输入发送，这条会进 **「待送达的插话」**（Queued messages），在它下一步时读到。排队的插话可以 **「撤回」**（Unsend）放回输入框，或者 **「立即中断并发送」**（Send now）。插话只能是文字，不能带附件。
- **也可以排队，等这一轮结束再发**：它在干活、输入框里有字时，发送键左边多一颗时钟按钮 **「稍后发送」**（Send later），电脑上按 Ctrl+回车（Mac 是 ⌘+回车）。排队的消息列在输入框上方，这一轮结束后合并成一条发出；每条可以 **「立即发送」**（Send now）——改成插话，下一步就读到、**「编辑」**（Edit）——拿回输入框、**「移除」**（Remove），多条时可以 **「全部清除」**（Clear all）。队列存在服务器上，重启不丢、各设备同步；一个对话最多排 20 条。
- **输入建议**：它回复完，输入框空着时会用灰字猜你接下来想说的话，电脑上按 Tab 填入，手机上点「填入」。每条建议多一次便宜模型的请求；不想要就在 **「设置 → dimensio」** 的「对话」里关掉 **「输入建议」**（Prompt suggestions）。
- **停止**：对话末尾那行状态旁边的 **「停止」**（Stop），不在输入框上。有工作流或子 agent 在跑时要点两次。停止会把这个对话的后台命令也一起停掉。
- 同一个浏览器里最多同时跑 3 个对话。
- **关掉浏览器、断网，任务照样在服务器上跑**，回来会自动接上；只有停止才会停。

### 斜杠命令

- 在开头输入 `/` 弹出命令面板：`/new` 新对话、`/compact` 压缩上下文、`/handoff` 带摘要开新对话、`/goal <目标>` 开目标模式；装过的技能也会列在这里（技能要管理员在「设置 → 扩展」里装、给 dimensio 打开，新对话生效）。

### 附件

- 输入框的 ＋ **「添加文件」**（Add files）：**「从设备上传」**（Upload from device）选文件或文件夹，或者从 **「工作空间」** 里挑已有文件。也可以粘贴、拖到页面上，或从文件管理器拖进对话。
- 限制：单个文件 30MB，一条消息最多 10 个附件；图片只收 PNG / JPEG / WebP（单张 8MB、一条合计 16MB），GIF、HEIC 这类会让整条消息发不出去；视频 MP4 / WebM / MOV（能看视频的型号）；音频只有 MiMo 能听。
- 附件存在这个对话自己的附件目录里，不进你的项目仓库，删对话时一起删掉。
- 把侧栏里另一个对话拖到输入框上，可以**引用那个对话**（一条消息最多 3 个）。

## 运行设置：档位、权限、离开、目标

**点右上角的用量环**打开面板，最上面三段就是这个对话的运行设置（以前在输入框左下的档位胶囊里，现在输入框上没有了）。选了面板不关，几项可以一次调好。设置不是默认值时，用量环旁边会直接写出来并高亮，比如「只读」「仅工作空间」「离开」「目标」「全权」（手机上只剩图标）。

- **「工作档位」**（Mode）四选一：
  - **「自主」**（Auto）：默认档，直接干，不问；规则可以把个别高危调用改成每次问你；
  - **「只读」**（Read-only）：只能读，不能写文件、不能跑命令；
  - **「计划」**（Plan）：先只读调研、交一份计划，你批准后才切到自主开始干；
  - **「全权」**（Bypass）——**只有管理员有**，成员的面板里不列：所有工具调用直接执行、不弹卡片，整机可读写，连密钥文件的保护也关掉。选它之前要清楚后果：它不再问你任何事，包括删文件、强推这类不能撤回的操作。
- **「目标模式」**（Goal mode）开关：打开后面板收起，把目标当成消息发出去，它自己一轮接一轮做到达成（输入框上方可以填一条验证命令，比如 `npm test`；最多 1–50 轮，默认 10 轮，最长 2 小时）。连续 3 轮没动手、轮数或时间用完会暂停，顶部有目标条可以继续 / 结束。它正在干活、或者在等你回卡片时没有这一项。
- **「离开模式」**（Away mode）开关：出门前打开，这一轮不会卡在没人点的卡片上——提问按合理假设继续；要批准的操作和待审的计划怎么办，看 **「设置 → dimensio」**「对话」里的「离开模式下的批准请求」：默认不同意（操作直接拒、计划留着等你回来审），也可以改成默认同意（操作直接放行、计划直接批准并开工；「从不允许」的规则照样拦）。你一发消息它就自动关掉。**对话开始后（发出第一条消息后）才有这一项**，新对话的空白页上没有。
- **「工作权限」**（Access）：**「整机可访问」**（Full access）——默认，或 **「仅工作空间」**（Workspace only）。「仅工作空间」挡的是明显越界的路径和命令，防手滑，不是严格隔离；这个对话在权限卡上放行过的工作区外只读目录列在下面，点 × 收回。成员没有这一段，固定是仅工作空间；选了「全权」时这一段也不出现。
- **「运行环境」**（Environment）：这台 Muse 上平时没有这一段。只有用户把电脑登记成设备后才出现 **「电脑」**（Computer）一行，选这个对话连哪台电脑（见本章最后「没有的功能」）。
- 面板里改的每一项**对当前对话立刻生效**（正在跑的一轮从下一次工具调用起按新的算），**同时成为新对话的默认**——包括「全权」，用完记得切回去。新对话的默认档位也可以在 **「设置 → dimensio」** 的 **「默认运行档位」**（Default mode）里改，那里只有自主执行、只读、先出计划三档。

### 权限规则

- 在 **「设置 → dimensio」** 的「权限与安全」里，两张列表各点进去：
  - **「每次问我」**（Always ask），比如 `Bash(git push:*)`；
  - **「从不允许」**（Never allow），比如 `Bash(rm -rf:*)`。
- 每条一行：在输入框里写规则、点 **「添加」**（Add）（粘贴多行会自动拆成多条），每条可以单独删。添加、删除当场保存。
- 写法：`工具名` 匹配这个工具的所有调用，`工具名(前缀:*)` 匹配以前缀开头的命令或路径。保存后所有对话从下一次工具调用起按新规则走，重启也保留。规则是防误操作的软闸，不是安全沙箱。

### 卡片：它在等你

卡片出现在输入框上方，一次只显示一张，别的排队。

- **批准卡片**：命中「每次问我」、高危命令、不能撤回的操作（强推、发布、全局安装……）、启动工作流、改 AGENTS.md 这类控制文件时出现。按钮：**「拒绝」**（Deny）、**「拒绝并停止」**（Deny and stop）、**「本会话都允许」**（Allow for this session）、**「允许一次」**（Allow once）。**10 分钟没人批就按拒绝处理。**
- **问题卡片**：它问你问题（最多 4 题，可以选「其他…」自己写）。**10 分钟不答（计划档位下是 60 分钟），它就按合理假设继续。**
- **计划卡片**：**「批准并执行」**（Approve and run）；**「退回修改」**（Request changes），可以附上要改什么；也可以选在新会话里实施。**60 分钟没人审，计划保持未批准。**
- 卡片在的时候直接在输入框里打字：批准卡片 = 拒绝并把这段话告诉它；问题卡片 = 当作回答；计划卡片 = 退回并附上意见。
- 任何一台登录着的设备都能处理卡片。
- 怕卡在卡片上：出门前开「离开模式」。
- **通知**：它要你批准、等你回答、一轮做完或出错停下时会通知（正看着这个对话时不打扰）。三类在 **「设置 → dimensio」** 的「通知」里分别开关，总开关在「通用」里（见 07-settings.md）。

## 对话里的东西

- **工作过程**：默认把连续的工具调用折叠成一行（「读取了 3 个文件，执行了 2 条命令」），点开看细节；想全部展开，在 **「设置 → dimensio」** 的「对话」里打开 **「显示全部工作过程」**（Show full work process），只存在这台设备上。之前的轮次会折叠成「处理过程 · n 次工具」。
- 跑了超过 10 秒的命令有 **「转后台」**（Move to background）按钮。**后台命令跑完后它会自己接着干**：这一轮已经结束、命令才跑完（或输出里出现它盯着的那句话，比如「启动成功」）时，会自动开一轮把结果交给它；你在界面上停掉的不算。不想要就关掉「对话」里的「后台任务跑完自动接着做」。
- **生成的文件**：最终回答下面最多 12 张文件卡片，点开在工作区「文件」里预览。它也可以主动把做好的文件弹给你看（提示「agent 想给你看 …」，点打开）。
- **对话内图表**：它可以在对话里直接画图表、流程图和能点的小部件；卡片右上的菜单能复制为图片、下载、查看代码。不想要就关掉「对话」里的「对话内交互图表」，新对话生效。
- **验收提示**：改了代码却没有通过的验证时，它会先自己补跑检查（最多 3 次）；还不行就在回答末尾附上「⚠️ 未验证…」之类的提示（只有中文）。
- **出错卡片**：一句话说明原因（key 无效、余额不足、被限流、上下文太长……），**「原始报错」**（Error details）可以展开原文，最后一次失败上有 **「接着做」**（Continue），还能 **「导出诊断包」**（Export diagnostic report）。限流、上游忙、超时这类会自动重试。
- **从这里改写**：电脑上鼠标悬停（手机上点）你发的某条消息 → **「从这里改写」**（Edit from here）：对话退回到那条消息之前、文字放回输入框。**文件不会跟着退**，8 秒内可以撤销。

## 撤销改动：检查点和审阅

- 顶栏的历史图标 **「回滚到检查点」**（Rewind to checkpoint）：你发的每条消息都是一个检查点，**「回滚到这里」**（Rewind to here）把文件和对话一起退回去；它删文件、丢弃 git 改动之前也会自动拍一个快照，可以只回滚文件。回滚前的状态也会存成检查点，回滚本身也能撤销。
- 只保留最近 30 个对话的检查点，50MB 以上的文件不记录。正在跑的时候不能回滚。
- 工作区的 **「审阅」**（Review）：看这个对话（或整个项目 git）改了哪些文件，可以单独撤销某个文件的改动（之后还能「找回」）。

## 子 agent、工作流、任务

- 它会派子 agent 去调研、写代码；大任务会启动**工作流**（一批子 agent，启动前要你批准）。对话里显示 agent 卡片和工作流卡片。
- **按难度挑模型**：派子 agent 时，dimensio 把此刻能用的模型按性价比排成最难 / 难 / 常规 / 机械四档，难的活用强的模型、机械的活用便宜的。**「设置 → dimensio」** 的「子 agent 调度」里：**「按难度选型阶梯」**（Difficulty-based model ladder）是这套分档的开关，默认开；「子 agent 调度偏好」可以写一段话给它，比如「审查一律用某个模型」，和默认分档冲突时以你写的为准。两项改了对之后新建或重新打开的对话生效。
- 工作区的 **「任务」**（Tasks）：进行中 / 已完成的子 agent、工作流、后台命令；点开子 agent 看它收到的提示词、每一步、改了哪些文件、结果。
- 后台命令每个对话最多 8 个，默认 30 分钟超时。

## 会话协作：子会话、会话之间发消息

- dimensio 可以**自己另开一个会话**去做一件独立的事：新会话出现在侧栏里，缩进挂在开出它的那个对话下面，点开就能直接和它聊；子会话这一轮做完会自动回来汇报，父会话接着往下做。
- 会话之间能**互发消息**；对话里这类消息显示成一张卡片，写着「来自父会话 / 子会话 / 兄弟会话」或「…派来的任务」，卡片上的会话名可以点开那个会话。
- **和 Claude 互相派活**：dimensio 能给 Claude 开会话、发消息，Claude 也能给 dimensio 派任务（两个 agent 都开着时）。dimensio 开出去的 Claude 会话在侧栏里是一行带 Claude 字样的条目，点了在 Claude 页打开。
- 它什么时候会另开会话，看 **「设置 → dimensio」**「会话协作」里的「dimensio 发起新会话」：先问我（默认）、直接开始、只在我要求时。Claude 会话发来的消息要不要收，看同一组的 **「其它会话发来的消息」**（Messages from other sessions）：直接接收（默认）、先存着等你在那个会话里发话时一起带上、拒收。
- 会话之间互相唤醒，连着 6 轮（可改，1–20）都没有你发话，就先停下，攒着的消息等你下次在那个会话里发话时一起送到。

## 拉取请求（只有管理员）

- 工作区 **「审阅」** 面板顶上有一张 **「拉取请求」**（Pull request）卡：让 dimensio 建一个 PR，或点 **「跟踪拉取请求」**（Track pull request）贴一个已有 PR 的链接，卡上就显示它的状态、检查通过 / 失败 / 进行中、有没有合并冲突，能在 GitHub 打开。不想跟了点 **「从会话移出」**（Remove from session）。
- 卡上的 **「自动修复」**（Auto-fix）开关：CI 失败、出现合并冲突或有新评审意见时，自动叫醒这个会话去修。连续自动修了 5 次都没有人发话、或当天次数用完会暂停。所有会话的默认值是 **「设置 → dimensio」**「Git 与拉取请求」里的 **「自动修复拉取请求」**（Auto-fix pull requests），默认关。
- 前提和 Claude 页一样：VM 上装了 gh 并且登录了 GitHub，项目是 GitHub 仓库（见 02-claude-code.md「拉取请求」）。没满足时卡片不出现，或写着「未安装 GitHub CLI（gh）」「请运行 gh auth login 登录」。成员没有这个功能。

## 上下文、压缩、用量

- 右上角的用量环：上下文用了多少（显示的上限是自动压缩的触发点，不是模型的全部窗口）。超过 82% 变色。
- 点开用量环，运行设置下面是 **「上下文」**（Context）一段：**「立即压缩」**（Compact now）、**「带摘要开新会话」**（New session with summary）——都要调一次模型，慢的模型可能要一两分钟。再下面是这个对话按任务分的 token 用量表（没有金额）。新对话还没聊时只有运行设置。
- 长对话隔了一阵子再发消息时，输入框上方可能提示缓存已经凉了，建议压缩或开新会话；不管它也能继续。
- **空闲压缩**：用 Anthropic 官方接口聊得很长的对话，空闲快一小时、提示缓存快过期时，会先自动压缩一次，回来接着聊更省钱。开关和起点（默认上下文 12 万 token 以上才做）在 **「设置 → dimensio」** 的「对话」里。
- **不常用的工具按需加载**：拉取请求、工作区协同这类不常用的工具平时只带一句简介，它第一次要用时再取完整说明，每次请求更省。也在「对话」里，只对新对话生效。

## 记忆

- 打开：**「设置 → dimensio」** → **「记忆管理」**（Manage memory），或项目菜单里的 **「项目记忆」**（Project memory），或工作区的「记忆」标签。
- 两层：全局记忆（关于你和这台电脑的，总共 2000 字以内）和每个项目的记忆。
- 每条有四种状态：待确认、被隔离（过期 / 冲突，暂不使用）、生效（进每个新对话）、已退场。可以确认、编辑、驳回（可以写理由）、删除。全局记忆都要你确认才生效；读过网页 / 搜索结果的对话写的记忆也要你确认。
- **空闲时自动整理**：所有对话都停了 20 分钟以上时，dimensio 会把还没人复核的项目记忆拿回当初写它的那段对话核对一遍——重复的合并、过时的改正、错的退掉。只有在原对话里找到你亲口说过的那句话，才让它直接生效；其余的标上「对照原对话：成立 / 说不清 / 不成立」，留在记忆面板里等你。项目记忆面板里有 **「现在整理」**（Tidy up now）可以马上整理一遍；整理后成立的待确认条目可以点 **「全部确认」**（Confirm all）一次确认掉。同一个项目半天最多自动整理一次，用的是这个项目最近一次对话的模型（会花一点 token）。不想要就关掉「对话」里的「空闲时整理记忆」，关了仍可以手动整理。全局记忆不参加自动整理。
- 它也会读项目里的 `AGENTS.md`、`CLAUDE.md`、`GUIDE.md` 当常驻指令。

## 项目和对话列表

- **项目 = 文件夹**。项目旁边 ＋ **「新建项目」**（New project）→ 文件选择器里**按住文件夹拖到底部那条栏**上。
- 项目菜单（…）：在这个项目里新建对话、**「重命名」**（Rename）、**「置顶项目」**（Pin project）、**「项目记忆」**、**「隐藏项目」**（Hide project）——只是不显示，文件和对话都不删，在列表最底下「已隐藏的项目」里恢复。拖动项目可以排序。
- **对话标题**：第一轮回复后会用便宜模型自动起一个短标题（「对话」里的「AI 起标题」，默认开）；你手动改过的不会被覆盖。
- **对话菜单**：电脑上右键一个对话，手机上左滑后点「更多」→ **「重命名」**（Rename）、**「归档」**（Archive）。归档只是不在列表里显示，在侧栏底部 **「已归档」**（Archived）里能找回、**「取消归档」**（Unarchive）；正在跑、在等你处理或有排队消息的对话归档不了。也可以在 **「设置 → dimensio」** 的「会话管理」里设 **「归档不活跃的会话」**（Archive inactive sessions），默认从不。
- **搜索**：侧栏搜索框 **「搜索项目或对话」**（Search projects and chats），搜项目名和对话标题；输入 2 个字以上还会搜消息正文。
- 删对话：电脑上点垃圾桶再点「删除」（3 秒内），手机上左滑。**删了找不回来**，会停掉它的任务、删掉对话记录、附件和检查点；它在项目里写的文件不删。
- **快照对话**（闪电图标那一条）：不属于任何项目的一次性空间，只保留最新一条；＋ 开一个全新的。它的「…」菜单里有 **「存为工作空间」**（Save as workspace），把它变成普通项目留下来。
- 列表每页 100 个对话，底部可以加载更早的。
- 电脑上宽屏可以把对话拖到对话区左 / 右半边分屏。

## 重启、断网之后

- 服务重启（VM 重启、更新）打断的一轮，会提示「服务重启打断了这一轮」并自动接着做；连续被打断两次后不再自动续，说一句「继续」就行。
- **VM 重启后，要有人打开一次 dimensio 页面，它才会启动并接着做**之前被打断的任务。
- key 不会因为重启丢：都加密存在服务器的磁盘上。排队的消息也在。

## 诊断包

- **「设置 → dimensio」** 最下面的 **「诊断」**（Diagnostics）→ **「导出诊断包」**（Export diagnostic report）：列出最近的几个对话，点一个导出。里面是这一轮的事件记录、服务输出、体检结果与版本信息，不含对话正文和任何 key，可以发给开发者排查（报告问题见 `../MUSE.md` 第 8 节）。出错卡片上也有同一个按钮。

## 调试模式（只有管理员）

- **「设置 → dimensio」** 的「调试」里有 **「调试模式」**（Debug mode），默认关。打开后 dimensio 会把「找 dimensio 自己的毛病」放在第一位：工具报错先查是不是工具的问题，遇到多余的设计、缺的功能、不得不绕的路都当场记一份问题说明，存在服务器上的 harness-feedback 文件夹里，回答末尾会说这一轮记了几条；这时用户交代的任务排第二。
- 这是给开发者改进 dimensio 用的，**平时不用开**。这些记录只留在服务器上，不会自动发给任何人。

## 多人使用时（注册账号）

- 新账号默认没有 dimensio，管理员在控制台按人打开（06-users-admin.md）。
- 每人一个独立的 dimensio，访问范围锁死在自己的文件夹（「仅工作空间」，不能改），没有「全权」档。同时最多 4 个人在用，20 分钟没动静会自动停掉（再用时自动启动）。
- **成员没有模型中心**。能用哪些模型：
  - 管理员在模型中心里打开了「共享给成员」的服务——用的是管理员的 key；
  - 内置那几家里，升级前就让 Muse 用 set-api-key 写在服务器上的 key，成员照旧能用（也是管理员的 key）；
  - 自己在 **「设置 → dimensio」** 的 **「API Key」** 里给某家填了 key 的，这一家就用他自己的；
  - 他自己在模型服务面板里加的自定义服务（见上面「成员自己加自定义服务」）。
- 没有命令行权限的账号没有终端。拉取请求、调试模式只有管理员有。
- 人太多时会提示「同时在用 dimensio 的人太多了（上限 4），请稍后再试」。

## 常见提示

| 看到的 | 意思 / 怎么办 |
|---|---|
| 一直停在「等待模型回复」 | 多半是 Muse 里有一张这家接口网站的审核卡没批：让用户去批（选项见 `../MUSE.md` 2.0），或者用户在场时让 Muse 跑 `allow-sites`。见 08-faq.md |
| 新对话页提示「先在模型中心添加 … 的服务」 | 这家还没有 key：管理员在模型中心里添加这家的服务（先让 Muse 放行它的接口网站，见「配 key」） |
| 消息被退回输入框，带 `No API key for provider` | 同上；成员则是在 **「设置 → dimensio」** 的 API Key 里填，或请管理员共享 |
| 「模型服务」面板里找不到某一家 | 管理员的面板只列模型中心里已经加好的；去模型中心加这家的服务、把模型勾给 dimensio |
| API key 无效、过期或没有这个模型的权限 | key 填错了或没开通这个型号：到模型中心里这家的服务上换 key（「API Key」一栏的「更换」），或换型号 |
| 账户欠费或额度用完 | 去厂商控制台充值，或换一家；重试没用 |
| 被限流 / 上游繁忙 / 超时，n 秒后重试 | 会自动重试，等着就行 |
| 等待网络恢复（已等 …） | 服务器连不上这家接口，最多等 30 分钟；多半也是审核卡没批 |
| 上下文超出了模型窗口 | 会自动压缩一次；还不够就「带摘要开新会话」 |
| 「dimensio 的设置暂时读不到」（设置页里）/「连不上服务器，历史会话暂时看不到」（侧栏） | dimensio 没启用或没装、或者正在重启；管理员在 **「设置 → dimensio」** 页头看开关，没装的话让 Muse 跑 `set-agents claude,dimensio` |
| 服务正在重启（部署中），这一条没有发出 | 等一会儿再发 |
| 最多同时运行 3 个对话 | 等一个跑完 |

## 没有的功能（别答应用户）

浏览器 / 截图 / 打开网页、连接你自己的浏览器、本机模型、显示花了多少钱——这些在 Muse Bridge 的 dimensio 里都没有。操作电脑桌面只有一种情况可以：用户用 bridge 的 Windows 桌面客户端连上这台服务器（要绑自己的域名），把电脑登记成设备后，右上角用量环点开的面板里会多出 **「运行环境」**（Environment）一段，在 **「电脑」**（Computer）那一行选上那台电脑才行（见 07-settings.md「设备」）。
