# 多人使用与服务端控制台

## 只自己用 vs 多人用

- **只自己用**（`set-users solo`）：只有管理员令牌（和「服务账号」）能登录，没有注册和邀请码。
- **多人用**（`set-users multi`，默认）：可以给朋友开账号、发邀请码，每人有自己的文件夹和用量额度。
- 切换让 Muse 跑对应的命令（`../MUSE.md` 第 6 节）。
- 控制台「用户」页最上面有一张 **「给别人用」**（Sharing）卡：开关项 **「开放给其他人使用（多用户）」**（Let other people use this server (multi-user)）在这台 Muse 上是**只读**的，只显示一个 **「多用户」**（Multi-user）或 **「单人」**（Single-user）标记，下面写着「由 Muse 管理：在 Muse 里说『把 bridge 改成多人用』或『改成只自己用』」。要改单人 / 多人，跟 Muse 说一句，由 Muse 跑 `set-users`。
- 同一张卡上还写着当前的隔离等级：Muse 的 VM 上所有成员和服务跑在同一个系统账户下，彼此之间只有逻辑隔离。

## 三种身份

| | 管理员 | 完全信任账号 | 普通账号 |
|---|---|---|---|
| 怎么登录 | 管理员令牌（或扫码） | 账号密码 | 账号密码 |
| 能动的文件 | 整台服务器 | 自己的文件夹 | 自己的文件夹 |
| 命令行（终端、让 Claude 跑命令） | 有 | 有 | 没有 |
| 用量额度 | 不限 | 受管理员设的额度限制 | 同左 |
| 能用哪些 agent | 全部已开启的 | 管理员给他勾的（新账号默认只有 Claude） | 同左 |
| 技能 / 连接器 / 插件 | 生效 | 管理员装在「全服统一」里的生效；另外能添加自己的技能（只有技能，05-customize.md「成员自己的技能」） | 同左 |
| 自定义模型（Claude 自定义 API、dimensio 自定义服务） | 自己加，能连任意地址 | 能加自己的（只能连公网地址，不占本站额度）；还能用管理员「共享给成员」的（用管理员的 Key、计入额度，看不到地址和 Key） | 同左 |
| 服务端控制台、「额度与注册」、订阅号池、agent 开关、扩展里的连接器 / 插件 / 功能扩展 | 有 | 没有 | 没有 |

- 界面上的叫法：设置 › 账户里显示 **「管理员」**（Admin）、**「完全信任用户」**（Full trust user）或 **「普通用户」**（Standard user）；控制台里档位叫 **「完全信任」**（Full trust）和 **「普通」**（Standard）。
- **完全信任账号等同管理员**：有命令行和终端，跑在服务端同一个系统账户下，能读到服务器上所有人的对话、文件和全部凭据（Claude 订阅令牌、各家 API key）。**只给完全信任的人**，邀请默认发普通档。
- **隐私**：管理员**默认只能看到成员的会话标题、时间和用量**。看对话正文（含定时任务的提示词和结果）、代他发消息、替他回答提问和审批、看他登记的电脑，都要**成员自己**在 **「设置 → 账户 → 管理员可见性」**（Settings → Account → Admin visibility）里打开对应的开关；管理员每次查看或代操作，成员那边的 **「管理员的访问记录」**（Admin access history）里都有一条，还会弹提示。服务账号默认全部允许。技术上服主仍能读到服务器上的文件，这里约束的是控制台的默认行为。给朋友开账号前可以先告诉他。
- 所有人用的是**同一份 Claude 订阅**的额度。

## 打开服务端控制台

- **「设置 → 服务端控制台」**（Settings → Admin console）：在设置根页的 **「服务器」**（Server）分组里，只有管理员看得到。手机、电脑上都能打开。
- 左边（窄屏是顶部）是各个页面：**「总览」**（Overview）、**「活跃进程」**（Active processes）、**「用户」**（Users）、**「额度与注册」**（Quotas & sign-ups）、**「会话 / 续聊」**（Sessions）、**「定时任务」**（Routines）、**「媒体」**（Media）、**「Claude 账号」**（Claude accounts）、**「设备」**、**「服务控制」**（Service）。
- 只自己用时，「用户」页叫 **「服务账号」**（Service accounts），没有「额度与注册」。
- 「媒体」页列的是生成的图片 / 视频这类媒体；这台 Muse 不带媒体生成，一般是空的。

## 给朋友开账号

两种方式：

1. **发邀请码**（朋友自己注册）：**「用户」** 页点 **「＋ 普通邀请码」**（＋ Standard invite）或 **「＋ 完全信任邀请码」**（＋ Full trust invite）→ 复制邀请码发给朋友。朋友打开同一个地址，在登录页点 **「注册新账号」**，填上邀请码（见 01-access.md）。
   - 一般朋友发普通的就行。点完全信任那个会先弹确认框 **「发完全信任邀请码？」**，要点 **「我了解，给完全信任」**（I understand, grant Full trust）才会生成。
   - 邀请码**一次性**，**7 天内有效**，没用的可以在邀请码那一行点 **「作废」**（Revoke）；关掉注册开关后，没用过的邀请码也都会失效。
   - 改名「完全信任」之前开的老账号和不过期的老邀请码，会单独列在 **「待确认的完全信任账号」**（Full trust accounts to review）这类卡片里：可以 **「全部确认」**（Confirm all）保留、**「全部作废」**（Revoke all），或在账号的「管理」里降为普通。
2. **直接建账号**：**「用户」** 页 **「＋ 新建账号」**（＋ New account）→ 填用户名、密码（至少 8 位），选 **「普通（无命令行）」**（Standard (no shell)）或 **「完全信任（有命令行）」**（Full trust (shell access)）→ **「建账号」**（Create account），再把账号密码告诉朋友。表单里还有一个「服务账号」选项（给程序用的账号），一般用不到。

## 管理某个账号

「用户」页每个账号右边点 **「管理」**（Manage）：

- **「升为完全信任（给命令行）」**（Upgrade to Full trust (shell access)）/ **「降为普通（收回命令行）」**（Downgrade to Standard (no shell)）。降级会马上中止他在跑的对话、关掉他的终端，账号、对话和文件都保留。
- **「改登录名」**（Change username…）：给他改用户名（账号 id 不变，文件夹和对话不受影响）。
- **「改密码」**（Reset password…）：给他设新密码，**他所有设备都会被踢下线**。用户忘了密码就这样处理。
- **「停用账号」**（Disable account）/ **「启用账号」**（Enable account）：停用后他立刻被登出、在跑的对话中止，再登录提示「账号已被禁用，请联系管理员」；数据都保留。
- **「删除」**（Delete）：弹出确认框，他会立刻被登出、在跑的对话中止，两种处理数据的方式：默认 **「连对话、文件、媒体一起删（不可恢复）」**（Also delete their chats, files, and media (can’t be undone)）；或选「数据归档」，按钮变成 **「删除并归档」**（Delete and archive）——整个目录挪进用户根下的 `_archive` 文件夹，只有管理员能找回。删掉的账号 id 不再复用，同名的人重新注册拿不到旧人的任何东西。
- **「能用的 agent」**（Available agents）：给他勾上 Claude、dimensio。**新账号默认只有 Claude，要用 dimensio 得在这里勾上**。
- **「他允许管理员做什么」**（What they allow the admin to do）：只读地显示他在自己设置里允许了哪几项（看对话内容 / 代聊与代答 / 看他的电脑）。
- 额度：**「调整额度」**（Edit quota）单独给他设每天 / 7 天的轮数和花费上限；空着 = 跟默认，填 0 = 对他不限。

## 额度与注册

控制台的 **「额度与注册」**（Quotas & sign-ups）页（多人用模式才有）。注册开关和默认额度在「服务器」分组的 **「设置 → 额度与注册」**（Settings → Quotas & sign-ups）里也能改，手机上更方便。

- **「凭邀请码注册」**（Invite-code sign-ups）开关，默认开。关掉后只有管理员能直接建账号。
- **「注册用户的默认额度」**（Default quotas for registered users）：每天最多几轮、最近 7 天最多几轮、每天 / 7 天最多花多少（美元），全服同时最多几轮；控制台里还有每人同时最多几轮、每人最多几条启用中的定时任务。留空或 0 = 不限。花费按 API 价估算，不是真花出去的钱（大家用的是订阅）。
- 「每天」按哪个时区换日（Time zone for daily resets），默认北京时间。
- **「成员能用的高消耗功能」**（High-cost features for members），只在控制台里：**「快速模式（fast）」**（Fast mode）、Ultracode、**「1M 上下文」**（1M context）几个开关。只管注册账号，管理员自己不受限；关掉的功能成员那边按钮还在，但发出去会按关着的处理（比如 Ultracode 降成 Extra）。页面上图片 / 视频这类媒体的额度在这台 Muse 上用不到。
- **「改用推荐值」**（Use recommended）：一键把默认额度、并发、定时任务数和这几个开关都换成给别人用的稳妥值；单独给某个人设过的额度不受影响。
- 额度**只算 Claude**（大家共用 Claude 订阅），dimensio 不计；管理员不受限。
- 用户超额时，他的对话里会提示「今天的额度用完了」之类，并说明什么时候恢复、可以联系管理员。
- 每个账号（包括管理员）同时跑的 Claude 对话有上限，这台 Muse 设的是 3 个。

## 其他页面

- **「总览」**：在跑的 agent、账号数、订阅用量（5 小时 / 7 天窗口，整台服务器共用一个读数）。
- **「活跃进程」**：所有正在跑的 Claude 对话，每个都能 **「中止」**（Stop）。
- **「会话 / 续聊」**（Sessions）：选一个用户、一个对话。**成员没有授权时只列标题和时间**，要成员先在 **「设置 → 账户 → 管理员可见性」** 里允许查看对话内容，才能看到消息；代他继续发消息要再允许「代聊与代答」，发出的消息算他的额度，开头标着「【管理员代发】」。
- **「定时任务」**：所有人的定时任务一览（只读，改要到各自的「定时触发」页）。
- **「设备」**：用 bridge 桌面客户端登记进来的电脑（见 07-settings.md「设备」），可以改名、断开、吊销。没人接过桌面客户端时是空的。
- 「用户」页底下还有一块 **「管理员登录」**：每台用管理员令牌或扫码登录过的设备，可以 **「吊销」**（Revoke）或 **「吊销其它设备」**。手机丢了就在这里把它踢掉；重新生成访问令牌（`reset-token`）会让这里全部作废。

## Claude 账号（订阅号池）

服务器上配的 Claude 订阅令牌。两个地方都能管，内容一样：控制台的 **「Claude 账号」**（Claude accounts）页，和 **「设置 → Claude」** 页上的 **「订阅号池」**（Subscription Pool）（只有管理员看得到，手机上改起来更方便）。

- **「添加账号」**（Add Account），控制台里叫 **「＋ 添加账号」**（＋ Add account）：名称随便起，令牌是用户在**自己电脑上**跑 `claude setup-token` 得到的 `sk-ant-oat…`（不能在 VM 上生成，见 `../MUSE.md` 4.4）。
- 可以加几个（比如主号、备用号），**「切到此号」**（Switch to this account）切换：从下一条回复起对所有人生效，对话不受影响。每个号显示自己的 5 小时 / 每周用量，点 **「刷新用量」**（Refresh usage）重读。
- **「编辑账号」**（Edit account）可以换某个账号的令牌（留空表示不改）。令牌过期、Claude 报「登录已失效」时就在这里换。
- **「额度用尽自动换号」**（Switch accounts when a limit is reached）：号池里有两个以上账号时，当前号用满就自动换到还有余量的号；打开后还能选 **「额度恢复后回到首选号」**、**「会话中无缝换号」**。

## 服务控制

**「服务控制」**（Service）页：

- **「运行状态」**（Status）：在跑的对话、内存、负载、数据盘剩余、dimensio 实例数，以及部署形态和监听地址：Muse 上是服务端形态，只监听本机端口，经 Cloudflare 隧道对外。
- **「重启服务」**（Restart service）：**「空闲时重启」**（Restart when idle）——等没人在跑对话时重启，最多等 30 分钟；或 **「立即重启」**（Restart now）——会打断正在跑的对话，记录不丢。
- **「最近日志」**（Recent logs）：最近几百行服务日志（重启后清空），完整日志让 Muse 用 `journalctl -u bridge` 看。
- 「更新」那一行没有按钮，只写着「这台是 Muse 部署：在 Muse 里说「更新 bridge」…」：在 Muse 上更新跟 Muse 说「更新」就行（`../MUSE.md` 第 6 节）。

## 开关 agent

- 设置根页的 **「Agent」**（Agents）分组里每个 agent 一行，点进去最上面是「启用 Claude」/「启用 dimensio」开关，只有管理员能改。关掉的 agent 所有人都看不到它的页面；只剩一个开着时，打开网址直接就是那一页。
- 行尾和页头写着状态；还没配认证时有提示——Claude 是「在下面『订阅号池』里添加账号」（或让 Muse 按 `../MUSE.md` 4.4 配），dimensio 是一家模型厂商的 key 都没配（让 Muse 跑 `set-api-key`）。
- 没装 dimensio 想加上：让 Muse 跑 `set-agents claude,dimensio`（要重新装依赖，几分钟）。别在 **「设置 → 扩展 → 功能扩展」**（Settings → Extensions → Modules）里装卸 dimensio，那会和 Muse 的部署对不上。

## dimensio 在多人模式下

- 每个注册账号有自己独立的 dimensio，访问范围锁在自己的文件夹。内置厂商默认用管理员配的 key；成员也可以在自己的 dimensio 设置里填自己的 key。**自定义服务和成员自己填的 key 每人各存各的**，互相看不到。
- 同时最多 4 个人在用，20 分钟不用自动停（再打开会自动启动）。

## Agent 接入（密钥）

每个登录的人都能在 **「设置 → Agent 接入」**（Settings → Agent access）给自己生成 agent 密钥，密钥只带生成者本人的权限、90 天过期。成员改密码、管理员重置访问令牌，名下的密钥全部失效。细节见 07-settings.md。
