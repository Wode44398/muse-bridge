# 多人使用与服务端控制台

## 只自己用 vs 多人用

- **只自己用**（`set-users solo`）：只有管理员令牌（和「服务账号」）能登录，没有注册和邀请码。
- **多人用**（`set-users multi`，默认）：可以给朋友开账号、发邀请码，每人有自己的文件夹和用量额度。
- 切换让 Muse 跑对应的命令（`../MUSE.md` 第 6 节）。

## 三种身份

| | 管理员 | Pro 账号 | 普通账号 |
|---|---|---|---|
| 怎么登录 | 管理员令牌（或扫码） | 账号密码 | 账号密码 |
| 能动的文件 | 整台服务器 | 自己的文件夹 | 自己的文件夹 |
| 命令行（终端、让 Claude 跑命令） | 有 | 有 | 没有 |
| 用量额度 | 不限 | 受管理员设的额度限制 | 同左 |
| 能用哪些 agent | 全部已开启的 | 管理员给他勾的（新账号默认只有 Claude） | 同左 |
| 技能 / 连接器 / 插件 | 生效 | 不生效 | 不生效 |
| 服务端控制台、自定义页、设置里的 Agent | 有 | 没有 | 没有 |

- **Pro 账号的隔离是「软」的**：路径和命令检查防的是手滑，挡不住故意绕过；有命令行的人有可能读到服务器上共享的订阅凭据。**Pro 只给完全信任的人**，邀请默认发普通档。
- **隐私**：管理员能在控制台里看任何人的 Claude 对话，还能代他继续对话。给朋友开账号前可以先告诉他。
- 所有人用的是**同一份 Claude 订阅**的额度。

## 打开服务端控制台

- **「设置 → 连接 → 服务端控制台」**（Settings → Connection → Admin console）→ **「打开」**（Open）。只有管理员看得到。
- 左边（窄屏是顶部）是各个页面：**「总览」**（Overview）、**「活跃进程」**（Active processes）、**「用户」**（Users）、**「额度与注册」**（Quotas & sign-ups）、**「会话 / 续聊」**（Sessions）、**「定时任务」**（Routines）、**「Claude 账号」**（Claude accounts）、**「服务控制」**（Service）。
- 只自己用时，「用户」页叫 **「服务账号」**（Service accounts），没有「额度与注册」。

## 给朋友开账号

两种方式：

1. **发邀请码**（朋友自己注册）：**「用户」** 页点 **「＋ 普通邀请码」**（＋ Standard invite）或 **「＋ Pro 邀请码」**（＋ Pro invite）→ 复制邀请码发给朋友。朋友打开同一个地址，点 **「注册新账号」**，填上邀请码（见 01-access.md）。
   - 三个按钮里蓝色高亮的是 Pro 那个，别点错：一般朋友发普通的就行，Pro 带命令行，只给完全信任的人。
   - 邀请码**一次性、不过期**，单个邀请码没法撤销；关掉注册开关后，没用过的邀请码都会失效。
2. **直接建账号**：**「用户」** 页 **「＋ 新建账号」**（＋ New account）→ 填用户名、密码（至少 8 位），选普通或 Pro → **「建账号」**（Create account），再把账号密码告诉朋友。

## 管理某个账号

「用户」页每个账号右边点 **「管理」**（Manage）：

- 升为 Pro / 降为普通（给 / 收回命令行）。
- **「改密码」**（Reset password…）：给他设新密码，**他所有设备都会被踢下线**。用户忘了密码就这样处理。
- 停用 / 启用账号：停用后立刻登不上（提示「账号已被禁用，请联系管理员」）。
- **「删除」**（Delete）：默认只删账号，文件夹留在磁盘上；勾上「连磁盘文件夹一起删」才彻底删。
- **「能用的 agent」**（Available agents）：给他勾上 Claude、dimensio。**新账号默认只有 Claude，要用 dimensio 得在这里勾上**。
- 额度：**「调整额度」**（Edit quota）单独给他设每天 / 7 天的轮数和花费上限；空着 = 跟默认，填 0 = 对他不限。

## 额度与注册

**「额度与注册」**（Quotas & sign-ups）页（多人用模式才有）：

- **「凭邀请码注册」**（Invite-code sign-ups）开关，默认开。关掉后只有管理员能直接建账号。
- 注册账号的**默认额度**：每天最多几轮、最近 7 天最多几轮、每天 / 7 天最多花多少（美元），还有全服同时最多跑几轮。留空或 0 = 不限（默认都不限）。
- 「每天」按哪个时区换日（默认北京时间）。
- 额度**只算 Claude**（大家共用 Claude 订阅），dimensio 不计；管理员不受限。
- 用户超额时，他的对话里会提示「今天的额度用完了」之类，并说明什么时候恢复、可以联系管理员。
- 每个账号（包括管理员）最多同时跑 3 个 Claude 对话。

## 其他页面

- **「总览」**：在跑的 agent、账号数、订阅用量（5 小时 / 7 天窗口，整台服务器共用一个读数）。
- **「活跃进程」**：所有正在跑的 Claude 对话，每个都能 **「中止」**（Stop）。
- **「会话 / 续聊」**（Sessions）：选一个用户、一个对话，看最近的消息，还能以他的身份继续发消息（算他的额度）。
- **「定时任务」**：所有人的定时任务一览（只读，改要到各自的「定时触发」页）。
- 「用户」页里还有一块 **「管理员登录」**（Admin sign-in）：每台用管理员令牌登录过的设备，可以 **「吊销」**（Revoke）或 **「吊销其它设备」**（Sign out other devices）。手机丢了就在这里把它踢掉。

## Claude 账号

**「Claude 账号」**（Claude accounts）页：服务器上配的 Claude 订阅令牌。

- **「＋ 添加账号」**（＋ Add account）：名称随便起，令牌是用户在**自己电脑上**跑 `claude setup-token` 得到的 `sk-ant-oat…`（不能在 VM 上生成，见 `../MUSE.md` 4.4）。
- 可以加几个（比如主号、备用号），**「切到此号」**（Switch to this account）切换：从下一条回复起对所有人生效，对话不受影响。
- **「编辑」**（Edit）可以换某个账号的令牌（留空表示不改）。令牌过期、Claude 报「登录已失效」时就在这里换。
- 用量读数是整台服务器共用的一个，不分账号显示。

## 服务控制

**「服务控制」**（Service）页：

- 运行状态：运行时长、在跑的对话、内存、负载、磁盘剩余、dimensio 实例数。
- **「重启服务」**（Restart service）：**「空闲时重启」**（Restart when idle）——等没人在跑对话时重启，最多等 30 分钟，等不到就放弃；或 **「立即重启」**（Restart now）——会打断正在跑的对话，记录不丢。
- **「最近日志」**（Recent logs）：最近几百行服务日志（重启后清空），完整日志让 Muse 用 `journalctl -u bridge` 看。
- 这里没有「更新」按钮：在 Muse 上更新跟 Muse 说「更新」就行（`../MUSE.md` 第 6 节）。

## 开关 agent（设置 → Agent）

- **「设置 → Agent」**（Settings → Agents），只有管理员有：每个 agent 一个 **「启用」** 开关。关掉的 agent 所有人都看不到它的页面。
- 状态说明：**「可用」**（Available）；**「还没配认证」**（Not signed in yet）——Claude 没配令牌（有 **「去配置」**（Set up）按钮直达 Claude 账号页）、dimensio 没配任何 key；这台机器上没装（只装了另一个 agent 时）。
- 没装 dimensio 想加上：让 Muse 跑 `set-agents claude,dimensio`（要重新装依赖，几分钟）。

## dimensio 在多人模式下

- 每个注册账号有自己独立的 dimensio，访问范围锁在自己的文件夹，用的是管理员配的 key，不能加自定义服务。
- 同时最多 4 个人在用，20 分钟不用自动停（再打开会自动启动）。
