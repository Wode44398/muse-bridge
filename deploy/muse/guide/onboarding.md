# 入门讲解（写给 Muse）

用户装好、拿到地址和令牌之后，问他要不要你带他上手。这一章是几档讲解的「剧本」：每一步说清楚点哪里、他会看到什么，等他确认了再往下。

## 怎么问

装好交付完（`../MUSE.md` 第 3 节），用一条消息问。没装的 agent 相关的档不要提。例：

> 要不要我带你熟悉一下？可以选：
> 1. **5 分钟快速上手**（推荐第一次用）：登录、发第一句话、认识界面
> 2. **Claude Code 深入**：项目、附件、终端和文件、定时任务……
> 3. **dimensio 深入**：换模型、加别家服务、权限和计划模式、记忆……
> 4. **管理员与多人使用**：给朋友开账号、控制台
> 5. **手机上用**：安卓 app、iPhone、手机扫码帮电脑登录
>
> 不用也行，以后随时问我「这个怎么用」。

其他适合问一句的时机：用户说「我是新手」「不知道从哪开始」；他明显是第一次用某个功能；更新带来了他用得上的新功能（见最后一节）。他说不用就别再追问。

## 带的时候注意

- **一步只说一件事**，说完等他回「好了 / 看到了」再说下一步。他卡住了，先问他看到了什么，再对照这份说明书找原因。
- **用他界面上的名字**：他的界面是中文就说中文名，是英文就说英文名（说明书里两种都写了）。不确定就问他看到的是中文还是英文。
- 你看不到他的屏幕，别说「你应该已经看到了…」，要说「你会看到…，看到了吗？」。
- 手机和电脑操作不一样（手机：回车是换行，要点发送按钮；侧栏要点左上角菜单拉出来）。先问他用的是手机还是电脑。
- 碰到要你跑命令的步骤（配令牌、配 key、放行网站），先说清楚会弹什么、让他怎么选，再跑。
- 每一档讲完，问他还有没有想了解的，提醒他有问题随时问你。

## 第 1 档：5 分钟快速上手

1. **打开并登录**：让他用浏览器打开公网地址（手机电脑都行）→ 点 **「登录」**（Sign in）→ **「用访问令牌登录」**（Sign in with access token）→ 粘贴令牌。只装了一个 agent 时，登录框是自动弹出来的。
   - 看到的：两个 agent 都装了 → 主页上有 Claude 和 dimensio 两个方块；只装一个 → 直接是那个 agent 的页面。
   - 提醒：令牌就是管理员密码，存进密码管理器；临时地址变了要用同一个令牌重新登录。
2. **配好认证**（还没配的话）：Claude 按 `../MUSE.md` 4.4（令牌在他自己电脑上生成）；dimensio 按 4.5（你跑 `set-api-key`，提醒他批审核卡）。
3. **发第一句话**：
   - Claude：点 Claude 方块（或已经在 Claude 页）→ 在输入框里输入「你好，介绍一下你能做什么」→ 电脑按回车、手机点发送。几秒内开始回复就说明通了。
   - dimensio：点 dimensio 方块 → 同样发一句。右下角的模型胶囊显示用的是哪家哪个型号。
   - 一直转圈：多半是审核卡没批，见 08-faq.md。
4. **认识界面**（以 Claude 页为例）：
   - 左边侧栏是项目和历史对话（手机上点左上角 **「菜单」**（Menu）拉出来）。**点一个项目就在那个文件夹里开新对话**；最上面的「快照对话」是随手问问用的临时对话。
   - 输入框里右下角、发送按钮左边两个芯片：模型、思考深度；左下角的 ＋ 加附件。
   - 右上角是工作台：终端、审阅、文件、任务（手机上是右上角的 **「工作台」**（Workbench）按钮）。
5. **让它干点实事**：建议他试一句「在这个文件夹里写一个 hello.html，做一个会动的问候页」，做完点回答里的文件卡片预览。顺便告诉他文件都在 **「工作空间」**（Workspace）里，入口在账户卡菜单。
6. **知道去哪找设置和求助**：账户卡 → **「设置」**（Settings）；遇到问题可以 **「设置 → 反馈 → 报告」**（Settings → Feedback → Report），或者直接问你。
7. 最后提一句：安卓手机可以装 app（第 5 档），有更多想了解的可以选其他档。

## 第 2 档：Claude Code 深入

按他的兴趣挑着讲，不用全讲。细节都在 02-claude-code.md。

1. **项目**：**「新建项目」**（New project）→ 按住一个文件夹拖到底部栏上（或先新建一个文件夹）。之后在这个项目里开的对话，Claude 都在这个文件夹里干活。
2. **附件**：输入框左下角的 ＋ **「附件与功能」**（Add files and more）加文件 / 图片，或直接拖进来；单个 20MB。整个文件夹用 **「挂载文件夹」**（Attach folder）。
3. **模型和深度**：输入框右下角、发送按钮左边的第一个芯片换模型（默认 Opus 5.5），第二个调思考深度；Ultracode 最强也最费额度。
4. **它干活时**：可以关掉浏览器，回来再看；要停就点 **「停止生成」**（Stop response）。它在干活时这个对话里不能再发消息。
5. **工作台**：
   - **「终端」**（Terminal）：跟 Claude 共用的终端，它敲的命令你都看得到（管理员和 Pro 账号才有）；
   - **「审阅」**（Review）：git 项目里它改了什么；
   - **「文件」**（Files）：当前项目的文件；
   - **「任务」**（Tasks）：子 agent、后台任务的进度。
6. **改坏了怎么办**：你发的消息下面 ↺ **「回滚到这条消息之前」**（Rewind to before this message）→ **「文件+对话」**（Code and conversation）。
7. **结果文件**：回答里的文件卡片点开预览、点 Download 下载；文件夹会打成 zip。
8. 进阶（他有兴趣再讲）：
   - git 项目新对话里勾 worktree，在隔离副本里改；
   - 把侧栏的对话拖到输入框上引用它；
   - **「定时触发」**（Routines）让它每天定时干活——**提醒时间按服务器时区（一般是 UTC）**；
   - 输入框左下角 ＋ 旁边的用量圆环看额度。

## 第 3 档：dimensio 深入

细节在 03-dimensio.md。

1. **选模型**：右下角模型胶囊 → 选型号和思考深度。换厂商：菜单最下面 **「切换模型服务…」**（Switch provider…），换厂商会开新对话。
2. **加一家**：问他想用哪家，你用 `set-api-key` 配（提醒批审核卡）。**别让他在网页设置里填内置厂商的 key**——重启就没了。
3. **自定义服务**（有中转站 / OpenRouter / 自建模型时）：你先跑 `allow-sites <接口地址>` 让他批卡，再让他在模型服务面板里点 **「添加自定义服务」**（Add custom provider）。
4. **插话**：它干活时可以直接发消息纠偏，它下一步就会读到。停止在对话末尾的状态行上。
5. **档位**：左下角档位胶囊 → 试一下 **「先出计划」**（Plan first）：让它先交计划，他点 **「批准并执行」**（Approve and run）才开始干。**「只读」**（Read-only）适合只想让它看、不让它改的时候。
6. **权限规则**：**「设置 → dimensio → 权限规则」** 里加一条 `Bash(git push:*)` 到 **「每次问我」**（Always ask），以后推代码前会弹卡片问他。卡片 10 分钟没人批就算拒绝；出门前开 **「离开模式」**（Away mode）。
7. **撤销**：顶栏 **「回滚到检查点」**（Rewind to checkpoint）能把文件和对话一起退回去。
8. **记忆**：**「设置 → dimensio → 记忆管理」** 看它记住了什么，可以确认、驳回、删除。

## 第 4 档：管理员与多人使用

细节在 06-users-admin.md。

1. 打开控制台：**「设置 → 连接 → 服务端控制台」**（Settings → Connection → Admin console）→ **「打开」**。
2. 还是「只自己用」模式的话，先问他要不要改成多人用，要就跑 `set-users multi`。
3. **给朋友开账号**：**「用户」** 页 **「＋ 普通邀请码」**（＋ Standard invite）→ 复制发给朋友，朋友在登录框点 **「注册新账号」**（Create account）填上。提醒：Pro 邀请码给的账号有命令行，只给完全信任的人。
4. **让朋友用 dimensio**：「用户」页他那一行 **「管理」**（Manage）→ **「能用的 agent」** 勾上 dimensio（新账号默认只有 Claude）。
5. **额度**：**「额度与注册」**（Quotas & sign-ups）设默认的每天轮数 / 花费上限（大家共用一份 Claude 订阅）。
6. **Claude 账号**：**「Claude 账号」**（Claude accounts）页加备用号、令牌过期时在这里换。
7. **服务控制**：**「服务控制」**（Service）页看运行状态、重启服务、看最近日志。
8. 提醒隐私：管理员能看到朋友们的 Claude 对话。

## 第 5 档：手机上用

细节在 01-access.md。

1. **安卓**：手机浏览器打开地址 → **「设置 → 安卓 app」**（Settings → Android app）→ **「下载 apk」** → 安装（允许浏览器安装未知应用）→ 回到这一页点 **「在 app 里打开」**（Open in app）→ 用令牌登录。
2. **iPhone**：Safari 打开地址 → 分享 → 添加到主屏幕。
3. **地址变了**：app 会弹「连不上服务器」，点「更换地址」粘新地址（你会告诉他新地址）。
4. **用手机帮电脑登录**：电脑登录框点 **「扫码登录」**（Sign in with QR code）；手机上账户卡菜单 **「扫一扫登录网页版」**（Scan to sign in on the web）→ 扫 → **「确认登录」**。
5. 手机上的习惯：回车是换行，点按钮发送；左边缘右滑回主页；返回键一层层关。

## 更新后：演示新功能

两种时机：你替用户跑完 `update`、当场切换成功（`update` 开头会打印「更新内容」；老版本不打印的话，用提议更新时 update_available 给你的 notes），或者看门狗的 update_done 事件（等空闲切换、自动更新，事件里带 notes）。告诉用户更新好了之后：

1. 从 notes 里挑出**用户用得上**的新功能（修 bug、内部改动不用演示）。
2. 在这份说明书里找到对应章节（新版本的说明书已经换好了）。没找到就别演示，只用一句话讲讲。
3. 问一句：「这版新增了 X，要不要我带你试一下？」他说好，就按章节里的步骤一步步带；说不用就算了。
4. 他之前报告过、这版修好了的问题（update_available 事件里的 your_reports_fixed），也顺带告诉他。
